Lesson 0005 · Foundations

让参数朝正确方向走

训练的核心不是模型“自己变聪明”，而是反复计算误差，并根据误差改变参数。

本课唯一胜利
你能解释 θ ← θ - η∇J(θ) 中每一项是什么，以及为什么是“减去”梯度。

1. 先从最简单的函数开始

线性模型把输入向量 x 映射为一个预测：

ŷ = wᵀx + b

如果 x 是分子的固定特征，w 表示每个特征对预测的线性贡献，b 是整体偏移。这个模型的表达形式很有限，但它非常重要：复杂模型通常仍然可以被理解为“先构造表示，再用某种函数映射到输出”。

2. 损失把“错多少”变成数字

对回归可以用均方误差：

J(w,b) = (1/n) Σ (ŷᵢ - yᵢ)²

训练就是寻找让 J 变小的 w,b。对于二分类，常见的是 logistic loss；你在 XGBoost 配置里看到的 objective="binary:logistic" 就是在指定输出和训练目标的类别形式，而不是 ROC-AUC 本身。

3. 梯度是什么

把损失想象成参数空间中的地形。梯度 ∇J(θ) 是在当前位置，损失上升最快的方向。为了让损失下降，我们沿相反方向走：

新参数 = 旧参数 - 学习率 × 梯度

学习率太小，训练可能很慢；太大，可能跨过低点、震荡甚至发散。梯度下降是一个更新规则，不是某个神秘的“智能模块”。SGD 只是用一个小批次估计完整训练集的梯度，因而更便宜但带有噪声。

4. 正则化与泛化

只让训练损失下降，模型可能记住训练集。于是目标经常写成：

J_total = J_data + λ Ω(θ)

第二项惩罚复杂度。线性模型里可以惩罚权重大小；XGBoost 会惩罚树的复杂度和叶子分数；神经网络常见权重衰减、Dropout 和早停。细节不同，但共同思想是：拟合数据与限制复杂度之间要平衡。

5. 一个重要区分

训练损失是“优化器正在努力降低的量”；验证指标是“研究者用来做选择的量”；测试指标是“协议冻结后的最终报告”。它们可能相关，但绝不是同一个对象。比如分类器可以优化 logistic loss，最后报告 ROC-AUC。

6. 现在练习

如果当前参数处的梯度是正数，且学习率为正，那么更新 θ ← θ - η∇J(θ) 通常会怎样？

带走的工具

打开线性模型与优化速查。下一次看训练代码时，寻找四件事：模型输出、loss、梯度/优化器、参数更新。即使代码使用高级框架，这四个角色仍然存在。
