Lesson 0011 · Evidence and attribution

提升来自哪里？

A 比 B 高，只是观察到差异；科研要继续追问：差异究竟归因于表示、模型、协议，还是它们的组合。

本课唯一胜利
面对两个实验结果，你能指出它们同时改变了哪些因素，并提出一个最小对照来缩小归因范围。

1. 一个比较可能捆绑了很多变化

例如下面的比较：

KSVD 固定向量 + XGBoost　vs　原子/键图 + GNN

两边不仅模型不同，输入表示、可用关系、参数化方式、训练循环和可能的选择规则也不同。即使左边分数更高，最稳妥的表述仍然只是：

在这两种输入、模型和协议的联合比较下，左边的预测结果更好。

它还不能单独证明“KSVD 表示更好”“XGBoost 更适合分子图”，更不能证明 GNN 没有能力。

2. 最小工具：2×2 对照矩阵

把研究关心的两个轴分别记为表示 R 和模型 M：

模型 M0模型 M1
表示 R0R0 + M0
基线		R0 + M1
只换模型
表示 R1R1 + M0
只换表示		R1 + M1
完整方案

比如：

  • R0：原始/固定特征；R1：KSVD 特征；
  • M0：Logistic Regression；M1：XGBoost。

比较同一列，主要观察表示变化；比较同一行，主要观察模型变化。四格都应尽量共享 split、标签、指标、选择规则、训练预算和随机种子集合。

3. 如何读一个示意结果

示意 ROC-AUC，不是实际实验结果
Logistic M0XGBoost M1
固定特征 R00.710.76
KSVD 特征 R10.730.77

从同一模型看，KSVD 表示带来 +0.02 或 +0.01；从同一表示看，XGBoost 带来约 +0.04 或 +0.05。这提示模型变化可能比表示变化更大，但要结合多 seed、误差范围和任务定义，不能只看一个小数。

如果 R1 只在 M1 上有效，可能存在表示 × 模型的交互：不是“表示普遍更好”，而是它更适合某种下游读取方式。这个区别会改变论文主张。

4. 对照不是越多越好，而是要对应解释

担心规模信号：加入 size-only 或 degree-only 基线。若复杂方法只比 size 高一点，结构主张要收紧。

担心维度/容量：使用 random、PCA 或参数量匹配的表示/模型。

担心模型记噪声：做 label shuffle，并保持流程、预算和选择规则不变。

声称使用了关系：只打乱关系或 assignment，保留内容、数量和容量，观察性能是否下降。

一个好的对照不是“再跑一个模型”，而是针对一个具体的替代解释设计的。先写“我担心提升其实来自什么”，再决定要改哪一处。

5. 现在练习

如果想隔离“表示本身”的增量价值，哪种比较最直接？

“KSVD 向量 + XGBoost”优于“原始图 + GNN”时，最稳妥的第一句话是什么？

如果只完成了 R0+M0 与 R1+M1 两个实验，最强能支持哪句话？

带走的研究句

先写替代解释，再设计对照。
“我想声称 KSVD 表示带来增量信息；可能的替代解释是维度、模型容量、size 信号或协议差异。因此我固定下游模型和 split，并加入 size、PCA/random 与关系打乱对照。”

打开提升归因速查，并回看实验协议。下一课将继续问：一次提升在不同 seed 和不同子集上是否稳定。
