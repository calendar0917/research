Lesson 0012 · Robustness and uncertainty

一次提升，稳定吗？

一个 seed 的漂亮结果是线索，不是结论。要判断它是否可信，需要把训练随机性、数据划分和子群体分开检查。

本课唯一胜利
看到一组实验结果时，你能判断它检查了哪一种稳定性，以及还缺哪一种证据。

1. “seed”不是一个问题

代码里常见多个随机来源：

模型 seed：初始化、batch 顺序、dropout 等改变；主要检查训练过程是否敏感。

split seed：哪些样本进入 train/valid/test 改变；主要检查结论是否依赖某次划分。

数据采样 seed：patch、负样本或增强样本改变；主要检查数据构造是否稳定。

因此，“我们跑了 5 个 seed”还不够。要问：改变的是模型随机性，还是数据划分？两者回答不同的问题。

2. 比较差值，而不只看两个均值

比较方法 A 和 B 时，尽量让它们在同一 run 使用相同 split 和 seed，然后计算配对差值：

Δrun = score(A, run) − score(B, run)

示意：

这里 A 的总体均值可能接近 B，但只有 2/4 次胜出，方向并不稳定。若只挑 run 0，报告会制造“确定提升”的错觉。均值和标准差是摘要，不是对每个运行的替代；原始值、n 和选择规则仍要保留。

3. 多 seed、多 split、外部验证各自回答什么

多模型 seed：固定官方 scaffold split 和配置，改变初始化/训练顺序。它回答“训练偶然性会不会改变结果”。

多 split/fold：改变训练与测试样本的组成。它回答“结论会不会依赖某一批样本”。

外部数据：换数据集、领域或分布。它回答“方法能否迁移”，要求更强的任务和表示对齐。

评估多个预先规定的 seed 本身没有问题；问题是看完 test 后挑最好 seed、挑最好 split 或修改方案，再把选后的数字称为最终证据。

4. 总体分数也可能藏住失败

MolHIV 这类分子任务中，可以进一步按分子大小、scaffold、稀有标签或结构密度分组。总体 ROC-AUC 相同，不代表每个群体都同样好；某一类新 scaffold 可能明显掉分。

子群体分析的第一个问题不是“哪个群体最好”，而是：每个群体有多少样本？分组是否在看完结果后才临时挑的？小群体的极端分数是否被过度解读？

5. 现在练习

哪种运行安排主要检查训练过程的随机性？

如果某方法只在 1/5 个 seed 上胜出，最稳妥的说法是什么？

比较 A 和 B 时，哪种安排更有利于公平归因？

总体均值相同但某个重要子群体明显变差时，下一步应怎样做？

带走的研究句

不要只报告“最好”，要报告“在什么变化下仍然成立”。
“在固定 scaffold split 的 5 个模型 seed 上，A 相对 B 的配对差值为……；这检查了训练随机性，但还不能说明它对其他 split 或新 scaffold 同样稳定。”

打开结果稳健性速查，回看提升归因和实验协议。下一步会把这些工具应用到一段真实训练代码和实验报告。
