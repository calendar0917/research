Lesson 0008 · Classical models

XGBoost 如何走完一轮？

把上一课的“顺序纠错”拆成可以审计的计算：当前预测、梯度、二阶信息、叶子权重和切分收益。

本课唯一胜利
给定一组当前预测和一个候选切分，你能判断新树应该往哪边修正，以及这个切分是否值得保留。

1. 先记住时间顺序

Boosting 的当前模型记作 Fm−1。第 m 轮不会从头训练一棵“最终模型”，而是先用已有模型得到每个训练样本的当前预测，再添加一个修正函数：

Fm(x) = Fm−1(x) + η fm(x)

  1. 旧的树集合给出当前预测 ŷᵢ。
  2. 在每个 ŷᵢ 处计算损失的一阶导数 gᵢ 和二阶导数 hᵢ。
  3. 把样本按候选树的叶子分组，汇总成 G、H，比较叶子与切分的正则化收益。
  4. 建好新树后，用 η 缩放它，再加入旧模型。

这就是第五课“梯度告诉我往哪改”的函数版本：参数向量不再直接移动，而是添加一棵能降低损失的树。这个加法训练视角见 XGBoost 官方模型教程。

2. 梯度告诉方向，二阶信息告诉曲率

对样本 i，令损失为 ℓ(yᵢ, ŷᵢ)：

gᵢ = ∂ℓ / ∂ŷᵢ
hᵢ = ∂²ℓ / ∂ŷᵢ²

gᵢ 是“如果预测再增大一点，损失会怎样变化”的局部答案；hᵢ 描述这个答案变化得有多快。XGBoost 用损失的二阶 Taylor 近似来决定新树的叶子值，而不是只看一个粗糙的正确/错误计数；原始论文给出了这个正则化目标的推导。

为了算得清

下面的小例子暂用平方损失 ½(y−ŷ)²，因此：

gᵢ = ŷᵢ − yᵢ，hᵢ = 1

预测偏高时 gᵢ>0，修正应为负；预测偏低时 gᵢ<0，修正应为正。二分类 logistic 会换成对应的 gᵢ,hᵢ，但“先按当前预测计算，再聚合并选树”的结构不变。

3. 一个叶子能给出多大的修正？

假设若干样本落入同一个叶子，记：

G = Σ gᵢ，H = Σ hᵢ

对这个叶子的常数输出 w，二阶近似加上 L2 正则化后，最优值为：

w* = −G / (H + λ)

这条式子很适合审计代码和日志：

  • G 决定方向：G>0 往下调，G<0 往上调；
  • H 和 λ 出现在分母，控制更新幅度；
  • 得到的 w* 还是新树的原始叶子权重，最终贡献还会乘上 η。

4. 一个候选切分值不值得？

把父节点切成左、右两个叶子时，XGBoost 比较正则化目标的下降量：

gain = ½[ GL²/(HL+λ) + GR²/(HR+λ) − G²/(H+λ) ] − γ

γ 是新增叶子/切分的复杂度代价。gain 为正，才说明“分开以后获得的拟合收益”超过了复杂度成本。注意：这只是训练目标在该轮的局部收益，不是验证集 AUC 的保证。

带走的审计模板

看到 XGBoost 日志或代码时，按这个顺序问：

当前预测从哪里来？训练目标是什么？g,h 针对哪个损失？叶子/切分是否包含正则化？报告里的 eval_metric 是否被误说成了训练目标？
