Experiment tooling / quick reference

Python 环境：uv 与 conda

判断规则：依赖能走 pip 轮子 → uv；需要 conda-forge 原生二进制 → conda。两条路线的命令都列在这里。

三层心智模型

解释器（谁提供 Python）→ 包（谁解析依赖）→ 位置（环境装在哪）

uv：解释器自下载 · pip 轮子 · 项目 .venv ｜ conda：环境自带 · conda-forge 二进制 · <prefix>/envs（可用 -p 改）

uv 常用
动作命令
安装（无 sudo）curl -LsSf https://astral.sh/uv/install.sh | sh
新建项目uv init && uv add torch numpy
按 lock 重建uv sync
运行uv run python main.py（自动用项目 .venv）
新增/更新依赖uv add pkg==1.2.3 / uv remove pkg
下载解释器uv python install 3.12；列表 uv python list
临时跑工具uvx mypy .
导出 requirementsuv pip compile pyproject.toml -o req.txt（可选 --universal）
torch CUDA 变体（pyproject.toml）

PyPI 的 torch 2.x Linux 轮子默认捆绑 CUDA；需要指定版本时用 PyTorch index（uv ≥ 0.5.3）：

[[tool.uv.index]]
name = "pytorch-cu124"
url = "https://download.pytorch.org/whl/cu124"
explicit = true

[tool.uv.sources]
torch = [{ index = "pytorch-cu124" }]
torch-geometric = [{ index = "pytorch-cu124" }]

常用 URL：.../whl/cpu、/whl/cu118、/whl/cu121、/whl/cu124、/whl/cu128。GPU 扩展（flash-attn、torch-scatter）见 wheels.astral.sh。

conda 常用
动作命令
在脚本中复活函数
（不写 .bashrc）		eval "$(/home/hxy/enter/bin/conda shell.bash hook)"
建到自己的目录conda create -p ~/papers/xxx/env -c conda-forge python=3.9 mpi4py
按名激活（默认 envs）conda activate myenv；按路径 conda activate ~/papers/xxx/env
一次性跑一条命令conda run -p ~/papers/xxx/env python train.py
列出环境conda env list（active 行带 *）
记录环境conda export > environment.yml（跨机 → --from-history）
精确重建（锁文件）conda export --format=explicit > spec.txt；需 conda ≥ 26.5 支持 conda-lock.yaml
按文件重建conda create -n myenv --file spec.txt / -f environment.yml
删除conda env remove -n myenv
这台服务器备忘
  • conda 前缀：/home/hxy/enter；默认 envs 在 ~/enter/envs（导师共享目录，勿写入）
  • 无 sudo；系统 Python 3.10.12，无 pip；驱动 550 支持 CUDA 12.4
  • 已有环境：Graph_recover（py3.9/torch2.8+cu128）、graph_lab（py3.9/torch2.1+cu121）等
  • /home 剩约 732G（99% 满）；uv 缓存可指 UV_CACHE_DIR=/tmp/uv-cache 省空间（重启清空）
  • 长任务用 tmux 挂住；跑前 nvidia-smi 看谁在占卡
