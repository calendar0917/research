Research literacy / quick reference

实验协议

一个模型分数不是孤立事实；它是数据、表示、目标、选择规则和评估边界共同产生的结果。

标准闭环

train：学习参数 → valid：做选择 → freeze：冻结决策 → test：最终评估

三种数据角色
数据允许做什么不应做什么
train拟合模型参数、学习训练内表示把训练分数当泛化证据
validation选超参数、epoch、阈值或候选方法把它包装成完全未见数据
test冻结方案后的最终估计反复调参、挑 seed 或挑结果
目标与指标
对象回答的问题典型例子
objective / loss模型训练时朝什么方向改变logistic loss、平方损失
eval metric我们用什么尺子比较结果ROC-AUC、PR-AUC、accuracy
selection rule用哪份证据决定保留哪个方案best valid AUC、early stopping

三者可以不同，但必须写清楚。比如模型优化 logistic loss，研究报告用 ROC-AUC，checkpoint 按 validation AUC 选择。

泄漏检查
  1. 先 split，再对 train 调用 fit。
  2. valid/test 只能调用已经学好的 transform 或 predict。
  3. 把 scaler、PCA、字典、特征筛选器和模型都视为可能学习信息的对象。
  4. 如果有 transductive 预训练或全数据无标签预处理，必须明确声明协议，不能默认为 inductive 泛化。
结论模板

“在固定的数据集、表示、划分、训练目标、选择规则和随机性设置下，方法 A 的 test 指标为……；这支持……，但还不能说明……。”
