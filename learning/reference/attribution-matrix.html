提升归因

先把“比较”拆成变量，再决定一项结果能支持多大的结论。

核心问题

当结果变化时，究竟是表示 R、模型 M、协议 P，还是它们的组合发生了变化？

2×2 最小矩阵
模型 M0模型 M1
表示 R0R0 + M0
基线		R0 + M1
模型变化
表示 R1R1 + M0
表示变化		R1 + M1
完整方案

四个格子使用相同 split、标签、指标、选择规则、预算和随机性设置；每次只改变研究问题所关注的轴。

常见对照
对照它主要排除什么解释
简单统计量 / size-only任务本身被容易的全局规模信号解释
random / PCA representation提升只是因为增加了特征或改变了维度
capacity-matched model提升只是参数量、训练预算或模型强度
label shuffle高分只是流程在小样本上拟合噪声
relation / assignment shuffle模型是否真的使用了声称的结构关系
结论边界

只改变表示并在同一模型、同一协议下提升，才开始支持“表示有增量价值”。要声称“结构关系是原因”，还需要结构关系的破坏对照。
