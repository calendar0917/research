Classical models / quick reference

XGBoost 一轮更新

每一轮都在已有模型上添加一棵树：用当前预测计算损失的局部方向与曲率，再选择能让正则化目标下降的树结构。

核心流程

当前模型 → ŷᵢ → gᵢ,hᵢ → 汇总 G,H → 叶子权重/切分 gain → 新树 → η 缩放后相加

一阶 / 二阶信息

gᵢ = ∂ℓ(yᵢ, ŷᵢ) / ∂ŷᵢ：在当前预测处，损失希望预测向哪边改。

hᵢ = ∂²ℓ(yᵢ, ŷᵢ) / ∂ŷᵢ²：损失曲率，帮助决定这次改动应该多谨慎。

平方损失 ½(y−ŷ)² 下：gᵢ=ŷᵢ−yᵢ，hᵢ=1。二分类 logistic 的 raw margin 下通常是 gᵢ=pᵢ−yᵢ，hᵢ=pᵢ(1−pᵢ)。

一个叶子

对落入同一叶子的样本求和：G=Σgᵢ，H=Σhᵢ。L2 正则化为 λ 时，局部最优叶子权重是：

w* = −G / (H + λ)

所以 G>0 时往下修正，G<0 时往上修正。λ 越大，叶子更新越保守。

一个切分

候选切分把父节点分为左右子节点。带有“每增加一个叶子”的复杂度代价 γ 时：

gain = ½[ GL²/(HL+λ) + GR²/(HR+λ) − G²/(H+λ) ] − γ

gain 为正，说明这个切分带来的损失下降超过了复杂度代价；否则应拒绝或继续寻找别的切分。

研究审计句

我能声称：该轮在给定训练样本、当前预测、损失和正则化设置下选择了一个局部上有利的树更新。
我还不能声称：该切分在验证集或测试集上一定带来收益。
