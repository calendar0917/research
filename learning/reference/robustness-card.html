Evidence / quick reference

结果稳健性

稳定不是一个数字，而是结果对训练随机性、数据划分和样本群体变化的敏感度。

三个不同问题

seed：换初始化/数据顺序还好吗？
split：换一批训练与测试样本还好吗？
subgroup：总体分数是否掩盖了某类样本的失败？

如何安排运行
目的固定改变
训练稳定性同一 split、配置和协议模型 seed
划分稳健性方法、预算和评估规则split seed / fold
公平比较同一 run 的随机条件方法本身
子群体检查冻结后的模型和预测样本分组方式
建议报告
  1. 每个 seed/fold 的原始指标，不只报最高值。
  2. 均值、波动范围和运行数量 n。
  3. 同一 run 的配对差值 Δ = A − B，以及 A 胜出的次数。
  4. 预先规定 seed、split、选择规则和停止条件。
  5. 按重要子群体报告样本量和性能，避免小群体的夸张解读。

多个 seed 可以在冻结协议下批量评估；不能根据 test 结果挑出最好的 seed 再报告。

证据等级

单次运行 = 观察到一次结果；多 seed = 对训练随机性的检查；多 split/fold = 对数据划分的检查；外部数据 = 对迁移性的进一步检查。
