Classical models / quick reference

决策边界与树规则

模型可以理解为在输入空间中画出一个预测函数。不同模型的关键差异，是它允许画出什么形状。

线性分类器

wᵀx + b = 0 是决策边界。二维时是一条直线，高维时是超平面。它不能直接表达 XOR 这种非线性分隔。

决策树

每次选择一个特征和阈值，例如 x₁ ≤ t，把空间切成两个区域；递归切分后得到轴对齐的分段区域。叶节点保存预测值或类别比例。

树的代价

深树能表达更复杂规则，但容易过拟合；浅树偏差较高但更稳。max_depth、min_samples_leaf 和剪枝控制复杂度。

表达能力不是越大越好：
要比较一个模型，既要问它能表达什么，也要问它是否有足够数据把这种表达学对。
