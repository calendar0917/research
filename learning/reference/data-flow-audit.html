Research literacy / quick reference

数据流审计

核心问题：每个数据子集在代码中扮演了什么角色？谁可以学习，谁只能被转换或评估？

训练集：可以用于 fit、选择参数和学习表示。
验证集：可以用于选择模型或配置，但不能参与最终无偏报告。
测试集：只在协议冻结后用于一次最终评估。

四个动作

  1. Split：先确定索引，避免预处理先看全数据。
  2. Fit：凡是“学习参数”的动作，只能接触训练集。
  3. Transform / Predict：验证集和测试集只能使用已经学习好的变换或模型。
  4. Evaluate：验证集可用于开发期判断；测试集不能用于挑选赢家。

审计代码时标记

  • 给每个数组标注来源：`train`、`valid`、`test`。
  • 圈出所有 `fit`、`fit_transform`、`select`、`best`、`max` 和调参循环。
  • 确认这些操作是否接触了 `valid` 或 `test`。
  • 检查最终报告是否把单次分数误写成稳定结论。
