Foundations / quick reference

机器学习基本对象

先统一语言，再学习模型。模型不同，下面这些对象仍然反复出现。

样本 sample

一个待处理的对象，例如一张分子图、一个节点或一行表格数据。

特征 feature / x

描述样本的输入信息。可以是向量、节点矩阵、边列表或更复杂的结构。

标签 label / y

训练时希望预测的目标。训练集有标签；预测时通常只有输入。

模型 f_theta

把输入映射为预测的函数：ŷ = fθ(x)。模型族规定函数的可能形式，参数 θ 决定其中具体是哪一个函数。

损失 loss

衡量预测与目标差异的函数：L(y, ŷ)。训练通常是在训练数据上寻找较小损失的参数。

超参数 hyperparameter

训练前设置、而不是通过当前训练直接学出的选择，例如树深、GNN 层数、学习率和正则化强度。

统一骨架：
数据给出 (x, y)，模型给出 ŷ = fθ(x)，损失评价 y 与 ŷ，优化器改变 θ。
