Classical models / quick reference

集成学习

集成的核心不是“树越多越强”，而是让多个基学习器以不同方式提供互补信息。

Bagging / Random Forest

对样本或特征做随机扰动，训练相对独立的树，再平均或投票。目标主要是降低方差、提高稳定性。

Boosting / GBDT

从简单模型开始，每一步新增一个模型去修正当前预测的损失方向，最后加法组合。目标是逐步降低偏差。

XGBoost

梯度提升树的高效、正则化实现。每一轮增加一棵树；使用损失的一阶梯度和二阶信息选择结构与叶子值，并控制树复杂度。

重要超参数

n_estimators：树的数量；learning_rate：每棵树的贡献缩放；max_depth：单棵树的复杂度；subsample、colsample_bytree：随机性与正则化；reg_lambda、reg_alpha：叶子值正则化。

一句话区分：
随机森林是“许多不同意见的平均”；Boosting 是“后一个意见专门纠正前面的错误”。
