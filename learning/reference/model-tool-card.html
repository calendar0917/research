六个必问

输入是什么？输出是什么？模型学了什么？训练优化什么？报告测量什么？什么情况下不能相信结果？

通用接口
代码对象要理解的含义
fit(X, y)用数据改变模型内部状态；通常只应使用训练数据。
predict(X)产生预测；调用本身不应继续学习。
predict_proba(X)产生类别概率；排序指标通常应使用连续分数。
forward(...)神经网络的前向计算；输入可能是张量或图结构。
objective训练时希望最小化/最大化的目标或损失。
eval_metric用于监控、比较或报告的指标，不自动等于训练目标。
四个模型的最小定位
模型典型输入核心机制首先审计什么
XGBoost固定长度向量 [N,d]逐棵树修正预测特征是否已包含结构信息
MLP固定长度向量多层非线性映射容量、正则化和训练稳定性
GNNx + 边/邻接关系聚合邻居消息图构造、任务层级和信息泄漏
KSVD样本/patch 特征矩阵字典与稀疏编码表示是否独立于标签、重建目标是否匹配
60 秒代码审计
  1. 找出 fit：哪些数据真正参与了学习？
  2. 找出预测调用：输出是标签、概率、分数还是表示？
  3. 找出目标与指标：训练目标和报告指标是否一致或有意区分？
  4. 找出关键旋钮：容量、步长、正则化和随机性在哪里？
  5. 确认验证集用于选择，测试集只用于最终评估。
  6. 写出一句边界：结果只支持哪个数据、表示和协议下的主张？
