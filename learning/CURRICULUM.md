# 课程路线：从研究问题到可信结论

## 最终目标

这门课的主线不是“把模型目录学完”，而是建立一套可以迁移到新论文、新代码和新实验上的科研理路：

```text
研究问题 → 可检验主张 → 数据/表示 → 方法假设 → 训练目标
    → 实验协议 → 证据与替代解释 → 结论边界 → 下一步实验
```

模型、数学和代码都是支撑这条链条的语言。课程的终点是能用这条链条重建一项研究，而不是记住更多模型名称。

## 每个模型只学到什么程度

对当前阶段，每个模型先掌握一张“研究卡”，不要求完整推导或从零实现：

1. 接口与输入输出：输入是什么，输出是什么，张量/特征的形状和语义是什么；
2. 核心机制：它到底对输入做了哪种计算；
3. 方法假设：它利用了什么结构，忽略了什么结构；
4. 关键变量：哪些变量控制容量、步长、正则化和随机性；
5. 训练目标与评估指标：优化什么，报告什么；
6. 失败方式与结论边界：什么情况下结果不能支持原来的主张。

公式和算法细节只有在能帮助审计代码、解释异常结果或判断方法边界时，才进入必修部分；其余放在参考卡中按需查阅。

## 主线阶段

### A. 研究问题与主张

目标：先学会判断“一句话结果”究竟支持了什么。

- `0001-from-score-to-claim.html`：从分数回到可检验主张；
- `0002-follow-the-data.html`：沿数据流检查实验边界；
- `0003-representation-and-bias.html`：预览表示、模型和归纳偏置的差异。

阶段出口：能把“某模型更好”改写成带有数据、输入、协议和结论边界的准确表述。

### B. 数据、任务与最小方法语言

目标：知道研究对象如何变成模型可以处理的输入，以及预测、损失和参数分别是什么。

- `0004-data-vector-function.html`：数据对象、向量、函数和参数；
- `0005-linear-model-gradient.html`：线性模型、损失、梯度和优化的操作性直觉；
- 后续补充：标签、任务类型、数据划分和图构造。

阶段出口：能顺着代码说出 `X`、`y`、预测值、损失、参数、超参数和数据划分各自扮演什么角色。

### C. 把模型当作研究假设

目标：不是背模型，而是判断“这个方法为问题带来了什么归纳偏置”。

- `0006-boundaries-and-trees.html`：线性边界与树规则；
- `0007-ensemble-learning.html`：随机森林的平均与 Boosting 的顺序纠错；
- `0008-xgboost-one-round.html`：XGBoost 的一轮更新；当前只需掌握更新方向、复杂度控制和参数角色，公式是可选深挖；
- 后续以同一研究卡学习：MLP → GNN → Transformer → 表示学习/KSVD。

每个模型只回答：它接收什么表示？利用什么关系？适合什么问题？与哪个基线比较？不能声称什么？

阶段出口：面对一个新模型，能在几分钟内说清它的输入、机制、假设、关键变量、适用边界和比较位置。

### D. 训练与实验协议

目标：把“模型跑出来了”与“实验可以支持结论”区分开。

- 训练目标、评估指标、参数/超参数的区别；
- train/validation/test 的职责、调参边界和数据泄漏；
- 基线、公平比较、随机种子、重复实验和不确定性；
- 早停、模型选择、停止条件和结果记录。

阶段出口：能审计一段 AI 生成的训练代码，指出模型究竟优化了什么、什么时候看了验证集、测试集是否被污染，以及报告中的指标是否对应正确协议。

### E. 证据、归因与反事实检查

目标：判断提升来自哪里，以及还存在什么替代解释。

- 消融、对照、置换/打乱和容量匹配；
- 表示增益、模型增益、协议增益的拆分；
- 错误分析、子群体稳定性、跨 split/seed 的稳健性；
- “相关、预测有效、机制成立”三种结论的边界。

阶段出口：能设计一个最小可辨护实验，回答“提升是否真的来自结构表征/KSVD，而不是特征泄漏、模型容量或协议差异”。

### F. 回到当前研究并形成汇报

目标：把前面的语言用于 MolHIV、分子图和 KSVD，而不是停留在练习题。

- 画出真实代码的数据流和张量形状；
- 把一个实验压缩成“问题—假设—方法—协议—证据—边界”；
- 设计并复现最小实验；
- 向导师汇报已知证据、可支持主张和未知部分；
- 用下一步实验区分竞争性解释。

阶段出口：能独立审阅一项研究，并提出一个具体、成本可控、能改变结论置信度的后续实验。

## 学习节奏

每一节课保持短小，但不再把每个公式都当作必修。固定结构是：

1. 一个与当前研究相关的核心概念；
2. 一张模型/实验研究卡；
3. 一个很小的回忆或审计练习；
4. 明确“证据支持什么、还不能支持什么”；
5. 一张可反复查阅的参考卡。

概念层可以先建立流畅度；只有用户通过练习展示了能使用它，才把关键认知写入 `learning-records/`，作为下一阶段的起点。
