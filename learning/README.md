# 科研能力学习工作区

这个目录独立保存长期学习材料，不属于任何一个科研 track，也不写入实验主表。

## 目录

| 路径 | 用途 |
|------|------|
| `MISSION.md` | 学习使命与成功标准 |
| `RESOURCES.md` | 经核验的高质量知识与社区资源 |
| `NOTES.md` | 教学偏好与过程备注 |
| `lessons/` | 可反复打开的短 HTML 课程 |
| `reference/` | 课程配套速查文档 |
| `learning-records/` | 已被证实掌握的关键认知 |
| `assets/` | 课程共用组件 |

课程总路线见 [`CURRICULUM.md`](CURRICULUM.md)。课程不会把 XGBoost、GNN、Transformer 当作仅有的三种模型；它们会被放回线性模型、核方法、概率模型、树模型、集成学习、表示学习和结构化神经网络的完整谱系中。

## 当前方向

课程不以某个模型为中心，而以提升图神经网络科研素养为主线：

- 能把研究问题、方法假设、实验协议和结论边界分开；
- 能判断 XGBoost、Transformer、GNN 等方法在具体问题中的适用位置；
- 能读懂、审计、复现和质疑 AI 生成的代码与实验报告；
- 能将判断落到 KSVD、分子图和 MolHIV 等真实研究场景。
