# 教学备注

- 用户希望提升的是整体科研素养和科研路线理解，不是只学习某一个模型或分类器。
- 核心场景是图神经网络研究；优先联系 KSVD/结构、MolHIV/分子图，同时保留通用方法训练。
- 用户自评：能读 Python，但难以审计复杂实验代码；当前代码较多由 AI 生成，主要工作是看结果和把控方向。
- 课程应避免只给结论，要求用户进行回忆、判断和最小验证。
- 2026-08-30：新建独立学习工作区；2026-08-31 用户确认最终目标是建立从研究问题到证据和结论边界的整体科研理路，使命文本现视为稳定版本。
- 用户指出前两课偏向科研流程，基础知识仍是主要缺口；从第三课起采用“基础概念 + 小型审计练习”双轨，而不是只讲流程。
- 用户进一步指出模型地图过于局限、学习顺序不够自底向上；已改为分层课程：数学与数据对象 → 学习框架 → 经典模型 → 神经网络 → 图与 GNN → Transformer → 表示学习 → 实验能力。
- 2026-08-31：路线再次调整为“科研闭环主线 + 按需方法支撑”：问题/主张 → 数据/表示 → 方法假设 → 训练目标 → 实验协议 → 证据/替代解释 → 结论边界；原有模型层保留为支撑地图，不再要求逐模型、逐公式推进。
- 当前主线已推进到数学与数据对象/优化基础；第三课作为模型比较预览保留，不代表主线已跳过基础层。
- 第六课完成经典模型层的入口：用决策边界和条件规则连接线性模型与树模型；下一步进入集成学习和 XGBoost 原理。
- 第七课完成集成学习入口：区分随机森林的并行平均与 Boosting 的顺序纠错；下一步进入 XGBoost 单轮更新。
- 2026-08-31：用户反馈模型层的公式拆解粒度偏细。后续模型课程以接口、关键变量、输入输出、训练/评估边界、适用假设和结果审计为主；数学细节只保留能帮助做出科研判断的最小骨架，必要时放入可选速查卡。
- 2026-08-31：用户补充模型作为工具仍需基本理解；第九课采用“接口层 + 语义层”的模型契约，要求能读懂输入输出、关键变量、训练目标、评估指标和数据边界，不要求完整数学推导。
- 第十课进入训练与实验协议：先区分 objective/loss、eval metric、selection rule，再检查 train/valid/test 和表示学习动作是否越界。
- 第十一课进入证据归因：用 matched controls 和 2×2 矩阵区分表示效果、模型效果及交互，避免把联合比较误写成单一机制结论。
- 第十二课进入稳健性：区分 model seed、split seed 和 subgroup 检查，强调配对差值、原始运行值、样本量与“不要根据 test 挑最好 seed”。
