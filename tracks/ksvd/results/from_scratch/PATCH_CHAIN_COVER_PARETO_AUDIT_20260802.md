## 4. 边界

- raw pair slots 是 patch count × patch pair capacity；它衡量未压缩观察成本，不等于最终 sparse-code 存储。
- Pareto 不选单一冠军，只排除在成本和 coverage/error 上同时被支配的 cells。
- sampler failure 计入 feasibility；不因高 coverage 子集而忽略失败图。
