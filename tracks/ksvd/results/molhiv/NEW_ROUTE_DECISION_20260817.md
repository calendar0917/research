# MolHIV 新路线阶段性决策

## 已经确认的事实

1. 整体局部块词元会丢失关键槽位信息，因此关系无法真正发挥作用。
2. 改成 8 个槽位词元，并加入同一真实原子在不同局部块中的精确对应后，局部结构恢复明显改善。
3. 这个改善在每折 1000 个分子、三折实验中稳定出现；在第 0 个内部骨架折使用全部官方训练集分子时仍然成立。
4. 随机 BFS 也能产生同样的桥收益，而且当前绝对结构误差优于 Beam8。
5. 桥层接到 HIV 分类后平均有小幅收益，但三折中正确绑定没有稳定超过打乱绑定。

## 当前主线

保留：

> 槽位级 Transformer + 精确共享原子关系 + 分子级读出

这个主线的核心不是 GIN、GINE，也不是 KSVD，而是“保留槽位内容，并显式传递共享原子对应关系”。

## 暂时降级的部分

- **Beam8**：降级为一种局部块覆盖候选生成器。需要和随机 BFS、均匀随机局部块做公平比较，不能直接称为核心贡献。
- **GIN/GINE**：只保留为分类基线或可选原子编码器，不强制接在新模型前面。
- **KSVD**：暂时只做原始槽位、PCA、随机原型的压缩对照。若不能保持结构和分类性能，就定位为压缩/初始化工具，不再作为方法主体。

## 下一步顺序

1. 全量内部折分类已经完成首轮复核：正确桥优于打乱桥，但没有超过无桥。
2. 现有三折化学预训练迁移也不稳定，说明继续增加结构预训练轮数不是主要解决办法。
3. 终止“通过 Beam8/KSVD 邻接重构直接提升 MolHIV 分类”的主张。
4. 若继续追求下游增益，应改为化学任务对齐：官能团、键类型、远程片段相互作用或已知活性子结构，而不是继续压低邻接重构误差。
5. KSVD 只在新的化学目标已经显示稳定分类收益后，作为压缩对照重新进入。
