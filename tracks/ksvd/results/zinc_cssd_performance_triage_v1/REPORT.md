## 5. 从结果到下一项研究决定

**为什么不买 Q 的 cycle 路径**（净损失规模、可恢复性、历史失败、成本四项都反）：

1. 规模与位置：Q 净伤害 +0.02736 的 75.8% 已定位在 2 行、95.7% 在 9 行稀有 k 行。
2. 可恢复性：gid 1424 是**同输入函数不可分**（同一 T25 在 fit 池携带冲突 k=0，任何
   T25 的确定性函数不可能同时输出 ~0 与 −20.79）；gid 3775 是**训练未覆盖**（单例类
   不在 8001 fit 池）且其标签罚项是 (图, 生成器节点序) 的函数、非图不变量——图不变
   输入不能承诺恢复该 ordering artifact。剩余 k=−2/k=−1（B_Q ≤0.0067）未定位，
   但全部可恢复也不到 MAE_y 的 6%。
3. 历史：精确类修复路线已停在
   `zinc_cycle_prototype_transfer_cpu_v1`（收益单行主导：剔除最差行后增益
   −2.9e−5，CI 未过；其 next-responsibility 结论本身就指向 body error）；全局
   拓扑/长环输入方向已存在（T25 即 compact-v4 hinge 通道，25D longest+counts+阶梯；
   该轮结论"更多 cycle 特征边际为负"，official terminal test 为负）。扩大同 T25 的
   MLP 不能消除真实输入冲突。
4. 结论：**Q 路线在本冻结接口内的可购买预算 ≈ 0**；新输入必须给出具体图可计算、能
   分离上述冲突对的信息并与旧 global-topology 候选对照——当前证据不支持。

**为什么预算方向是 g 泛化/读出但仍暂不购买具体候选**：

- 74.0% 的 MAE_y 是 k=0 行的 e_g（fit MAE_g 0.029→dev 0.092，~3 倍泛化差），这是
  唯一够大的预算池；且 DICT 的微小优势也集中在 k=0。
- 但形成候选缺三条具体信息：
  1. **dev 上 e_g 的逐组件定位（ell vs s）**：dev 预测文件按设计无逐行
     ell_hat/s_hat，本轮禁止重跑前向补齐——没有它无法判断剩余 e_g 走哪个分量通道
     （fit 侧只有域内信息）；
  2. **k=−2/−1 尾部 67 行的 Q 误差定位**（是否同属冲突/未覆盖；q_spotcheck 只定位
     了 2 行）——它决定 Q 侧可恢复预算是 ~0 还是 ≤0.007，及 Q 路线能否正式关闭；
  3. **k=0 内部 e_g 的结构**（n_nodes / |g| 尾部 / 稀有原子组的分解）——判断误差
     是集中可定位子群还是弥散接近数据底噪。
- 相邻配方全部已有停止/阴性结论，当前观察不构成新候选的证据：RAW 臂（局部信息严格
  更多、无基底重构损失）并不更好，排除"补回基底信息损失/直接喂稀疏码"一族；
  `zinc_local_dictionary_component_supervision_seed0_v1` 已停旧接口的可训练 IHT
  局部字典；N/E joint 已闭；prototype 救场已停；容量/超参搜索未获购买；不能仅凭
  s 的单项 MAE 更大改 COMP 权重（0.5 为披露的辅助监督条件，本轮不动）。
  DICT−RAW 的 −0.001 CI95 [−0.0036, +0.0014] 跨零，也不构成"换接口方向"证据。

**决策分支**（每一支如何改变下一决定）：
- 若 (1)+(3) 显示 e_g 集中在可定位子群（如大分子/|g| 尾部）→ 形成消费者读出侧的
  具体候选（基底与接入方式冻结，只动消费者泛化/读出），按新预注册进入下一轮；
- 若 e_g 弥散、无子群结构 → 该接口族的误差接近数据底噪，转向 STATE 中开放的
  whole-graph 表示问题，不再向此消费者投训练预算；
- 若 (2) 显示 k=−2/−1 同属输入冲突/未覆盖 → Q 路线可恢复预算确认为 ~0，正式关闭
  Q cycle 路径；若显示覆盖但未拟合（prototype 的 valid:0172 型）→ 最多值
  ≤0.005 的 Q 侧修复候选，但其历史（单行主导、CI 未过）已预先警示。

## 6. 字典里程碑与上轮两处文字勘误

- **里程碑保持成立**：冻结 CSSD 基底供给 M_COMP 局部 phi65 接口——性能承接
  （两 seed Δ −0.00097/−0.00106，平均 −0.00102，CI95 [−0.0036, +0.0014] 跨零、
  上界 < +0.003 工程容忍）且稀疏残差有真实、有害可换的读出（|Δpred| p95
  3.38/1.74 ≫ 1e−4，换均值 alpha 后 ΔMAE(y_raw) +1.76/+0.58）。本轮新增：Q 伤害
  与 g 误差质量在两臂**对称**（共享 Q，四组结构逐臂几乎相同），DICT 的微小 dev
  优势 83% 集中在 k=0 组。不声称字典优于普通编码，不改字典规格，不把 alpha 均值
  干预损失称为"字典贡献量"。
- **勘误 1（上轮 REPORT §2 措辞）**："fit/dev 方向一致"不成立：fit y_raw DICT 略差
  （0.04083/0.03778 vs 0.03962/0.03514，两 seed 平均 Δ +0.00193）、dev 略好
  （−0.00102），**方向相反**；两 seed 的 dev 优势不构成稳定的正则化收益。
- **勘误 2（上轮 REPORT §8c 措辞）**："s 分量 DICT 略好"不成立：四 run 平均 s
  MAE 未变好（RAW 0.08107 → DICT 0.08138），ell 变差（0.05357 → 0.05634），只有
  g 变好（0.09359 → 0.09257）；分量抵消 gap 0.0410 → 0.0451 只是误差合成变化。
  两处仅勘正文字，不改任何旧数值/roster/记录。
