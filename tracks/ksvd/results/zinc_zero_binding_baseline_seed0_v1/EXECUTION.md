## 4. Engineering deviations (recorded)

1. The two failed smoke attempts were local, <= a few seconds each, **before**
   the formal run and after no optimizer step of the formal recipe: the
   comparison model's `kappa` buffer was not filled before the state-dict
   comparison, and the bridge/reader gradient keys were looked up with the
   wrong prefix. Both fixed in `dc96fac`; the first successful smoke is the
   committed one.
2. The N0 slot probes (`_probe`, forward hooks) run under `eval()`/`no_grad`
   and consume no RNG; the recorded stream hash equals the frozen schedule
   hash, so training shuffle/dropout streams are not perturbed by diagnostics.
3. Slurm elapsed (20:14) includes container/setup overhead; the in-process
   training wall is 1189.2 s (`N0.json`). Both are reported; GPU billing uses
   the Slurm figure.
4. `rr pull` landed the snapshot in `.rr/pulled/zbb-n0-s0-…/result/…`; the
   five N0 files were copied from that snapshot into the results directory
   (byte-identical, verified by the hashes in `manifest.json`). No remote
   tracked file was edited on the compute copy at any point.
5. `N0.json` fit_raw is a GPU prediction; the local CPU replay differs by
   `5.7e-6` (same CPU/GPU float32 class of difference as the source round).
6. No execution-code file was modified after `dc96fac`; all later commits are
   documentation/artifacts only.
