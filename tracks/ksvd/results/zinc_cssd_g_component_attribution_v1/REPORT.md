## 1. 一句话决定

**s（剩余化学分量）确认为当前四个冻结消费者共同的主要样本外难点**：dev 上四个 run 的
MAE_s 惊人稳定（0.0804–0.0824，两臂两种子不变），MAE_ell 反而波动（0.0518–0.0590），
且 s 的 fit→dev 膨胀（×2.3–2.7）远大于 ell（×1.7–1.8）。s 误差有**两臂/两种子方向一致
的粗粒度条件**（小分子、含 N/O 组成），但它是覆盖常见分子的**宽幅梯度**，不是可分离的
少数失败子群（top-20 行只占 Σ|e_s| 的 7.7%，均匀参照 1.0%）。**字典替换在分量级别上
没有任何正效应**：DICT−RAW 配对差在 s 上为零（k=0 dev +0.0005，CI [−0.0015, +0.0026]）、
在 ell 上显著为正（+0.0027，CI [+0.0010, +0.0047]，DICT 更差），唯一的 g 微弱优势
（−0.0007）全部来自更强的行内抵消（triangle gap 0.0451 vs 0.0410）。**下一笔研究预算的
证据权重指向消费者（s 通道的读出/泛化）方向，不支持把"重新设计字典结构对象"作为下一项
研究的第一优先**；但本轮不能排除携带结构—化学联合统计的其他字典对象在别的接入方式下的
价值——只是当前证据不支持，且 dev 为历史开发集，只可作探索性定位。

读法：

1. **s 是主要样本外难点，且是四 run 共同的**：dev MAE_s/MAE_ell = 1.51 (RAW) / 1.44
   (DICT)；|e_s| 占两分量绝对误差的 59–60%。fit→dev 膨胀 s ×2.66/×2.37（RAW/DICT）
   vs ell ×1.81/×1.77。与 `zinc_chemistry_component_supervision_seed0_v1` 在新 COMP 模型
   上的独立发现（s dev-G0 0.083 vs ell 0.054）方向一致——两个不同训练轮都指向 s。
2. **镜像偏差结构**：全部四个 run 的 dev bias_s > 0 > bias_ell（fit 侧 bias_ell 亦全部
   为负），bias_g 在 ±0.009 内。读出把两个头当反向修正器使用，g 近无偏而分量偏差大
   （异号 54–62%，triangle gap 0.041–0.045）。这是消费者侧现象，与臂无关。
3. **DICT−RAW 配对差（dev k=0，canonical-SMILES 组 bootstrap 2000 次 seed 20261022）**：
   - e_s：+0.00053，CI95 [−0.00148, +0.00257]（跨零；两 seed −0.00001/+0.00097）；
   - e_ell：+0.00271，CI95 [+0.00101, +0.00447]（**DICT 在 ell 上显著更差**，两 seed 同向）；
   - e_g：−0.0007（k=0；全 dev −0.00102）——全部来自 DICT 更强的行内抵消
     （triangle gap 0.04513 vs 0.04104、异号 0.582 vs 0.558）。
   即：**字典通道在两个分量上都没有边际收益；其 g 微弱优势是读出几何效应**。这把
   consumer replacement REPORT 的"性能承接"和 triage 勘误 2 分量化坐实。
4. k 组（dev，两 seed 平均，贡献以全 N=1999 归一，加回检查精确 <1e-9）：k=0 的 C_g
   占 0.0892/0.0926（96%+），稀有 k 组 g 误差极小（k≤−3 两行的 |e_g| 仅 0.045——
   它们的巨差全在 Q，与本轮分量问题无关）；s 分量在 k=0 组内 MAE_s 0.0805/0.0800，
   k=−1（60 行）0.0987/0.1048，k=−2（7 行）0.1725/0.1678——稀有 k 上两臂同样对称。

## 5. 诊断 4：信息流与"是否需要重新定义结构—化学字典"

**当前部署信息流**（`notes/zinc_cssd_graph_information_sufficiency_v1.md` §2，已以代码
复核）：字典只供给 tuple 特征中的 phi65 块——phi65（每 root 纯拓扑 65D，无化学）→
冻结 `cssd_decode`（alpha 被丢弃，消费者只见重构 phi_hat）；**化学 one-hot28/28/4、
真实 J incidence、Sem108+size2、静态 relation、global_context、topology25、reader、Q
全部绕过字典**。RAW 臂同骨架保留原始 phi65（局部信息严格更多）。

**哪些数据不支持"字典对象已经不够、需要重新设计"**：

1. 分量级配对证据：替换为原始 phi65（RAW）既不改善 s（+0.0005 CI 跨零）也不改善
   ell（反而显著更差）——**字典重构不是当前局部接口的约束**（§3.3）。
2. s 难度两臂完全对称、四种 run 不变（0.0804–0.0824）——字典替换不触碰主导难点。
3. RAW 包容性：更多局部信息同样无效——"把局部对象做得更丰富"的朴素重设计方向
   （信息量维度）已被现有证据压制；`zldc`（可训练 IHT 局部字典劣于配对 MLP，差距
   在 s 通道）与 graph-information-sufficiency 分支 B（字典支持×共覆盖见证无增量）
   同向。
4. s 的误差条件（小分子、N/O）所需的化学信息**已经在消费者的旁路通道里**
   （one-hot28/28/4 + Sem108），消费者依然在这些子群上失败——瓶颈在读出/泛化，
   不在字典缺化学。

**哪些数据支持（或至少不排除）字典方向**：

1. s 是"剩余化学分量"，其难度条件是化学—尺寸条件，而当前字典对象（radius-2 无类型
   phi65 重构）按构造不含化学——"结构—化学联合统计的字典对象"在概念上仍是对准 s 的；
   本轮的阴性只覆盖**当前 phi65 拓扑对象与 RAW 替换对照**，不覆盖其他对象类。
2. 消费者本身的容量不是瓶颈的历史证据（`zldc` 中配对 MLP 同样在 s 上失败；
   graph-info 的头容量对照同样无信号）——纯"更大消费者"没有被支持过。

**综合**：这些数据**不能区分**"任何未来更好的字典对象"与"更好的消费者"这种一般性
命题（没有做也做不起该对照）；它们能说的是：在当前消费者、当前接入方式、当前对象
（phi65 拓扑重构）下，字典通道没有分量级正效应、没有子群特异失效，且主导难点（s）
两臂对称。按证据权重，下一步优先级在**消费者 s 通道的训练/泛化**（其镜像偏差结构、
小分子/N,O 梯度是明确的可作用面）；字典对象重设计当前**没有正证据购买**，只保持为
"未被排除"的远期方向。

## 6. 判读边界（如实声明）

- **dev 是历史开发比较集**（旧 select∪confirm，多次用于开发）：本轮全部 dev 结论是
  探索性定位，不是新确认；不据此宣称任何候选有效。
- 四个 run 共享同一消费者家族/数据/监督——两臂对称性不能排除该家族共同的泛化极限
  （triage 决策分支中"弥散→接近数据底噪"与"有子群梯度"之间，本轮测得的是后者：
  有稳定梯度、无主导子群）。
- 镜像偏差（bias_s > 0 > bias_ell）是描述结构，不是机制结论；不得据此直接改 COMP
  权重或加偏置校正候选（triage 已有先例约束）。
- k=−2/−1 共 67 行的 Q 尾部定位（triage 缺失信息 2）本轮未处理，Q 路线关闭与否
  维持 triage 的状态不变。
- 配对 bootstrap 只覆盖分子抽样（canonical-SMILES 组），不含训练 seed/基底不确定性；
  两 seed 方向一致性单独披露。
- 无因果解释；全部分组为预注册粗粒度描述统计。
