## 2. 「可行性」我们证明了什么 / 没证明什么

### 2.1 已有证据（算可行性的一部分）

| 类型 | 内容 | 对应 |
|------|------|------|
| **机制探针** | C4 vs C8：B0~0.85，RW+共享KSVD~1.0 | R1–R2：更大感受野能采到 1-hop 没有的闭包 |
| **可视化** | 环上 B0=P3，RW 可盖 C4 | R2 直观 |
| **负对照** | 错误任务上 RW 可劣于 B0 | 说明「不是 RW 万能」 |
| **文献定位** | 核/嵌入/SAINT/PE/GSN·CIN 角色表 | R3 骨架 |
| **工程** | 诱导子图→向量→共享D→\(s_v\)；多 walk pool | R2+R7 管道通 |
| **融合教训** | 节点级>广播；MUTAG 下游弱 | R7 后半 |

### 2.2 录音要求达标表

| 要求 | 状态 | 缺口 |
|------|------|------|
| R1 感受野动机 | ✅ 论述+C4+**RF 曲线** | `results/COVERAGE_RF_SUMMARY.md` |
| R2 RW 构子图再分解 | ✅ 管道+C4 | 分子下游仍弱 |
| R3 文献与约束 | ✅ v0.2 角色表+精读链 | 覆盖专文可再补 |
| R4 少重复覆盖 | ✅ **过程主表**+软降权 | 非理论最优，但是可测目标 |
| R5 非全点+软惩罚 | ✅ **coverage 采样**（分层/uncovered 种子+预算） | 节点级 GIN 仍可选用每点 walk |
| R6 忌硬删 | ✅ `hard_delete=False` 不变量 | — |
| R7 KSVD 后融合 | ⚠️ 试过 | MUTAG 几乎无增益（另表） |
| R8 非 CIN 刷榜 | ✅ | — |

### 2.3 结论（对「是否达到录音要求」）

| 问题 | 答案 |
|------|------|
| 可行性（机制）证明了吗？ | **部分证明**：闭包 motif 上 RW 相对 1-hop **可行且必要** |
| 录音清单全达标吗？ | **R1–R6 工程/过程侧已补齐**；R7 下游仍弱 |
| 任务有效性证明了吗？ | **否**；MUTAG 不能当「有效」主证据 |

**一句话：**  
**机制 + 覆盖/感受野过程指标**已按录音补实；**分子任务增益**仍未证明。

## 3. 若要把 KSVD 方案做到「CIN 级别」——指什么

CIN 级别 ≈ 同时具备：

1. **清晰结构对象**（环/cell）  
2. **结构进入计算图**（不只是弱特征）  
3. **表达力/机制故事**  
4. **分子数据上可辩护的增益**  
5. **可复现协议与完整训练体系**

KSVD 路线要对齐的是 **1–4 的问题层级**，不是抄 cell complex。

## 4. 通向 CIN 量级的思路菜单（由近到远）

### 路线 A — 采样做成「一等公民」（先补录音 R4/R5）

| 做法 | 作用 |
|------|------|
| **覆盖驱动 RW** | 边权随访问下降；目标：高覆盖、低重复（过程指标主表） |
| **每图少量种子 walk** | 非「每点一条」，更贴 R5 |
| **motif 感知偏置** | \(q\) 偏局部 / 环上停留；或禁止拆关键边（R6） |
| **多尺度 \(L,m\)** | 显式感受野曲线，对齐 R1 |

产出：采样论文式贡献 + 仍接 KSVD。

### 路线 B — 结构对象向 CIN 对齐（「学环」而非只采邻域）

| 做法 | 作用 |
|------|------|
| RW/枚举得到 **候选环或回路** 再字典 | 原子更像化学环 |
| 混合：小 \(k\) 环枚举 + 残余结构 KSVD | 人设 + 数据驱动 |
| 字典原子可视化/匹配到环 | 可解释，对标 CIN 叙事 |

产出：与 CIN **同一数据故事**（环重要），机制不同。

### 路线 C — 计算图升级（结构进入传播）

| 做法 | 作用 |
|------|------|
| \(s_v\) **残差/门控进每层 GIN**（已有弱版） | 结构参与 MP |
| **边级** \(s_i,s_j\) → GINE | 更贴键 |
| 双塔：属性 GNN ‖ 结构字典编码 → 融合 | 量级接近「完整模型」 |
| （远）可微稀疏编码 / 联合训 D | 端到端 |

产出：从「特征探针」到「可训练结构模块」。

### 路线 D — 数据与协议（CIN 同桌）

| 做法 | 作用 |
|------|------|
| **ogbg-molhiv** scaffold + atom/bond encoder | 主对标 |
| ZINC MAE | 第二主表 |
| 固定协议、多种子、与 GIN/GSN **同设定自跑** | 可辩护数字 |
| 小模型预算（~100k）对照 CIN-small | 公平量级 |

无 D，只有 A–C，仍难称 CIN 级别。

### 路线 E — 理论（可选加分）

| 做法 | 作用 |
|------|------|
| 固定感受野 patch 字典 vs 1-WL / 环可分性 | 对齐「>1-WL」叙事 |
| 覆盖约束下的信息保留 | 回应 R4 |

组内已有「一阶 >1-WL」口述，可写成引理级，非必须先于 D。

## 5. 推荐路径（务实）

```
阶段 1（录音补全）  A：覆盖指标 + 非全点种子 + 感受野曲线
阶段 2（表征变强）  B：环/回路候选进 Y，或混合枚举+KSVD
阶段 3（模型变完整）C：结构进入 MP（残差/边）+ 属性
阶段 4（同桌 CIN）  D：molhiv/ZINC 协议化主表
```

**不要**：在 MUTAG 上无限换 fusion。  
**不要**：未做 A/B 就宣称对标 CIN。

## 6. 对「RW 方案还要深入」的直接回答

| 问题 | 回答 |
|------|------|
| 方案还浅吗？ | **是**——实现是可行性探针，不是覆盖约束下的完整采样理论 |
| 可行性？ | **机制可行**已部分证明；**任务可行**未证明 |
| 录音要求？ | **动机+管道+部分文献**有；**约束采样主算法**未完成 |
| 到 CIN 级？ | 要走 **A→B→C→D**，把「环/结构对象 + 进计算图 + 分子协议」补齐，而不是只加深 walk |
