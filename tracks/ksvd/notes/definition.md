# 组内 KSVD 定义（luyin3 / 4 / 10 对齐）

> 决策笔记。数字进 `results/`；概念谱系仍以 `docs/literature/deep/concepts.md` 为准。

## 1. 一句话

**KSVD 轨**：把图的局部结构变成「可还原」的稀疏编码——学字典原子 \(D\)，用系数 \(X\) 表示每个子结构如何由原子线性组合而成；下游用 \(X\)（及可选 \(D\) 摘要）做分类/融合，而不是靠 MPNN 隐式聚合。

## 2. 相对谱系的位置

| 方法 | 结构从哪来 | 是否可还原 | 子结构来源 |
|------|------------|------------|------------|
| GNN | 消息传递 | 否 | 隐式 |
| GSN | 计数注入 MPNN | 否（计数非分解） | **人设** H（环/团等） |
| Kernel | WL 等特征 + 核 | 否 | 预定义过程 |
| **组内 KSVD** | 稀疏字典 \(Y \approx DX\) | **是**（重构残差可解释） | **数据驱动**原子 |

与 GSN 同属「显式结构」，差别在：GSN 预定义并计数；KSVD 从数据分解出原子。

## 3. 管道（当前基线版 = 一阶邻域）

```
图 G
  → 对每个节点 v：取一阶邻域结构信号 y_v（邻接/子图向量化；需固定节点排序约定）
  → 堆成 Y = [y_1 | … | y_n]（或批图内同构对齐后的列）
  → K-SVD：交替稀疏编码 X 与字典更新 D，使 Y ≈ D X（残差迭代 / K 次原子更新）
  → readout：由 X（可加 D 的使用统计/能量）压成定长向量
  → 下游：仅结构 MLP，或与节点属性融合（融合方式后议）
```

### 3.1 符号（组内约定）

| 符号 | 含义 |
|------|------|
| \(Y\) | 结构信号矩阵：列 = 一个节点的局部子图编码 |
| \(D\) | 字典：列 = **原子**（学出的「简单结构基」） |
| \(X\) | 稀疏系数：每列描述对应 \(y\) 如何用原子组合 |
| \(K\) | 字典更新轮次 / 原子相关超参语境中的「K 次」迭代 |
| \(T\) / sparsity | 每列 \(x\) 最多用几个非零原子（**必须显式设定**，见 luyin4：未设则易退化到 1–2 个原子） |

### 3.2 K-SVD 在组内口述中的机制

1. 稀疏编码：固定 \(D\)，求稀疏 \(X\)（OMP 等）。  
2. 字典更新：逐原子（或残差）做 SVD，更新 \(D\) 列，再更新对应系数。  
3. 交替直至重构误差 / 能量准则稳定。  
4. **\(D\) 与 \(X\) 一起学**；不能默认「字典事先固定且跨图相同」——跨图对齐是工程问题，需单独约定（共享字典 / 每图字典 + 仅比系数形态等）。

### 3.3 Readout（定长）

下游需要同维输入。组内可行方向（luyin3）：

- 对 \(X\) 的行/列做 sum / mean / max；  
- 或「原子使用次数 / 能量」直方图；  
- 是否拼接 \(D\) 本身：可选；**仅比结构是否相同**时有时只靠 \(X\) 形状，但跨图比较仍依赖字典可对齐。

## 4. 理论边界（已讲、待写证明稿）

| 结论 | 内容 |
|------|------|
| 下界 | 一阶邻域 KSVD 表征 **严格强于 1-WL**（组内已有证明思路） |
| 上界 | 表达力受 **感受野** 限制；存在 3-WL 可分而本方法（固定感受野）不可分的反例 |
| 扩大感受野 | 全图 \(k\)-hop 很快占图很大比例（小图 3–4 阶往往已很大）→ 复杂度高、意义有限 |

**表达力 ≠ 下游 Acc**（与 GNN/GSN 轨同一纪律）。

## 5. 一阶基线的已知缺陷（luyin10）

1. **感受野过小 / 过粗**：只看 1-hop，上限清楚。  
2. **边冗余**：每个节点抽邻域 → 同一条边被多次计入，编码有冗余与偏置。  
3. **子结构选择过简单粗暴**：非数据驱动的「子图采样」，只是星形/一阶块。

## 6. 本轮新方向（导师 luyin10，未定型）

**目标**：在不大到「半张图」的前提下扩大有效感受野，并减轻边冗余。

**设想**：

1. 用 **随机游走（RW）** 从节点/边出发构造待分解子图（或结构信号），替代「全体一阶邻域硬切」。  
2. 约束（理想）：边/节点被覆盖 **尽量恰好一次** 或少重复（非硬删，可软约束）。  
3. 在 RW 得到的子结构上再跑 **KSVD**，保证原子仍有「可还原、数据驱动」意义。  
4. 下游：结构能量 readout → 分类；有节点属性时 **融合**（方式后议）。

**风险（学生当场反例）**：关键 motif（如某碳连四氢）若从氢出发游走并「删边」，可能拆坏标志结构。→ 约束与采样策略是研究点，不是实现细节。

**近期任务（导师原话优先级）**：

1. 调研图上随机游走：约束、覆盖、图核/子图采样相关文献。  
2. 再共同定：RW → 子图 → KSVD → readout 的最小形式化。  
3. 实验后置；需要时再跑。

## 7. 明确不做（本阶段）

- 不重开 GNN/GSN 全库横比主战场（archived `gnn-gsn`）。  
- 不与旧轨结果混协议进同一主表。  
- 不把「RW 一定优于 1-hop」当已证结论。  
- 不先做复杂融合/Transformer 大改，直到基线 \(Y,D,X,\) readout 写清并可复现。
