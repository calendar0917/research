# 采样实现细节 · 指标是否够 · 低重复 vs 节点系数

## 1. 具体怎么实现的

代码：`code/coverage_sample.py`（图级覆盖采样）  
节点级 GIN 用的是另一条：`code/node_struct.py`（**每点** r 条 walk）——**两套模式，目的不同**。

### 1.1 少重复（软惩罚，不硬删）

```
每条边初始 weight = 1
走完一条轨迹后，对轨迹上的边：
  weight[e] *= edge_decay   # 默认 0.7
下一次选边：转移概率 ∝ node2vec_α(p,q) × weight[e]
```

- **没有**从邻接表删边；图 G 始终完整（R6）。  
- 「少重复」= 已被走的边在**后续采样分布**里变难走，不是结构消失。

### 1.2 非全点（种子策略）

在 `max_walks` 预算内选 **起点**，不是默认「每个点一条」：

| `seed_policy` | 做法 |
|---------------|------|
| `degree_stratified` | 按度分低/中/高桶，轮转随机抽起点 |
| `uncovered` | 优先选「邻边平均 weight 仍高」的点（局部未充分走） |
| `random` | 均匀随机起点 |
| `all_nodes` | 对照：每点至少一个起点 |

可 `cover_target` 早停：轨迹边覆盖率 ≥ 阈值则停。

### 1.3 一条 walk 产出什么

```
start → node2vec_walk → 节点序列
  → 去重 cap 到 max_nodes 得 S
  → 诱导子图 G[S] 作为 patch
```

### 1.4 和「节点系数拼接」的关系

| 模式 | 用途 | 是否每点 walk |
|------|------|----------------|
| **Coverage 图级** | 录音 R4/R5 过程指标；将来图级字典 \(Y\) | **否**，少量种子 |
| **NodeStruct 节点级** | 给每个 \(v\) 一个 \(s_v\) 拼 GIN | **是**，每点 r 条 |

**不能**用「coverage 低重复」直接当「节点级特征也该全局不重复」。

## 2. 评判标准够不够？

### 2.1 现有

| 指标 | 数据 | 规模 |
|------|------|------|
| traj cover / repeat | 1 张合成环+弦 n=24,e=28 | 很小 |
| c4_hit RF 曲线 | C4 vs C8，**每类 80 图**（共 160）n=14 | 中小探针 |

### 2.2 够什么 / 不够什么

| 目的 | 是否够 |
|------|--------|
| 演示覆盖算法 + 软降权可测 | ✅ 够 |
| 演示感受野增大 → 闭包 motif 命中上升 | ✅ 够（单 motif 族） |
| 证明采样对**一般图/分子**都好 | ❌ 不够 |
| 证明下游有效 | ❌ 从未用这些指标代替 Acc |

**C4 单一**是刻意的**机制探针**（1-hop 理论上看不见闭包），不是完整 benchmark。  
要加厚应：再加 1–2 个 motif（如 C6 vs 两弦）、或分子小图上的「环是否进 patch」统计——仍属过程层。

## 3. repeat 更低是否合理？会不会丢节点结构？

### 3.1 指标本身

- `traj_edge_cover`：轨迹边覆盖比例（采样是否摸到边）  
- `traj_edge_repeat`：重复走的「多余次数」质量  

在 **固定预算、目标高覆盖** 时，**更低 repeat 更好**（同样 cover 用更少重复劳动）。  
合理前提：**和 cover 一起看**；cover 低时 repeat 低没有意义。

### 3.2 和节点系数会不会冲突？

**会冲突，如果混用目标。**

| 目标 | 对「重复」的态度 |
|------|------------------|
| **图级覆盖采样**（录音：少冗余、少全点） | 希望全局边少重复 |
| **节点级 \(s_v\)** | 每个 \(v\) 需要自己的局部 patch；**邻居共享边被多个 \(v\) 看到是正常的** |

若强行「全图每条边只进一个 patch」再给节点拼系数：

- 某些 \(v\) 的邻域边可能被别的种子「占走」→ **该点结构被抽空**  
- 违反「节点结构特征应描述 **v 自己的** 局部」

因此：

1. **Coverage 低 repeat**：只评价 **图级 / 字典语料 \(Y\) 怎么采**，或「用多少 walk 覆盖图」。  
2. **节点级 \(s_v\)**：允许甚至需要 **局部重叠**（同一条边出现在多个 \(v\) 的 1-hop/RW 里）。  
3. 节点级若要「少冗余」，应是 **对单个 \(v\) 的 r 条 walk 之间** 降权，而不是跨节点禁止共享边。

### 3.3 推荐口径

```
过程主表（录音 R4/R5）：coverage 模式 + cover/repeat
表征/下游：node 模式 + 允许跨节点重叠；可选「同一 v 的 walk 间」soft decay
```

---

## 4. 一句话

实现上：软降权 + 分层/未覆盖种子 + 预算/早停。  
指标上：C4+小合成只够 **机制/过程**，不够当全面有效性。  
repeat 低在 **图级覆盖** 合理；**节点系数拼接不应追求全局边不重复**，否则会丢节点结构。
