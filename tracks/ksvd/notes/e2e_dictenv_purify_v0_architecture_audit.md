## 4. Audit findings

### F1 — local chemistry has **two structurally different entries**

There are two entries through which the *local* chemistry enters `E_i`:

**(a) dictionary-mediated (structure-conditioned) chemistry — 2 tensors**:

```text
alpha_v per shell     x  atom category q_v         -> W_A_S / W_A_C   (288 per root)
edge structural role  x  bond category b_uv        -> W_E_S / W_E_C   (288 per root)
```

Here chemistry is *valued on the basis*: the atom/bond category only ever
interacts with the sparse structural coordinate through an elementwise product,
so chemistry cannot reach the environment without the structure coordinate
(A2/P1 established that this pairing carries task value).

**(b) independent raw-chemistry bypass — the 62-D anchor `p_i` (M8/M11)**:

```text
root atom identity          28   (q_i, raw one-hot)
patch atom marginal         28   (sum_{v in P_i} q_v, no shell grouping)
patch bond marginal          4   (sum_{e in E_i} b_e, no shellpair grouping)
size                         2   ([log1p|V_i|, log1p|E_i|], pure structure)
```

These 60 chemistry dims do **not** pass through `alpha` or through the
dictionary; they enter the environment through their own 62->32->32 encoder and
12 % of the fusion input.  From the T1 lesson this is exactly the shape of
pathway that can make the dictionary auxiliary when it is wide enough (T1
`patch_cont` 146-D: `G_zero` 0.855 -> 0.0179).  In P1/H1 the bypass is narrow
(60 dims, whole-patch marginals only) and P1 measured that the dictionary stays
load-bearing (`G_zero` 0.3471, `G_node` 0.0131), so this is **not** a measured
defect — it is the *representational* inhomogeneity this round asks about.

**Counts (reference): local chemistry entry tensors = 5**
(`W_A_C`, `W_E_C`, anchor root identity, anchor atom marginal, anchor bond
marginal); **local raw-chemistry bypasses = 3** (the three anchor blocks);
**structure-conditioned entries = 2**.

### F2 — global chemistry has an additional independent entry (different scope)

`global_context[30:62]` is a whole-molecule atom marginal (28) plus a
whole-molecule bond marginal (4) and is encoded by the same 62->32->32 MLP as
the 30-D pure-topology block.  Its *scope* is the whole graph, not an
overlapping radius-2 patch, so it is **not** assumed redundant with F1(b).
This round (i) keeps it, and (ii) renames/structure it as an explicit object —
`GlobalZerothOrderAttributeMeasure` — distinct from
`GlobalStructuralInvariant` (`global_context[0:30]`).  The encoder itself stays
fused (one MLP over 62 dims) because changing it would break Stage-0
functional equivalence and would confound the single purification principle.

### F3 — global pure topology is **not** a redundancy candidate

`global_context[0:30]` (cycle / structural statistics) and
`topology_features` (25-D, M19) are kept unconditionally.  A radius-2 local
dictionary cannot in general recover long-range/global invariants; nothing in
this audit suggests they are redundant.

### F4 — parameter concentration

`fusion` (M12) alone is 54.8 % of all parameters and the whole H1 decoder
(M9-M12) is 71.5 %; the dictionary plus both bindings are only 13.0 %.  So the
"clean dictionary core" is parameter-light and the read-out of the local
environment is parameter-heavy.  This is recorded so that the purification
result is not confused with a capacity effect: the purified candidate must have
`<= 97,487` trainable parameters and identical decoder widths (`32 + 3*48 +
6*32 = 368 -> 128 -> 48`).

### F5 — verified non-issues (checked, keep)

| check | finding |
|---|---|
| pair composition (M13-M16) | fully pure-topology + `E_i`-only; no pair chemistry beyond the edge binding; **frozen this round** |
| distance gate (M15) | a monotone re-weighting of the pair product; no chemistry; **frozen** |
| reader (M21) | one 2-hidden-layer MLP on 302 inputs; no normalization/dropout/attention; **frozen** |
| dictionary design (M2/M3) | K=32, s=8, IHT=10, exact top-8, trainable `D`, tied reconstruction, SDB-v0 K-SVD init; **frozen** |
| pair→centre / message passing / recurrence / attention | absent (enforced by P1 gates G9-G11) |
| official test | never loaded in this round |

### F6 — the exact local-chemistry redundancy hypothesis of this round

> The 60 raw-chemistry dims of the 62-D anchor (root identity, patch atom
> marginal, patch bond marginal) can be absorbed by a *unified attributed
> structural measure*: a fixed constant structural channel `1` concatenated
> with the sparse structural coordinate `alpha`, valued by the existing atom /
> bond matrix, with the anchor reduced to the 2 pure-structural size scalars.

Only that one change is authorized this round (one purification principle per
round).  Honesty boundary: adding a constant structural channel changes the
*organization* of zeroth-order chemistry — it becomes routable through the same
shell / shellpair structure as the structure-conditioned part, so it is not
information-byte-equivalent to the old anchor.  That is intentional
consolidation, and it is not claimed to be "just deleting a branch".

buckets, the topology branch or the reader; no node/edge decoder unification; no
fusion-width change; no dictionary capacity or sparsity change; no coder change;
no attention / message passing / recurrence / residual bypass; no new feature;
no radius change; no optimizer or lambda sweep; no official test.
