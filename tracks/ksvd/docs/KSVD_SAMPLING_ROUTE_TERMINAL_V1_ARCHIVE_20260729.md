# KSVD / 采样路线终局机制报告（2026-07-29）

> 本报告回答 `docs/luyin/luyin10.txt`、`luyin11.txt` 中关于 patch、随机游走、置换不变、字典共享和 patch 关系的问题。重点是判断机制是否成立，而不是追 TUData 排行榜。

## 1. 实验问题与统一协议

- 统一预算：每图 8 个 patch，每个最多 8 个节点；游走最多 16 步。
- 采样器：一阶邻域 B0、二阶邻域 R2、普通随机游走、覆盖优先随机游走、自避免路径、PPR 扩散。
- patch 表示采用不依赖节点编号的 WL 统计；TUData 同时纳入节点标签。
- 每折字典只用训练折 patch 学习；固定 8 个字典原子、每个 patch 最多使用 2 个原子。
- `内容`：忽略 patch 位置，只统计字典原子的出现；`真实关系`：保留中心相邻与 patch 重叠；`打乱关系`：保留内容袋和关系图，只随机错配两者。
- TUData 没有这里所称的官方划分，采用固定 5 折分层交叉验证；数字不可直接当作论文 benchmark。

## 2. 关系模块正控制

任务：12 节点环，两类图拓扑完全相同、A/B 节点各 6 个；一类交替排列，另一类成块排列。只有相邻关系不同。

| 读出 | Acc |
|---|---:|
| raw patch 均值 | 0.500 |
| KSVD 内容袋 | 0.500 |
| 仅真实关系 | 1.000 |
| 内容 + 真实关系 | 1.000 |
| 内容 + 打乱关系 | 0.531 |

这个正控制用于确认：如果类别真的由‘什么 patch 与什么 patch 相邻’决定，关系读出能够识别；而打乱对应后应失效。

## 5. 终局判断

### 已经成立的部分

1. 节点重编号不应通过排序硬修；不变统计可以直接解决表示随编号变化的问题。
2. 随机游走不是必要条件。真正有用的是在固定预算下获得更大的、且与任务匹配的有效范围。
3. patch 关系可以被轻量矩阵读出保留，不必先上完整 GNN；正控制检验了实现本身。
4. 重建误差、采样覆盖率和分类效果是不同指标，不能互相替代。

### TUData 是否支持把关系/采样作为性能主线

没有组合满足预先的关系晋级标准。若真实关系与打乱关系接近，说明当前字典原子尚未形成可跨图泛化的关系语义。

### KSVD 是否应继续作为核心

判断应直接比较表中的 `raw mean` 与 `KSVD 内容`：若 KSVD 没有跨数据集稳定超过不学字典的原始 patch 均值，那么字典学习不是主要增益来源，不应继续作为核心词汇；最多保留为压缩、解释或诊断工具。

### 建议

- 若真实关系稳定高于打乱：保留‘不变 patch + 轻量关系矩阵’，优先研究更有语义的 patch，而不是加深 GNN。
- 若只在合成图有效：明确停止性能主线，把它定位为机制与解释实验。
- 若某个采样器只提高覆盖率、不提高分类且降低 seed 稳定性：淘汰该采样器。
- 不再以更低重建误差作为继续 KSVD 的理由。
