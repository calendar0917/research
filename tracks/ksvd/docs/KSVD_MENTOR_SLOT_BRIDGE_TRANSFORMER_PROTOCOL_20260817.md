# 槽位—共享节点桥 Transformer 协议

> 日期：2026-08-17  
> 前置结论：每个局部块只有一个整体词元时，关系优于无关系，但正确绑定不优于打乱绑定。

## 核心修改

每个 8 节点局部块不再先压成一个整体统计向量，而是保留 8 个规范槽位。每个槽位输入：

- 该节点在局部块中的完整邻接行；
- 局部度；
- 是否为局部块中心。

目标局部块被整体移除。其他局部块先进行块内注意力，再进行块间注意力。若目标槽位对应的真实节点也出现在其他局部块中，则通过共享节点桥聚合这些可见槽位状态。

最终预测目标局部块完整的 28 维上三角邻接。

## 三个等容量对照

1. `NO_BRIDGE`：删除全部共享节点桥；
2. `TRUE_BRIDGE`：把可见槽位状态送回正确目标槽位；
3. `SHUFFLED_BRIDGE`：保留完全相同的桥状态多重集合，但循环分配给错误目标槽位。

三个分支的局部块内容、模型容量、初始化、训练轮数和全局上下文完全一致。

## 数据与门槛

- 导师 50 节点子图库冻结 100 图选择；
- 三折根候选分组；
- 不使用图标签、源节点编号嵌入、KSVD、GIN/GINE；
- 正确桥相对无桥和打乱桥均至少降低 2% RMSE；
- 两项比较均至少赢 2/3 折。

通过后才扩展模型种子并迁移到 MolHIV。失败时说明当前 Beam8 精确共享节点关系即使在槽位粒度下也没有稳定重构价值，不再通过增加普通注意力容量补救。
