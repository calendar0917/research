日期：2026-07-29

## 一、我认为导师真正关心的不是“随机游走本身”

从 `luyin10` 第 445–669 行和 `luyin11` 的四条记录来看，核心问题可以概括为：

> 能不能把一张图拆成一组可比较、可还原的局部结构，再从这些局部结构恢复对整张图有用的信息？

这里有四个相互独立的环节：

1. **怎么取局部结构（patch）**：一阶邻域、二阶邻域、随机游走，或者其他方法。
2. **怎么把一个 patch 变成不受节点编号影响的向量。**
3. **KSVD 学到的字典是否真的形成了跨图可比较的结构“词汇”。**
4. **多个 patch 如何重新组成一张图，而不是只做无序统计。**

随机游走只属于第 1 步。它不是整条路线的核心，也不应该预先假定必须使用。

## 二、问题 1：KSVD 的重建指标应该怎么设计？

### 2.1 导师的问题

`luyin11` 第 1–2 行指出：单看 `Y≈DX` 的重建误差，只说明字典能否还原多个 patch，并不直接说明整张图的表示好不好。

这是正确的。当前路线过去有时把“重建得好”与“结构表示得好”靠得太近，需要明确拆开。

### 2.2 当前回答

**不能用一个重建误差同时评价 patch、字典、图表示和分类。应分四层评价。**

#### 第一层：patch 是否被还原

只在**同一种 patch 构造、同一种向量化、同一种归一化**下比较：

- 每个 patch 的相对误差：`||y-Dx|| / ||y||`；
- 误差的均值、中位数、90% 分位数和最大值；
- 训练折与验证折误差的差距。

这一层回答“字典是否覆盖了输入 patch 空间”，不回答“图分类是否更好”。尤其不能直接拿一阶 patch 的误差和随机游走大 patch 的误差比较，因为后者本来就包含更多、更复杂的信息。

#### 第二层：字典是否健康、稳定

至少检查：

- 每个 patch 实际用了多少个字典原子；
- 是否存在几乎从不使用的“死原子”；
- 原子之间是否高度重复；
- 换一次训练样本或随机种子后，原子能否匹配回来；
- 同一张图多次采样后，稀疏码是否稳定。

这里原子的顺序和正负号本身没有意义，因此比较两个字典时要先做原子匹配，不能直接逐列相减。

#### 第三层：patch 汇总后是否形成稳定的图表示

应检查：

- 节点重新编号后，图向量是否不变；
- 随机游走重复采样后，图向量变化有多大；
- 同一个图的不同采样是否比不同图更接近；
- 是否有大量不同图被压成几乎相同的向量。

#### 第四层：是否对下游任务有用

使用训练折学习共享字典，在验证折上评价固定分类器。最终指标可以是 accuracy 或 ROC-AUC，但必须与前三层同时报告。

### 2.3 小实验结果

MUTAG 五折实验中，改变字典大小得到：

| 字典大小 | 验证 patch 重建误差 | 稀疏码图表示 Acc | 稀疏码+重建统计 Acc |
|---:|---:|---:|---:|
| 4 | 0.0021 | 0.829 | 0.867 |
| 8 | **0.0002** | 0.835 | 0.846 |
| 16 | 0.0013 | 0.824 | 0.851 |
| 32 | 0.0018 | **0.840** | **0.867** |

字典大小 8 的重建误差最低，但分类并不是最好。更强的反例来自合成图：

- 一阶 patch：重建误差 `0.0039`，分类 `0.500`；
- 随机游走 patch：重建误差更高，为 `0.0275`，分类却为 `1.000`。

因此可以明确回答导师：

> **重建误差是必要的诊断量，但不是图表征优劣的主指标。** 它最多说明“输入 patch 能不能由字典表示”，不能说明“这些表示能不能区分整张图”。

另外，MUTAG 上“重建误差分布本身”也能取得约 `0.84–0.86` 的分类率。这不意味着重建误差就是好字典的标准；它可能在利用图大小、patch 类型多少和异常程度。它应该被视作一种图特征，而不是字典质量的唯一评价。

### 2.4 建议给导师的简短回答

> 我们准备把评价拆成四层：patch 重建、字典稳定性、图表示稳定性、下游分类。重建误差只在相同 patch 空间内比较。小实验已经看到，误差最低的字典并不是分类最好的；甚至一阶 patch 可以近乎完美重建，却完全不能区分两个全局结构不同的图。因此后续不会再用重建误差单独判断方法优劣。

## 2.5 理论表达力更强，是否就应该有更高分类准确率？

`luyin10` 第 470–475 行提出的这个质疑也完全成立。图同构区分能力只回答“两个不同结构有没有可能被表示成不同结果”，并不回答：

- 数据集标签是否真的由这种结构差异决定；
- 样本量是否足以学会使用这种差异；
- 更强表示是否同时引入了更多噪声和过拟合；
- 优化过程能否找到正确参数。

现有证据正好说明两者必须分开：C4 合成任务证明更大感受野具有机制优势，但 MUTAG 上 RW 与节点级 KSVD 没有稳定超过 GIN，MolHIV 上 valid 的提升也没有稳定转化为 test 提升。因而后续应把论文命题拆成：

1. **表达力命题**：构造严格控制的合成图，证明哪些结构可以/不可以区分；
2. **任务收益命题**：在真实数据、严格验证协议下证明泛化收益。

不能用其中一个替代另一个。

## 三、问题 2：邻接矩阵的置换不变性怎么解决？

### 3.1 导师的问题

`luyin10` 第 359–369 行讨论了“能否给一般图找到唯一排序”；`luyin11` 第 4–6 行提出两种想法：使用统计式 patch，或者采用多种排序指标，而不只按度排序。

### 3.2 当前回答

需要区分三件事：

1. **patch 选取规则**在节点改名后是否仍选到对应的节点集合；
2. **patch 向量化**是否不依赖节点编号；
3. **多个 patch 的汇总**是否不依赖 patch 顺序。

当前最需要修正的是第 2 点。

#### 仅靠排序并不能严格解决

按度排序、BFS 排序都可能遇到平局。旧实现用节点编号打破平局，因此同一张图改一次节点编号，邻接向量就可能改变。把多种排序结果拼起来也不能消除这个问题，因为每种排序仍可能依赖节点编号。

MUTAG 80 张图、每张 8 次随机重编号，共 640 次比较：

| 表示 | 随机改编号后的平均相对变化 | 完全相同比例 |
|---|---:|---:|
| BFS 排序邻接 | 0.830 | 9.1% |
| 度排序邻接 | 1.276 | 0% |
| BFS+度排序拼接 | 1.097 | 0% |
| WL 统计表示 | 0 | 100% |
| 带节点标签的 WL 表示 | 0 | 100% |

因此，“一般图大多能排出唯一顺序”不能作为方法保证。分子图中相同碳原子和对称支链很常见，恰恰容易产生平局。

#### 当前可行方案

- 如果使用邻接矩阵，需要真正的 canonical labeling（规范化编号），不能只用简单排序冒充；
- 更稳妥的工程方案是用不依赖节点顺序的统计表示，例如度分布、边两端度数分布、WL 颜色直方图、节点/边标签直方图；
- 节点特征可以进入 WL 更新，因此“不变性”和“使用节点特征”并不冲突；
- 对多个 patch 用 sum/mean/max 汇总，可以保证 patch 顺序不影响结果。

但 WL 统计也有边界：它是不变的，却不一定能区分所有非同构 patch。这里是“保证不随编号变化”和“能区分多少结构”两个不同问题。

### 3.3 当前代码状态需要明确

- 早期 `topo` 的 padded adjacency + BFS/度排序**不是严格置换不变**；
- 后续 MolHIV 路线使用的 WL/带化学标签的 WL patch 是置换不变的；
- 以后机制实验不应再把旧 `topo` 结果作为严格不变方法的证据。

### 3.4 建议给导师的简短回答

> 我们验证后发现，仅按度或 BFS 排序不能严格解决置换问题，增加多种排序也不行，因为平局最终仍由节点编号打破。MUTAG 随机重编号实验中，两种排序拼接的完全一致率仍是 0。当前更可靠的方案是直接使用不依赖节点顺序的 WL/统计式 patch；节点标签也可以放进 WL 更新中。后续会把“置换不变”和“区分能力”分开评价。

## 四、问题 3：随机游走到底是不是必要的？

### 4.1 导师的原意

`luyin10` 第 605–669 行已经说得很谨慎：希望借随机游走扩大感受野，但并不确定随机走出的形状是否有意义。`luyin11` 第 8 行进一步明确：“不一定是随机游走，只是一个解决问题的思路”。

### 4.2 当前回答

**随机游走不是理论核心，只是“如何构造较大而又不过大的 patch”的一个候选算法。**

真正的问题是同时满足：

- 比一阶邻域看得更远；
- 不一下子吞掉整张图；
- 尽量覆盖有用边；
- 不因重复采样产生太多冗余；
- 不因为硬删除访问过的边而破坏关键结构。

可以比较的候选包括：

- 确定性的二阶/三阶邻域；
- 限长最短路径或路径集合；
- 随机游走；
- PPR/扩散得到的高相关节点集合；
- 从局部环或高密度区域向外生长的 patch；
- 学习式采样器。

### 4.3 小实验结果

我们构造了两类 8 节点图：立方体图与 Möbius ladder。它们都是连通、3-正则、无三角形图，因此每个节点的一阶邻域都是同一个 `K1,3` 星形。

| patch 构造 | KSVD 图分类 Acc |
|---|---:|
| 一阶邻域 B0 | 0.500 |
| 确定性二阶邻域 R2 | 1.000 |
| 随机游走 RW | 1.000 |

这说明需要的是**更合适的感受野**，而不是随机性本身。至少在这个问题上，二阶邻域和随机游走都能解决，而二阶邻域更稳定、重建也更容易。

已有实验同时表明，随机游走并非总是更好：当一阶 patch 已经包含判别结构时，随机游走会把清晰的局部信号混在更大 patch 中，反而下降。

### 4.4 patch 是否存在硬限制？

理论上没有固定的“必须小于多少节点”。限制来自表示方式与计算：

- padded adjacency 必须预设 `max_nodes=m`，超过后会截断，维数约为 `m²`；
- WL 直方图不必截断邻接矩阵，但大 patch 会混入更多无关结构，且多个图可能很快接近整图；
- patch 越大、不同 patch 重叠越多，计算和冗余也越大。

所以 patch 大小不是理论禁令，而是一个需要用“命中有效结构—噪声—计算量”曲线选择的参数。过去 C4 探针中，`m=8,L=8` 是经验平衡点，不是普遍规律。

### 4.5 关于“访问过的边尽量不再走”

CoverageRW 已经实现软降权而不是硬删除，也证明能减少 walk 数。但它只控制“游走轨迹重复”，不能保证“诱导子图中的边不重复”，也不能保证一定保留任务关键结构。因此这一部分只能说**实现了导师设想的初步版本**，不能说理论问题已经解决。

### 4.6 建议给导师的简短回答

> 我们现在把随机游走降级为候选采样器，核心问题改成“如何构造受控的大感受野 patch”。在一个一阶邻域完全相同的合成任务上，一阶方法只能 50%，二阶邻域和随机游走都能 100%，说明起作用的是感受野而不是随机性。下一步应在统一预算下比较二阶邻域、随机游走和路径/扩散采样，而不是继续只调随机游走参数。

## 五、问题 4：当前 patch 只是片段，片段之间的关联没有解决

### 5.1 导师的判断是准确的

当前图级流程基本是：

1. 每个 patch 单独编码成稀疏码；
2. 对所有稀疏码做 mean/max/usage 等统计；
3. 得到整图向量。

这个操作把 patch 当作一个无序的“袋子”。交换任意两个 patch 的位置，输出完全不变。因此以下信息会丢失：

- 哪两个 patch 相邻；
- 哪些 patch 共享节点或共享边；
- 某个结构原子出现于图的同一侧还是相隔很远；
- 多个局部结构按什么顺序组成更大结构。

### 5.2 小实验给出的直接证据

立方体图与 Möbius ladder 的一阶 patch 多重集合**完全相同**。因此无论 KSVD 字典多强，只要每个 patch 独立编码后再做无序汇总，就不可能区分它们。实验结果正好是 `0.500`。

二阶 patch 或随机游走达到 `1.000`，是因为它们把一部分“patch 之间的关系”包进了更大的单个 patch。这是一个临时补救，但图再大时不能无限扩大 patch。

### 5.3 可以怎样补上关系？

有三个由轻到重的方案。

#### 方案 A：结构原子的邻接/共现矩阵（优先做）

对相邻或重叠的 patch，统计字典原子 `a→b` 的共现：

- patch 共享节点；
- 两个中心节点在原图中相邻；
- 一条随机游走中前后出现。

最后得到一个小的 `D×D` 关系矩阵，再做低维读出。它比完整 GNN 简单，而且 KSVD 字典仍是核心词汇。

#### 方案 B：构建 patch 图，做一层很轻的传播

- patch 作为新图的节点；
- 稀疏码作为 patch 节点特征；
- patch 重叠或原图相邻作为边；
- 只做一层共享参数聚合。

这是“参考子图 GNN 聚合结构信息”的直接实现，想法本身合理。但必须设置控制：如果去掉 KSVD 码、只用普通 patch 图 GNN 也一样好，那么创新点不在 KSVD。

#### 方案 C：直接使用更高阶子图 GNN

表达力可能最强，但最容易退化成“另一个 GNN 主干 + KSVD 旁支”，同时参数量和创新边界都不清楚，不建议现在直接上。

### 5.4 一个重要限制

把 patch 构成图，再套普通一阶 GNN，并不自动解决问题。上面的两个合成图都是规则图；如果所有 patch 初始码完全相同，普通消息传递仍可能无法区分。关系模块需要与更丰富的 patch 内容、重叠类型或更高阶统计结合，而不是简单“再加一层 GNN”。

### 5.5 建议给导师的简短回答

> 当前方法确实只保留了 patch 的内容分布，没有保留 patch 怎样连接。我们用两个一阶 patch 多重集合完全相同、但整图不同的合成图做了验证，现有袋式读出只能 50%。下一步最小改动不是直接堆一个大 GNN，而是先统计相邻/重叠 patch 的字典原子共现，形成一个小的原子关系矩阵；如果这个机制成立，再考虑一层轻量 patch 图传播。

## 六、节点特征是否被充分利用？

### 6.1 回答

早期 KSVD 路线大多只分解邻接结构，节点特征往往在后面的 GIN/GINE 中使用。这会导致 KSVD 字典学到的是“纯拓扑词汇”，不能区分拓扑相同但原子类型不同的 patch。

节点特征可以在不破坏置换不变性的前提下进入 patch：把节点标签作为 WL 的初始颜色，再按邻域标签集合更新。这样字典原子描述的是“结构 + 节点类型”的联合模式。

### 6.2 MUTAG 小实验

| 表示 | 5-fold Acc |
|---|---:|
| 全图节点属性统计 | 0.851 |
| 纯拓扑 patch + KSVD | 0.835 |
| 带节点标签的 patch + KSVD | 0.877 |
| 带标签 patch + 全图节点属性 | 0.888 |

这说明节点标签进入字典在 MUTAG 上有正向作用，而且置换测试仍是 100% 一致。

但这不能被解释成“KSVD 已经解决了任务”：

- MUTAG 很小；
- 没有做超参数搜索和严格 nested CV；
- 节点标签本身已经很强；
- 结果只说明该机制值得保留。

### 6.3 字典是否应该与任务匹配？

建议先保持以下分工：

- 字典用训练图无监督学习，形成跨图共享的结构/属性词汇；
- 下游监督模块学习哪些原子以及哪些原子关系与标签有关。

这样可以避免用标签直接塑造字典导致过拟合，也更符合导师最初“数据驱动地学习结构原子”的想法。过去 MolHIV 的标签增强字典并没有得到稳定收益，因此现在没有证据支持把监督式 KSVD 作为核心。

## 七、对当前路线的重新定位

### 7.1 已经可以回答的

1. 一阶邻域确实有感受野上限；
2. 随机游走可以扩大感受野，但不是唯一方式，也不是总有益；
3. 共享字典是跨图比较的必要条件；
4. 简单度/BFS 排序不能保证置换不变；
5. 重建误差不能代替图级评价；
6. 当前袋式读出确实丢失 patch 之间的关系；
7. 节点特征可以在保持不变性的条件下进入字典。

### 7.2 还不能回答的

1. 什么 patch 构造在真实图上最稳定；
2. 字典原子是否在不同训练折中保持同样语义；
3. 原子关系矩阵是否比普通局部统计更有用；
4. 这种关系表示能否在 TUData 多数据集上稳定超过节点属性/GNN 基线；
5. 如何从稀疏码近似还原“整图”，而不只是还原独立 patch。

### 7.3 我建议下一步只做两个动作

#### 动作 1：先完成“小型 patch 关系闭环”

在合成图和 MUTAG 上比较：

- patch 内容袋；
- patch 原子邻接/共现矩阵；
- 打乱 patch 连接但保留 patch 内容的负对照。

这里“打乱”的目的不是提高模型，而是检查收益是否真的来自片段之间的正确连接。如果真实连接与打乱连接一样，说明关系模块没有使用结构。

#### 动作 2：统一比较三种 patch 构造

在相同 patch 数量、相同平均节点数、相同字典和分类器下比较：

- 二阶邻域；
- CoverageRW；
- 路径或扩散 patch。

评价同时报告：有效结构命中率、重复率、置换稳定性、重建误差、字典稳定性和分类结果。

在这两个机制问题回答之前，不建议继续在 MolHIV 上小修融合层，也不建议直接开发更大的 GNN 主干。
