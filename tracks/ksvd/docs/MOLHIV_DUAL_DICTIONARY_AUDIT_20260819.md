# MolHIV：双层内容／关系 KSVD 审计

日期：2026-08-19

## 要回答的问题

普通 KSVD 只压缩单个 patch 的内容。此前把 patch 关系作为训练时的辅助
约束，要求单个 patch 编码同时重构内容并预测关系；真实关系与打乱关系没有
稳定差异，且主成分压缩更好。

本轮改用一个更合理的假设：

1. 第一层 KSVD 学习带原子、化学键和局部结构信息的 patch 内容字典；
2. 第二层 KSVD 学习**已知** patch 对的关系事件字典；
3. 分子分类同时读取第一层 patch 编码与第二层关系编码。

关系不是强行塞进单个 patch 编码的属性，而是两个具体 patch 在输入分子中
发生的连接事实。

## 固定协议

- 数据：MolHIV 的 8k 开发集，官方训练部分内的固定骨架三折；
- 每折使用全部可用的训练／留出图：4090/2284、4206/2168、4452/1922；
- patch：最多 8 个覆盖采样 patch，使用 `wl_chem_ring`，保留原子和化学键
  属性；
- 内容字典：12 个原子、每个 patch 至多 3 个非零编码；
- 关系事件：两个 patch 编码的和、绝对差、逐位乘积，加上重叠、跨 patch
  化学键、共享节点比例和跨键比例；
- 关系字典：12 个原子、每个关系事件至多 3 个非零编码；
- 分类器：所有方法均为同一个标准化逻辑回归；字典和主成分仅从当前训练折
  拟合，未读取留出折标签。

比较对象：

| 方法 | 含义 |
|---|---|
| 内容 KSVD | 只读 patch 内容编码 |
| 内容 KSVD＋原始关系 | 不压缩关系事件 |
| 内容 KSVD＋主成分关系 | 用主成分压缩关系事件 |
| 双层 KSVD | 内容与关系均由 KSVD 压缩 |
| 随机字典 | 两层均使用随机抽取的真实训练样本字典 |

## 关键的严格对照

早期“随机换关系边”对照不够强：真实 patch 关系图平均有 76.2% 的可能
patch 对相连，因此随机换边后仍平均保留 76.4% 的原始端点。

最终对照改为：保留每个分子的 patch 编码集合、关系图、关系数量和关系
属性不变，只在关系分支中把 patch 内容编码无固定点地重新分配给关系端点。
也就是说，任何关系事件都不会再看到其真实端点的内容编码。这直接检验
“内容—关系对应”是否真的有用。

## 结果

下表为留出折的排序能力（ROC-AUC；0.5 约等于随机，越高越好）。

| 方法 | fold 0 | fold 1 | fold 2 | 平均 | 折间标准差 |
|---|---:|---:|---:|---:|---:|
| 内容 KSVD | 0.6176 | 0.6167 | 0.5646 | 0.5996 | 0.0304 |
| 内容 KSVD＋原始关系 | 0.6424 | 0.6353 | 0.5719 | 0.6165 | 0.0388 |
| 内容 KSVD＋主成分关系 | **0.6399** | **0.6475** | **0.6156** | **0.6344** | 0.0167 |
| 上行主成分关系的严格打乱 | **0.6717** | 0.6267 | **0.6607** | **0.6530** | 0.0235 |
| 双层 KSVD | 0.6450 | 0.6359 | 0.5727 | 0.6179 | 0.0394 |
| 双层 KSVD 的严格打乱 | 0.6272 | **0.6371** | **0.6465** | **0.6370** | 0.0097 |
| 主成分内容＋主成分关系 | 0.6156 | 0.5921 | 0.6127 | 0.6068 | 0.0128 |
| 随机内容／关系字典 | 0.6273 | 0.6109 | 0.5824 | 0.6069 | 0.0227 |

必要差值：

| 比较 | fold 0 | fold 1 | fold 2 | 平均 |
|---|---:|---:|---:|---:|
| 双层 KSVD − 内容 KSVD | +0.0274 | +0.0192 | +0.0082 | +0.0183 |
| 双层 KSVD − 主成分关系 | +0.0051 | −0.0117 | −0.0429 | −0.0165 |
| 双层 KSVD − 严格打乱 | +0.0178 | −0.0012 | −0.0738 | **−0.0191** |
| 主成分关系 − 严格打乱 | −0.0317 | +0.0208 | −0.0451 | **−0.0187** |

## 结论

双层 KSVD 没有通过进入最终 MolHIV 分类的门槛：

1. 它虽比只读内容 KSVD 高 0.0183，但不如更简单的主成分关系压缩；
2. 更关键地，真实的内容—关系对应没有稳定胜过严格打乱，平均反而低
   0.0191；
3. 主成分关系也没有通过严格打乱对照，说明这一批关系事件的绝对分数主要
   仍受关系数量、patch 袋及有限样本波动影响，不能归因于正确关系绑定；
4. 因此不能声称“关系字典学习”已经帮助 MolHIV 下游分类，也不能把它作为
   KSVD 创新性的证据。

本结论否定的是“以当前覆盖 patch 和当前关系事件，用无监督第二层 KSVD
压缩关系即可获得分类增益”这一变体；它不否定化学 patch 必须保留原子／键
属性，也不否定关系在某些受控表示任务中存在信息。

## 后续决定

停止继续调第二层 KSVD 的字典大小、稀疏度、传播层或分类器。下一次新尝试
必须先给出一个不同的、可证伪的标签相关机制，而不能只换一个关系压缩器。
若仍坚持 KSVD 主线，候选方向应是由标签目标约束的稀疏局部词表，并与
非 KSVD 的同容量词表作严格对照；这已是新的研究假设，不能视为本路线的
自然延伸。
