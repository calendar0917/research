# MolHIV：结构—化学条件异常字典

日期：2026-08-20

## 动机

上一轮共享支持字典已经证明真实的结构—化学 patch 对应可以被学到，但分类上不如原始
patch。最直接的解释是它主要编码了两种视角都已经包含的常见共同信息。

本轮改变字典的学习对象，而不是增加分类器容量：

1. 仅用训练折的 patch 对，学习“结构通常对应什么化学信息”以及反向映射；
2. 对每个 patch 保留真实信息减去预测信息后的残差，称为条件异常；
3. KSVD 只编码这些异常的方向，残差大小单独保留；
4. 原始双视角 patch 始终保留，异常编码只能作为小的附加读出。

因此要回答的是：结构—化学之间**不可互相预测**的局部例外，是否比常见共同模式更接近
MolHIV 的标签信号。

## 对照与防泄漏

- 所有缩放、双向预测、主成分、随机原型、字典和分类器只在当前训练折拟合；
- 分类器固定为同一个标准化逻辑回归；
- 未压缩异常：检查异常本身是否补充原始 patch；
- 主成分、随机真实异常原型、独立 KSVD：检查任何压缩是否已经足够；
- 共享支持、分离系数 KSVD：本轮的 KSVD 主方法；
- 预测时打乱：原始 patch 不变，只将异常分支内每个结构 patch 配到错误化学 patch；
- 训练时打乱：双向预测器与字典均由无固定点打乱的训练对应学习。

## 晋级门槛

进入下一阶段必须同时满足：

1. 真实对应留出 patch 的双向预测残差低于打乱对应；
2. 未压缩异常相对原始 patch 至少在两个骨架折为正，说明该对象有标签补充；
3. 共享支持 KSVD 同时优于主成分、随机原型和独立 KSVD，并在至少两个折优于原始 patch；
4. 共享支持 KSVD 在真实对应下优于预测时与训练时两种打乱对照。

任何一项失败均停止此 MolHIV 分支；不以更大网络、更多字典原子或分类器调参补救。

## 全量三折结果：停止

三折完整结果中，真实 patch 对的双向条件残差均低于两种打乱：预测时打乱相对真实的
平均残差平方误差增加 `0.00229`，以打乱对应训练的预测器相对真实增加 `0.00139`。因此
“结构能预测一部分化学信息”这个机制没有问题。

但它不产生分类补充：

| 表示 | 平均排序能力 |
|---|---:|
| 原始双视角 patch | 0.6558 |
| 原始 patch＋未压缩条件异常 | 0.6256 |
| 原始 patch＋主成分异常 | 0.6460 |
| 原始 patch＋随机真实异常原型 | 0.6549 |
| 原始 patch＋独立 KSVD 异常 | 0.6390 |
| 原始 patch＋共享支持 KSVD 异常 | 0.6530 |

共享支持 KSVD 相对原始 patch 为 `-0.0028`，相对随机异常原型为 `-0.0019`。它相对预测时
打乱和训练时打乱的差仅 `+0.0001/+0.0006`，不具备稳定的真实对应特异性。未压缩异常在三折
均低于原始 patch（`-0.0443/-0.0054/-0.0408`），因此甚至没有通过进入字典比较的对象门槛。

结论：MolHIV 上的“条件异常字典”分支停止。它进一步说明，当前二分类标签未能从局部
结构—化学共同部分或局部结构—化学例外中获得原始 patch 之外的稳定增益；不继续调整
预测器正则、字典容量或分类读出。
