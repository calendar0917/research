## 1. 可行性：怎么「证明」？（分层，不要混）

「可行」≠「已在 molhiv 超过 CIN」。应拆成 **四层主张**，每层用不同证据。

### 1.1 问题层：一阶为什么不够？（动机可行）

| 主张 | 论证类型 | 我们有的 |
|------|----------|----------|
| 1-hop 星形看不到闭包 | **组合/几何** | 环上点 \(S=\{v\}\cup N(v)\)，\(\|S\|=3\)，诱导 = **P3**，无第 4 点闭合 |
| 边被多端点重复计入 | **计数冗余** | definition / luyin10 口述 |
| 感受野靠堆 hop 会半图爆炸 | **图论经验** | 小图直径、六度；luyin10 |

→ 证明的是：**需要 >1-hop 的局部结构来源**，不是证明 RW 是唯一解。

### 1.2 机制层：RW 能否采到 1-hop 采不到的结构？（采样可行）

| 主张 | 论证类型 | 证据 |
|------|----------|------|
| 存在任务使 B0 失败、更大 \(S\) 成功 | **构造性 + 实验** | **C4 vs C8**：同 \(n,\|E\|\)；B0~0.85，RW+共享 KSVD~1.0 |
| 可视化上 RW 盖住环、B0 不盖 | **展示性证明** | `results/viz/pure_C4.png` 等 |
| RW 不是万能 | **负对照** | distant-triangle：局部度已可分 → B0 满分、RW 更差 |

形式化一点（答辩可用）：

> **命题（机制）**：若标签依赖长度为 \(\ell\geq 4\) 的 induced cycle 的存在性，而特征仅来自 1-hop 诱导星形，则存在同分布宏观统计下不可分的图对；允许 \(\|S\|\geq \ell\) 的连通采样（含足够长的 RW 轨迹诱导）时可分。  
> **我们**：用 C4（\(\ell=4\)）作 **实例证明**，不是一般图论定理全文。

### 1.3 表征层：接到 KSVD 是否自洽？（接口可行）

| 主张 | 论证 |
|------|------|
| 诱导子图 → 定长 \(y\) → \(Y\approx DX\) | 管道已实现；共享 \(D\) 使 \(X\) 可比 |
| 多 walk → 多 \(x_i\) → pool \(s_v\) | 与 DeepWalk/n2v「多序列」一致；重建对象是 **patch** 不是「节点本体」 |
| recon 不作跨族排名 | B0/RW 的 \(Y\) 分布不同，recon 只作同族诊断 |

→ 证明的是：**RW 输出可以成为 KSVD 的合法输入**，不是证明系数已是最优分子特征。

### 1.4 下游层：任务是否涨点？（应用可行）

| 主张 | 现状 |
|------|------|
| MUTAG + GIN（Xu 协议）稳定增益 | **未成立**（~持平，最好约 +1pt 不稳） |
| molhiv / CIN 同桌 | **未做** |

→ **应用可行性未证明**。调研收口应写清：机制可行 + 接口可行；应用待验证。

### 1.5 一句话

| 问 | 答 |
|----|-----|
| RW 子图采样可行吗？ | **机制 + 接口上可行**（C4 + 管道） |
| 已经证明方法有效吗？ | **只证明了机制有效**；下游有效 **否** |

③ 方案：RW → 诱导 G[S] → 共享 D → s_v（可还原 DX）
④ 文献格子：我们站在「采样×字典」，不是核/嵌入/PE

## 3. 若要把 KSVD 方案做到「CIN 级别」——差在哪、有何思路

### 3.1 「CIN 级别」指什么（先对齐期望）

| 维度 | CIN 已有 | 我们现在 |
|------|----------|----------|
| 结构对象 | 全图 **枚举环** 进计算图 | **稀疏采样** patch |
| 计算 | 多层 **cell MP** 端到端 | 固定 \(D\) + 浅融合 / 浅头 |
| 数据 | ZINC / **molhiv** 主表 | 合成 + MUTAG 探针 |
| 理论 | CWL 表达力 | 1-WL 边界口述 + C4 实例 |
| 工程 | 完整训练与超参 | 研究原型 |

做到 CIN **级别** ≈ 至少：**分子主基准 + 端到端可训练的结构通路 + 可辩护的结构先验/学习**，不是把 CIN 的 ring lift 抄进 KSVD 名字。

### 3.2 差距清单（按优先级）

1. **结构覆盖**：CIN 环是（近似）完备枚举；我们是随机采样 → 易漏 motif、方差大。  
2. **与任务耦合**：CIN 表示端到端为标签服务；我们 \(D\) 多为重构/无监督。  
3. **多尺度层次**：CIN 原子–键–环三层；我们单层 patch 系数。  
4. **基准与协议**：无 OGB 主表。  
5. **理论包装**：缺与 WL/子结构表达力的紧定理（可选）。

### 3.3 路线图（由近到远，可并行）

#### 路线 α —「采样版 CIN 先验」（较近）

- 不放弃可还原字典，但 **patch 分布对齐环**：  
  - 环感知 RW（在环上停留/偏置 \(q\)）；  
  - 或 **混合**：枚举小 \(k\) 环作部分 \(y\) + RW 补其余（半 GSN/CIN 先验）。  
- 展示：mol 小图上「RW 命中真环比例」vs 均匀 RW。

#### 路线 β —「可学习字典 + 下游」（中）

- \(D\) 或编码与 GNN **联合训练**（可微近似 OMP / 字典层）。  
- 节点 \(s_v\) 用 **residual/gate**（已试浅版）加深为每层注入。  
- 目标：C 层证据；仍可保留重构正则（多任务）。

#### 路线 γ —「层次 KSVD / 多尺度」（中远）

- 0-hop 特征 / 1-hop / RW-patch / 图级 多层字典或 coarse-to-fine。  
- 对应 CIN 的 0/1/2-cell 层次，但是 **学出来的层次**。

#### 路线 δ —「基准升级」（远，才叫 CIN 桌）

- ogbg-molhiv + 原子/键 encoder + 正经训练预算。  
- 基线：GIN / GSN（若可）/ 文献 CIN；**同 OGB 协议**。  
- 成功标准：AUC 进入可讨论区间，或消融证明「无 RW/无字典则掉点」。

#### 路线 ε —「理论」（可选加分）

- 将「\(\|S\|\geq \ell\) 的诱导子图袋」与子图计数/WL 变体联系。  
- 不阻塞工程，但提升「体系感」。

### 3.4 不建议的「假 CIN 级」

- 只刷 MUTAG 乐观协议小数点。  
- 图级 100+ 维广播再冠名 KSVD。  
- 无过程指标、只报一次 Acc。  
- 宣称与 CIN 同级但无 molhiv/ZINC。

### 3.5 推荐组合（若导师要「再往上做」）

```
短（1–2 周）：展示件（感受野曲线 + 覆盖热力）+ 报告定稿
中（阶段课题）：α 环感知采样 + β 轻量端到端 + NCI1/ZINC-subset
长（论文级）：δ molhiv 主表 + 完整消融 + 可选 ε
```

## 4. 直接回答三个问题

### (1) 可行性怎么证明？

- **几何 + C4 构造实验 + 可视化 + 负对照** → 机制可行。  
- **共享 D + 节点系数管道** → 接到 KSVD 可行。  
- **MUTAG** → 应用可行 **尚未证明**。

### (2) 怎么展示？

- 主线：P3 失明图 → 管道 → 文献格子 → **viz + C4 表** → 负对照 → 下游诚实。  
- 材料路径见 §2.2。

### (3) 到 CIN 级？

- 补：**覆盖（枚举或环感知采样）、端到端、层次、分子主基准**。  
- 不是把 KSVD 改名，而是 **结构通路的覆盖度与可训练性** 拉到同一量级。
