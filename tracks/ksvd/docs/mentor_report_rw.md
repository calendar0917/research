# 随机游走子图采样 × KSVD — 阶段汇报

**对象：** 导师（对应 luyin10）  
**范围：** 仅 RW 取样与图级利用；不含 CIN 刷榜、不含节点 GIN 细枝  
**日期：** 2026-07-25  

---

## 1. 问题（录音原意）

| 点 | 内容 |
|----|------|
| 现状 | 一阶邻域做结构块：感受野小、边被多点重复计入 |
| 想法 | 用 **随机游走** 在可控范围内扩大感受野，得到 **代表图的一系列子图**，再 **KSVD** |
| 约束 | 不必点点游走；边 **至少覆盖、少重复**；**软惩罚、不硬删** |
| 下游 | 结构 **readout → 图分类**；与节点属性融合后议 |
| 当轮任务 | 查 RW 文献与约束，判断是否可行——**非**立刻超 CIN |

---

## 2. 文献定位（一句话）

RW 在图学习中常见四类用法：**核相似度 / 嵌入采样 / 训练子图采样 / 位置编码**。  

本组不做核或 Skip-gram 终点，而做：

> **有约束的 RW → 诱导子图集合 → KSVD → 图向量**  

与 GSN/CIN 同属「显式结构」，差别是：子结构 **学字典原子**，不是手数/环 lift。

---

## 3. 默认方法（图级）

**CoverageRW → KSVD → Readout**

1. **种子**：度分层抽样（非全点），预算 `max_walks`  
2. **游走**：node2vec（\(p,q\)）+ 可选不回头  
3. **软降权**：轨迹边权 \(\times\gamma\)；图结构不删边  
4. **Patch**：访问集 \(S\)（cap \(m\)）→ 诱导 \(G[S]\)  
5. **早停**：轨迹边覆盖率 ≥ 阈值或用尽预算  
6. **KSVD**：train 上堆 patch 学共享 \(D\)；图上 OMP 得 \(X\)  
7. **图向量**：对 \(X\) 做能量/统计 readout → 分类  

**两套旋钮：** \(p,q\) 管形态；边权 \(\gamma\) 管「少再走」。二者相乘，不是互相替代。  

**与节点级：** 覆盖指标是 **图级**；节点系数 \(s_v\) 是后续接口，录音当轮主线是图级。

## 4. 回答录音中的核心问题

### Q1：RW 走出的子图有没有意义？有无约束？

- 有约束：\(p,q\)、长度/规模上限、软降权、种子策略。  
- 意义不靠「像不像三角形」先验，而靠：**能否覆盖 1-hop 看不到的结构**（见下）。  
- 硬删边会破坏 motif（录音反例）→ **实现禁止硬删**。

### Q2：能否扩大感受野且不过度吞掉整图？

- 用 \(L,m\) 与预算控制规模，而不是全图 \(k\)-hop。  
- **C4 探针：** 1-hop 对「含 C4 的图」命中率 **0**；RW 随 \(L,m\) 增大命中率 **0.33 → 1.0**。  

### Q3：能否减轻「每点一阶」的边冗余？

- 一阶：每点一星形 → 边被两端重复计入。  
- Coverage：少量种子 + 软降权；**同覆盖下 walk 数明显少于全点 B0**（过程表）。  
- 指标：轨迹 **cover** 与 **repeat** 联立看；低 repeat 仅在 cover 高时有意义。

### Q4：子图之后怎么用？

录音路径（已实现闭环）：

```
子图集 → 向量化 → KSVD(D,X) → 图级 readout → 图分类
```

属性融合、消息传递：**后置**，非本阶段验收。

### Q5：是否已证明「有效」？

| 层级 | 结论 |
|------|------|
| 机制（闭包结构） | **是**：C4 上 coverage-KSVD **91%** vs B0-KSVD **82%** vs 度 **82%** |
| 过程（覆盖/预算） | **是**：可复现 cover/repeat/walks |
| 分子下游 | **否**：MUTAG 等未显示稳定增益；不在此汇报硬吹 |

## 5. 关键证据（精简）

**过程（多图）**  
- C4 集 200 图：coverage 均 walk≈5.7 且 cover≈1；B0 walk=14。  

**感受野**  
- B0：c4_hit=0；RW \(L=8,m=8\)：≈0.99。  

**闭环（图分类，合成）**  
- C4 vs C8：coverage+KSVD 优于 B0。  
- 三角任务：B0=100%（1-hop 可见），coverage 更低 → **RW 非处处更优**（负对照保留）。  

**交互说明**  
- `results/viz_pipeline/index.html`：种子 → 逐步游走 → patch → 字典 → 编码。  
- 注：页面上「少 patch + 等量原子 → recon≈0」仅为示意，**不能**当字典已学好的证据。

## 6. 未完成 / 边界

- \(p,q,L,m\) 多为设定值，非分子任务网格最优。  
- 覆盖算法是 **可测启发式**，非最优覆盖理论解。  
- 图级闭环主要在 **合成机制任务**；真实分子图级/协议化主表未立。  
- 与 CIN：问题同类（结构显式），**实现量级与数据主表均未对齐**。

---

## 7. 结论（对老师）

1. **可行：** 用有约束 RW 构造分解前子图，再 KSVD 做图级表征——在 **需要多跳闭包** 的设定上，相对一阶 **成立**。  
2. **录音要求：** 动机、文献骨架、不硬删、非全点+软降权、图级 readout 路径——**已落实为算法+过程指标+合成闭环**。  
3. **未宣称：** 分子 SOTA、覆盖理论最优、节点 GNN 已涨点。  
4. **建议下一步（请拍板）：**  
   - **A.** 收口本阶段，转向其他工作；或  
   - **B.** 同一图级管线接到 1 个中等真实图分类协议；或  
   - **C.** 再加强覆盖目标形式化 / 环候选进字典（靠近分子叙事）。
