## 1. 问题

| 点    | 内容                                                 |
| ---- | -------------------------------------------------- |
| 现状   | 一阶邻域做结构块：感受野小、边被多点重复计入                             |
| 想法   | 用 **随机游走** 在可控范围内扩大感受野，得到 **代表图的一系列子图**，再 **KSVD** |
| 约束   | 不必每一点都游走；边 **多覆盖、少重复**；**但是不直接删除**                 |
| 下游   | 结构 **readout → 图分类**                               |
## 2. 文献参考

RW 在图学习中常见四类用法：**核相似度 / 嵌入采样 / 训练子图采样 / 位置编码**。  

1. 核相似度(RW-kernel)：根据两图随机游走得出的序列相似性，来判断两图是否同类
2. 嵌入采样（DeepWalk、node2vec，自监督学习）：
    - 采样：从每个节点出发，进行多次固定长度的随机游走，生成大量节点序列
    - 学习：将这些节点序列视为“句子”，节点视为“单词”，输入到 Word2Vec 的 **Skip-gram 模型**中进行训练。
    - 产出：训练后，每个节点得到一个固定长度的稠密向量（嵌入），该向量编码了节点的拓扑信息
3. 训练子图采样（GraphSAINT，将大图拆分为小图）：
    - **采样**：对每个批次，通过随机游走等方式从大图中采样一个节点子集
    - **诱导**：基于采样的节点子集，从原图中提取出**诱导子图**，包含这些节点间所有的原始边。
    - **归一化**：为解决采样带来的偏差，对子图中的聚合和损失进行重要性归一化（低概率被采样的节点如果被采样到，消息传递时权重升高）
    - **训练**：在这个完整的子图上执行完整的GCN模型，进行梯度计算和反向传播
4. 位置编码（RWPE，给节点赋予位置向量，解决 GNN 对节点位置的盲区）
    - **计算返回概率**：对每个节点，计算从它出发的随机游走在 k 步后**回到自身**的概率
    - **构成特征向量**：将不同步长的返回概率拼接起来，形成该节点的位置编码向量
    - **注入模型**：将这个位置编码向量作为**额外的节点特征**，拼接到原始节点特征上，再输入给 GNN 或 Graph Transformer
    - 物理意义：位于稠密社区中心的节点容易绕回，反之容易遗失

另外，还有一篇 WL-KSVD 可以参考（见末尾）。思路是通过字典编码图的 WL 子树，然后送入 SVM 来进行分类。但是效果比较一般，比 CIN 在 TUData 上大概低 20%
## 3. 当前方案

参考 Node2vec、GraphSAINT 的游走、采样思路，选取子图。

1. **种子**：只选取定额节点进行游走。选取方式可以按照节点度数划分，高度-中度-低度节点交替选取，达到目标边覆盖率以后可以提前停止。
2. **游走**：通过 q、p 两个参数来控制游走方向。当 p 升高，倾向于深度优先；反之，倾向于广度优先。节点游走的步数为定值(或者达到步数上限)。概率控制如下：
$$
\begin{aligned}
& \text{回头路} \quad (x = t, \; d_{tx} = 0) : \alpha = \frac{1}{p} \\
& \text{近邻路} \quad (x \text{ 与 } t \text{ 直接相连，即局部三角}, \; d_{tx} = 1) : \alpha = 1 \text{ (基准)} \\
& \text{远行路} \quad (x \text{ 离 } t \text{ 更远，即向外冲}, \; d_{tx} = 2) : \alpha = \frac{1}{q}
\end{aligned}
$$
3. **路过降权**：走过某条边以后，下次经过这条边的概率降低，以减小边的重复
4. **导出**：根据游走的访问节点集合，导出诱导子图，作为字典的训练集合
5. **停止游走**：轨迹边覆盖率 ≥ 阈值，或者选取节点数达到阈值  
6. **KSVD**：在训练集的子图上学习一套**共用**的结构基（字典）；每张图用这套基做稀疏分解，得到系数
7. **图向量**：把系数汇总成一个向量（例如能量、均值、最大值等统计量），再做图分类

在自制的图上简单测试了一下，发现四元环可以正常被识别（只看一阶邻居则不行），但是游走长度、子图大小、q/p 等等都还需要调。

实现时又补了两点（仍算图级主线）：

1. **字典必须共用**：若每张图各自学一套字典，系数无法跨图比较，合成任务准确率大约只有 0.55；改成训练集统一学字典后大约到 0.86。
2. **过程上能核对**：边覆盖了多少、重复走了多少、四元环有没有被某个子图兜住。只看一阶邻居时，四元环几乎兜不住；随机游走加长以后可以兜住。分类上：任务真需要多跳闭环时，游走+KSVD 好于一阶邻居；若只看度数就能分，游走不必更好。

**和录音任务的对应：**  
「约束下的随机游走 → 子图 → KSVD → 整图向量」这条链，机制上已经能跑通。  
分子数据集刷分、和神经网络怎么拼，**不是**这一轮必须交差的内容。

## 4. 后续自行尝试（主线之外）

随机游走的图级方案跑通之后，我又往「下游好不好用」推了几步。  
这些是**自己加的探索**，用来看卡点；向导师汇报主线时仍以 §1–§3 为主。

### 4.1 整图结构向量怎么接到神经网络

| 做法 | 现象 |
|------|------|
| 先得到整图一个结构向量，再复制到每个节点，和 GIN 拼在一起 | 明显变差 |
| 尽量落到节点上的系数，再和 GIN 拼接 / 残差 / 门控 | 和小分子集 MUTAG 上的纯 GIN 差不多，最多略好一点 |
| 整图结构向量直接拼进分子模型 GINE | 稳定地不如纯 GINE |

判断：如果结构信息最后只剩**「一张图一个数向量」**，再塞进消息传递，往往太晚，还容易打乱原来的原子特征通道。

### 4.2 不用神经网络，只靠结构通道分类

流程：随机游走（或固定规则）采子图 → 编成固定长度的局部描述 → 共用字典做 KSVD → 对系数做统计 → 逻辑回归（并加上图有多大）。

在分子数据集 MolHIV 的**官方验证集**上（换 5 次字典随机种子）：

| 方法 | 验证集 AUC |
|------|----------:|
| 只用图的大小 | 0.679 |
| 同样的子图，但不做 KSVD、只随机抽一些子图当「假字典」 | 0.685 |
| **完整 KSVD + 系数统计** | **0.712**（5 次都赢过「假字典」） |
| 同样设定改成普通主成分分解 | 比「只用大小」还差 |

说明：KSVD 相对「瞎抽子图当基」「普通线性降维」**确实多学到了一点东西**；但 0.71 仍远低于常见分子 GNN，**单靠这一路不够当主分类器**。

### 4.3 改成「每个原子一段局部码」，再喂给 GINE

针对 4.1：不再先压成整图一个向量，而是——

1. 对**每个原子**取两跳以内的局部邻域；
2. 用训练集上的 KSVD 字典编成一段短的稀疏系数（每个原子一段）；
3. 经过一层小映射，按网络层用**从 0 开始学的门**加进 GINE。  
   训练刚开始时门为 0，模型等于纯 GINE，避免一上来就被结构通道带偏。

注意：这里已经是**每个原子都取邻域**，不再是 §3 那种「少量种子随机游走」；随机游走主线仍以 §3 为准。

设定大致是：两跳邻域、字典 32 个基、每段系数很稀疏、GINE 宽度 64、3 层。  
用训练集内部再划出一块来选「训练几轮」，选完后在全部训练集上重训，再评官方验证 / 测试。

| 指标 | 纯 GINE | 加上 KSVD 局部码 |
|------|--------:|----------------:|
| 官方验证集（5 次训练种子平均） | 0.770 | **0.795**（平均高 2.5 个点；5 次里赢 3 次，统计上不算显著） |
| 官方测试集（5 次平均） | **0.753** | 0.752（基本打平） |
| 和参数量接近、略加宽的纯 GINE 比测试集 | — | 大约低 1 个点 |
| 5 个模型预测概率取平均后再测 | 0.775 | 0.770 |

参数量：后面可训练的大约 **4.4 万**（若把冻结的字典也算进「存下来的数」，大约 7 万）；文献里 CIN 一类大约十几万到二十多万。  
试过把网络加宽、加深、字典加大、换成更复杂的逐点门控等，**多半更差**，不像是「模型太小所以不够」。

判断：

- 验证集上能看到结构通路带来的提升；**换到按分子骨架划分的测试集后，提升保不住**，也远没到 CIN 大约 0.81 的测试水平。
- 更可能的问题是：字典主要在拟合「训练里好重建的局部样子」，换一批骨架就不稳；再加上「训练几轮」本身波动大——**不一定是参数太少**。
- 探索阶段曾经看过测试集，所以后来的测试结果只能当作**方案锁定之后的核对**，不能再根据测试集改来改去还声称公平。

### 4.4 和主线的关系

```text
主线（录音）：带约束的随机游走 → 一组子图 → 共用字典 KSVD → 整图汇总再分类
             要回答：子图有没有意义、约束够不够、机制是否跑得通

自行延伸：   整图向量怎么接神经网络？
             只靠结构通道在分子数据上有多强？
             改成每个原子一段码再进 GINE，验证集/测试集是否都好？
```

自行延伸说明：整图汇总**可以**分类，但接到神经网络、在分子标准划分上稳定变好，都还难。  
这些难处**不否定**主线里「随机游走子图 + KSVD」在机制上是否成立。

## 5. 待解决的问题

**主线（优先，对应录音）：**

1. 边覆盖率、重复率、环有没有被兜住——这些过程量，和**最后分类好不好**如何对齐？不能默认「边走全了分类就好」。
2. 游走方向 \(p,q\)、长度、子图大小、种子怎么抽、路过降权多重：合成图上有效，但还缺一套**说得清楚的选取原则**（不能只调到四元环好看）。
3. 子图怎么变成向量，目前仍偏工程；和「学出可还原的结构基」这件事，表述上还要更干净。

**延伸（若继续做分子或融合）：**

4. 结构若只汇总成整图一个向量，很难好好进消息传递（见 4.1）；改成按原子编码后，采样方式已不是随机游走主线，写的时候要分开。
5. 分子数据上验证集有增益、测试集打平：字典偏「重建」、训练轮数选不稳、换骨架后含义漂移（见 4.3）。
6. 和 CIN 比：我们参数更少，但用的是学出来的局部码，不是显式的环上消息传递；**不能**只凭验证集分数或参数量宣称达到 CIN。
