# MolPCBA：局部化学变化字典协议

日期：2026-08-20  
状态：进行中；此文件在任何官方验证集、测试集结果之前固定。

## 1. 要修正的对象

此前的字典编码的是一张分子里静态 patch 的共同内容。MolHIV 的结果表明：无论编码共同
结构—化学信息，还是编码条件异常，真实对应本身可以被识别，却没有给单分子分类带来稳定
增益。因此本轮不再问“一个 patch 是什么”，而是问：

> 在相同核心骨架下，把一个局部支链从 A 换为 B，这个**有方向的变化**能否迁移到未见
> 核心骨架？

如果可以，KSVD 学的不是静态片段词表，而是可复用的局部变化词表。

## 2. 数据与防泄漏

- 数据：`ogbg-molpcba`；只读官方 `train` 划分；
- 开发任务预先固定为高标签密度的 93、94、47、60；
- 官方 `valid` 与 `test` 不被读取，不参与任何表示、参数或任务选择；
- 每个任务把官方训练集按 Bemis--Murcko 核心骨架的稳定散列分成三折；一个骨架家族只能
  出现在训练侧或留出侧之一；
- 缩放、主成分、随机原型、KSVD 字典、逻辑回归均只由当前两折学习。

因此，本轮的“未见样本”是未见核心骨架，而不是同一系列中的另一张分子。

## 3. 什么算一个干净的局部变化

对每个分子：

1. 取 Murcko 核心骨架；
2. 找出与核心只通过一条键相连的外部连通支链；多点连接的融合环不进入本轮；
3. 对支链保留连接键、连接原子的原子类型和邻近核心环境；
4. 在同核心、标签一正一负的两张分子中，只有当所有其余支链完全相同、仅一处支链替换时，
   才形成一条样本：`负支链 → 正支链`。

支链向量在原始合法分子上由半径为 2 的原子—键局部指纹生成，避免把芳香环硬切为不合法的
子分子；变化向量为正、负支链向量之差。

## 4. 第一关：原始变化是否值得压缩

在留出的核心骨架上，用固定的线性分类器判断一个有符号变化是否指向“负 → 正”。反向变化
`正 → 负`作为相反类别；随机猜测约为 50%。

同时做“跨核心配对”对照：保留相同的正、负支链边际分布，但打破它们原本同核心的对应。
这项对照用于排除“模型只是在背诵全局常见活性片段”。

只有同时满足以下条件，才进入 KSVD：

1. 同核心原始变化在至少两折的方向准确率超过 55%；
2. 同核心变化相对跨核心打乱对照，在至少两折的配对排序能力高出至少 0.01；
3. 不用官方验证/测试结果挑选任务或参数。

这一关通过只代表“局部变化存在可迁移的机制信号”，不代表普通单分子分类已经提升。

## 5. 第二关：KSVD 是否是必要的压缩

在通过第一关的任务上，比较同为 32 维的表示：

| 表示 | 作用 |
|---|---|
| 原始变化 | 未压缩上限 |
| 主成分 | 通用线性压缩对照 |
| 随机真实变化原型＋稀疏编码 | “只要有稀疏原型就够了”对照 |
| KSVD 变化字典＋稀疏编码 | 本轮方法 |

KSVD 只有在以下条件全部满足时才保留：

1. 至少两折同时优于主成分和随机原型；
2. 三折平均也优于两者；
3. 相比未压缩变化，配对排序能力损失不超过 0.01；
4. 报告留出变化的重建误差，但不把重建误差当作任务成功证据。

任何一项失败，都停止“KSVD 是这个变化任务关键压缩器”的主张；不会通过增大字典、增加
迭代次数或改大分类器补救。

## 6. 只有两关都过后，才谈下游分类

下一阶段仍然是标准单分子分类：输入一张未见分子，按“核心＋带连接点的支链”分解后，用已经
冻结的变化字典编码支链；128 个任务共享字典、各自学习很小的任务权重。最终在官方验证集、
再一次性在官方测试集上报告平均精确率。

配对仅是训练期的弱监督，测试时不存在需要配对的参考分子。若配对方向有效、但单分子分类
没有提升，只能称为局部变化分析，不得称为下游分类方法。
