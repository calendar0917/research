# KSVD 能否学习图结构词汇？一组逐步证伪实验

> **日期：** 2026-07-31  
> **实验范围：** 2026-07-23 至 2026-07-30 完成的 KSVD 机制实验、真实结构审计和补救实验  
> **本文目的：** 说明我们为什么尝试 KSVD、怎样逐步检验它、实验实际得到了什么，以及这些结果对后续研究意味着什么

---

## 摘要：我们问了什么，得到了什么结论

我们的长期目标不是单纯提高一个分类分数，而是学习一种**显式且自适应的图结构表示**：

- “显式”是指模型能指出自己使用了哪些局部结构，以及这些结构出现在图的什么位置；
- “自适应”是指结构词汇由数据学习，而不是由研究者预先枚举三角形、环、团等模式。

KSVD 是我们首先尝试的工具。直观上，可以把它理解成：先从图中截取大量局部片段，再让算法把这些片段压缩成一本共享的“结构词典”。每个词典条目称为一个**原子**，每张图则由少量原子的出现情况来表示。

围绕这条路线，我们依次检验了五个问题：

1. 更大的采样范围是否能看到一阶邻域看不到的结构？
2. KSVD 原子是否能形成跨图共享的结构内容？
3. “什么原子出现在什么位置”是否带来额外信息？
4. 学到的原子是否对应合法、稳定、可解释的真实子图？
5. 如果强制原子成为真实子图，或者不用 WL 表示，结果能否被挽救？

实验给出的结论是：

- **机制实现是有效的。** 合成正控制表明，采样模块可以扩大感受野；当任务真的由“什么内容位于什么位置”决定时，关系模块能够识别这一信号。
- **真实数据上存在结构信号，但它通常不来自 KSVD 特有的字典学习。** 简单 patch 均值、真实 patch 原型、PCA 或关系图统计经常与 KSVD 持平，甚至更好。
- **普通欧氏 KSVD 没有学出令人信服的结构词汇。** 自由原子往往不能直接对应训练集中的合法 patch，其跨训练划分的结构语义也没有优于“直接选择真实 patch”这一简单方法。
- **两轮主要补救均未改变结论。** 强制原子投影为真实 patch 后，没有获得跨数据集、跨随机划分的稳定增益；改用完整邻接矩阵的规范表示后，也没有形成稳定优势。

因此，本文的最终判断是：

> **普通欧氏 KSVD 不再作为“自适应结构词汇学习器”的主路线。** 它可以保留为压缩方法、原型初始化器和诊断基线；但继续调字典大小、稀疏度、随机游走或投影强度，已经缺少充分依据。

这个结论**不否定**“学习显式结构词汇”这一更大的研究方向，也**不等于**已经回答 MolHIV 上能否达到 CIN 水平。它只说明：在当前 patch、表示和评估协议下，KSVD 的欧氏重构目标与我们真正需要的“合法、稳定、与任务相关的结构相似性”没有对齐。

## 1. 研究动机：从隐式表示到可检查的结构词汇

### 1.1 当前方法留下的问题

GIN、GCN 等图神经网络通过邻居信息传播学习节点或整图向量。它们可能在向量中编码结构信息，但这些信息通常是**隐式的**：我们很难从一个连续向量中直接读出“模型使用了哪个环、哪个局部连接模式，以及它具体出现在哪里”。

GSN、CIN 等方法进一步显式使用子结构或高阶单元，但通常需要研究者事先规定哪些结构值得使用。这样会产生三个问题：

1. 不同数据集需要的结构可能不同；
2. 人工结构集合可能遗漏真正有用的模式；
3. 枚举大量候选结构会增加计算量，也会引入许多无关结构。

因此，我们希望研究：

> 能否从数据中自动学习一组跨图共享的结构原型，并把这些原型在每张图中的出现位置和相互关系显式恢复出来？

### 1.2 为什么首先想到 KSVD

KSVD 是一种稀疏字典学习方法。它输入一批向量，学习一组共享原子，使每个输入向量可以由少量原子近似重建。

如果把一个局部图结构表示成向量，KSVD 看起来正好提供了以下能力：

- 从大量局部片段中自动总结共享模式；
- 用少量原子描述每个片段；
- 通过稀疏系数记录某个原子在一个片段中出现的强弱；
- 在不同图之间使用同一本字典，从而比较它们的结构组成。

但这里存在一个尚未证明的关键跳跃：

> KSVD 学到的是“有利于欧氏重建的向量方向”，它不一定等于“合法、稳定、与分类任务有关的图结构”。

后续实验的核心，就是检查这个跳跃是否成立。

## 2. 我们希望 KSVD 学到什么

理想情况下，KSVD 结构词汇应同时满足以下四个条件。

| 编号 | 条件 | 直观含义 | 主要检验方式 |
|---|---|---|---|
| H1 | **合法、可回指** | 每个原子应对应一个真实可存在的局部图，而不只是若干向量的数学混合 | 给原子寻找最近的真实训练 patch；再强制原子取自真实 patch |
| H2 | **跨划分稳定** | 更换训练数据或随机划分后，仍能学到语义相近的原子 | 对不同运行的原子做一对一最优匹配，比较其最近真实结构 |
| H3 | **有独立任务价值** | 在控制图大小、度分布等简单统计后，仍能稳定改善分类 | 与 raw patch、PCA、真实 patch 字典等同条件基线比较 |
| H4 | **位置关系有意义** | 不仅知道图中有哪些原子，还应知道它们出现在哪里、怎样相邻 | 正确的原子—位置对应与打乱对应、关系图自身进行比较 |

这四个条件中，任何一个缺失都会削弱“学到了显式结构词汇”的解释：

- 只有分类增益而没有合法原子，不能称为可解释结构词汇；
- 原子合法但跨划分不稳定，难以作为共享词汇复用；
- 原子稳定但不优于简单基线，没有必要引入 KSVD；
- 内容有效但位置绑定无效，则还没有形成可组合的高阶结构表示。

## 3. 方法：从图到 KSVD 表示

### 3.1 整体流程

```text
一批输入图
  ↓
从每张图中采样多个局部片段（patch）
  ↓
把每个 patch 转成固定长度向量
  ↓
只使用训练折的 patch 学习一套共享 KSVD 字典
  ↓
用字典稀疏编码每个 patch
  ↓
汇总一张图使用了哪些原子
  ↓
可选：恢复 patch 的位置、相邻和重叠关系
  ↓
使用逻辑回归进行图分类
```

### 3.2 文中常用概念

**Patch（局部片段）**  
从原图中截取的一个局部诱导子图。例如：

- `B0`：以一个节点为中心的一阶邻域；
- `R2`：以一个节点为中心的二阶邻域；
- `UniformRW`：普通随机游走访问到的节点所形成的片段；
- `CoverageRW`：优先访问未覆盖区域的随机游走片段；
- `PPR`：根据图扩散分数选择一组相关节点形成片段。

**Patch 表示**  
为了输入 KSVD，需要把大小不同、节点编号任意的 patch 变成固定长度向量。主要实验首先使用 WL 统计；最后又使用规范化后的完整邻接矩阵，排查 WL 信息损失。

**共享字典**  
一套字典由训练集中的所有图共同学习，而不是每张图单独学习。早期合成实验中，每图独立字典约为 0.55，共享字典约为 0.86。这说明只有共享字典的原子编号才可能在不同图之间具有可比性。此后所有正式实验均使用训练折共享字典。

**关系图**  
把每个 patch 当作一个节点；若两个 patch 的中心相邻或片段重叠，就在它们之间连边。关系图描述“这些局部片段怎样组织在一起”。

**平衡准确率**  
各类别召回率的平均值。它能减少类别数量不均衡对结果的影响。本文真实纯结构实验均报告 balanced accuracy。

### 3.3 KSVD 实际优化什么

KSVD 反复进行两步：

1. 在字典固定时，用少量原子的线性组合近似每个 patch；
2. 在稀疏系数固定时，更新原子以降低总体重建误差。

因此，KSVD 直接优化的是：

> **怎样用少量向量，在欧氏空间中尽量准确地重建输入 patch 向量。**

它并不直接优化以下目标：

- 原子必须是一个合法图；
- 原子在不同训练划分中具有相同语义；
- 原子对下游标签有判别力；
- 原子之间的欧氏距离等于图结构之间的相似度。

这正是为什么需要后面的合法性、稳定性和任务对照实验。

## 4. 实验设计：怎样避免把普通信号误认为 KSVD 的贡献

### 4.1 真实纯结构数据

最终机制判断使用三个不含节点和边属性的真实图分类数据集：

| 数据集 | 版本与 patch | 图数 | 类别数 | 选择原因 |
|---|---|---:|---:|---|
| IMDB-BINARY | cleaned / B0 / 最多 12 节点 | 493 | 2 | 一阶局部结构以团为主 |
| IMDB-MULTI | cleaned / B0 / 最多 12 节点 | 321 | 3 | 与 IMDB-BINARY 相似，但为三分类 |
| REDDIT-BINARY | raw / R2 / 最多 24 节点 | 2000 | 2 | 二阶片段更大、结构类型更多 |

IMDB 使用 cleaned 版本，是为了避免重复或同构图过多地影响机制判断。

### 4.2 训练与评估协议

- 外层评估：3 个数据划分种子 × 5 折交叉验证；
- 内层选择：只在外层训练折内部，用 3 折验证选择逻辑回归正则强度；
- 所有 PCA、字典和投影均只在外层训练折拟合；
- 每折最多使用 4000 个训练 patch；
- 最终 projected-KSVD 实验固定为 16 个原子、每个 patch 最多使用 2 个原子、10 次字典更新；
- 不把测试折信息用于字典学习或参数选择。

### 4.3 必须比较的同条件基线

| 方法 | 它回答的问题 |
|---|---|
| `stats` | 图大小、边数、密度、度分布、连通分量、三角形、独立环数量等简单统计已经能做到什么？ |
| `raw` | 不训练字典，直接汇总原始 patch 向量是否更好？ |
| `PCA` | 普通线性降维能否达到相同效果？ |
| `clustered real-patch` | 直接从训练集选择有代表性的真实 patch 是否已经足够？ |
| `unconstrained KSVD` | 自由 KSVD 原子是否具有额外价值？ |
| `projected KSVD` | 强制原子为合法真实 patch 后，能否挽救结果？ |
| `relation-only` | 只使用 patch 之间的连接关系、不使用任何原子内容时能做到什么？ |

另外，在比较“内容 + 关系”时，不同内容表示会拼接**完全相同的关系图特征**。这样，如果 KSVD+graph 更好，才有可能把差异归因于 KSVD 内容，而不是关系模块容量不同。

### 4.4 位置关系的关键对照

我们区分五类读出：

| 读出 | 保留的信息 |
|---|---|
| `content` | 只统计图中有哪些原子，不记录位置 |
| `relation-only` | 只看 patch 之间的相邻或重叠关系，不看原子内容 |
| `content+graph` | 同时使用内容统计和关系图，但不强调某个内容具体对应哪个位置 |
| `true binding` | 保留“哪个原子位于关系图的哪个位置” |
| `shuffled binding` | 保留内容总量和关系图，只随机打乱内容与位置的对应 |

`shuffled binding` 是负对照，不是训练技巧。若正确对应不能稳定优于打乱对应，就不能声称模型学到了有意义的原子组合关系。更严格地说，正确对应还应优于更简单的 `content+graph`；否则增加的绑定信息可能只是高维噪声。

## 5. 先验证实验能检测到真正的结构信号

真实数据上的负结果只有在代码和对照能够检测到正信号时才可信。因此，我们先进行了多组合成实验。

### 5.1 正控制：类别只由内容—位置关系决定

构造 12 节点环。两类图的拓扑完全相同，且都含 6 个 A、6 个 B：

- 一类为 A、B 交替排列；
- 另一类为 6 个 A 连续、6 个 B 连续。

两类图的内容总量相同、关系图形状相同，唯一区别是 A/B 在环上的排列。

| 读出 | 准确率 |
|---|---:|
| raw patch 均值 | 0.500 |
| KSVD 内容袋 | 0.500 |
| 仅关系图形状 | 0.500 |
| 内容 + 关系图形状 | 0.500 |
| **真实内容—位置对应** | **1.000** |
| 内容 + 打乱对应 | 0.531 |

这个结果说明：当任务确实依赖“什么内容与什么内容相邻”时，当前关系实现能够识别；打乱对应也确实会破坏信号。

### 5.2 采样范围正控制：Cube 与 Möbius 图

两个 8 节点规则图的每个节点都有 3 个邻居，但全局连接方式不同。一阶局部邻域无法区分它们，二阶邻域可以。

| 采样方式 | raw / 内容分类结果 | 解释 |
|---|---:|---|
| B0（一阶） | 0.500 | 一阶局部视图相同 |
| **R2（二阶）** | **1.000** | 确定性二阶邻域已经看到差异 |
| UniformRW | 约 0.92 | 随机游走也扩大了范围，但带来采样方差 |
| PPR | 0.500 | 即使覆盖全图，当前表示也没有区分这两个规则图 |

因此，**看得更远**与**表示得出来**是两个独立条件。扩大 patch 不是充分条件，而且随机游走也不是唯一方法。

### 5.3 早期 C4/C8 探针

在“含四元环”与“含八元环”的合成图上，一阶邻域看不到环闭合：

- B0+KSVD 约为 0.85；
- 随机游走+共享 KSVD 约为 1.00；
- CoverageRW 图级闭环为 0.91，而度基线和 B0+KSVD 均约为 0.82。

这证明采样扩大感受野在合适任务上可以有效。但 distant-triangle 负控制中，一阶邻域已经看得到三角形，B0 接近 1.00，随机游走反而下降到约 0.80–0.95。由此可见：

> 更大范围只在任务确实需要远距离结构时有帮助；否则它可能引入噪声。

### 5.4 合成实验的作用边界

这些实验支持以下两点：

1. 代码能够检测采样范围和位置绑定信号；
2. KSVD 在规则、重复、信号明确的合成数据上可以形成有用编码。

但它们不能证明真实图中也存在同样清晰、重复且与标签相关的结构词汇。因此，后续必须在真实数据上继续使用简单基线和负对照。

## 6. 第一轮真实实验：采样范围与位置关系

这一轮使用 MUTAG、PTC_MR 以及多种采样器，主要回答两个问题：

1. 覆盖更多节点和边，是否会带来更好的结构表示？
2. KSVD 原子与 patch 位置的正确对应，是否比关系图自身或打乱对应更有用？

### 6.1 采样覆盖率提高，不等于分类提高

在 PTC_MR 上：

- UniformRW 的节点/边覆盖约为 0.978/0.974，KSVD 内容为 0.572；
- CoverageRW 的节点/边覆盖进一步升至 0.985/0.982，KSVD 内容反而降至 0.533；
- PPR 的 raw patch 均值为 0.607，经 KSVD 压缩后为 0.558。

因此，更多覆盖可能同时带来更高重叠、更多重复和更多任务无关结构。**覆盖率是过程指标，不是性能保证。**

### 6.2 关系图有时有用，但收益不等于来自 KSVD

MUTAG 的一次统一协议结果中：

| 采样 | raw | KSVD 内容 | 内容+关系图 | 正确绑定 | 打乱绑定 |
|---|---:|---:|---:|---:|---:|
| B0 | 0.768 | 0.757 | 0.793 | 0.753 | 0.750 |
| R2 | 0.768 | 0.752 | 0.777 | 0.757 | 0.745 |
| UniformRW | 0.713 | 0.725 | 0.796 | 0.789 | 0.777 |
| CoverageRW | 0.747 | 0.768 | 0.802 | 0.757 | 0.775 |

这里确实可以看到：加入关系图后，部分设置明显优于只看 KSVD 内容。例如 UniformRW 从 0.725 提升到 0.796。

但加入正确的原子—位置绑定后，UniformRW 从 0.796 降为 0.789；CoverageRW 则从 0.802 降为 0.757。关系图的低维拓扑统计可能有用，但这并不能证明 KSVD 原子具有可迁移的组合语义。

### 6.3 多随机种子复查否定了表面正例

对最有希望的 UniformRW，进一步固定 3 个采样种子并更换 3 个数据划分种子，共检查 9 组五折结果：

| 数据集 | 内容 | 内容+关系图 | 正确绑定 | 打乱绑定 | 正确绑定 − 内容+关系图 | 正确绑定 − 打乱 |
|---|---:|---:|---:|---:|---:|---:|
| MUTAG | 0.728 | 0.796 | 0.768 | 0.778 | -0.027 | -0.010 |
| PTC_MR | 0.569 | 0.567 | 0.557 | 0.542 | -0.011 | +0.015 |

PTC_MR 上正确绑定虽高于打乱绑定，但仍低于内容和内容+关系图。只比较“正确 vs 打乱”会得到过于乐观的解释；更低容量的 `content+graph` 是必须保留的对照。

### 6.4 这一轮得到的判断

- 确定性 R2 已能完成部分需要更大范围的任务，随机游走不是必要条件；
- 提高覆盖率没有转化为跨数据集稳定收益；
- 真实数据上的关系增益主要来自 patch 关系图自身，而非 KSVD 原子与位置的精确绑定；
- raw patch 有时优于 KSVD，说明字典压缩可能丢失任务信息。

这促使我们把问题进一步收缩到：**在没有节点属性干扰的真实数据上，KSVD 原子本身究竟是什么？**

## 7. 第二轮真实实验：纯结构数据上的系统审计

### 7.1 先检查输入给 KSVD 的 patch 是否合理

如果采样得到的 patch 几乎全是同一种简单结构，字典学不到丰富词汇并不奇怪。因此先检查 patch 的实际组成。

| 设置 | 主要现象 | 含义 |
|---|---|---|
| IMDB-BINARY / B0 | 82.4% patch 为团；图内不同结构比例约 0.306 | 字典容易主要按团大小和度数分组 |
| IMDB-MULTI / B0 | 81.8% patch 为团；图内不同结构比例约 0.287 | 与 IMDB-BINARY 类似 |
| REDDIT / B0 | 61.9% patch 只是单边 | 一阶 patch 过于简单 |
| REDDIT / R2 / 最多 12 节点 | 62.0% patch 触及 12 节点上限 | 二阶结构更丰富，但截断明显 |
| REDDIT / R2 / 最多 24 节点 | 8167 种结构签名；图内不同结构比例约 0.680 | 比前述设置丰富，适合做最终复查 |

需要特别区分：**61.9% 单边对应 Reddit 的 B0 设置，而不是最终使用的 R2/max_nodes=24 设置。**最终 Reddit 设置中只有约 0.7% patch 为单边，48.3% patch 触及 24 节点上限。

### 7.2 最终同条件协议结果

下表均为“简单图统计 + 对应结构特征”的 balanced accuracy，来自 3 个划分种子 × 5 折。不同方法共享相同训练预算和下游分类器选择方式。

| 方法 | IMDB-BINARY | IMDB-MULTI | REDDIT-BINARY |
|---|---:|---:|---:|
| stats | 0.7533 | 0.5009 | 0.8432 |
| raw patch | **0.7668** | 0.5463 | 0.8202 |
| PCA | 0.7549 | 0.5172 | 0.8325 |
| clustered real-patch | 0.7544 | 0.5538 | 0.8252 |
| unconstrained KSVD | 0.7479 | 0.5400 | 0.8328 |
| final-projected KSVD | 0.7536 | 0.5410 | 0.8318 |
| iterative-projected KSVD | 0.7480 | **0.5673** | 0.8333 |
| relation-only | 0.7466 | 0.5055 | **0.8550** |
| KSVD + graph | 0.7600 | 0.5570 | 0.8480 |
| 最佳 projected + graph | **0.7663** | **0.5685** | 0.8403 |

这张表不能只看每列最高值，还要看结果是否来自 KSVD、是否跨种子稳定：

- **IMDB-BINARY：** raw patch 为 0.7668，高于所有只使用字典内容的方法。final-projected+graph 达到 0.7663，但并未超过 raw，而且相对真实 patch+graph 的优势不是 3/3 种子一致。
- **IMDB-MULTI：** iterative-projected 为 0.5673，出现了值得注意的局部正信号；它平均比真实 patch 字典高 0.0135，但三个种子的差值为 `[+0.0047, -0.0129, +0.0487]`，方向不一致。
- **REDDIT-BINARY：** 最好结果是完全不使用原子内容的 relation-only，达到 0.8550。所有 KSVD 内容方法均低于 stats；KSVD+graph 也低于 relation-only。

因此，可以说“某些 patch 或 patch 关系包含结构信息”，但不能说“KSVD 特有的字典学习稳定提取了这些信息”。

## 8. 原子语义审计：KSVD 学到的到底是不是图结构

分类结果不足以证明原子可解释。我们又直接检查每个原子与训练集真实 patch 的关系。

### 8.1 “可投影代理指标”是什么意思

对每个 KSVD 原子，我们寻找余弦相似度最高的真实训练 patch，并检查：

- 最近真实 patch 是否足够接近；
- 原子中是否含有较多与计数型结构特征不一致的负值；
- 原子的多个近邻是否具有一致的结构签名；
- 更换训练划分后，匹配原子的最近真实结构是否一致。

本文把“最近余弦相似度不低于 0.95，且负值质量不高于 0.05”称为**可投影代理指标**。它只是一个向量层面的必要检查：

> 通过该指标，不代表已经严格解码为一个图；未通过该指标，也不能证明原子在任何意义下都不含结构信息。

它能回答的更窄问题是：该原子能否被直接解释成一个足够接近、合法的训练 patch。

### 8.2 审计结果

| 数据集 | KSVD 可投影代理比例 | KSVD 最近结构跨运行一致率 | 真实 patch 字典一致率 |
|---|---:|---:|---:|
| IMDB-BINARY | 0.554 | 0.717 | 0.733 |
| IMDB-MULTI | 0.496 | 0.670 | 0.692 |
| REDDIT-BINARY | 0.158 | 0.412 | 0.435 |

主要观察如下：

1. IMDB 中约一半自由原子满足代理条件，但输入 patch 本身约 82% 是团。原子的高纯度很大程度上是在重复团大小和度数，而不是发现复杂结构。
2. Reddit 的 R2/max_nodes=24 patch 更丰富，但 KSVD 原子的平均最近余弦相似度降至 0.863，负值质量升至 0.077，只有 15.8% 满足可投影代理条件。
3. 15.8% **不等于**“只有 15.8% 原子在数学上能够代表图”。准确表述是：只有 15.8% 能通过当前定义的“接近合法训练 patch”的必要代理检查。
4. 直接从训练集中选择的 clustered real-patch 字典天然 100% 合法、可以回指具体 patch，而且其跨运行结构一致率不低于 KSVD。

因此，普通 KSVD 最多被证实学到了 patch 向量空间中的压缩方向；现有证据不足以把这些方向称为稳定、合法的局部子图词汇。

## 9. 第一轮补救：强制每个原子成为真实 patch

自由 KSVD 原子不一定合法，一个自然的替代解释是：

> KSVD 的想法可能没有错，只是自由向量原子不可解释；如果把每个原子投影到最近的真实训练 patch，结果也许会改善。

我们实现了两个版本：

- **final-projected：** 普通 KSVD 训练结束后，把所有原子一对一投影到不同的真实训练 patch；
- **iterative-projected：** 每轮字典更新后立即投影，再重新进行稀疏编码。

投影后每个原子都来自训练集真实 patch，因此合法性检查为 1.0。但最终门槛要求的不只是合法，还要求同一个方法：

1. 对 raw、PCA、clustered real-patch 三个基线都更好；
2. 三个数据划分种子方向一致；
3. 在至少两个结构差异明显的数据集上复现；
4. 控制简单图统计后仍保留增益。

结果是：

- final-projected 没有在任何数据集上同时满足上述三个基线的 3/3 种子优势；
- iterative-projected 也没有通过；
- IMDB-MULTI 的 iterative-projected 平均结果较好，但相对真实 patch 字典的种子方向不一致；
- Reddit 上 projected 内容虽略优于 raw，却没有超过 PCA，也明显低于 relation-only；
- 投影还提高了训练 patch 的重建误差，但重建误差的变化与分类排序并不一致。

**判断：NO-GO。**

这个实验排除了一个重要解释：此前失败不只是因为自由原子“不合法”。即使让每个原子都成为合法真实 patch，仍没有出现跨数据集稳定的 KSVD 特有增益。

## 10. 第二轮补救：不用 WL，保留完整邻接结构

### 10.1 为什么要做 non-WL 实验

WL 统计是置换不变的，但理论上会把某些非同构图映射到相同表示。例如，triangular prism 与 `K3,3` 在当前 WL 向量下相同。因此，有必要检查：KSVD 失败是否主要来自 WL 的信息损失。

我们比较三种表示：

| 表示 | 保留的信息 |
|---|---|
| WL | 度、度对和 3 轮 1-WL 统计；置换不变，但理论上有损 |
| canonical | 经过规范标号的完整邻接矩阵和节点掩码；在无根图同构意义下保留完整结构 |
| rooted canonical | 在 canonical 基础上额外保留采样中心在 patch 中的角色 |

这里没有采用“增加几维排序依据”的启发式方案。原因是只要排序仍有并列，并最终依赖原始节点编号打破并列，表示就不再严格置换不变。规范标号提供了更严格的无 WL 对照。

### 10.2 实际 patch 中观察到了多少 WL 冲突

- 在 IMDB-BINARY、IMDB-MULTI 和 REDDIT-BINARY 的实际 patch 中，没有观察到一个 WL 类型对应多个无根 exact graph 类型；
- Reddit 中观察到相同无根 patch 对应不同采样中心角色，因此 rooted canonical 仍有检查价值。

这并不意味着 WL 在理论上无损，只意味着**本实验实际采到的 patch 中，未观察到无根结构类型冲突**。

### 10.3 最终“不使用 WL”结果

| 数据集 | WL 中最有利的相关结果 | canonical 中最有利的相关结果 | rooted 中最有利的相关结果 |
|---|---:|---:|---:|
| IMDB-BINARY | raw 0.7668 | real-patch 0.7579 | raw 0.7502 |
| IMDB-MULTI | iterative-projected 0.5673 | final-projected 0.5485 | raw 0.5128 |
| REDDIT-BINARY | iterative-projected 0.8333 | final-projected 0.8418 | iterative-projected 0.8417 |

表中每一格取该表示下 raw、PCA、真实 patch、普通 KSVD 和 projected-KSVD 内容方法中的最高值，不包含关系图特征。按照预先设定的门槛：

- WL 的两个 projected 方法均没有通过任何数据集；
- canonical final-projected 只在 IMDB-MULTI 上稳定超过该表示自己的 raw、PCA 和真实 patch 基线；
- rooted 的两个 projected 方法没有通过任何数据集；
- 没有一种 projected 方法在至少两个数据集上通过；
- Reddit 上所有这些字典内容结果仍低于 relation-only 的 0.8550。

**最终判断仍为 NO-GO。**

不使用 WL 的实验说明，表示几何确实会影响原型选择，不能说完整邻接信息“完全没用”。但失败不能主要归因于已观察到的 WL 类型冲突或采样中心丢失：即使保留完整邻接结构，普通欧氏 KSVD 仍没有形成跨数据集稳定优势。

## 11. 总证据：四个核心条件得到了什么支持

| 条件 | 实验判断 | 关键证据 |
|---|---|---|
| H1 合法、可回指 | **自由 KSVD 未通过；投影后可强制满足** | Reddit 上只有 15.8% 自由原子通过“接近合法真实 patch”的代理检查；投影可使原子合法，但未带来稳定任务增益 |
| H2 跨划分稳定 | **未获得相对简单基线的优势** | KSVD 最近结构一致率在三个数据集上均不高于真实 patch 字典 |
| H3 独立任务价值 | **未获得足够支持** | 没有一种普通或 projected KSVD 在至少两个数据集上、对 raw/PCA/真实 patch 均保持 3/3 种子优势 |
| H4 位置关系有意义 | **合成正控制成立，真实数据未成立** | 合成任务正确绑定为 1.000；真实数据中正确绑定未稳定超过更简单的 content+graph 和打乱对照 |

比“全部假设被数学上证伪”更准确的结论是：

> **在当前测试范围和预先设定的判断标准下，四个条件都没有得到足以支持 KSVD 主路线的证据。**

其中 H1 可以通过投影在形式上修复，但 H3 和 H4 仍未随之成立。也就是说，单独解决“原子合法”还不够。

## 12. 为什么这条路线没有成立

### 12.1 最核心的不匹配：重建几何不等于任务结构

普通 KSVD选择原子的标准是降低向量的欧氏重建误差。它偏好的是能够解释数据方差的方向，而我们真正需要的是：

- 图结构上相近；
- 与任务标签相关；
- 在不同数据划分或环境中稳定；
- 能对应合法离散结构；
- 能恢复精确出现位置和关联关系。

这些目标之间没有必然等价关系。一个重建能力强的原子，可能只是平均了多个 patch；一个常见 patch，也可能只反映图大小或度数；一个分类偶然有效的方向，也可能无法跨划分复现。

### 12.2 Patch 分布本身可能被简单结构主导

IMDB 的一阶 patch 大多是团，Reddit 的一阶 patch 大多是单边。扩大 Reddit patch 后，结构种类变丰富了，但大 patch 又频繁触及节点数上限。因此，词汇可能主要学习采样尺度、星形大小或度分布，而不是更有意义的高阶结构。

### 12.3 连续原子难以承担离散结构语义

自由 KSVD 原子允许正负线性组合。它在向量空间中可以是很好的重建方向，却未必对应任何一个真实图。把它事后映射到最近真实 patch 可以获得合法性，但这种映射并没有自动获得任务相关性和跨环境稳定性。

### 12.4 位置绑定维度高、数据支持不足

真实图中的 patch 数量、重叠方式和原子激活都很不规则。精确绑定会引入大量稀疏组合特征。在数据量较小时，这些特征容易过拟合。实验中更低维的 relation-only 或 content+graph 经常更稳定，符合这一解释。

### 12.5 更丰富的输入不自动产生更好的欧氏空间

non-WL 实验保留了完整邻接矩阵，但分类仍未稳定改善。这说明问题不仅是“信息有没有被保留”，还包括“向量空间中的距离和线性组合是否符合结构语义”。完整信息放进一个不合适的几何空间，仍不保证 KSVD 能学习到合适词汇。

## 13. 结论边界：什么被关闭，什么仍然开放

### 13.1 本轮可以关闭的路线

在没有新的机制假设之前，不再把以下内容作为主要实验方向：

- 继续普通地调 KSVD 原子数、稀疏度或迭代次数；
- 仅通过增加随机游走长度、patch 数量或覆盖率来挽救性能；
- 继续设计多维节点排序来替代严格规范标号；
- 仅通过更强投影或更复杂连续原子约束来解释结构合法性；
- 在没有同条件对照的情况下，把关系图的增益归因于 KSVD；
- 直接把当前 KSVD 原子的出现记录接到 CIN 式网络中，并把性能变化解释为“学到了结构词汇”。

### 13.2 KSVD 仍可保留的角色

- **压缩基线：** 检查稀疏编码是否优于 raw 和 PCA；
- **候选初始化器：** 为后续离散结构选择提供初始候选，而不是作为最终词汇；
- **数据诊断：** 判断某类 patch 是否存在明显重复方向；
- **可视化工具：** 通过最近真实 patch 辅助理解局部结构分布。

### 13.3 更大的研究方向仍然开放

本轮真正被否定的是一个具体实现：

> “普通欧氏 KSVD + 当前 patch 向量 + 稀疏重建”可以直接充当显式、自适应的结构词汇学习器。

更大的目标仍可以保留，并应更严格地表述为：

> 从合法离散候选中，学习一组跨图、跨数据划分或跨环境稳定的结构原型；同时恢复这些原型在每张图中的精确出现位置和关联关系，并证明它们提供了超出简单统计、内容袋和关系图自身的任务增益。

## 14. 对 CIN / MolHIV 后续路线的启示

这组实验不直接回答 MolHIV 上能否达到约 0.80，也不能用 TUData 的交叉验证数字与 CIN 的官方结果直接比较。MolHIV/CIN 需要单独使用官方分子骨架划分（scaffold split）、ROC-AUC 和一致的训练协议。

为了避免后续工作变成对 CIN 的简单模仿，创新点不应只是“把 KSVD 原子当成 cell，再套用 CIN 的消息传递”。更清楚的区别应是：

| CIN 式思路 | 我们仍可探索的方向 |
|---|---|
| 预先规定某类高阶 cell，例如环 | 从合法候选中学习哪些结构应进入共享词汇 |
| cell 类型由人工规则给定 | 词汇由数据和任务共同选择，但候选本身保持可解码 |
| 重点是高阶 cell 上的消息传递 | 重点先放在词汇合法性、精确的出现位置、对应关系和跨环境稳定性 |
| 性能可证明模型有效 | 除性能外，还要求通过真实/打乱绑定、仅关系图、简单结构统计等对照 |

更合理的下一步不是继续优化 KSVD，而是研究：

1. **合法候选生成：** 从真实子图、环系统、路径或化学片段中产生可回指的候选；
2. **学习式选择：** 学习哪些候选应成为共享结构词汇，而不是在连续空间中自由混合；
3. **结构度量：** 学习更符合任务的结构相似度，而不是直接使用欧氏重建误差；
4. **精确出现与关联：** 明确记录每个原型在哪些节点、边或高阶单元上出现；
5. **跨环境稳定：** 在分子骨架划分、其他数据划分或结构分布变化后，检查同一词汇能否保持语义；
6. **严格边界对照：** 必须证明学习得到的词汇超过人工结构、raw/PCA、真实 patch、仅关系图和打乱位置等对照。

只有在这些条件得到支持后，才值得把学习得到的词汇接入 CIN 风格的高阶消息传递，并在 MolHIV 官方协议下检验能否接近或超过 CIN。

---

## 15. 最终判断

### 15.1 关于 KSVD

**NO-GO：普通欧氏 KSVD 不再作为当前课题的核心结构词汇学习方法。**

原因不是某一个数据集分数低，而是完整证据链没有闭合：

- 自由原子缺乏充分的合法性；
- 结构语义稳定性不优于直接选择真实 patch；
- 分类增益没有跨数据集和随机划分稳定超过简单基线；
- 正确位置绑定在真实数据上没有显示额外价值；
- 强制合法投影与 non-WL 完整邻接表示都没有改变最终判断。

### 15.2 关于科研主命题

**GO：显式、自适应结构学习仍值得继续，但需要从“连续重建字典”转向“合法离散候选上的学习式选择与组合”。**

这组负结果的价值在于，它把后续工作需要满足的条件变得更清楚：

> 一个真正可信的自适应结构词汇，不能只重建得好或在一个数据集上偶然涨点；它必须合法、可回指、跨环境稳定，能够恢复精确的出现位置和对应关系，并在严格同条件对照下提供可复现的任务增益。
