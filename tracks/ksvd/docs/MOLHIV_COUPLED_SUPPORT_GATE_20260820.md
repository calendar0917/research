# MolHIV：结构—化学共享支持字典的机制门槛

日期：2026-08-20

## 要回答的问题

此前的两个极端都不理想：只用结构 patch 会遗漏分子的原子和化学键信息；把
结构与化学特征直接拼接后再做字典学习，则要求它们使用完全相同、数值也相同的
稀疏系数。这一要求没有化学依据，也可能解释了早期联合字典的不稳定。

本轮的假设是：一个局部结构模式和一种局部化学模式可以是同一个“词”，但在某
个具体 patch 中，二者出现的强弱不必相同。

## 表达方式

对每个 patch 同时建立两种向量：

- 结构视角：不含原子／化学键信息的局部拓扑摘要；
- 化学视角：原子和化学键统计、带标签的局部消息、环与芳香性事实。为避免把
  拓扑重复塞入，这一视角显式去掉了前面的无标签结构坐标。

一个字典原子也有结构部分和化学部分。编码时，两种视角必须选中同一小组原子
编号（共享支持），但随后分别最小二乘求各自系数（分离强度）。

这与“拼接后用一个系数”不同，也不是简单把两套独立编码拼起来。

## 必要对照

1. 两套完全独立的 KSVD；
2. 直接拼接后、强制同一系数的普通 KSVD；
3. 本方案：共享支持、分离系数；
4. 严格打乱：仅打乱训练中每个结构 patch 对应的化学 patch，且没有任何 patch
   保持原对应；结构集合、化学集合、样本数和字典容量均不变。

所有均只用当前骨架训练折拟合均值、缩放和字典；留出折没有参与。

## 进入分类前的门槛

不能仅因重构误差低而进入分类。至少需要在完整骨架折上同时看到：

1. 本方案的双视角重构不显著弱于直接拼接；
2. 在留出 patch 上，结构侧和化学侧独立推断出的字典支持，真实对应的重合度
   高于同样 patch 集合的无固定点打乱；
3. 用真实对应训练出的字典，在真实对应的留出 patch 上联合重构优于打乱对应；
4. 上述两项的差异大于“从打乱对应训练字典”所能产生的差异。

若达不到这些机制门槛，就不进入下游分类，也不以换更大的分类器掩盖问题。

分类阶段若启动，仍需与原始 patch、主成分、普通 KSVD、完全共享系数联合字典
及真实—化学对应打乱版本，在同一低容量读出器下公平比较。

## 全量三折机制结果

使用 8k 开发集的固定骨架三折；每折均使用全部训练／留出图，12 个字典原子、
每个 patch 至多选择 3 个原子。下表中的“支持一致性差”是留出 patch 上，真实
结构—化学配对的一致性减去无固定点打乱配对的一致性；“配对重构差”是打乱配对
的联合误差减去真实配对的联合误差，正数表示真实配对更好。

| 骨架折 | 真实对应训练：支持一致性差 | 打乱对应训练：支持一致性差 | 真实对应训练：配对重构差 | 打乱对应训练：配对重构差 |
|---|---:|---:|---:|---:|
| 0 | 0.0735 | 0.0053 | 0.0108 | 0.0019 |
| 1 | 0.0490 | 0.0005 | 0.0069 | 0.0014 |
| 2 | 0.0337 | -0.0011 | 0.0090 | 0.0003 |
| 平均 | 0.0521 | 0.0016 | 0.0089 | 0.0012 |

并且共享支持、分离系数的联合重构误差在三折均低于强制同一系数的拼接字典
（0.5760 对 0.6155；0.5879 对 0.6257；0.5867 对 0.6252）。因此机制门槛通过：
真实的结构—化学对应确实能被新字典识别，且不是两套视角各自压缩造成的假象。

## 第一轮分类结果：替换式读出不通过

同一三折上，所有方法用同一个标准化逻辑回归。把新编码**替换**原始 patch 的结果：

| 表示 | 平均排序能力 |
|---|---:|
| 原始双视角 patch | 0.6558 |
| 双视角主成分 | 0.6112 |
| 独立两套 KSVD | 0.5768 |
| 直接拼接、强制同一系数 | 0.6024 |
| 共享支持、分离系数 | 0.5937 |

新编码本身不通过分类门槛：低于主成分，也低于直接拼接。但其对应关系有分类相关
信号：预测时只打乱结构—化学对应后，0.5937 降为 0.5425；训练时打乱对应，降为
0.5717。下一项也是最后一项直接检验：在不丢弃原始双视角 patch 的前提下，只将
共享支持编码追加为一个小的旁路；若它不能同时超过原始表示和两种打乱对照，即停止
该下游分支。

## 最后旁路检验：不通过，停止分类分支

最后将原始双视角 patch 的读出原封不动保留，只追加共享支持编码的读出。三折平均
排序能力如下：

| 表示 | 平均排序能力 |
|---|---:|
| 原始双视角 patch | 0.6558 |
| 原始双视角 patch＋真实共享支持旁路 | 0.6525 |
| 原始双视角 patch＋预测时打乱对应的旁路 | 0.6557 |
| 原始双视角 patch＋打乱对应训练出的旁路 | 0.6584 |

真实旁路相对原始表示为 -0.0033；相对预测时打乱为 -0.0032；相对打乱训练为
-0.0059。三项都不满足正向增益，且后两折方向一致为负。

因此结论需要分开说：

1. **机制成立。** 共享支持、分离系数的 KSVD 能识别真实结构—化学 patch 对应，
   且这一对应会影响其自身的分类读出；
2. **MolHIV 分类路线不成立。** 无论替换原始 patch，还是作为保留原始 patch 的
   旁路，它都不提供稳定额外排序能力；
3. **停止条件触发。** 不应继续通过更换池化、调字典容量、加入 GIN/GINE 或放大
   注意力模型来试图把这一结果调成正数。这些做法将无法回答 KSVD 是否必要。

若继续研究，应将问题转为：在另一个带丰富属性、标签与局部化学模式更直接相关的
数据集上，先复现“机制成立且对原始表示有条件补充”的必要条件；或将本路线写成
“结构—化学局部对应的可验证表示”工作，而不再宣称它改善 MolHIV 分类。
