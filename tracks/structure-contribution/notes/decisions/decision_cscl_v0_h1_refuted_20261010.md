## 结论

1. **H1 被反驳**:在 v0 的表示层级(类型 embedding + 单元描述子 + 单元间键
   关系)上,显式加性单元贡献 + 真实单元对关系贡献**没有**带来增量价值;
   真实关系对应不仅无益,而且稳定地有害(B < C:打乱关系反而更好)。
2. **机制读法**:C≈A 都好于 B——关系槽的额外容量本身无害,但强迫 γ 与
   真实单元对对齐后性能下降;同时 D(同输入、通用非线性读出)显著好于 B,
   说明关系信息并非不可用,而是**加性成对分解这一形态**在此表示层级上
   损失了表达能力(成对加性 + 无高阶聚合)。
3. **可辨识性两面**(如实记录):
   - 合成任务:惩罚有效(α 承担类型效应,spearman 0.875;λ=0 时塌缩 0.488);
     真交互 γ 检出(0.134 vs 陷阱 0.069)。
   - 真实 ZINC:λ=0.01 只部分起效(δ̄ 0.06,γ̄ +0.107 未归零);跨 seed
     α 一致性中等(pearson 0.73,符号一致 0.78)。
4. soup 权重平均破坏 embedding 归因几何(addendum)——解释对象已固定为
   best-epoch 检查点。

## 决定(按预注册停止条件)

- 触发:"正式结果判 DEGRADED 且 B 不优于 XGB" → **停止当前方法形态**,
  不追加超参搜索、不增种子、不改判据。
- **保留的资产**(经证据支持):RINGCHAIN-v0 划分(标签盲审计全过、跨分子
  复用充分、对齐校验 10000/10000)、单元类型词表与 UNK 路由、贡献导出与
  三层解释评价管线、配对比较协议。
- **下一轮唯一有证据支持的方向**(非自动执行,需新预注册):把已验证的
  RINGCHAIN 单元划分作为**强 backbone 特征的归因单元**(在 ksvd 轨
  ~0.12-0.19 级别的特征/读出上做单元级分解),而不是在弱表示上重建预测
  能力;以及把"关系"从成对加性 γ 升级为受限的高阶聚合(与 D 的读出对齐)。
  K-SVD/CSSD 维持"可选工具"地位不变。

## 被反驳命题的边界(防止过度解读)

- 本轮反驳的是"**在 v0 表示层级 + 加性成对分解形态下**关系项有增量价值",
  不是"RINGCHAIN 划分无用"也不是"任何显式分解都无用"(D 用同输入更好,
  说明输入信息充足、瓶颈在读出形态)。
- 全部数字为内部 fit/dev 开发划分,official test 从未加载,official valid
  本轮未加载。
