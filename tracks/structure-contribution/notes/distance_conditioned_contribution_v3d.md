> 研究命题：Full-Y 的强预测能力部分依赖按原子对距离桶组织的 pair-value 一阶、二阶矩，
> 而 v3/v3b/v3c 映射到 RINGCHAIN 单元时只保留了跨桶合并的边际矩。完整恢复这些统计量后，
> 结构化贡献模型能否在不增加隐藏预测旁路的条件下缩小与不透明读出及 Full-Y 的差距？
>
> **答案：是，且情况 A 的预注册判据全部满足**——但同信息下 S−O 的剩余差距（+0.011）不随
> 信息恢复而缩小，说明剩余代价属于加性读出结构本身，而非信息缺失。

### 三个科学结论（超越 MAE 记录）

1. **O−F 的"距离桶压缩"解释被完全证实**：v3b/v3c 反复记录的 O−F ≈ +0.025 差距，在恢复
   完整桶级矩后变为 **−0.0003（CI 跨零）**。不透明读出与 Full-Y 的全部差距基本就是这份
   被压缩的按距离桶组织的 pair 一阶/二阶矩信息。
2. **S−O 的剩余差距与信息无关**：v3c（信息不全）S−O = +0.0108；v3d（信息完整）S−O =
   +0.0108。同信息条件下结构化加性出口的剩余代价稳定在 ~0.011 —— 它不是信息缺失造成的，
   而是加性读出结构（α+δ 逐单元 + γ 逐单元对 + 逐特征全局 bank）相对不透明混合读出的
   表达/优化边界。下一步研究 Full-Y reader 的非线性混合机制（但按任务书边界，情况 A 的
   预注册下一步是独立验证，不是继续改架构）。
3. **S−F 缩小 2/3**（+0.036 → +0.011）：结构化贡献模型在信息完整后距离强预测基础仅一步之遥。

## 1. Phase A：CPU-only 诊断（`results/cscl_v3d/phase_a_s0.json`）

### 1.1 UNK 是 O/S 共同瓶颈，不是结构化模型特有

在**完全相同的 dev 分子**上（874 含 UNK / 1126 不含）：

| 组 | n | F | O | S_v3c | O_bucket | S_bucket |
|---|---:|---:|---:|---:|---:|---:|
| 含 UNK | 874 | 0.1490 | 0.1936 | 0.2056 | **0.1534** | 0.1663 |
| 不含 UNK | 1126 | 0.0911 | 0.1007 | 0.1105 | **0.0872** | 0.0964 |

- v3c 的"UNK 分子 0.206 vs 0.111"在 F/O 上同样成立（F 含 UNK 也只有 0.149）——
  UNK 困难是**所有重训模型的共同模式**，Full-Y 的 soup 选择与端到端信息路径缓解了它。
- 组内配对差（S_bucket−O_bucket）：含 UNK +0.0130 [+0.0033, +0.0230]，不含 +0.0092
  [+0.0047, +0.0139] —— 同量级，S/O 差距在 UNK 与非 UNK 分子上同质。
- 混杂核查：has_unk 与 n_atoms 相关 −0.07、与环复杂度 −0.15、与 y≤−3 相关 +0.09
  （UNK 分子 y 尾比例 8.9% vs 4.4%）—— 无强混杂；n_unk=2/3 的组 n=63/2 太小，不下结论。
- n_unk 分层（F/O/S_v3c 全体误差随 n_unk 单调上升，n=2 时连 F 都 0.283）。

### 1.2 冻结 v3c γ 诊断（不训练）

- |γ| 与关系 pair 数相关 0.47（Spearman 0.50）；每分子关系贡献和平均幅值 0.181。
- **bonded vs 非键连**单元对：|γ| 均值 0.045 vs 0.023（9,136 vs 19,166 个 dev 关系）——
  直接键连的单元对承担更大的关系贡献。
- **关键结构性发现：没有任何关系实例的主导桶是 bucket-0**（n=0）。物理键 pair 总是与
  同一单元对的远距离 pair 混合在一个无序单元对里，而 v3c 的 γ 每个单元对只输出一个标量
  ——它**原则上无法**区分"这对单元的 bonded pair 贡献"与"远距离 pair 贡献"。这正是
  距离条件信息的丢失点，也是本轮特征的动机。
- 零-γ 反事实（仅当前模型计算依赖诊断，不是重训消融，无化学因果解读）：置 γ=0 后
  MAE 0.152→0.253（+0.101），|Δpred| 均值 0.181，corr(|Δpred|, |err|)=0.09。

### 1.3 信息丢失清单（量化）

- dev 分子 pair 桶分布：50.6% 的 pair 在 bucket-4（距离≥5）、10.0% 在 bucket-0（bonded）；
  1998/2000 个分子的 pair 分布于全部 5 个桶；归一化桶熵均值 0.84 —— 桶条件结构普遍存在。
- 丢失内容（v3 代码确认+边界文档核实）：per-(unit×bucket) 与 per-(unit-pair×bucket) 的
  一阶/二阶矩在提取时被计算但未存储（`intra_b_*`/`cross_b_*` 是局部变量）；
  v3 输入只保留跨桶边际（unit_sum_pv、rel_sum_pv）+ 关系级桶计数。

## 3. Phase C：共享增强输入的两臂

**同一 `BucketBatch`**（v3 V3Batch + 两个新块，由**同一个** collate 函数产出，测试钉住
两臂收到逐位相同张量）：

- 单元桶块 485 列 = 每桶 [count, mean48, rms48]（bucket-major，零桶→全零；
  mean/rms 可由存储的 sum/sumsq 与 count 精确恢复）
- 关系桶块 480 列 = 每桶 [mean48, rms48]（桶计数已在旧列 rel_bucket_counts）
- 旧列全部来自未改动的 v3 collate（逐位相等，测试钉住）

**S-bucket**（继承 v3c 全部语义）：`pred = bias + Σ_u(α_t+δ_u) + Σ_r γ_r + g_ctx + g_topo`；
δ 输入 [z384 | ctx40 | type_emb16 | 桶485] = 925；γ 输入 [v3 行1273 | 桶480] = 1753；
桶信息路由（AST 钉住）：**单元内桶信息只经 δ，跨单元桶信息只经对应 γ**；无融合 MLP、
无学习型全局桶残差、无 Full-Y 预测输入。

**O-bucket**（继承 v3 O 全部原则）：unit_enc 440→925、rel_enc 1273→1753，DeepSets
mean+sum 池化与不透明 reader 原样，只加宽输入层。

**初始化纪律**：seed-0 构建未训练 v3c 头 / v3 O 头 → 逐位复制全部形状不变参数 → 新列
零初始化。**两臂新增参数完全相同（各 +61,760 = 485×64 + 480×64）**；未训练预测与参考头
**逐位相等**（两臂 diff = 0.0）。S 参数量 131,368→193,128；O 138,753→200,513。
可学习性：零初始化新列第 0 步即获梯度，一步优化后非零且扰动桶输入即改变预测（测试钉住）。

**容量/损失混杂披露**：两臂 vs 各自历史版本的改善同时引入 +61,760 参数，无无桶消融对照
（协议禁止），改善不能全部归因"桶信息本身"；S 保留历史 γ 惩罚（1.0）而 O 用纯 L1，
S−O 不是纯粹的加性形式因果代价；F 的 checkpoint 规则（soup）与两臂（best-monitor）不同。
但 **S_bucket vs O_bucket 是同信息、同新增容量、同 batch 序列的比较**，是本轮主判据。

## 6. 十二个问题的正式回答

1. **v3c 丢了什么**：per-(unit×bucket) 与 per-(unit-pair×bucket) 的 pair-value 一阶/二阶矩
   （§1.3 清单；单元内桶计数也丢了）。图级 count 块本来就被 C6 掩码（F 同样），不是差异。
2. **能否从缓存重建**：能——从**已存储**数组重建 Full-Y reader 每桶 first/second 矩至
   5.8e-7（门 2e-4）；桶和精确包含旧边际场；计数精确守恒（§2 表）。
3. **S/O 是否同输入**：是——单一 collate 函数，测试断言两臂收到的全部 9 个张量逐位相等。
4. **新增参数**：两臂**各 +61,760**（S 193,128 / O 200,513）；vs 历史：S 比 v3c +61,760，
   O 比 v3 O +61,760。初始化共享部分逐位、新列零初始化、未训练预测逐位相等（diff 0.0）。
5. **S_bucket vs S_v3c**：**−0.02515** [−0.03357, −0.01708]（0.15209 → 0.12694）。
6. **O_bucket vs O_v3**：**−0.02518** [−0.03182, −0.01854]（0.14129 → 0.11610）。
7. **S−O 差距**：+0.01084 [+0.00573, +0.01596] —— 与 v3c 的 +0.01080 几乎相同：**没有
   进一步缩小**；剩余差距是读出结构边界，不是信息缺失。
8. **S_bucket 距 F**：+0.01053 [+0.00424, +0.01700]（从 v3c 的 +0.03567 缩小 2/3）。
9. **桶信息是否真正影响 S 的单元/关系贡献**：是——合成任务 B 斜率 0.781/corr 0.979 证明
   γ 以桶条件方式响应真值；真实 ZINC 上 bonded 单元对 |γ| 系统性更大；δ 的桶输入可学习
   （梯度/扰动测试）。但真实 ZINC 上 γ 的方差占比仍小（1.5%），桶信息主要经 δ 起作用。
10. **UNK/低 y 尾**：含 UNK 0.206→0.166（S），O 0.194→0.153；y≤−3 S 0.311 vs F 0.315
    （首次持平）；组内 S−O 差距 UNK/非 UNK 同质（+0.013/+0.009）。F/O 相同分子对照见 §1.1。
11. **α/δ/γ 分工、gauge、合成**：全部保持可信（§4 各门 + 占比未异常 + 分半未恶化）。
12. **进入独立验证还是研究表达边界**：预注册判据给出**情况 A**——按任务书应冻结方法定义、
    预先确定独立评价指标、在隔离数据上做一次独立确认。同时记录：S−O≈0.011 的稳定残差
    说明加性出口仍有表达边界，该问题应作为独立验证之外的并行研究方向（本轮不执行）。

## 7. 限制与披露（最终结论的边界）

- **正确性与数值守恒事实**：守恒/重建/对齐门全部通过（§2）；gauge 与加性门通过（§4）。
  这些是实现与数值事实，由测试与运行时断言验证，不是数学证明。
- **预测性能结果**：单 seed 0、单一 dev 2000；bootstrap 是分子重采样区间，不是训练种子
  稳定性；O_bucket−F = −0.0003 的"追平"读数在 CI 跨零意义下成立，不能声称"优于 F"。
- **合成机制证据**：两个任务的真值均预冻结、无生成器调参；任务是机制证据，不构成
  真实 ZINC 上的化学因果。
- **真实 ZINC 归因**：全部为"模型预测归因"；γ 的桶敏感不等于因果交互；通道占比非独立解释率。
- **容量、损失与架构混杂**：+61,760 参数对两臂对称，但 vs 历史版本的改善混杂容量；
  S 的 γ 惩罚使两臂目标不同；F 的 checkpoint 规则（soup）与两臂（best-monitor）不同，
  F=0.11641 与 O_bucket=0.11610 的比较应考虑这一差异（soup 通常略优于 best-monitor，
  即真实 F vs O_bucket 差距可能更偏向 O_bucket 一侧，方向上不威胁"追平"结论）。
- **单 seed 限制**：无 seed 1（协议禁止）；跨 seed 稳定性未验证。
- **多轮 dev 复用**：dev 已被 v0–v3d 六轮使用；本轮所有数字只是内部开发证据，dev 上的
  "接近 F"不能替代独立验证。
- **未验证的化学因果意义**：α/δ/γ 与桶条件的分解没有化学因果解释力；RINGCHAIN 类型锚定
  与贡献语义边界延续 research_core §5。
