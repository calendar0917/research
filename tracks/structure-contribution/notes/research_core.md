## 1. 核心研究问题【已确定】

> 能否构造一种**跨分子共享、结构上可对齐**的单元—关系表示，在不依赖
> GNN/Transformer 消息传递的情况下实现有竞争力的分子性质预测，同时对局部结构
> 贡献与上下文交互提供**忠实、稳定、可检验**的分解？

四个不可分割的目标：

1. **预测性能**：不以明显牺牲性能为代价追求形式上的可解释性。
2. **跨分子共享**：同类结构在不同分子中对应、可比较，而非每分子孤立解释。
3. **显式组合关系**：局部结构、结构属性及结构间连接/相对位置如何组合进入预测。
4. **解释可信度**：贡献必须反映真实模型计算（加和恒等式），并检验稳定性
   与可辨识性。

**边界声明**：本路线的直接目标是解释**模型预测机制**（prediction attribution）。
它**不**自动构成化学因果机制证据；真实 ZINC 上的分数只称"模型预测归因"。

## 3. 当前科学假设与可反驳条件【未验证】

**H1（主假设）**：在 ZINC y-回归上，
B（加性单元贡献 + 真实单元间关系贡献）≥ A（纯加性单元贡献），且 B ≈ C
被破坏（B 优于关系打乱对照 C），同时 B 的性能接近不透明对照 D（差距在预注册
容忍带内）。
→ 支持该假设则"显式单元—关系分解"同时买到了可解释性与竞争力。

可反驳条件（任一成立即 H1 不成立）：

- B−A 配对差 ≈ 0 或为负（关系项无增量价值）；
- B 与 C 差异 ≈ 0（真实关系对应关系不是收益来源——收益来自"存在关系特征"
  这一容量而非其结构对应）；
- B 比 D 差得多（超出容忍带，显式分解损失了关键信息）；
- B 性能好但合成真值/稳定性检验失败（预测成功≠解释命题成立）。

**H2（可辨识性假设）**：§5 的约束足以使"单元基础贡献 α / 上下文修正 δ /
关系贡献 γ"的分工对训练扰动（种子）与输入扰动（重标号）稳定。
→ 反驳：不同 seed 的贡献分配发生大幅迁移（不是整体平移）。

**H3（合成可恢复假设）**：在已知真值的合成任务上（unary 效应 + pair 交互 +
噪声 + 结构共现相关性），模型恢复正确方向、识别真交互、不把强共现误认为交互。
→ 反驳：方向错误 / 真交互漏检 / 伪交互率高。

## 4. 方法约束【已确定】

- 核心预测机制**不使用** GNN、Transformer、图注意力、迭代消息传递。
- 允许：共享小 MLP、显式统计特征、结构关系算子、加性/低阶交互函数、
  共享 embedding 表。
- K-SVD/CSSD 是可选工具，非必需【暂定：v0 不使用】。
- 每个进入预测的项必须**可归因**：要么是某结构单元的贡献，要么是某单元对的
  贡献，要么是全局 bias。禁止隐藏的全局 MLP 旁路。
- 第一版监督只用原始 `y`；不使用旧模型的 `g/ell/s/c` 辅助标签或冻结 Q 头。

## 5. 解释可信度要求【已确定的目标，实现方案暂定】

1. **计算完整性**：`pred = b + Σᵢ(αᵢ+δᵢ) + Σ₍ᵢⱼ₎γᵢⱼ` 在数值容差内逐分子成立；
   可导出（分子ID, 单元ID, 单元类型, 原子/键, 基础贡献, 上下文修正, 关系对象,
   关系贡献, 预测）。
2. **可辨识性约束**（v0 方案，暂定）：
   - 上下文特征按"同类型内训练域中心化"→ δ 在类型典型上下文处为 0，
     α 承担类型平均贡献（α/δ 分工）；
   - 关系描述子在训练域中心化 → 关系平均贡献并入 b，γ 只承担残差交互；
   - unary 路径与 relation 路径参数完全分离（各自 embedding 表与输出头）→
     分解由架构决定，不允许参数在项间自由转移。
   - **仍无法解决的歧义**（如实记录）：同类型单元共享 α → 类型级与实例级
     归因在 δ 内仍混叠；共现相关的结构对可被 γ 解释为交互（由 H3 合成任务
     定量检验）；bias b 吸收所有不可归因的全局均值。
3. **稳定性**：重标号/端点互换/batch 顺序不变；跨 seed 贡献分布与主规律稳定；
   未知类型有明确、一致的处理（UNK 桶）。
4. **代价声明**：中心化与参数分离可能损失少量性能（表达力下降、信息被迫
   走显式通道）——这正是 D 臂要测量的对象，不是隐藏成本。

## 6. 为什么不再把 K-SVD 当作前提【已确定】

- 历史证据（ksvd 轨）：字典对 RAW 的收益 CI 跨零（DICT≈0.1199 vs RAW≈0.1210,
  历史 dev 口径，不可与新 y-only 对照混比）；GSCN-v0/PSD-v0/TCCD-v0..v7 系列的
  负结果均指向"机制被使用 ≠ 有泛化收益"。
- 导师明确：K-SVD 只是实现方式；目的是结构级归因。
- 中心命题改为贡献分解后，字典既不必要也不充分：它解释了"哪些 patch 活跃"，
  但不提供非重叠归属、显式关系分解或跨分子类型对齐。
- K-SVD/CSSD 可作为未来候选工具重新进入，但需在新证据下论证（如何记录：
  §10）。

## 7. 与现有工作的重叠与待证明差异

见 `notes/prior_work_positioning.md`（全文）。一句话版：

motif/fragment 化 GNN、跨分子共享 fragment、片段贡献打分、片段连接解释、
非 GNN 预测、加性/二阶交互模型均有先例。**候选生态位**（未成立，待证明）：

> 在有竞争力的预测性能下，使跨分子共享的结构贡献与上下文交互
> **更可对齐、更可辨识、更可验证**——即同时给出 (a) 非重叠、保环的确定性
> 划分， 使原子/键归属无歧义； 与预测内生（非事后归因）的
> 加性+成对分解， 且每条键归属唯一； 的可辨识性约束与
> 三层独立评价（完整性/稳定性/合成真值）。

现有工作的典型组合是"GNN + 事后解释"或"attention 内生但不加和可分解"或
"加性模型但性能弱/词表手工"。本路线押注的是：确定性化学划分 + 参数分离 +
训练域中心化能在 ZINC 尺度上守住性能。**如果 v0 显示 B 明显弱于 D 或弱于
XGBoost，则该生态位不成立。**
