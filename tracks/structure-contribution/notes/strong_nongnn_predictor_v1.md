### 1.2 三体定义的数据验证（全 10k，标签盲）

- `pair_bucket == 0`（图距离 1）与 env 键列表去重复核：**0 失配、0 重复、
  0 自环**；最大度 4（ZINC 子集）。
- 三体数 = Σ_j deg(j)(deg(j)−1)/2：fit_inner 249,105 / monitor 27,800 /
  dev 69,453（dev 平均 34.7 个/分子，0 个零三体分子，所有分子三体 ≥1）。
- 三体是现有 forward 的**不可表达**新增量：Full-Y 的 `pool_moments` /
  `pool_pair_moments` 只做 [Σx, Σx², log count]，没有任何跨原子对乘积项；
  三体 (i,j,k) 的联合统计必须由新算子产生。

### 1.3 历史高阶层路线审计（tracks/ksvd，只读）

| 路线 | 形态 | 结果 | 对本轮的启示 |
|---|---|---|---|
| PSD-v0 | pair-state 编码器 | 失败 | 不用对配对状态做迭代编码 |
| GSCN-v0 | 字典核替换 | 被拒绝 | 不改字典核 |
| BAT-v1 | bond-anchored triples + reader | M_soup 0.12300 vs 门槛 0.120，无信号 | 仅"三体+reader"不够；本轮用 live E + bond-angle 语义 + 端到端联合 + 零初始化新列 |
| BAT-joint-tune | train 降 18%，valid 无改善 | 泛化不动 | 端到端优化的收益必须落到 dev，否则停止 |
| JointBond | denormal 塌缩、分支惰性 | 失败 | 新分支必须通过梯度活性 + 敏感性门 |
| RoleCorr / typed-cycle / TCCD | 机制有效但无绝对收益 | 停 | 机制证据 ≠ 精度收益；本轮以 dev MAE 为唯一判据 |

**本轮与 BAT 的关键差异**：三体读取的是训练中实时更新的 per-atom 环境向量 E
（不是冻结描述子），边类型由真实键给出（含闭合位），算子与 reader 端到端联合
训练，且新 reader 列严格零初始化保证初始函数与历史 Full-Y 逐位一致。

## 2. 模型（唯一新组件）：FullY-StaticTriplet

- 数据：每个分子取**真实化学键**集合（`pair_bucket==0` ≡ env 键去重），
  按 (lo,hi) 排序；对每个中心 j 枚举邻居的无序端点对 {i,k}，
  三元组 (j; i, k) 唯一、无自环、无双向重复。
- 特征（177 维）：`[h_i+h_k, |h_i−h_k|, h_i⊙h_k]`（h = 共享 MLP 投影
  E→32）+ `h_j` + 键型对称 one-hot 和 (4) + 键型对称外积 (16) +
  中心原子 one-hot (28) + 闭合位 (1)。
- 算子：共享 MLP 177→64→32（SiLU），对每个三元组输出 q∈R³²。
- 汇总：每分子 `[Σq ; Σq²]`（64 维）拼到原 reader 输入（814→878）。
- 端点为**无序**：交换 (i,k) 与两条键类型，q 严格不变（测试钉住）。
- 参数：三体算子 18,112 + reader 新列 2,496；全模型 429,259 =
  408,651（历史 Full-Y 参数逐位复制）+ 新增。
- 初始恒等：新 reader 列全零 + 新算子不动旧路径 ⇒ 初始预测与历史
  Full-Y 的差 ≤5e-5（实测 1.8e-7）。

三体算子内不含任何消息传递/attention：E 在每个 tripet 内只做**逐元素**
共享投影，汇总只做图级矩池化；无邻居状态迭代、无跨层传播。

## 3. 训练协议（与 Full-Y 完全一致，唯一一次正式运行）

- 数据划分：fit_inner 7200 / monitor 800 / dev 2000（冻结 v0 split）。
- 从头训练（非续训）；旧参数按历史 seed-0 构造逐位复制，新 reader 列零初始化，
  三体算子用独立私有 RNG（seed 20261011），不扰动父模型 RNG 流。
- 超参：raw y L1 + 披露的 label-free 重建辅助（λ=33.95873017865987），
  Adam lr 1e-3 / wd 1e-5 / clip 5 / bs 128 / 240 epochs / shuffle seed 101。
- 选择：top-5 monitor-epoch soup 为主指标；secondary best-monitor；
  tertiary last；auxiliary +fit-median-b 校准。dev 不参与任何选择。
- 计算：`res` GPU1（pool `res-gpu1`，进程内 cuda:0），经 `rr`，commit 冻结后部署。

### 6.2 判断带（运行前预冻结）

主指标 0.11589 **> 0.106** ⇒ **情况 C：无信号，停止该分支**（不做复现、

改善幅度仅为历史 MAE 的 0.45%）；校准后 0.11466 vs 历史 0.11452 反而 +0.00014。

### 6.3 新分支确实被训练/使用，但无绝对收益

- 训练动态：soup 成员 [187,200,226,229,240]；三体参数绝对值 753.7→352.5
  （收缩，wd 作用），reader 新列 0→25.95；最后 epoch 梯度探针仍非零
  （env_proj 0.83 / mlp 1.21 / reader-new 0.41）——分支未塌缩，只是学不到
  可泛化的增量。
- 冻结敏感性 ablation（载入 soup，dev 2000；基线 MAE 0.11589）：zero_summary
  平均 |Δpred| 0.0150（MAE 0.11682），zero_endpoint_env 0.0668（MAE 0.14013），
  zero_bond_types 0.0192（MAE 0.11584），zero_center_env 0.0017，zero_atom_type
  0.0104（MAE 0.11513，**移除原子类型反而略好**），zero_closure 0.00004
  （闭合位几乎被忽略），cyclic_bond_types 0.0096（MAE 0.11723）。⇒ 分支主要
  依赖端点环境/键型，中心环境与闭合位贡献很小；没有任何消融把 dev 明显降回基线以下。
- 三体统计：q RMS 0.039，逐分子汇总 RMS 0.298，reader 新列/旧列 L2 比 0.119，
  三体参数 Frobenius 4.24。

### 6.5 结论

**在预注册判据下，一次性非迭代三体算子没有突破 Full-Y 的内部 dev 水平
（情况 C，停止该分支）。** 该实验排除的是这一具体实现（live E + 共享 MLP +
[Σq;Σq²] 汇总 + 零初始化 reader 列，端到端联合训练，单 seed 0），不能外推到
所有高阶/三体表示；边界见 §9。

## 9. 必答问题（12 问）

1. **实际实现了什么？** 历史 Full-Y（408,651 参数）逐位保留，只加一个静态三体算子
   （18,112 参数）与 2,496 个零初始化 reader 新列；无 α/δ/γ 分解、无 GNN。
2. **初始函数是否与历史 Full-Y 一致？** 是：共享参数逐位全等、新列全零，16 分子
   max|Δpred| 1.79e-7（容差 5e-5）；形式论证：新模块只通过零列进入旧路径。
3. **三体为何是现有 forward 不可表达的能力？** Full-Y 的图级池化只有 [Σx, Σx²,
   log count]，没有跨原子乘积；三体 (i,j,k) 联合统计必须由新算子产生（Phase A 审计确认）。
4. **三体定义的数据验证？** `pair_bucket==0` ≡ env 键去重，全 10k 零失配/零重复/零自环，
   最大度 4；dev 69,453 个三体、平均 34.7/分子、无零三体分子。
5. **CPU 正确性门槛？** 唯一枚举/端点对称/梯度两步活性/zero_summary 敏感性（0.012）/
   零列与随机列接线对照/批不变性 6e-7/y 独立/save-load 逐位一致/非 GNN 静态扫描全过；
   7 个慢测试（含历史 soup 回放）全过。
6. **历史 soup 回放是否一致？** 是：增强 vs 参考 max|Δpred| 4.77e-7，与历史保存 dev preds
   逐分子 max 差 1.91e-6；重放 dev MAE 0.1164130 = 保存值。
7. **正式训练主指标？** top-5 monitor soup dev 0.11589（fit 0.04758 / monitor 0.11374），
   校准 0.11466；best-monitor 0.12360；last 0.13094；240 epochs、wall 1305s、单 seed 0。
8. **是否跨过预冻结判断带？** 否。0.11589 > 0.106 ⇒ 情况 C（无信号，停止分支）。
9. **分支是否真的被使用？** 是但无收益：梯度到尾 epoch 活跃；zero_summary 改变 0.015，
   zero_endpoint_env 0.067；信息主要来自端点环境与键型，闭合位/中心环境几乎未利用。
10. **结果是否只是容量增加？** 新增 20,608 参数（+5.0%）换来 ΔMAE −0.0005（CI 跨零）；
    无法把任何收益与容量分离（也没有可分离的正收益）。
11. **单 seed / dev 复用偏差？** 单 seed 0，无跨 seed 训练稳定性证据；内部 dev 已在 v2/v3 轮
    复用多轮，本轮又是同一 dev 上的阈值判定——这是内部分析证据，不是盲测；正因如此
    我们按预注册规则直接判情况 C，而不是选子群讲收益。
12. **official valid/test 是否重估？官方结论是什么？** 未加载、未重估（协议硬约束）；
    本轮的"无收益"只在内部 dev 上成立。若未来要检验三体类表示的官方泛化，需要新的预注册
    （新协议 + 新判据 + 用户授权读 official valid/test），不能复用本次 0.11589 与历史 test 数字
    做独立性声明。

## 10. 下一步（本轮已停止，仅记录可选项）
