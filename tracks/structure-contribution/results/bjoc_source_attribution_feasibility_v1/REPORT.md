## 0. 本轮做了什么

在“模型编码之后、Null 分组之前”的**真实 Junction 表示 `w_j`** 上：

1. 实现一种无监督重要性排序：**逐 Junction 积分梯度（IG）**，参照（baseline）预先固定为
   该分子 Junction 编码的逐维均值 `μ_G`（主）与零向量（仅稳定性对照），K=32 中点步。
2. 用**与排序计算完全独立**的方法检验预测响应：从结构匹配的参照分子取自然编码做位置对应的
   匹配替换 `w_j ← w_j + α(w_ref − w_j)`（α = 0.5/1.0），随后**完整重算** Null 分组 → Composer → Reader。
3. 预先固定比较：top-4 vs 同分子随机 Junction（配对符号检验）、top-4 的连通组合性 vs 随机 k-子集、
   跨 seed、跨参照、跨强度稳定性、以及 Junction 通道与 Atom/Bond/Global 通路的覆盖划分。
4. 未做：训练、模型选择、MAE/RMSE、官方 valid/test/Monitor/Locked 标签、化学编辑、GPU。

### 2.2 top-4 是否形成连通组合

| seed | top-4 内部邻接边均值 | 随机 4-子集边均值 | 超过随机 95 分位的分子比例 |

| 0 | 1.414 | 0.746 | 11.7% |

### 2.4 Junction 通道的覆盖划分（回答“能解释哪一部分”）

256 分子（复算，seed 0/1）：

| 量 | seed 0 | seed 1 | 说明 |
|---|---|---|---|
| Junction 通道总效应：`mean\|pred(W=V=0) − pred\|` | 0.3605 | 0.3669 | 通道级反事实（前 32 分子复现 v1：0.2450/0.2702）|
| 联合重置效应：`mean\|pred(natural) − pred(所有 w_j=μ_G)\|` | 0.1409 | 0.1946 | 组内“均值水平+二阶矩”联合改变 |
| 逐 Junction 有符号和 `\|Σ_j IG_j\|` | 0.1257 | 0.1695 | ≈ 联合重置的 87–89% |
| 归因质量 `Σ_j \|IG_j\|` | 0.8400 | 0.9675 | 远大于有符号和 → 大量正负抵消 |
| 不可加性 `\|ΣIG − 联合重置\| / \|联合重置\|` | 0.633 | 0.227 | seed 间差异大（E4 类似现象）|
| 其余通路置零（复现 v1） | z_bond 0.452 / sum_atom 1.161 / sum_sq 0.935 / global 0.152 | 0.429 / 1.124 / 0.690 / 0.158 | 均远大于 Junction 组内可归因量 |

解读：
* 单个 Junction 的贡献**分散且相互抵消**：归因质量 0.84/0.97，但有符号和只有 0.13/0.17；
* Junction 通道中“全体 Junction 的均值水平/二阶矩”占了联合重置效应的 87%/77%（用联合重置近似），

* 通道总效应 0.36 与模型其它通路（Atom 块 1.16/1.12）相比是小量，说明**即使完美解释 Junction 通道，
  覆盖面也有限**；
* seed 0 的不可加性（0.633）远大于 seed 1（0.227），提示组内交互项本身 seed 依赖，
  单 seed 结论不可外推。

## 4. 五个问题的回答

### Q1. 来源级归因是否可信？

**是（在明确界定的意义上）。** 依据：

* 方法数学与实现经过严格校验：逐点恒等式 `IG_j = −occ_j`（相对误差 ≤6.6e-4）、排列等变性、对称性、
  已知真值 top-1、与精确遮蔽的排序 Spearman ≥0.999。
* 验证干预与排序计算分离（IG 排序 / 匹配自然替换验证），未使用同一响应选结构再证明。
* 证据分级：这些属于“公式/实现必然 + 冻结模型数值干预”，**不是**化学因果或真实分子编辑证据。

限制（必须随每次引用）：参照 `μ_G` 表示“换成该分子平均 Junction 内容”，零参照逐维 OOD；
位置对应的匹配替换不声称化学对应；Null 下每个 Junction 通过均值影响**所有** Bond，
因此 `IG_j` 不是“某条键的局部贡献”。

### Q2. 与随机对照相比，top Junction 是否有超出随机的预测响应？

**是，且两 seed、两强度一致。** top-4 的匹配替换响应约为随机 Junction 的 2.0–2.2 倍，
92%±1% 的分子为正，符号检验 p ≤ 6.4e-46。效应大小中等（0.048–0.052 的绝对差），
但方向、量级和稳定性都远超噪声。

**但注意**：没有证据支持 top-4 是连贯的连通组合（§2.2）。归因信号存在，但它不以“连通子结构”的
形式自动组织起来。

### Q3. 跨 seed / 参照 / 强度是否稳定？

**总体稳定，位置级中等。** 参照与强度稳定性很好（Spearman 0.91–0.99）；
跨 seed 池化排序相关 0.81/0.83；top-4 集合 Jaccard 0.38（随机 0.075），约 58% 分子超过随机 null 95 分位。
即：**信号可复现，但精确图位不完全一致**，单 seed 的 top 集合不可直接当作结构结论。

### Q4. 可解释的模型比例是多少？

* Junction 通道总效应（W=V=0）：`mean|Δpred|` = 0.360/0.367（256 分子）；前 32 分子复现 v1 的 0.245/0.270。
* 其中逐 Junction 可归因部分（有符号和）≈ 0.126/0.169，约为联合重置效应的 87%/77%；
  归因质量 `Σ|IG|` = 0.84/0.97，说明贡献高度抵消。
* 不可加性（联合重置 vs 逐 Junction 之和）为 63%/23%，seed 依赖强，且与“均值水平”分量耦合，
  在 Null 分组下不能归因到单个 Junction。
* 与其它通路相比 Junction 通道是小量：Atom 块置零效应 1.16/1.12，Bond 块 0.45/0.43，
  Global 块 0.15/0.16。

**结论**：来源级方法能解释的是“Junction 组内偏差”的一小部分，且其中很大一部分是
不能归因给个体的组间均值/二阶矩分量。整体模型的可解释比例很低。

### Q5. 继续结构解释，还是转向局部-全局架构重构？

**建议转向局部-全局架构重构；停止“连通子结构解释”方向。** 依据：

* “连通子结构解释”在本轮未获支持（任意候选与归因 top-4 都不形成可辨识的连通优势），
  且前审计 ERRATUM 显示原接口探针不能排除该假设；再做同接口的结构搜索投入产出低。
* 但 Junction 来源信号是真实、稳定、可验证的（2× 响应、跨 seed 0.81），值得保留为
  **测量工具**，而不是继续当作解释接口。
* 不可加性/seed 依赖与均值水平主导表明：瓶颈在**架构把 Junction 信号压成组均值**，
  而不是归因方法本身。最有价值的下一步是预注册的
  **local–global 双通道分解配对实验**（把 `c_b` 的局部项 `PSI(b_b, n_b, bond_feat)` 与
  全局项 `Ψ(W_b, V_b, …)` 拆成两条 reader 通路；比较 accuracy-parity 与忠实性/归因稳定性），
  约 0.5–1 GPU-h、2 seeds，co-primary 指标预先固定。

本轮**不启动**该实验、不购买 GPU；仅提交建议与证据。

## 5. 限制与未决

* 参照编码：主参照 `μ_G` 分布内但语义是“平均内容”；零参照 OOD。匹配替换是位置对应，不是化学替换。
* 干预均为模型内部反事实：不是真实分子编辑，不能外推为化学因果。
* 256 分子、两个 seed；不可加性等统计量存在明显 seed 差异（0.63 vs 0.23），单 seed 不外推。
* Junction 通道值小、抵消大：不是“单个 Junction 忠实解释”的证据。
* 合成校验使用真实 smoke 结构上的精确遮蔽作为已知真值，未包含新构造的完全合成任务。
* 未使用任何标签；未计算 MAE/RMSE；未读取官方 valid/test 或 Monitor/Locked。

## 6. 证据分级对照

* **公式/实现必然**：`IG_j = −occ_j`、Null 组均值线性结构、排列等变性、通道分解恒等式。
* **冻结模型数值干预**：IG 排序、匹配替换响应、top vs 随机、跨 seed/参照/强度稳定性、通道覆盖。
* **无证据/未决**：化学因果解释、真实分子编辑、无重训练的忠实连通子结构解释、
  local–global 分解的收益（未做实验）。
