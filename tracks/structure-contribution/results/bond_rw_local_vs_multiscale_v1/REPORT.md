## 2. Phase 0 数学核查（详 `MATH_AUDIT.md`）

- **修正上一轮解释**：对称 φ 下只有**全图双重求和**在 K 与 Ks 之间相等（残差 3.55e-14）；**逐键 r_e 并不相等**（平均 `max_e|r_e−r'_e|`=1.355，K123 为 1.523），精确恒等式 `r_e(Ks)=(r_e(K)+(Kᵀφ)_e)/2`。上一轮“使用 K 与使用 Ks 相同”的说法只在双重求和层面成立；上一轮模型实际消费的是 Ks triplet，历史预测/训练记录不受影响，但解释必须修正。
- 对称化改变**每行权重总量**：`rowsum(Ks)=(rowsum(K)+colsum(K))/2`。K123 的 symK 行和 CV=0.089，corr(线图度, rowsum)=0.888。由于 Pair MLP 有偏置，这等价于一个度/中心性相关的偏置项；R1 与 R123 都含此效应，U 的行和恒为 1，因此 R1/R123 相对 U 的优势不能排除行和/度效应的贡献（见 §4 解释边界）。
- 历史合成任务 MAE 不一致（0.3025 / 0.3755 / 0.7174）核查：数据采样有 numpy seed，但 tiny regressor 由全局 torch RNG 初始化且函数内不设 manual seed；同 `torch.manual_seed(0)` 两次结果一致=True，不同 seed 结果不同=True。历史记录不改动。

## 5. 结论（对应本轮五问）

1. **多步随机游走是否提供超过一跳的额外价值？** 没有可检出的证据。R123−R1=+0.0027（正=多步更差），CI95 [−0.0017, +0.0075] 跨 0 → `MULTISCALE_INDISTINGUISHABLE`。点估计略偏向一跳，且优势集中在尾部。
2. **一跳局部拓扑本身是否携带可用信息？** 是。R1−U=−0.0125，CI95 [−0.0184, −0.0066] 全部为负 → `LOCAL_TOPOLOGY_GAIN`；历史 R123−U=−0.0097 同向，R1−U 更大（−0.0125）。
3. **这是"真实成对组织"还是对称化/度效应？** 不能完全分离。数学核查显示 Ks 的逐键消息与行权重都含度/中心性重分配（corr=0.888），且该效应对 R1/R123 与 U 的对比不可忽略；K 全图双和等价只说图级总量，不保护模型消费的逐键消息。此处只报告预测差异与核的可检测量，不称其为已解释的化学贡献。
4. **与 BJOC-Null（A2）比较说明什么？** 仅描述性：A2 MAE 0.10396 略低于 R1 0.10480，但 RMSE 0.493 远差、max AE 14.3、worst-1 SSE 0.839，且 A2 参数 413,505、SSL 组成与初始化均不同（历史轨迹）。不能据此归因“结构表达不如 count 条件 null”。
5. **是否值得继续研究 Atom/Atom–Bond 多尺度组织？** 按预注册停止规则：**一跳 Bond 邻接已足够；不扩展多尺度组织**。若后续继续，问题更可能在 Reader/接口与误差尾部，而不是增加关系深度；本轮不自动开启下一轮（stop_after_round=True）。
