## The one next proposition

**Proposition (falsifiable).** Part of the extreme-magnitude error of the
frozen P model is a *sample-sharing* failure: rare atom types / local
environments have plenty of occurrences overall but no shared parameter that
accumulates a directly supervised contribution across all of them, so under
the L1 objective their conditional median is shrunk towards the bulk.  Giving
the model an explicit, cross-molecule-shared per-type contribution channel —
trained jointly under the same raw-y L1 objective — will lower the valid tail
MAE while leaving ordinary molecules non-worse.  If the tail does not improve
(or ordinary degrades), the proposition is false and the route stops.

**Concrete mechanism (one): Shared-Type Residual Composition (STRC).**
Keep the complete pretrained BJOC-Null forward and fine-tune it exactly as P
(C1).  Add a small explicit residual channel before the output:

```
y_hat = f_theta(x)  +  s1 * sum_{i in atoms} alpha[type_i]  +  s2 * sum_{j in junctions} beta[type-triplet context_j]
```

where `alpha` is a shared scalar table over the 28 atom types (init 0) and
`beta` a shared scalar over a small frozen junction-context vocabulary
(paired endpoint types, init 0, exact shared counts).  `s1`, `s2` are fixed
constants set by the CPU pre-check (not tuned on valid), so the channel is
≤ ~500 parameters and does not change the encoder/composer/reader widths.
The channel is *additive in raw type counts*, shared across molecules by
construction; every occurrence of a rare type contributes gradient to the
same scalar, so the estimate has the sample size of all its occurrences.

**Why the frozen P cannot satisfy it.** P can *represent* such a function only
through the reader MLP applied to the pooled embeddings; for rare types the
gradient of that pooled path is diluted by every other object in the molecule
and by the shared encoder, so the effective sample size of a rare type's
contribution is small.  The explicit shared table gives that contribution its
own high-sample-size parameter.  The diagnostics above show the failure is
signed (magnitude shrinkage) and concentrated in low-density regions, which
is exactly the signature of a sample-size rather than an expressiveness
bottleneck.

**Why this is not merely more capacity or output calibration.**  ≤ ~500 shared
parameters (0.1% of the model); parameter *tying* across molecules is the
mechanism, not width.  The added term depends only on the molecule's raw type
composition, not on the base prediction and not on a fitted per-molecule scale
factor; there is no `a(counts) * y_hat + b(counts)` calibration, no target
transform, no tail-weighted loss, no extra label, and raw-y L1 remains the
only supervised objective.

## Matched baseline, CPU pre-check, GPU design, gates

* **Matched baseline.**  Frozen P recipe on official train 10000: same seeds,
  same init, same batch order (torch.Generator seed+101), batch 128,
  Adam 1e-3 / wd 1e-5 / clip 5, fp32, 240 epochs = 18,960 updates, last-5
  soup, raw-y L1 only.  The STRC arm differs from P only by the residual
  channel (zero-initialised at start, so the first forward equals P exactly).
* **CPU-only pre-check (before any GPU purchase).**
  1. zero-init identity: STRC forward == P forward to 0.0 at initialisation;
  2. parameter audit: exact parameter count recorded, forbidden-module scan
     empty, no calibration/count-scale path in the forward;
  3. gradient activity: `alpha`/`beta` receive non-zero gradient on the first
     train batch and move; type-count linearity
     (`d y_hat / d alpha[t] == n_t`) and permutation invariance;
  4. a synthetic group-contribution truth: the STRC residual recovers the
     planted per-type coefficients with r > 0.9 while the frozen P head does
     not, proving the channel is identifiable and not a no-op;
  5. wall-time/parameter report vs P.
* **First GPU design.**  ≤ 2 seeds (0/1), one A100 per seed, matched to P's
  per-seed GPU regime (seed 0 on res-gpu0, seed 1 on res-gpu1), same
  checkpoints, same evaluation path (frozen official-valid structures and
  labels, single read after prediction freeze).
* **Purchase gate (single-model official-valid MAE, seed-mean of two seeds).**
  Buy only if `STRC - P <= -0.004`, both seed deltas < 0, ordinary
  (`y > -3`) delta <= 0, tail (`y <= -3`) delta < 0, RMSE not worse than P by
  more than 0.005, and the channel's `alpha` is stable across seeds
  (Spearman > 0.7).
* **Stop conditions.**  Gate failure stops the route permanently; no seed 3,
  no constant/vocabulary search, no tail-weighting, no post-hoc calibration,
  no test-set evaluation at all.
