# ADVISOR_BRIEF（中文）— cscl-bjoc-junction-mechanism-exploration-v2

**一句话结论：** Junction 的“内容”是必要的（仅计数不够），但“进入位置”和“池化组织方式”都不是当前主瓶颈；剩余误差高度集中在极端分子（y ≤ −3 的长尾）——这指向 (d) 极端分子覆盖，而不是继续改 Junction 的读出路。

所有数字来自 split-D Monitor（n=1000，历史已暴露的开发集），新预测在读数前冻结并哈希；Monitor 标签本轮只读一次；Locked 与官方 valid/test 从未读取。

## Q1. A2 的 RMSE 劣势是否来自少数极端分子？——是，一个分子主导。

A0/A1/A2 冻结预测的配对分析（Part I）：A2 的 MAE 更低（0.10396 vs A0 0.12151），但 RMSE 更高（0.49317 vs 0.32686）。分子 `row 514`（y = −15.327；A0 预测 −7.977，A2 预测 −1.038）一个分子就贡献了 A2−A0 全部正向 SSE 增量的 **96.0%**、净 SSE 变化的 **110.1%**。删掉它，A2 的 RMSE 立刻变成 **0.1977 < 0.2299**（A0）；删掉最差 20 个仍是 0.1829 < 0.2247。A1−A0 完全同型（top-1 占 95.7%，同一个分子）。A2−A1 无主导分子（top-1 正增量占比 8.3%），且 A1 与 A2 的绝对误差相关 0.990、与 A0 仅 0.897。**结论：A2 不是“普遍更差”，是长尾少数分子；A0 与 A1/A2 是两种不同的失败模式。**

## Q2. A0 更好的分子是否结构上更稀有？——略稀有，但不能解释差距。

用 label-blind 结构描述子（Fit-only 标准化，最近 Fit 距离）做 Monitor 新颖度四分位：A0 明显更好（ΔAE>0.05）的 137 个分子新颖度中位数 3.03，A2 明显更好的 301 个是 2.64；Q4（最新颖）里 A0-better 有 53 个。但**每个四分位 A2 的平均 AE 都更低**（ΔAE：Q1 −0.016，Q2 −0.030，Q3 −0.021，Q4 −0.004）。稀有性只调节优势大小（Q4 最小），不反转它。注意新颖度与标签尾部耦合（40/71 个 y≤−3 在 Q4，y 与新颖度相关 −0.37），1000 分子内两者无法干净分离。

## Q3. 在相近结构新颖度内，A0/A2 错误模式是否仍有差异？——是。

每个四分位内 A0-better 比例 0.32–0.44，双向分歧持续存在；而 A1 与 A2 在每个层内几乎重合（如 Q2 0.0620 vs 0.0585）。A0 与 A1/A2 的差异来自 composer 拓扑本身（A1/A2 同为 per-bond broadcast，仅归一化与否），不是新颖度、也不是归一化。换句话说，**“Junction 信息怎么进模型”确实会在部分分子上改变错误模式**，这为 Part II 的三条臂提供了动机。

## Q4.（a）只用计数 C 够不够？——不够，junction 内容必要。

`J_COUNT_ONLY`（W=V=0，q=log1p(n_e)）两种子均值为 MAE 0.1277，`C−A2` = **+0.0234，CI95 [+0.0146, +0.0325]`，显著更差且两种子同向（+0.0215/+0.0253）。C 在普通分子（y>−3）上约等于 A0（0.1016/0.1027 vs 0.1026），但尾部最差（0.4377/0.4873，全部臂中最差）。**计数不是信号，junction 矩（W,V）才是，且主要作用在极端分子上。**

## Q5.（b）直接读出 D 是否优于 per-bond broadcast？——预注册规则下 NO_GAIN，但方向偏尾部。

`J_DIRECT_READOUT` 把 `[z, zA, zA², g, μ_G, ν_G]`（513 维，新增 192 列零初始化）直接送读出头，参数量 462,657（已验证）。`D−A1` 种子均值 **−0.0028，CI [−0.0068, +0.0013]**，且两种子反号（s0 −0.0068，s1 +0.0011）：s0 的 D 是全场最好单模型（MAE 0.09948），s1 却不如 A1。描述性看 D 的优势集中在尾部（tail：s0 −0.076，pooled −0.037），`D−A2` = −0.0042 [−0.0093, +0.0004]。**两 seed 分不开 ~0.003 的效应：方向可继续验证，但不能宣称有用。** 另注意 A1 自身跨 seed 波动 0.1062→0.0995，seed 噪声与效应同量级。

## Q6.（c）类型条件池化 E + 与 luyin20 的对齐 + 下一步

**E = J_TYPE_CONDITIONED_POOL**（`W_e=n_e·μ_{r_e}`，`V_e=n_e·ν_{r_e}`，按原始物理键型 0..3 分组，label-blind，无新参数；守恒与独立循环已过 CPU 门）：`E−A2` 种子均值 **−0.0017，CI [−0.0040, +0.0006]**；s0 +0.0001，s1 −0.0035。E 的 Fit MAE 全场最好（0.00101/0.00109），普通分子两种子一致小改善（0.0791/0.0780 vs A2 0.0811/0.0797），但 s0 尾部变差（+0.0279，CI [+0.0101,+0.0466]）。**“拟合更好、普通分子更好、极端分子更差”——组织方式的收益没有落到 Monitor 上。**

**与 luyin20 的对齐：** 导师的三条主张在本轮有直接对应：(i) 不做黑盒、要能追溯到结构成因——我们的 composer 把 W/V per-bond 张量显式暴露，C/D/E 正是对“内容/入口/组织”的可控消融，D 在训练后 Junction 梯度非零（0.52/0.24），E 的类型桶可逐桶回溯；(ii) 每条边权重一致、避免重复统计——A2/E 满足 `Σ_e W_e = 2Σ_j w_j`、`Σ_e V_e = 2Σ_j w_j²`（≤2.6e-7），E 按边类型聚合保证 bond 级一致性，A2 的均值为无条件版本；(iii) 用更系统的 patch 而不是简单二阶子图——E 的类型条件池化是导师“按社团/类型分 patch”的 label-blind 最小版本，A2 是它的退化情形。性能上导师期望 ~0.06–0.07；本轮最好 D:0 = 0.0995，尾部 MAE 0.34 是主要缺口。

**下一步建议（本轮不执行、不承诺）：** 证据一致指向 (d)——极端分子/长尾覆盖是当前上限，而不是 Junction 的入口或池化形式。可选方向是长尾加权的训练/覆盖分析（例如 tail-aware 目标或分层采样），以及把 D 的尾部方向在更多 seed 上验证；不建议在没有新机制假设的情况下继续调 Junction 结构。同时必须说明：split-D Monitor 是已暴露开发集，以上均为 within-split 探索性结论。
