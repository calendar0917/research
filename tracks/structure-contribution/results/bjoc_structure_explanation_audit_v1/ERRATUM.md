## E1. Phase C 的 BFS 连通子集是“任意候选”，不是“解释结构选择”

**原文边界问题**：报告将 `EXISTING_INTERFACE_POTENTIALLY_USABLE` 判为 NOT SUPPORTED，
依据是“BFS 从 bond 0 出发的 8-bond 连通子集”与随机命中的 Δpred 无差别。

**修正**：该做法没有执行任何**解释结构选择**（没有按归因/重要性选出连通子结构再检验），
因此它只能支持：

> “未选择的、任意 BFS 连通子集”与同规模随机子集在预测响应上不可区分。

它**不能**排除“存在高质量连通子结构解释”（例如由归因排序引导选择的连通组合）。
要检验后者，需要“选择—独立干预验证”分离的实验设计，这超出原审计范围。

**新证据（补充，不改变原审计范围）**：后续 `bjoc_source_attribution_feasibility_v1`
以冻结模型实现了逐 Junction 积分梯度排序 + 独立的匹配自然编码替换验证：
top-4 Junction 的替换响应显著高于同分子随机 Junction（两 seed、两强度，符号检验 p ≤ 4e-46，
效应约 2.0–2.2× 平均 Junction 质量）；但 top-4 集合的**连通性**仅微弱高于随机
（top-4 内部邻接边均值 1.41/1.53 vs 随机 0.75；仅 11.7%/18.4% 的分子超过随机 95 分位）。
结论：非局部归因问题不只是“候选没选好”，但“连通组合是否可解释”仍未得到支持，
需要在下一轮用“按归因选择连通组合”的预注册实验单独检验。

## E2. `abs(mean(delta))` ≠ `mean(abs(delta))`

**原文边界问题**：Phase C 报告比较的是
`mean_j |delta_connected|` 与 `|mean_draws delta_random|`（先对随机 draw 取有符号均值再取绝对值），
而连通侧是逐分子绝对值均值；两个统计量语义不同，不能直接比较。

**修正（同一 32 分子、同一 RNG draws、独立重算）**：

| seed | connected（单次） | 随机连通：v1 风格 `\|mean_signed\|` | 随机连通：修正 `mean\|Δ\|` | 配对差（修正） |
|---|---|---|---|---|
| 0 | 0.132960 | 0.114520 | 0.123720 | +0.009240（56.3% 为正）|
| 1 | 0.114647 | 0.111740 | 0.115068 | −0.000421（56.3% 为正）|

**结论变化**：修正后“连通候选 ≈ 随机”的定性结论仍然成立，但依据从“可能因统计量混合而凑巧成立的比较”
变为“修正统计量下的直接比较”；且两 seed 的配对差**符号相反**（seed 0 微正、seed 1 微负），
说明不存在稳定的连通优势。原文中“connected 0.1330 > random 0.1145（+16%）”的表述应废除。

## E3. `norm(c − c_local)/norm(c)` 是零 W/V 反事实的相对变化，不是严格“全局贡献百分比”

**原文边界问题**：报告将 `mean_b ‖c_b − c_b^local‖ / ‖c_b‖`（0.650/0.657）解释为
“图级/全局信息占 c 的比例”。

**修正**：该量只有一个可辩护的语义：**把 W/V 置零后 c 的相对变化**（去掉 Junction→Bond 分组信号的反事实）。
它不是可加的贡献百分比，也不对应任何预测效应比例。

**可测量的替代量**（同一 32 分子复算）：
* 零 W/V 反事实的预测效应 `mean|Δpred|` = **0.245013 / 0.270249**（seed 0/1；与历史记录一致）；
* 相对变化均值 = 0.650355 / 0.656688（描述性，仅作复现）。

**结论**：报告应表述为“置零 W/V 的 c 相对变化 ≈ 0.65，对应预测效应 mean|Δ| ≈ 0.245/0.270”，
而不是“65% 的 c 来自全局/图级信息”。严格的加性贡献分解需要单独设计的通道分解实验。

## E4. B3 的 Organized 扰动使用了错误基线（最重要）

**原文边界问题**：B3 用 **Null 自然预测** `pred_null(natural)` 作为 Organized 模式扰动的基线：

```
delta_org_v1 = pred_org(w_j + δ) − pred_null(w_j)
```

这个量混合了“组织模式自然预测与 Null 自然预测的水平差”（≈ 0.033–0.040）与“扰动响应”。
因此原文“Organized 控制只改变 2 条键但 |Δpred| 更大（0.0404/0.0321）→ 说明 Null 的非局部放大”
是不成立的比较。

**修正（同 64 分子、同 e/j、同 δ、同 seed，独立重算）**：正确基线应为同一模式内的自然预测
`pred_org(w_j)`：

| seed | Null 扰动（复算） | **Organized proper（正确基线）** | v1 风格（错误基线） | v1 风格 − proper |
|---|---|---|---|---|
| 0 | 0.007825 | **0.008156** | 0.040370 | +0.032214 |
| 1 | 0.011244 | **0.016602** | 0.032083 | +0.015481 |

**结论变化**：
1. 正确同模式基线下，单 Junction 编码扰动在 Organized 模式中的预测响应与 Null 同量级
   （0.008/0.017 vs 0.008/0.011），**并不更大**；原文“organized 响应更大”的论证废除。
2. 两种模式下同一扰动的响应仅弱相关（Spearman 0.236 / 0.742），且“organized proper < null”的分子比例
   为 45.3% / 9.4%（seed 0/1），显示模式间响应集合差别较大且 seed 依赖。
3. 仍然成立的代数事实：Null 分组下 δ 通过 `W_b = n_b·mean_G(w)` 进入**所有**键（公式必然）；
   但“这导致更大的预测扰动”不再是有效证据。Null 非局部性的证据应引 Phase A 公式审计与
   后续归因审计（IG 排序与验证干预），而不是 B3 的跨模式基线比较。
