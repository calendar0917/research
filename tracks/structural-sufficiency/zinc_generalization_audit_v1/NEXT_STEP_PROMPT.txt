## 2. 模型定义（精确）

Base（完全保留 P3）：

```text
a, b, w = P3 encoders(batch)
Wg, Vg, n_b = P3 Null grouping(w)
c_glob = P3 group_composer([b, Wg, Vg, log1p(n_b), bond_feat])
```

Local channel：

```text
# L arm
Wl_b = sum_{j touches b} w_j
Vl_b = sum_{j touches b} w_j^2

# C arm (matched control)
Wl_b = n_b * graph_mean(w)
Vl_b = n_b * graph_mean(w^2)

c_loc = LocalComposer([b, Wl, Vl, log1p(n_b), bond_feat])
```

`LocalComposer = MLP(296 -> 80 -> 96)`（SiLU；dropout 0；无递归）。
Reader：

```text
reader_in = [sum_b c_glob, sum_v a, sum_v a^2, g,
             sum_b c_loc, sum_b c_loc^2]
reader = MLP(513 -> 256 -> 256 -> 1)
```

初始化：
- 先按 P3N 初始化 reader（321→256→256→1）；
- 新 reader 第一层扩到 513：前 321 列 copy P3N 权重，后 192 列 **zero**；bias 不变；后两层 copy；
- local composer 标准初始化；
- 这样初始 forward 与 P3N 的最大绝对差应 ≤1e-6（float32 累加顺序；prototype 实测 ≤1e-7）。
- L/C 两臂参数完全一致：**494,193**（P3 413,505 + local composer 31,536 + reader delta 49,152），cap headroom 5,807。

不要给 local branch 加零初始化输出门控；zero reader columns 已经是初始屏蔽，且能让 local composer 在第 2 步起获得梯度。不要改 P3 的 Null 通路。

## 3. CPU gate（正式 GPU 前必须全过）

写 `code/dcc_cpu_checks.py`，至少检查：

1. 参数：L/C 都是 494,193；两者 state_dict key 集合相同、shape 相同。
2. 初始化：base 参数逐 tensor 相同；local branch 参数逐 tensor 相同；L/C 只有 grouping 逻辑不同。
3. 初始 forward：L 和 C 对同一 batch 的输出与 P3N 的 max abs diff ≤1e-6；L 与 C 初始输出相同（因为 reader 新列为零）。
4. organized grouping 恒等式：每条 junction 恰好进入两个 bond 的 W/V；`sum_b Wl_b == 2 * sum_j w_j`；`sum_b Vl_b == 2 * sum_j w_j^2`；空 junction / 单 bond / 环分子边界有限。
5. Null control：`Wl_b == n_b * graph_mean(w)` 逐 bond 验证（max abs diff 0.0）。
6. 重编号不变性：整图随机重编号后，分子级预测差 ≤1e-6；batch 加入别的分子后目标分子预测差 ≤1e-6。
7. 梯度：step 1 reader 新列有梯度、local composer 梯度为 0（零列导致，记录即可）；step 2 local composer 梯度非零且有限；无 NaN。
8. 禁用模块扫描：无 GNN/MessagePassing/Transformer/GRU/LSTM/RNN/递归调用；无 test 文件路径。

任何 gate 失败：停止，不改模型继续。

## 6. 分析（valid-1000，只读一次）

用本审计 `analysis/per_molecule.csv` 的 row_id/结构列（同一 valid 顺序），生成：

- `analysis/model_metrics.json`：L/C/P3B 的 MAE、median、p90、p95、max、top-k share；
- `analysis/paired_contrasts.json`：L−P3B、C−P3B、L−C 的 paired bootstrap（10,000 resamples，固定 row ID；报告 mean Δ 和 95% CI）；
- `analysis/per_molecule_dual.csv`：row_id、y、P3B/L/C pred、signed/abs errors、n_atoms、n_rings、cycle_rank、radius2_unseen_atom_fraction、path_unseen_mass；
- `analysis/subgroups.json`：ordinary `y>-3`、`y<=-3`、radius-2 unseen、path unseen、`n_rings>=4` 的 MAE 对比；
- `analysis/decision.json`。

预注册 gate（必须同时满足）：

1. **主 gate A：** `L − P3B_s0 <= -0.003`（L 至少好 0.003 MAE）。
2. **主 gate B：** `L − C <= -0.002`（真实 ownership 至少好 0.002）。
3. **安全性：** ordinary `y>-3` 的 `L − P3B` 不得 > +0.002；top-100 绝对误差份额不得比 P3B 增加 >0.02。
4. 描述性报告 radius-2 unseen / path unseen / ring≥4 的方向；不要用它们替代主 gate。
5. 单 seed：不买 seed 1；不做任何 gate 失败后的 width/reader/grouping 搜索。

判定：
- 通过：`DUAL_CHANNEL_LOCAL_OWNERSHIP_GAIN`；写 REPORT，建议下一轮 seed 1（另申请预算，不在本轮）。
- 失败：`DUAL_CHANNEL_NO_GAIN`；关闭本方向。不要用“再宽一点/再深一点/再换 grouping”救。
- 如果 L 好但 C 也好：`CAPACITY_ONLY`，不是 ownership 证据，关闭。
- 如果只有 tail 好、ordinary 变差：按安全性 gate 失败处理。
