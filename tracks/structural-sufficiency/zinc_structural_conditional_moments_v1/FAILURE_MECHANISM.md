# SCM-v1 失败机制诊断（零 GPU，forward-only）

**结论标签：`READOUT_CANCELLATION_DOMINANT`**（次要成分 `ACTIVE_BUT_NONBENEFICIAL`：
存活下来的那一小部分确实活跃，但不与残差对齐）。

判据（先写，再看数）：若结构通道在冻结读出路径内的**存活幅度 < 25%**，且预测位移中
**常数项占比 > 2/3**，则判 `READOUT_CANCELLATION_DOMINANT`；若存活幅度 ≥25% 而只是
残差对齐差，则判 `ACTIVE_BUT_NONBENEFICIAL`；两者都不满足判 `MIXED_OR_INCONCLUSIVE`。
实测：存活 23.3% / 23.0%（S 通道，S-only / S+A），常数项占位移幅度 86% / 72%，
占可归因 MAE 74% / 72%。因此主标签是抵消/压缩，不是"学了但没用"。

本轮**没有**训练、没有新 rank/距离/归一化/初始化、没有标签探针、没有读 official test、
没有 GPU。全部数字来自 `1730990` 的两个冻结 best checkpoint，注入点是生产路径
（`local_composer` 的 forward hook），并与 `model(batch)` 逐值核对（≤1e-5）；读出
Jacobian 在训练权重处精确计算。JSON：`analysis/failure_mechanism.json`、
逐分子 `analysis/failure_per_molecule.csv`。

## 1. 冻结实现的一条恒等式（推导 + 数值验证）

实现里 `S[e,t] = (Σ_f μ_t[e,f] v_f − n_t[e]·mean_G(v)) / scale_t`（`scm_models.py:105`，
分母是冻结刻度 6.303 / 14.815）。对**对称**关系矩阵，行和即列和：

```
Σ_e S[e,t] = (1/scale_t) · Σ_f ( n_t[f] − mean_f(n_t) ) · v_f
           = (N_bonds / scale_t) · cov_bonds( n_t , v )
```

96 个真实分子上验证：max abs error **8.6e-7**（t1）、**1.7e-6**（t2），float32 前向对
float64 参考。两个直接推论，都被数值证实：

1. **关系规则（每个键的 n_t 相同）时，图级 S 恒等于 0**。这不是训练结果，是构造。
   ZINC valid 上 n1 的分子内 CV 中位数 0.242、n2 为 0.183，所以并非恒零，但只剩
   协方差这一项。
2. 存活幅度随 n_t 的离散度增长：corr(sd(n_t), ‖Σ_e S_e‖) = **0.573**（t1）、
   **0.775**（t2）。

## 2. 三级幅度预算（每分子中位数，valid 1000 分子）

| 层级 | S-only | S+A |
|---|---|---|
| 逐键 rms(δ)/rms(c_loc)（S / A / bias） | 0.150 / 0 / 0.168 | 0.159 / 0.082 / 0.140 |
| 池化均值通道 ‖Δzl‖ / ‖Σ_coherent δ‖（"如果同向叠加"） | 1.146 / 5.073 | 1.254 / 5.624 |
| **池化存活率**（S / A / bias） | **23.3% / – / 100%** | **23.0% / 43.6% / 100%** |
| ‖Δzl‖ 占既有 ‖zl‖ 的比例（bias / S / A） | 55.9% / 7.9% / – | 48.9% / 8.9% / 4.7% |
| 平方和通道 ‖Δzl2‖ / ‖coherent‖（S） | 44.3% | 46.2% |
| 预测位移 mean\|Δpred\|（bias / S / A） | 0.0290 / 0.0047 / 0 | 0.0310 / 0.0010 / 0.0108 |
| 去掉该块的 MAE 代价（bias / S / A） | 0.00787 / 0.00272 / 0 | 0.00774 / 0.00197 / 0.00104 |

（基数：MAE ≈ 0.079–0.082；"去掉该块"是同一权重下的读出反事实，**不是**重训收益。
"同向幅度"是指先逐键取 |δ|（逐分量绝对值）再求和，即不抵消时的上界；
存活率 = ‖Σδ‖ / ‖Σ|δ|‖，
与全局刻度无关，所以它能干净地把"抵消"和"幅度小"分开。平方和通道的同向幅度用同一
L1-then-L2 约定，对 `2·c⊙δ` 和 `δ²` 分别取绝对值后池化。）

## 3. 抵消发生在哪个环节

按贡献排序，三段衰减都是可测的：

1. **池化把 S 的 77% 抵掉**（存活 23.3% / 23.0%）。这是中心化的直接后果——逐对象修正减去
   分子均值后，求和恰好只留下与 n_t 的协方差；分子内 n_t 的离散度小，协方差就小。
   bias 存活 100%（常数不抵消），因此它反而最大。
2. **冻结刻度再除 6.3 / 14.8 倍**。逐键 S 本身不小（`c_loc` rms 的 15.0% / 15.9%），
   池化＋刻度一起把 5.07 的"同向幅度"压到 1.15。
3. **读出层的 zl/zl2 部分抵消**：`|J_zl·Δzl + J_zl2·Δzl2| / (|…|+|…|)` 中位数
   S = 0.59 / 0.64，A = **0.40**，bias = 0.92。即 A 的平方和项抵掉约 60% 的均值项。
   但平方和项本身只有均值项的 5–20%（S：0.0027 vs 0.0133），所以这一段是**二阶**的。
4. **剩下的是常数**：单常数 oracle 就能拿到同权重增益的 **77% / 82%**；bias 位移与
   既有均值通道的 cos² 中位数 0.21–0.32。也就是说，修正的主导作用是"按分子大小平移
   局部通道"——读出层本来就能用重标定近似的对象。

## 4. 存活的那 23% 有没有用

- 对齐度：corr(Δpred, 残差) = 0.194 / 0.198，**R² = 3.8% / 3.9%**，斜率 0.015 / 0.017。
- 它不是 c_loc 的逐维重标定：`δ_d ~ a_d c_d + b_d` 的 R² 只有 **0.007 / 0.011**
  （没有一个维度过 0.5），所以修正携带的确实是新内容；它只是不与"需要的方向"对齐。
- S+A 里出现**挤出**而非叠加：A 的单块代价 0.0010，S 从 S-only 的 0.0027 降到 0.0020；
  A 的池化存活率更高（43.6%）却贡献更小，说明它的增益部分与 S 的方向重复。

## 5. 分布与分层（描述性）

- 关系越规则，修正越小：n_t 离散度最低四分位 median|Δpred| 0.0286、同权重 MAE 增益
  0.0082；最高四分位 0.0358 / 0.0131。方向与第 1 节的协方差恒等式一致。
- 键越多位移越大：低四分位 0.0238，高四分位 0.0438（bias 项 ∝ n_b）。
- **零关系分层为空**：valid 里没有分子出现某个带 n_t=0（0/1000），该边界只在 CPU 关的
  合成图上验证过，本轮无法在真实数据上统计。
- 注意混杂：heterogeneous 分层的 MAE 本身高 1.6 倍，所以"增益大"部分来自分子更难，
  不作因果解读。

## 6. G5 是硬门槛，GPU 轮是带记录的协议偏离

- `data_feasibility.json` 的 `gates_pre_registered` 把 G1–G7 并列登记，G5 用的是与
  G4 完全相同的阈值形式（RMS(A)/RMS(c_loc) ≥ 0.01），**不是**"仅诊断"字段。
- 同一个文件里冻结的 `decision_rule` 写的是"any gate failure -> STOP_BEFORE_GPU"。
- 但代码 `scm_data_feasibility.py:304` 是
  `hard_fails = [k for k in fails if k != "G5_A_not_degenerate"]`，即**把 G5 从硬失败里
  豁免掉了**；这条豁免在任何预注册文本里都不存在，是在看到 A2=0.88% 未过线之后、
  GPU 之前写进代码的。
- 因此：`hard_failed_gates: []` **不能**读成"启动条件全部通过"；SCM-v1 的 GPU 轮是在
  **协议偏离**下执行的（偏离方向只会削弱正面结论：本轮本就是负结果，方向不受影响，
  但记录必须写成"未满足自身冻结的启动条件即开跑"）。

**对下一代架构形成实际约束的一条设计假设：**

> 只要读出层仍然只消费"逐对象和 / 平方和"，任何以**减去分子均值**为中心的逐对象修正
> 都会在池化时丢掉大部分自身信号（本轮实测 77%），因此结构信息必须以**不被中心化抵消**
> 的形式进入图级表示——例如直接给出与 n_t 的协变项、或直接把结构统计写进池化算子本身；
> 否则对象级再活跃，也不会改变图级预测。
