# REPORT — 同种编辑、不同核心的上下文效应筛选

Round: `lcrc_edit_context_screen_v1`
结果标签：**`EXPLORATORY_EXPOSED_DATA`**
预设决策：**`PILOT_PROMISING`**（四条预设准则全部满足）
但见 §5：该结论对"组件互斥"这一最严格独立性要求**不稳健**，应作为弱的资源信号，不是化学结论。

本轮不训练任何新模型、不重训 A0/C1、不做额外实验。所有数字来自冻结预测
（`pair_traces.csv`）与历史冻结标签。

## 1. 一句话回答

在 27 个有跨核心对照的变换家族上，冻结 C1 的家族等权 `ContextGain` 为
**+0.125 raw logD**（三 seed：+0.114 / +0.150 / +0.112），高于同家族置换对照中位数
（−0.044）且超过预设阈值 +0.05；但 3 个 seed 的家族聚类 bootstrap 区间都跨 0，
且在做组件互斥（每个组件最多用一次）的 12 个比较上增益反转为
**−0.015 / −0.064 / −0.022**。因此：**模型确实携带与上下文相关的信号，但现有数据无法
把它与"重复使用同一组件带来的偶然对齐"分开**。

## 4. 主结果

真实上下文差异的规模（83 个比较）：均值 `|context_y|` = 0.451，中位数 0.230，最大 3.35；
其中 50 个比较满足 `|context_y| ≥ 0.2`。

家族等权 `ContextGain`（raw logD，正 = 优于"同种编辑处处相同"的零参照）：

| 模型 | seed0 | seed1 | seed2 | 三 seed 平均 |
|---|---|---|---|---|
| **C1（主）** | **+0.1136** | **+0.1496** | **+0.1117** | **+0.1250** |
| A0（参考） | +0.0956 | +0.1348 | +0.1391 | +0.1232 |

* 三个 C1 seed 全部为正（预设要求 ≥2 个）。
* 家族等权平均 +0.1250 ≥ 预设阈值 +0.05。
* 优于置换对照中位数（−0.0435），且高于其 97.5 分位（+0.1088）。
* 删除任一单个家族都不翻转方向（最小 leave-one-family-out 均值 +0.0545）。

方向正确率（`|context_y| ≥ 0.2`，50 个比较，零预测差记为错）：
C1 0.64 / 0.68 / 0.70（家族等权 0.70 / 0.62 / 0.73）；A0 0.56 / 0.68 / 0.74。

## 5. 不确定性、置换对照与稳健性（本轮最重要的部分）

**① Bootstrap（家族聚类，2000 次）**：三个 C1 seed 的 95% 区间都包含 0
（[−0.078, 0.305]、[−0.018, 0.342]、[−0.026, 0.265]；三 seed 平均区间 [−0.030, 0.322]，
sd 0.088）。只有 27 个家族可用，区间宽度本身说明样本支持很薄。

**② 家族内置换对照（1000 次，6 个模型共享同一置换）**：把"每个单元的预测 `dp`"在家族内
随机重排，破坏结构上下文与预测响应的一一对应但保留家族内预测分布。C1 的单 seed 零分布中位数
−0.063 / −0.039 / −0.025，95 分位 +0.079 / +0.105 / +0.089；三 seed 平均零分布中位数
−0.0435、95 分位 +0.089、97.5 分位 +0.109。观测 +0.1250 落在零分布尾部之外。

**③ 组件互斥子集（最严格独立性）——结论反转**：把每个组件限制为最多使用一次，只剩
**12 个比较、10 个家族**，此时 C1 的增益为 **−0.015 / −0.064 / −0.022**
（家族等权 −0.016 / −0.077 / −0.027），A0 为 +0.008 / −0.048 / +0.015。
也就是说：**正增益主要来自复用组件所产生的比较对**，一旦要求分子级别完全独立，
模型不再优于零参照。这是本轮最需要被记住的结果。

**④ 少数家族影响**：27 个家族中 15 个为正、12 个为负；家族 gain 中位数只有 +0.026；
最大单家族（`[1*]N=>[1*]O`，2 个比较，真实差 3.30 logD）贡献了正增益总量的 58%，
前 3 个家族合计约 103%（其余家族净为负）。家族等权与比较加权差别很大：
家族等权 +0.125、比较加权 +0.029、pooled（C1:s0）+0.012。

**⑤ 增益与真实效应量强相关**（家族级 Pearson r = 0.84）：真实 `|context_y| ≥ 0.5` 的
13 个家族平均 +0.356（11 个为正），`< 0.5` 的 14 个家族平均 **−0.090**（仅 4 个为正）。
含义是：**模型对"真实的、大的"上下文差异是有响应能力的；但当同一种编辑在两种核心中
实际效果几乎相同时，模型会额外制造出并不存在的上下文差异**（例如
`[1*]C=>[1*]CC`：真实 MAE 0.122 → 模型 0.306，21 个比较，gain −0.184）。

**⑥ C1 与 A0 几乎相同**（+0.1250 vs +0.1232）。若 `b_mean` 块真的只提供全局基线，
这符合预期；但这也说明本轮指标无法区分"显式结构充分性"与"普通消息传递"。

## 7. 最重要的失败案例

`[1*]C1CC1=>[1*]CC`（环丙基→乙基）：真实上下文差异只有 0.19 logD，模型却给出 0.86 的
预测差异（gain −0.671），即模型把一个"几乎与核心无关"的替换误判成高度依赖核心。
`[1*]C=>[1*]CO` 同理（0.60 → 0.97）。这类"过度上下文化"是本轮最一致的失败模式，
也是 §5⑤ 中 14 个负增益家族的共同特征。

## 8. 能说什么、不能说什么

**可以说的**：按预先约定的四条资源准则，本轮通过，值得在**新的独立数据**上验证
"局部编辑效应依赖核心"这一假设；同时必须把验证设计成组件互斥，否则会重复本轮的
乐观偏差。

**不能说的**：① 不能说 LCRC 已证明能预测上下文效应——bootstrap 区间跨 0，
组件互斥子集反转为负；② 不能说这是独立确认——Audit 已曝光；③ 不能说 C1 优于 A0——
两者在噪声范围内相同；④ 不能把 +0.125 当作总体效应量，它主要由 13 个大效应家族驱动，
比较加权后只有 +0.029。
