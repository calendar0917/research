# REPORT — 保持连通的两键交换下，冻结模型对酰胺连接模式的响应

轮次：`lcrc-lipo-amide-connected-rewire-public122-v1`（协议见同目录 `PROTOCOL.md`，设计 revision
`0084daff`）
执行 revision：`64bb1c9f`（`res` / `res-gpu0` / process backend / 单卡 A100-SXM4-40GB）
上一轮（被本报告反复对照）：`lcrc_lipo_amide_dependency_public122_v1`（执行 revision `a0850d89`，
本轮只在其 `REPORT.md` 末尾追加了澄清附录 A，不改其任何协议与数字）

**一句话结论**：把"酰胺 C(=O)–N 连接"通过**保持连通的两键交换**换成"羰基＋胺的另一种连接方式"，
在组成、每个重原子的度、各种键型总量、环与连通性全部逐位不变（每个原子的 AF51 特征差 **0.0**）
的条件下，冻结的 LCRC-C1 仍然给出**方向一致、可解释口径下依然成立、并且比"保留酰胺但做同样
规模的改线"更大**的响应与参照偏差：Test `D` = **0.2571** [0.1680, 0.3564]、`J` = **0.3206**
[0.2346, 0.4114]、`B` = **0.4312** [0.3100, 0.5574]（105 分子 / 90 簇）；`G_FIXED` 口径几乎不变
（0.2550 / 0.3174 / 0.4287）。这是**本协议下的结构性观察**，不是化学因果效应，也不代表改线后的图
"应该"被预测得更差——`y` 始终是原分子的实验值。

## 0. 先回答三个问题

### 0.1 本轮修掉了上一轮的什么问题

上一轮用的是**删边（masking）**：T/K 视图各删一条键，图因此**断开**，`n_components`、`frac_unreachable_pairs`
飞出 Train 几个数量级，`FULL` 口径下的 `B` ≈ 7.5 logD 其实是"编码管线越界"的响应。上一轮无法把
"化学信息缺失"和"输入越界"分开。

本轮把干预换成**两键交换（rewire）**，对同一个 donor 键 `(u,v)` 构造一对视图：

| | 删除 | 保持/新增 | 结果 |
|---|---|---|---|
| `T`（破坏酰胺模式） | `(c,n)` + `(u,v)` | 交叉接 `(c,·)` 与 `(n,·)` | 酰胺消失：`c` 变成羰基碳（C=O + 2 个 C），`n` 变成远程胺 |
| `K`（保留酰胺模式） | `(c,acyl_c)` + `(u,v)` | 交叉接 `(c,·)` 与 `(acyl_c,·)` | 酰胺保留：`c` 仍是 C(=O)–N，第三个取代基换成 donor 碳 |

于是在 `O / T / K` 三者之间：**原子数、原子类别/电荷/H 数、每个重原子的度、键总数与每种键型的
总量、环原子/环键、环数、最小环尺寸、连通分量数（=1）、`frac_unreachable_pairs`（=0）全部相同**，
并且冻结适配器重建后**每个原子的 AF51 特征逐字节相同**（1206 个改线视图，`max|Δ| = 0.0`，见 §3）。
"越界"这条解释通道在本轮被关掉了，因此 `FULL` 与 `G_FIXED` 可以对照着读（§5）。

CI 为 scaffold 簇 bootstrap 1000 次 seed 20261114）：

`J` 只衡量"移动多少"，`D`/`B` 是与**原分子实验标签**的误差差。要点：

- **选择性是"T 比 K 更动"，而不是"任何改线都动"**：T 与 K 是同等规模的两键交换（都删 2 键、加 2 键、
  都改变同样两个 global 距离维、都保持连通），但 Test 上 `move_T` = 0.675 [0.589, 0.765] 是
  `move_K` = 0.355 [0.298, 0.418] 的约 **1.9 倍**；有符号位移 T 平均 **−0.399** logD（预测整体下降），
  K 平均 **+0.108**（几乎不动）。同一 donor、同一分子内配对比较，排除了"分子难度"这一层。
- **不是被少数分子拉动**：Test 上 80% 的分子 `J_m > 0`、73% `D_m > 0`、80% `B_m > 0`；
  `D` 的中位数 0.2416 与均值 0.2571 几乎相等（上一轮 FULL 是均值 0.470 / 中位数 0.554 的极端形态，
  本轮没有这种形状）。
- **固定影响检查全部仍为正**（Test，FULL）：去掉 `|D_m|` 最大的 1 个分子 → `D` = 0.2483、`J` = 0.3143；
  去掉最大的 5%（6/105，行 850/1400/2748/3012/3049/3365）→ `D` = **0.2274**、`J` = **0.2786**、
  `B` = 0.4097。`G_FIXED` 自己的检查同样成立（0.2461 / 0.3114；0.2252 / 0.2760）。
- **`G_FIXED` 几乎不动**：`D` 0.2550 vs FULL 0.2571（差 0.002）、`J` 差 0.003、`B` 差 0.002。
  也就是说，本轮效应**不是** global 分支贡献的：全局摘要只有两维移动且都在 Train 范围内（§5），
  响应几乎全部来自局部输入（S1 的 2-path 标量 + S2 路径统计）。
- **Valid 同向**（`D` 0.2355、`J` 0.3053、`B` 0.4120，121 分子 / 103 簇），所以不是 Test 特有。

### 0.3 能支持什么，不能支持什么

**能支持**：在这个冻结 checkpoint 与本协议下，"酰胺 `acyl_c–C(=O)–N` 连接存在"与"模型对原分子标签的
拟合"之间存在**可检测的关联**——破坏它（同时保持组成/度/环/连通/AF51 完全不变）比保留它（做同样
规模、同一 donor 的改线）多带来约 0.26 logD 的参照偏差与约 0.32 logD 的额外移动；方向在
Valid/Test、两个 scope、三组影响检查下一致。

**不能支持**：

1. **不是"信息量"**。`B`/`D`/`J` 都是**以原分子实验标签 `y` 为参照的误差差**，`y` 属于原分子，
   改线图是无标签的新图。`B` = 0.4312 只能读作"打断这条连接后，用原标签当尺子，误差多 0.43 logD"。
2. **`T` 不是"什么都没改、只删掉信息"**。它把酰胺中心变成"酮 + 一个迁移到远程的胺"：组成不变、
   官能团类别变了。因此这是"**酰胺 vs 酮/胺的另一种连接方式**"的对比，`K` 也不是化学等价阴性
   对照，而是"同 donor、同规模、保留酰胺"的对照。缺一个**化学匹配但明确非酰胺**的对照
   （例如把 N 换成 O 会改变组成，本协议做不到；这需要另一轮的设计）。
3. **不是唯一原子归因**。本协议交换的是 2 条键、涉及 6 个原子，只能谈"连接模式"，不能谈某条键的
   独占贡献。
4. **不能谈种子/模型普适性**：单一 checkpoint、单一 seed、Test 只有 105 分子 / 90 簇。
5. **不能谈"改线后应该更难预测"**：`D > 0` 只说明 T 的预测离**原分子标签**更远，而不是新图的真实
   性质更差。

## 2. 目标结构与支持度（结构定义在预测之前冻结）

目标仍是上一轮那个**受限**酰胺实例：`acyl_c–c(=O)–n`，`c` 为非芳香中性 C（度 3，三个邻居恰为
`o, n, acyl_c`），`o` 为度 1 的双键 O，`n` 中性且 3 个连接全为单键、`c–n` 是 Tarjan 桥，`c–acyl_c`
也是桥。**本轮唯一放宽**：主分析不再要求 `degree(n) = degree(acyl_c)`（上一轮的 `MATCHED` 要求只
保留为补充子集）。

donor 规则（无排序、无距离过滤、不看标签/预测）：同分量内中性非芳香 C–C 单键、是桥、`edge_stereo = 0`、

## 5. 为什么这一轮的 `FULL` 可以解读，而上一轮的不能

| 诊断 | 上一轮（删边） | 本轮（两键交换） |
|---|---|---|
| 切断/改线后视图越界（Test） | 91.8% 的视图至少一维越界，幅度最大 261.7 Train SD | **0%**；`diameter_max_finite` 最大 +5.0（Train 范围 3–38），`mean_finite_pair_distance` 最大 1.07（Train 1.90–14.03） |
| global42 变化维数 | `frac_unreachable_pairs` +223.5 SD、`n_components` +19.3 SD | **只有 2 维**（`diameter_max_finite` 平均 |Δ| 0.62、`mean_finite_pair_distance` 0.19），其余 **40 维逐位不变** |

| `FULL` 与 `G_FIXED` 的差（Test `D`） | 0.4705 vs 0.1449（差 0.33，且方向结论不同） | **0.2571 vs 0.2550（差 0.002）** |

也就是说：本轮 `FULL` 响应不再由编码管线越界主导，它和"只让局部输入变"的 `G_FIXED` 给出同一个
结论。这也顺便回答了上一轮遗留的问题——**上一轮的 `FULL` 效应确实是管道伪影，而本轮同类方向的
效应不是**。

唯一两个越界的视图是 **Valid 的 `1701:O` 与 `2087:O`**（`bonds_per_atom` / `junction_per_bond` /
`terminal_atom_fraction` 轻微越界）。它们都是**没有合格实例的分子**的 `O` 视图（不参与任何
`D/J/B` 计算），并且说明一件事：**逐维在 Train 范围内不是联合在分布内的保证**，原分子自己都可能
落在边缘。`analysis/view_out_of_range.csv` 只有表头——本轮没有任何 **pair** 因范围被剔除。

  注意它与上一轮 `MATCHED` Test（42 分子，`G_FIXED` `D` = 0.1449）**不是同一个人群**，不能直接相减。

## 12. 剩余不确定性

- **单一 checkpoint / 单一 seed**：无法区分"这个模型学到的"与"这类架构+数据学到的"。
- **对照的化学意义有限**：`K` 是"保留酰胺、换第三个取代基"，不是化学等价阴性对照；`T` 是"酰胺→酮+胺"
  的类别改变。真正想要的"化学匹配非酰胺对照"本协议构造不出（需要改变杂原子，就会破坏组成不变性）。
- **只能谈 2-path/S2 与两个距离维**：AF51 被钉死，所以结论限定在"局部拓扑统计"这条通道上，
  不能说明模型对"酰胺官能团身份"有表征。
- **覆盖率**：Test 只有 105/420 分子进入主分析；有实例无合法 donor 的分子被排除（本轮 0 个因范围被
  排除，但 donor 规则本身就筛掉了大量分子）。
- **`y` 的语义**：所有 `D`/`B` 都以原分子标签为参照，改线图没有、也不可能有测量值。
- **两个 Valid `O` 视图越界**（行 1701、2087）：提醒"逐维合法 ≠ 联合合法"，本轮无法给出联合距离判据。
