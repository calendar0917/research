# DCC-L 真实瓶颈定位 — `zinc_dccl_bottleneck_v1`

**边界**：official test 全程未构造、未读取。phase A 只用 4 个冻结 DCC-L（`B-R0`，494,193 参数）的
official-valid 逐分子预测（复算 0.07854/0.07384/0.07468/0.07691，与历史一致到 1e-6）；phase B 用
`bjoc_predictive_bottleneck_v1` 已冻结的嵌套 Fit4k/Fit8k/Monitor/Locked 划分（全部落在 official
train 10k 内），只跑原生 DCC-L。GPU 实耗 **1.423 A100·h**（上限 2.0；4 条正式轨迹 + 1 次
smoke，`res` 两卡并行，provenance 见 `analysis/rr_jobs.json`）。

## A. DCC-L 已排除哪些瓶颈（official valid，4 seeds）

全量 MAE **0.07599**；median AE 0.0407，top-10 分子占 18.5%，top-100 占 46.0%。

**互斥分组表**（U = 分子含 ≥1 个 radius-2 环境在 train 10k 中从未出现；T = y ≤ −3；R = 环数；
MAE 为 4-seed 均值，AE share 为对总绝对误差的贡献；完整 12 格见 `analysis/report_tables.md`）：

| U | T | R | n | MAE | AE share | signed(4 seed 同向?) |
|---|---|---|---:|---:|---:|---|
| seen | ord | r0–1 / r2–3 / r≥4 | 35 / 521 / 154 | 0.057 / 0.043 / 0.052 | 2.6% / 29.4% / 10.5% | −0.012 / −0.006 / −0.008 |
| seen | y≤−3 | r0–1 / r2–3 / r≥4 | 2 / 25 / 12 | 0.050 / **0.265** / 0.117 | 0.1% / 8.7% / 1.8% | +0.035 / **+0.229(是)** / +0.018 |
| unseen | ord | r0–1 / r2–3 / r≥4 | 35 / 149 / 41 | 0.099 / 0.102 / **0.228** | 4.6% / 20.0% / 12.3% | +0.038 / +0.030 / **−0.118(是)** |
| unseen | y≤−3 | r0–1 / r2–3 / r≥4 | 4 / 16 / 6 | 0.153 / 0.169 / **0.696** | 0.8% / 3.6% / 5.5% | −0.007 / +0.032 / **+0.676(是)** |

按"环境支撑"重排（全支撑 = 每个原子的 radius-2 签名都有 ≥5 个训练分子；低支撑 = 无未见但含
1–4 支撑原子；未见 = 含 0 支撑原子）：**0.0365（383 个）/ 0.0724（366 个）/ 0.1414（251 个）**，
即 61.7% 的分子（至少一个原子环境支撑 <5）承担 **81.6%** 的总误差。剂量-反应单调：未见原子
占比 0 → 5.4%（MAE 0.054）、≤5% → 8.7%、5–10% → 10.2%、>10% → **0.236（82 个分子，占 25.5% AE）**。

被排除的：

1. **seed / checkpoint 抽签**：signed error 跨 seed 相关 0.82–0.96（均值 0.89），组内 per-seed MAE
   差异 <0.002。种子是二阶噪声，不是平台。
2. **环复杂度 / 尺寸作为独立机制**：控制未见比例、原子数、|y| 后 rings 的 partial ρ 仅 **0.16**
   （同一控制下"未见比例"是 **0.41**）；全支撑分子里 rings≥4 的 MAE 0.0455（n=67）vs 全体
   0.0365。"环多"主要是"环境新"与"分子大"的代理。
3. **区域型系统性外推失败（H3 的均值漂移形式）**：确有多个结构组 4/4 seed 同号（上表粗体），
   但把 signed 与离散度分开后，n≥10 的组 bias²/MSE 全部 ≤0.084（9 个组中 5 个 ≤0.03），
   尾部组 0.045；逐分子符号一致率只有 0.44–0.83。也就是说，"组级偏置"存在但不承载误差质量，不能作为纠偏器目标。
4. **整分子结构近邻支持不足**：用预先固定的 IDF-WL(2) cosine（k=10）与 radius-2 签名 Tanimoto
   两套目标无关相似度，困难分子（top-100 AE，占 46% 总误差）的 top-10 相似度只比其余低
   0.678 vs 0.727；近邻标签离散度的 partial ρ 仅 +0.13；1-NN/10-NN 参考模型 MAE 0.92–3.55，
   远差于模型（0.076）。ZINC subset 没有近重复结构（top-1 相似度中位数 0.79），
   "近邻支持"不是可用的解释变量；真正有分辨力的是**精确局部环境覆盖**。
5. **容量/优化不足**：phase B 的 4k 臂在 47,400 updates 内把训练集拟合到 online MAE 6.8e-4
   （等于记忆），monitor 在 ~25–30k updates 后完全平坦；8k 臂同样（8.1e-4）。不是欠拟合。

## B. 哪个瓶颈获得最强支持（证据等级）

**H1（有限标签下的样本效率）— 证据等级 A（配对干预、同预算、两 seed、方向一致）。**

原生 DCC-L、同架构/同参数/同 SSL/同 R0/同 **47,400 updates**、标准化只用各自 Fit、Monitor 选点、
Locked-dev 最后读一次（2 seeds × 2 arms）：

| arm | epochs | locked (best-monitor) | locked (final) | monitor | official valid | 训练集 online MAE |
|---|---:|---:|---:|---:|---:|---:|
| Fit4k | 1482 | 0.1213 / 0.1203 | 0.1226 / 0.1208 | 0.1604 / 0.1646 | 0.1295 / 0.1364 | 6.8e-4 / 7.3e-4 |
| Fit8k | 753 | **0.0836 / 0.0834** | 0.0825 / 0.0837 | 0.1232 / 0.1278 | 0.0899 / 0.0955 | 8.1e-4 / 8.4e-4 |

Δ(Fit8k − Fit4k) on locked：**−0.0377 [−0.0498, −0.0293]**（s0）、**−0.0369 [−0.0421, −0.0317]**（s1）；
相对 **−30.9%**；67% / 69% 的分子变好；official-valid Δ −0.0396 / −0.0409。与 BJOC 历史 4k→8k 的
−0.0373 几乎相同。**"标签数量不足"不能停用；它现在是唯一测得的大杠杆。**

机制限定（这是本轮最重要的新事实）：**增益不是"覆盖补洞"，而是"共享函数的估计方差"。**
把 locked 分子按"4k→8k 是否新获得覆盖"分层，Δ 分别为
新覆盖（139 个）−0.041 / −0.059、仍然未见（287 个）−0.042 / −0.038、4k 已完全支撑（574 个）
−0.035 / −0.031。增益与分子在 4k 时的误差近似成比例（≈ −0.31×e₄），三层都接近。
即：多标签改善的是"环境贡献的估计精度与组合方式"，包括它从未见过的环境；
而不是"给未见环境补了查表项"。这直接解释了历史负结果：加性纠偏头
（`zinc_support_transfer_probe_v1`）在零支撑原子上学不到可迁移规则，因为缺失的本来就不是一个
逐环境的常数。

## C. 能影响多少总 MAE，够不够成为 <0.060 的目标

* 交叉截面：**全支撑的 383 个分子 MAE 0.0365，已经在 0.060 之下**；误差几乎全部来自
  "部分支撑/未见"的 617 个分子（MAE 0.1005，81.6% AE）。若未见组能到已见组水平，总 MAE 会变成
  0.054；反过来，只改善已见组无法达标（已见组只占 53% AE）。
* 边际：4k→8k 买到 −0.038 locked / −0.040 valid；描述性比较历史 10k（official valid 0.0760）
  得 8k→10k 的 −0.0167。于是 official valid 上的标签斜率约 **−0.008~−0.010 / 1k 标签**。
  幂律外推（α≈0.52 由 4k→8k、0.89 由 8k→10k，均值 0.70）：把 valid 从 0.0760 推到
  0.0687（按历史 valid→test 偏移 −0.0087，即 test 0.060）需要 **11.2k–12.1k 标签**。
* 对比：本仓库历史测得的所有单一机制最大只有 **−0.0048**（换主体）/ **−0.0045**（2-seed 平均，
  且不允许），结构机制一律 ≤0.005。要补的缺口是 **−0.0073 valid（−10% 相对）**：
  即"再一个结构机制"必须比历史最好机制大 1.5 倍才够，而数据斜率在同样预算下给出的是它的 2 倍以上。
* 因此：**<0.060 目前在数值上是一个"标签数量/估计方差"问题，而不是"缺少某个结构算子"问题。**
  这不能说表示已经充分（未证明），但可以说：没有任何已测的结构性误差区域能支撑一个
  针对区域的算子，且 H3 的均值漂移版本已被否证。

## D. 下一轮：性能导向、机制导向，还是停止

**性能导向（数据侧）**。理由：唯一 A 级证据是标签数量；机制导向的候选（局部因子化、共享原子
因子、branching fragment、加性纠偏、关系算子/attention、GRIT/DBT 原生 horizon）在本仓库里
已各自留下负结果，且与本轮的"误差与支撑剂量成正比、与结构类别无关"的图景一致——它们都在
试图修一个不存在（或至少不主导）的区域性缺陷。

**若"official 10k 训练集"是不可改动的前提**，那么本轮结论等价于：该家族在官方协议下的天花板
就是 0.0663（best seed）/0.0673（seed 均值），下一轮应当**停止把 <0.060 当作该家族的改进目标**，
而不是再买第 5 个结构机制。两者必须二选一，不能既要官方协议不变、又要 <0.060。

## E. 唯一最值得购买的下一项计算或实验

**在同一冻结协议下测标签数量斜率的 10k→12k 两点（2 条轨迹，≈0.75 A100·h + 一次性 prep）。**

* 10k 臂：official train 全量；12k 臂：再加 2k 个同分布 ZINC 分子（**逐分子排除与官方
  valid/test 同构的分子**，用 WL 指纹 + 精确图同构双重过滤，避免 test 泄漏）。
* 同架构 / 同 SSL / 同 R0 / 同 47,400 updates / Fit-only 标准化 / Monitor 选点 / Locked 只读一次；
  official valid 与上述 4k、8k、10k 点拼成同一条曲线。
* **判定（先写死）**：Δlocked(12k − 10k) ≤ −0.010 → 斜率在 10k 之外仍然有效，<0.060 是数据量问题，
  继续沿这条曲线买（或明确宣布改用外部标签，并同时改写 benchmark 口径）；Δ ≥ −0.004 → 4k→8k 的
  斜率是局部的（4k 早饱和效应），H1 降级，家族在官方协议下收尾。两者之间 → 只允许补一个 11k 点。
* 这是"唯一"的理由：它同时（i）验证本轮唯一 A 级结论的外推，（ii）直接判决 <0.060 是否可达，
  （iii）不需要新架构、不读 test、成本低于 1 GPU·h。

## Phase C（机制候选）：`NO_JUSTIFIED_NEW_MODEL`（forward 侧）

按任务要求逐条对照后，**没有任何 forward 运算改动通过"最强反对证据"门槛**：

* 分区/区域算子（环、macrocycle、junction 身份、ring-rich 区域）：本轮显示这些区域效应在控制
  "支撑剂量 + 大小"后只剩 partial ρ=0.16，且无可用均值偏置；对应的旧实验（organized/DBT/
  branching fragment/hierarchical relation）已是负结果。
* 低参数加性/因子化读出（"让每个标签约束更多参数"）：`zinc_shared_factor_v1` 判定 A_FAIL，
  `zinc_local_factorization_v1` F vs D 差 2e-5（test 反向 +0.0016）——同一命题已试过。
* 针对未见环境的纠偏/查表：`zinc_support_transfer_probe_v1`（加性纠偏学不到可迁移规则）、
  ESR/精确残差（更差）。本轮 phase B 进一步给出机制解释：缺失不是逐环境常数。

唯一仍站得住的机制候选是**数据/估计器侧**（forward 与 DCC-L 完全相同，不属于新模型）：
**标签数量斜率点 10k→12k**（见 E）。它不满足"与 DCC-L 的哪个 forward 运算不同"这一条，
因此本轮的 Phase C 判定是 `NO_JUSTIFIED_NEW_MODEL`，而不是编造第二个结构方案。
