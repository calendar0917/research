# `analysis/` — frozen artefacts

Every file here is regenerated by the committed code and was force-added at the end of the
round (the directory is otherwise gitignored so that runs never start from a dirty tree).
The mapping to the deliverables named in the brief:

| brief name | file(s) in this round | produced by |
|---|---|---|
| comparison | `../results/main_table.csv`, `../results/summary.json` | `psc_analysis.py --stage table` |
| support_novelty | `path_sparsity.json`, `molecule_novelty.json`, `unique_pair_metrics.json` (support classes) | `--stage sparsity`, `--stage molnov`, `--stage pairs` |
| unique_pair_metrics | `unique_pair_metrics.json` | `--stage pairs` |
| pair_residual_decomposition | `pair_residual_decomposition.json` | `--stage decomp` |
| sum_edit_ledger | `sum_edit_ledger.json` | `--stage ledger` |
| selection_lock | `selection_lock.json` (+ `cpu_lock.json`) | `--stage select` |
| final_eval_lock | `final_eval_lock.json` | `psc_final_eval.py --write-lock` |
| final Valid | `final_valid.json` | `psc_final_eval.py --score` (single label access) |
| checks | `checks.json` | `psc_checks.py` |
| compute_budget | `compute_budget.json` | `psc_budget.py` |
| uncertainty | `bootstrap.json` (D0), `bootstrap_D1.json` | `--stage bootstrap` |
| size strata | `size_strata.json` | `--stage sizes` |
| figures | `figures/fig1..fig4*.png` | `--stage figures` |
| tables | `tables.md` | `psc_tables.py` |
| report | `../REPORT.md` | `psc_report.py` |
| running logs | `logs/*.log` (launch/monitor logs, gitignored) | queue drivers |

Notes:

* `final_valid.json` was written by the one frozen Valid pass. The only earlier access to
  Valid labels in the tree is `final_eval_lock.json`'s record of *which* file is used (no
  label member read).
* `partial`/stale files are not kept: each JSON carries `generated_utc` and the git commit.
* The four figures are the only scientific figures of the round (`fig1` arms × seed,
  `fig2` pre-specified contrasts, `fig3` novelty strata, `fig4` training curves).
