给导师的一到两页摘要。**先说认识改变，再说哪些已收束、哪些还不能给。**
本轮没有新训练、没有新推理、没有新干预、GPU = 0；只做方法形式化、旧结果口径统一、材料整理。

## 1. 认识改变（比新数字更重要）

**① 「scalar 块没有作用」这个说法要撤回。**
八格分解里真正**单独**的标量项是 $g_3$，它在 amide/Test/校准人群上确实很小（−0.0017）。
但我们原来引用的 $R_3=\text{value}(123)-\text{value}(12)=+0.0307$ 不是单独项，
它等于 $g_3+g_{13}+g_{23}+g_{123}$，**含全部与 scalar 有关的交互**。
正确表述是「独立标量项小，但存在非零交互（S1×S2 等）」，不是「scalar 无影响」。

**② 「S2 独占 93%」这个说法要撤回。**
$R_2/J_C = 0.1355/0.1460 = 92.8\%$ 这个比例是真的，但 $R_2$ 自己就是
$g_2+g_{12}+g_{23}+g_{123}$。所以只能说「**条件 S2 恢复**占该子群端点差的约 93%」，
不能说「S2 独占贡献 93%」，更不能说「对所有分子必要」或「去掉 S2 重训必然失败」
（后者需要重训，我们没有做）。

**③ 两个恢复量必须分开写。**
`R2_T_H`（+0.4585，T 相对原分子）与 `R2_TminusC_H`（+0.13555，同一批 T 相对**匹配对照** C）
是不同的问题。混写会直接把「人群选择」误当成「通道机制」。

**④ 「酰胺支持」的边界比原来窄。**
它成立在**等剂量可匹配子群**：Test 62/164 分子（≈38%）、110/533 对（≈21%）。
它是相对对照的无量纲 $rC/E$ 陈述，不是原始 logD 幅度，也不是「所有含酰胺的分子」。
其他家族是**异质**的：磺酰胺只有 $E$ 明确、芳醚**反向**（−0.433）、芳胺 n=4 且 $E$ 为负、
酯未成立、磺酸酯根本没有对照（未检验，≠ 零效应）。

**⑤ 更强的跨家族结论属于**另一个**模型，不能拼接。**
实验 logD 侧的改线分子**没有标签**。四家族方向/幅度跟随的证据来自**新训练的 WC_LOGP 模型**
（seed 0，0.185 GPU·h）。把它写成「同一个 logD 模型已在四个家族验证化学机制」是错的。

**⑥ MolWt 不是「不变」，而且平均响应要换口径。**
参照变化严格为 0（构造性质），模型仍动：分子权重下逐家族 0.90–1.92 g/mol
（0.0084–0.0177 σ，σ_train=108.294），Test pooled 1.33 g/mol（0.0123 σ）。
旧文写的 1.81 g/mol 其实是**只取 T 视图 + pair 加权**，没有标注。
最大个例 14.24 g/mol（0.132 σ，`sulfonamide:1275:1:0:d9-14`）保留在主统计里。

**⑦ 方法本身有一条硬边界：签名充分但不完备。**
5 对**非同构**分子拥有相同的逐根签名与 `global42`，复用模型给出的预测差 ≤3e-7。
所以「模型看到的结构分辨率」是有限的；我们不能声称签名是完整化学表示或最小签名。

## 3. 现在不能给出的主张（缺证据，不是缺写作）

1. **「LCRC 独有这种能力」或「优于其他解释模型」**：没有同数据、同预算的对照解释器，
   也没有把签名喂给简单基线（加性/查表/线性）的对照。
2. **「所有（或多数）家族都验证了机制」**：logD 侧只有酰胺校准子群；芳醚反向、酯未成立、磺酸酯未检验。
3. **「S2 通道是必要的（架构必要性）」**：八格是固定权重的输入分组干预；必要性需要去 S2 重训。
4. **「MolWt 上模型精确不变」**：残留非零，且有 0.13σ 的个例。
5. **「跨 seed / 跨数据集稳定」**：全部结果是一个 seed、一个结构库。
6. **「改线分子的 logD 被正确预测」**：改线分子没有实验 logD。
7. **「某个原子/官能团的唯一贡献」**：$\Delta\rho$ 与 $\Delta q$ 同量级，池化耦合无法分摊。
8. **「签名是最小/完整表示」**：存在非同构分子的输入别名，且签名不同也不保证数值可分。

## 4. 如果整篇论文要更强的主张，具体缺什么（只列缺口，不执行）

| 想要的主张 | 需要的证据 | 现状 |
|---|---|---|
| logD 侧从「校准酰胺子群」扩到多家族 | 改线分子的实验 logD；或高支持的 MMP 同系物样本（每家族几十对以上、组件级 CI 不含 0） | 缺。现有 MMP 支持是 `LOW_SUPPORT`（如 sulfonamide 16 对 / 7 组件） |
| 稳定性 | 第二 seed（logD 一个 + 两计算任务各一个），同配方同预算 | 缺。目前全 s0 |
| 覆盖 | 第二结构库或第二改线族；补足酯（现 8 分子）与磺酸酯（现 0）的合法 C | 缺 |
| 「优于其他解释模型」 | 同输入、同预算的对照解释器（签名→加性/查表/线性），同人群同区间 | 缺。本轮明确不做 |
| 「S2 架构必要」 | 去 S2 用同配方重训（seeds 0/1），同人群比较 | 缺。本轮明确不做 |
| 「签名分辨率足以区分化学上不同的结构」 | 更高阶统计的独立审计 + 训练后是否有用的检验 | 部分缺。s3 已证 LOCAL3 可分 4/5 对但**未获益** |
| 更强的人群结论 | 每个家族把 C 覆盖率从 9–26% 提到接近 100% | 缺。受剂量匹配结构限制 |

这些缺口**都不是**本任务可以顺手补的：补任一项都需要新训练或新实验轮次。
本轮的立场是：先把能写的写准，把不能写的标清楚。

## 5. 建议的对外一句话

> LCRC 用显式局部结构统计做预测，能把一次具体连接改动追溯到「哪些原子的统计输入变了、
> 局部读出变了多少、池化项变了多少」；在既定面板上，这个可追溯性给出的是**有边界、
> 可检验的任务相关结构依赖**——实验 logD 侧限于等剂量可匹配的酰胺子群，跨家族的方向/幅度
> 跟随由计算参照任务（WC_LOGP）支持，组成不变量任务（MolWt）上残留小但非零的响应。
> 它不等同于普遍化学因果机制，也不提供唯一原子贡献。
