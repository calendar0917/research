## 首页：直接回答八个问题

**1. 线性模型能否通过合理学习约束明显改善？**
**能，而且这是本轮最干净的改进。** 沿用历史 class-balanced + 全列标准化的
`L-BAL-STD`，只把 C 从 0.03 收紧到 0.0003：Valid AUC 0.7463 → **0.7973**
（Δ +0.0510，95% CI [+0.0174, +0.0919]），Test 0.7495 → **0.7922**
（Δ +0.0427，CI [+0.0229, +0.0637]），AP Test 0.1197 → 0.2779；代价是 Train AUC
0.9872 → 0.9615。**但最优仍落在网格下边界 C=0.0003**，所以“已找到最佳线性模型”
不成立。普通监督的 `L-NAT-RAW` 在 C=0.03（网格上边界）拿到最高的 Valid
0.8025，Test 只有 0.7670；`L-NAT-STD` 为 0.7948 / 0.7786。相对 XGB-ALL
（0.8153 / 0.8174），`L-BAL-STD` 的 Valid 差距约 0.018、Test 约 0.025；
`L-NAT-RAW` 的 Test 差距更大（0.050）。结论：**此前线性模型的失败有相当一部分
来自正则化不匹配，但不能全部归因于此**；C 网格两端都触界，剩余差距仍可能来自
单结构非线性或交互。

**2. HIV 的树模型优势是否需要跨结构交互？**
**不能这样断言。** `H-ADD-TREE` 在 500 轮为 Valid 0.7871 / Test 0.7696，
XGB-ALL 为 0.8153 / 0.8174：Test 差 +0.0478（CI [+0.0162, +0.0804]），Valid 差
+0.0282（CI [−0.0063, +0.0650]）。但加性树的 Train AUC 只有 **0.8367**（完整树
0.9561），500 轮时曲线仍在上升，且只使用了 **91/4408** 个特征、3161 个叶节点。
按预注册规则未触发 `CAPACITY_CONFOUNDED`（训练差距 0.1194 < 完整树自身
Train−Valid 差距 0.1409），但 0.875 的训练拟合比和仍在上升的轮数说明**容量/拟合
程度无法排除**。因此这 0.048 的 Test 差距**不是**跨结构化学相互作用的干净证据。

**3. 同输入的神经模型表现如何？类别加权影响多大？**
`H-NN-JOINT`（普通 BCE）：Valid **0.8189** / Test 0.7844；
`H-NN-JOINT-BAL`（class-balanced）：Valid **0.8396** / Test 0.7687；
`H-NN-ADD`（加性神经，普通 BCE）：Valid **0.8191** / Test **0.7992**，
Test AP 0.3468（三个新神经模型中最高；XGB-ALL 为 0.3603）。两 MLP 的初始化哈希逐位相同
（`e31778b87e94`），batch 顺序相同，唯一差异是监督权重。
`JOINT − BAL`：Valid −0.0207 [−0.0415, +0.0011]，Test +0.0156 [−0.0054, +0.0363]；
即**类别加权改善 Valid、但不改善 Test**，主要改变的是“最佳 epoch”落在第 3 还是第 4 轮。
它**不能**解释此前树模型 vs MLP 的差距。`XGB-ALL − JOINT`：Valid −0.0036
[−0.0461, +0.0322]，Test +0.0330 [+0.0020, +0.0673]；`XGB-ALL − ADD-NN`：
Valid −0.0038 [−0.0428, +0.0329]，Test +0.0183 [−0.0108, +0.0526]。
**在 AUC 上，加性神经与 XGB-ALL 不可分辨；XGB-ALL 的 AP 在 Valid 上更高**
（+0.0775，CI [+0.0121, +0.1428]），Test 上差 +0.0135（CI 跨 0）。

**4. 加性神经函数能否保留主要预测价值？**
**能。** `H-NN-JOINT − H-NN-ADD`：Valid −0.0002 [−0.0273, +0.0294]，
Test −0.0148 [−0.0349, +0.0070]；AP Test 反而由加性模型高 0.0636。
ZINC 上 `Z-NN-ADD − ZN1` 的 MAE 差为 Valid −0.0086 [−0.0257, +0.0063]、
Test −0.0049 [−0.0206, +0.0100]（负 = 加性更差，但 CI 均跨 0）。
**两个数据集都没有检出“联合神经混合”相对“单特征加性函数”的额外价值**；
这支持把可解释的加性神经读出作为下一步的正式候选，而不是继续堆 MLP 宽度。

**5. ZINC 是否呈现相同计算机制？**
**读出层面相反，但证据受容量混杂。** `Z-ADD-TREE`：Valid 0.6493 / Test 0.6822，MAE 比 ZX1（0.4691 / 0.4845）
高 0.1802 / 0.1978；配对增益（MAE(ZX1)−MAE(ADD)）为
−0.1802 [−0.2017,−0.1606] / −0.1978 [−0.2192,−0.1778]（负值 = 加性更差）。它的 Train MAE 0.6117
远差于 ZX1 的 0.3661（比 0.1030 的完整树泛化差距还大），**预注册
`CAPACITY_CONFOUNDED = True`**。相反，`Z-NN-ADD` 与 ZN1 不可分辨
（−0.0049 Test，CI 跨 0），Train MAE 0.2110 vs ZN1 0.1120（过拟合更少）。
即：**ZINC 上 MLP 相对 XGB 的优势在加性限制下仍然存在；树的优势则在加性限制下消失。**
由于 ZINC 树容量受限，不能把它写成“ZINC 需要结构交互”的因果结论；数据量、WL
表示、目标与属性语义也都不同。HIV/ZINC 的差异应保留为**现象参照**。

**6. 具体观察到了哪些真实结构函数？**
在 Train 支持与训练后函数（不看 Test）选出的 7 个 HIV 结构中：

* `F[1783]`（size-4，Train 非零支持 1624）：树函数在 `x≈0.72` 后**饱和**在
  +0.613；加性神经继续近似线性上升至 +0.475；线性函数 +0.679。方向和幅度一致，
  函数形状不同。
* `F[1773]`（size-4，支持 1740）：树函数上升至 +0.675 后在最大分位点回落到
  +0.535（**非单调**）；神经单调上升至 +0.389；线性 +0.228。
* `C[145]`（size-3，支持 2623）：树为负且**饱和**（−0.231，最后回升到 −0.157），
  神经持续下降至 −0.647，线性 −0.185。
* `F[705]`（size-3，支持 3376）：树函数非单调且幅度小（−0.03…+0.20），
  神经平滑下降至 −0.257。
* `C[504]`、`C[175]`、`F[820]`：**树函数恒为 0**（这些特征没有进入 500 棵加性树），
  而神经学到单调负函数（C[504] 到 −1.001；C[175]/F[820] 到 −0.574/−0.685）。
  其中 `C[175]` 与 `F[820]` 是 COARSE/FULL 父子对，二者方向一致、子型更陡。
* ZINC 的 `F[1]`（size-2，支持 9311）：树函数 +2.10，神经仅 +0.073；
  `F[50]`/`F[0]` 也呈同样的“树强神经弱”。这与 Z-ADD-TREE 依赖少数高增益特征一致。

**7. 哪些假设获得支持，哪些仍不能区分？**
获得支持：强正则改善线性模型；HIV 的 AUC 不需要可检出的跨结构交互（加性神经与
XGB-ALL 不可分辨）；ZINC 的 MLP 优势不依赖联合混合；树只使用极少数特征。
仍不能区分：HIV 加性树与完整树的差距来自交互还是树容量/拟合轮数（容量不可排除）；
ZINC 树差距同样容量混杂；类别加权带来的 Valid 提升是真实机制还是早期 epoch 选择；
单 seed 下的模型家族差异；结构间是否存在真实的化学交互（本轮**没有**做因果删除或
化学机制检验）。不显著不等于等价。

**8. 下一阶段是否具备研究共享结构函数的具体依据？**
**具备，但只到“候选”级别。** 我们已能精确提取每个模型的实际单结构函数
（树闭合 7.7e-6，神经闭合 8.0e-7，`f_j(0)=0`），并找到若干 Train 高支持、
跨模型方向一致或形状明显不同的函数（F1783/F1773/C145/F705，父子对 C175/F820）。
下一阶段的合理问题是：这些**冻结函数**能否在第二个任务/第二个模型家族中复现，
以及共享的是“饱和形状”还是仅仅“方向”。这需要跨任务冻结函数评估，而不是新的 GNN
或更大规模的结构搜索。

## 2. Phase 0 — 贡献统计修复（不重训）

ISRD-v1 的 `contrib = (x−mu)/sd * w_raw` 在 `w_raw=w_std/sd` 之后又除了一次 `sd`。
零结构基准与均值中心化基准均以 1.4e-14 / 2.0e-14 的误差重建冻结 logit；历史错误
公式的误差为 8.4e3。Test 平均：结构项 |贡献| 总量 **33.11**（旧 2200.29），
top-5/10/20 = **35.0% / 51.5% / 70.3%**（旧 29.1/36.4/42.7%），
top-20 之外的有符号剩余 **−0.86**、绝对剩余 **10.85**；平均 89.0 个结构激活。
按 COARSE 父结构汇总后 top-5/10/20 = **49.6% / 70.2% / 89.1%**，平均 36.9 个家族激活。
旧集中度与绝对总量已被 [ERRATA.md](ERRATA.md) 替代；模型 AUC 不受影响。

## 3. Phase A — 线性学习约束（MolHIV）

选择规则：最高 Valid AUC，平局取更小 C。所有配置的 Train/Valid/Test AUC 与 AP 见
`analysis/metrics.csv`；下面为每组最优：

| 模型 | 监督 | 缩放 | C | Train AUC | Valid AUC | Test AUC | Valid AP | Test AP |
|---|---|---|---:|---:|---:|---:|---:|---:|
| COUNT-ALL（历史） | balanced | 全列 std | 0.03 | 0.9872 | 0.7463 | 0.7495 | 0.1235 | 0.1197 |
| L-BAL-STD | balanced | 全列 std | **0.0003** | 0.9615 | **0.7973** | **0.7922** | 0.3084 | 0.2779 |
| L-NAT-STD | natural | 全列 std | 0.003 | 0.9607 | 0.7948 | 0.7786 | 0.3064 | 0.2041 |
| L-NAT-RAW | natural | 仅大小项 std | **0.03** | 0.8243 | **0.8025** | 0.7670 | 0.3027 | 0.2900 |

* `L-BAL-STD` 与 COUNT-ALL 的配对 bootstrap（scaffold）：C=0.0003 Valid +0.0510
  [+0.0174,+0.0919]、Test +0.0427 [+0.0229,+0.0637]；C=0.003 为 +0.0321/+0.0247。
  AP 差 +0.1849/+0.1583。**Train AUC 下降、Valid/Test 同时上升**，是正则化假设的
  直接支持。
* `L-NAT-STD − L-NAT-RAW`：Valid −0.0077 [−0.0605,+0.0459]、Test +0.0116
  [−0.0299,+0.0535]；两种缩放没有可检出的差异。
* 边界：`L-BAL-STD` 最优在 **C 下边界 0.0003**，`L-NAT-RAW` 最优在 **C 上边界
  0.03**；不能宣称找到了最佳线性模型。
* 逐列标准化使低支持结构的有效系数被 `1/sd` 放大；`L-NAT-RAW` 保留原始冻结缩放后
  训练拟合明显更低（0.8243）但 Valid 最高，说明缩放与正则的交互真实存在，
  但 Test 排序并不一致。

## 5. Phase C — 神经读出

统一：seed 0，50 epochs，batch 256，AdamW lr 1e-3，wd 1e-4，clip 5，无 scheduler，
每 epoch 完整评价三划分，按 Valid 选最佳 epoch（平局取较早）。HIV 大小项 Train-only
标准化；结构计数保持冻结缩放。ZINC 严格沿用 ZN1 的大小项标准化 + 整块 clip ±10。

| 模型 | 参数量 | best epoch | Train | Valid | Test | Valid AP | Test AP |
|---|---:|---:|---:|---:|---:|---:|---:|
| H-NN-JOINT | 580 993 | 4 | 0.9331 | 0.8189 | 0.7844 | 0.3318 | 0.2833 |
| H-NN-JOINT-BAL | 580 993 | 3 | 0.9550 | 0.8396 | 0.7687 | 0.3138 | 0.2563 |
| H-NN-ADD | 39 673 | 7 | 0.9111 | 0.8191 | 0.7992 | 0.3202 | 0.3468 |
| Z-NN-ADD (MAE) | 53 110 | 47 | 0.2110 | 0.2927 | 0.2793 | — | — |

（ZN1 历史参照：Train/Valid/Test MAE 0.1120/0.2841/0.2744，best epoch 46；
ZX1：0.3661/0.4691/0.4845。）

* 两个 MLP 的初始化哈希完全相同（`e31778b87e94`），batch 顺序相同；唯一差异是
