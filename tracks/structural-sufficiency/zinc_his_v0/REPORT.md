## 1. 问题与唯一改动

LCRC-A 中 `path_emb` 是 `[189,32]`，按 `path_cat = middle_type*9 + (b1−1)*3 + (b2−1)` 索引，即 (21,3,3) 的类别表。它通过 first-layer 权重第 **320..352** 列（由真实前向 hook 反推、非硬编码）线性读取，定义有效线性响应

```
H[a,b,c,:] = path_emb.weight[a,b,c,:] @ W_pathᵀ ,  W_path = mlp.lins[0].weight[:, 320:352]
```

并做 ANOVA 分解 `H = H_≤2 + H₃`。唯一实验改动：

```
loss = L1(raw y) + λ · mean(H₃²)
```

`path_u/path_v` 的联合乘积通道、`path_gate`、汇聚方式、架构、前向、初始化、数据顺序全部不动。

**唯一与任务书字面不一致之处（在 GPU 之前记录）**：任务书正文印出的主效应符号版本（`AB+AC+BC−A−B+C+μ` 之类）不是真正的残差——它不满足三轴边缘归零，也无法在二阶合成张量上归零。我们实现的是

```
H_≤2 = AB + AC + BC − (A + B + C) + μ ,   H₃ = H − H_≤2
```

`tests/test_his_v0.py::test_literal_brief_formula_is_not_the_residual` 把字面公式的失败逐条钉死（重建误差、三轴边缘、二阶合成非零、纯三阶漏检）。这是实现层面的修正，不改变被检验的假设。

## 4. 机制证据：约束是否真的作用在第三阶响应上？是否被绕过？

**（a）约束饱和，而且非常快。** `||H₃||/||H||` 轨迹（每 100 epoch）：REPLAY `0.6578, 0.6553, 0.6533, 0.6532, 0.6531, 0.6530`（常量）；HIS `0.6409, 0.0138, 0.0035, 0.0018, 0.0015, 0.0005`。惩罚项 REPLAY `0.00893, 0.0420, 0.0916, 0.1274, 0.1414, 0.1441`（**在无约束模型里被放大 16 倍**），HIS `0.00669, 1.0e-6, 3e-7, 1.4e-7, 1.1e-7, 1.0e-8`。

**（b）被摘掉的通道确实“死了”。** best 检查点上，把 `path_emb` 替换为其 ≤2 阶投影（固定 512 训练分子）：REPLAY `mean|Δpred| = 0.0819`（MAE 0.0030 → 0.0809，93.6% 的行 > 0.010）；HIS `2.64e-5`（MAE 0.00784 → 0.00783，0% 的行 > 0.010）。同样干预不再有任何效果。

**（c）`H` 的整体尺度也变了。** best 检查点 `‖H‖_F`：REPLAY 110.74（`h_rms` 0.581，相比 epoch 1 的 0.128 放大 4.5 倍），HIS 43.90（`h_rms` 0.230）。即 HIS 不只是让三阶分量归零，它把整个 `path_emb` 读出通道压到约 40%。

**（d）优化器确实把一部分载荷挪到了未约束的 `path_u·path_v` 联合通道。** 该通道对 `path_cat` 是真双线性，无法直接做 ANOVA，因此用一个明确标注的代理：按每个类别在 512 分子中实际出现的 `path_end63` 经验分布做平均，得到 189 行的有效响应表 `J[c] = W_joint · joint_proj(u[c] ⊙ v̄_c)`（`W_joint = lins[0].weight[:, 384:416]`）。

| 诊断（512 训练分子，best 检查点） | REPLAY | HIS | 变化 |
|---|---:|---:|---:|
| 联合通道 `‖J₃‖/‖J‖` | 0.6382 | 0.6521 | ≈ 不变 |
| 联合通道 `‖J‖_F` | 65.49 | 78.25 | +19% |
| `path_u → ≤2 投影` 的 `mean\|Δpred\|` | 0.1045 | **0.1447** | +39% |
| `path_u → 行均值`（全类别变异） | 0.1644 | **0.2971** | +81% |
| `path_u → 0`（整条联合通道移除） | 0.1533 | **0.2836** | +85% |
| `path_emb → 行均值` | 0.1753 | 0.0421 | −76% |
| `path_gate → 均值` | 0.00765 | 0.00815 | ≈ 不变 |
| 三者同时消融（全部类别依赖） | 0.5466 | 0.3668 | **−33%** |
| `path_emb` 三阶份额 / 全部类别依赖 | 0.150 | 7.2e-5 | — |

读法：HIS **部分**把类别特异性载荷搬到了联合通道（该通道自身的“三阶占比”仍有 0.65，且被用得更重），但**总类别依赖下降 33%**，且性能全面变差。所以惩罚没有被“无损绕过”，而是被**部分补偿**了；`path_u/path_v` 是本次约束方式的结构性漏洞，但在 10k 标签、600 epoch 下它补不回被压掉的容量。

## 5. 与历史执行漂移的对比

同一份配置、同一 seed 0、同一数据顺序，历史上跑过三次：

| 运行 | full valid | minus row172 |
|---|---:|---:|
| 历史 LCRC A_s0（10-28） | 0.076582 | 0.070076 |
| CJP A-REPLAY s0（10-29） | 0.076116 | 0.070165 |
| **本轮 REPLAY_s0（10-30）** | **0.074222** | **0.069527** |
| 极差（执行漂移） | **0.002360** | **0.000638** |

本轮 REPLAY 比历史 A_s0 好 0.00236，其中 (6.575−4.765)/1000 ≈ 0.0018 来自 row172——与 CJP 轮“漂移几乎全由 row172 承担”的结论一致（本轮 row172 AE：REPLAY 4.7647，历史 A_s0 6.575）。

## 6. 七个必答问题

**Q1. HIS 是否约束到了一个“原本活跃”的第三阶响应？**
是，而且是决定性的是。冻结 LCRC-A 上 `‖H₃‖/‖H‖ = 0.655`，投影干预平均改变预测 0.0877，且 96.7%（best 检查点上 93.6%）的分子位移超过 0.010。训练中无约束模型的 H₃ 幅度被**放大 16 倍**（penalty 0.0089 → 0.1441），比率恒为 0.653。HIS 把它压到 0.0010（best）/0.00015（final），同一投影干预的效果从 0.0819 降到 2.6e-5。机制侧没有任何疑问：这是一个**活跃的、被模型主动使用的**三阶通道。

**Q2. 普通分子 / radius-2-unseen 环境上是否出现泛化改善？**
没有。ordinary **+0.003096**（CI 跨 0），r2-unseen ordinary **+0.006829**（CI 跨 0），seen ordinary **+0.001914**；r2-unseen 全部 **+0.012294**，ring-rich **+0.010907**。没有任何切片方向为负（除了噪声级别的个别行）。需要注意的是 r2-unseen 的“未见过”是**精确联合排布未见**，成分（code 与 `(code,end)` 上下文）248/251 都见过——在这个定义下，抑制三阶交互同样没有帮助。

**Q3. 这个变化超出历史执行漂移了吗？**
远超。full Δ 是漂移极差的 3.1 倍，minus-row172 Δ 是其 7.9 倍。同 commit 并行两臂，共享 initial state / SSL / 缓存 / 行序 / LR / 更新数（11 条门禁全过）。

**Q4. 变化来自更好的样本外预测，还是仅仅改变了训练拟合？**
都不是“变好”。HIS 的 train MAE（eval mode）在 best 点是 0.008671 vs REPLAY 0.003320（2.6 倍），valid 同时变差 0.0074。也就是说 HIS 既没有更好地拟合训练集，也没有更好地泛化——它是**容量被直接削掉**。作为对比，REPLAY 的 train MAE 到 600 epoch 降到 0.001295，HIS 也降到 0.001377（末端差距收敛），但 valid 差距始终保持在 +0.0078，说明差距不是“收敛速度”问题。

**Q5. 单 seed 的这个观察值得再买 seed 2 吗？**
**不值得。** 判定是 RED，且 Q2/Q3 表明这不是“接近门限”的结果：要翻成 GREEN 需要 Δ ≤ −0.005，而当前是 **+0.0074**（差 0.0124，约 5 倍历史漂移极差、8 倍于最小可检测改善）。机制也给出了物理解释（H₃ 被主动放大并承载真实信号）。加 seed 只会把 `[+0.0012, +0.0151]` 收紧到 0 的右侧，不改变方向。按协议，本轮不追加 seed、不做 λ 扫描、不加新通道。

**Q6. 这个正则是否被未约束的 `path_u/path_v` 通道绕过了？**
**部分绕过，但不是无损绕过。** best 检查点上：联合通道自身的 `‖J₃‖/‖J‖` 仍是 0.638→0.652，`‖J‖_F` 增 19%，`path_u` 全消融的预测敏感度从 0.164 涨到 0.297（+81%），`path_emb` 全消融从 0.175 掉到 0.042（−76%）。即优化器把相当一部分类别特异性（包括三阶）载荷搬到了联合乘积通道。但**总类别依赖 0.547 → 0.367（−33%）**，说明补偿不完全，代价体现在 MAE 上。这也意味着：**“消除三阶结构”这个操作在架构层面不可能靠单一 `path_emb` 惩罚实现**，任何后续同类实验都必须同时处理 `path_u·path_v` 与 `path_gate`（且不能事后扩大约束对象——本轮明确没有加）。

**Q7. 哪些结论不能从本轮得出？**
- 不能得出“三阶交互在 ZINC 上普遍无用/有害”：本实验只检验了 **LCRC-A 架构 × 10k 子集 × raw-y L1 × 单一 λ（梯度范数匹配 0.10）× seed 0** 这一种设置。
- 不能得出“λ 太强了所以失败、小 λ 会好”：本轮协议禁止 λ 扫描，我们没有数据；只能说**在“惩罚梯度 = 10% 的 L1 梯度”这个强度下**，把 H₃ 压到 0 是净损失。
- 不能得出“该通道只在拟合训练集”：恰恰相反，投影干预在训练集上把 MAE 从 0.0030 抬到 0.0809，而 HIS 在 valid 上也更差，说明这部分信号对样本外同样有效。
- 不能得出关于 official test 的任何结论（全程未构造/未读取）。
- 不能把 +0.0074 的 full-MAE 差额当作“典型分子退化 0.0074”：逐分子中位数是 +0.0016，净差额的 94% 由 10 个分子贡献（其中 row172 单个就 +2.32）。真正的稳健陈述是“minus-row172 仍 +0.0051，CI 排除 0”。
- r2-unseen 的“未见”在本轮定义为精确 `(path_cat, path_end63)` 联合排布未见，**不是**“成分未见”；因此不能推断模型对全新局部成分的泛化。

## 7. 失败模式分析：假设为什么错了

原假设把“显式 2-hop 路径表的三阶分量”当作**欠约束的自由度**（189 类只有 33 类出现，直觉上应被收缩）。实测给出相反图景：

1. 三阶分量**不稀疏**：33 个出现过的 code 里，第三阶交互占其响应的绝大部分（比率 0.655），而且这些 code 的 DF 中位数是 441（不低）。
2. 模型在训练中**主动放大**该通道（H 的 RMS 0.128 → 0.581，penalty ×16），说明梯度持续把它当作有用特征，而不是记忆噪声。
3. 因此“把 H₃ 压到 0”等于删掉一个被使用的特征子空间，代价是 MAE。
4. 部分载荷可以挪到 `path_u·path_v`，但那条通道的表达方式是“类别 × 端点类型”的乘积，不能等价替代 `path_emb` 上纯粹的 (α,β,γ) 三向结构，所以补偿不完全。

**这意味着“低阶优先正则”的方向本身没有错，错的是对象层级**：在 LCRC-A 里，真正“支持度不足”的是 **156 个完全未出现的 code**（82.5%）和 **11,907 个联合上下文里只用了 159 个**——这些应当用**支持度条件收缩**（见 SCSB 轮）或**结构等价类共享**处理，而不是对已出现类别的三阶分量做无差别惩罚。
