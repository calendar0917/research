# HIS-v0 设计 — 显式结构统计的层次交互约束（Hierarchical Interaction Shrinkage）

**Round:** `zinc-his-v0`
**Track:** `tracks/structural-sufficiency/zinc_his_v0/`
**性质:** seed-0 exploratory screen。不是 benchmark、不是超参搜索、不是最终 test 实验。
**official test:** 全程不构造、不加载、不评分。

---

## 1. 假设

**H:** 显式二跳结构的**纯高阶交互响应**，在 10k 分子级标签条件下受到有限监督约束；对该响应施加**低阶优先**的统计正则化，可能改善未见局部结构组合的泛化。

这不是"再增加统计信息"的假设，而是"**如何利用已有统计信息**"的假设。LCRC-A 已经拥有 `path_cat`（189 类）这条显式二跳路径通道；本轮**不新增任何输入、模块或参数**，只改变这条通道被拟合的方式。

## 2. 被约束的对象

`LocalContent` 的 S2 路径通道是一个 `nn.Embedding(189, 32)`，索引为

```
path_cat = 9 * type(middle_atom) + 3 * (bond1_type - 1) + (bond2_type - 1)
```

即一个 `(21, 3, 3)` 的类别表。把每一格对第一层 LocalContent MLP 的**有效线性响应**记为

```
H[a, b, c, :] = path_emb.weight[a, b, c, :] @ W_path.T          ∈ R^192
W_path = local.mlp.lins[0].weight[:, s : s + 32]
```

`W_path` 的列切片由 `LocalContent.forward` 的拼接顺序决定：

```
[a_v 96 | Σ_e b_e 96 | mean_e b_e 96 | nbr 32 | path_emb 32 | end_emb 32 |
 path_joint 32 | closure 8 | content_agg 96 | scalars 9] = 529
```

因此 `s = 3*96 + 32 = 320`，路径块是输入列 `[320, 352)`。这个切片**不是硬编码猜测**：`his_cpu_checks.G2` 在真实前向上做扰动实验——随机扰动 `path_emb` 只改变输入列 320..351，且第一层输出的改变量**恰好等于** `Δx[:, 320:352] @ W[:, 320:352].T`（相对误差 1.3e-6），而其它候选列块无法复现（相对误差 1.0）。`path_cat` 的轴约定由 `G10` 用手工搭建的三原子链证明。

## 3. 约束项

对 `H` 在三个类别轴上做平衡 ANOVA 分解：

```
H_le2 = AB + AC + BC - (A + B + C) + mu          （≤2 阶可加部分，最小二乘最优）
H_3   = H - H_le2                                 （纯三阶交互残差）
loss  = L1(pred, y) + lambda * mean(H_3 ** 2)
```

其中 `A = mean_{b,c}H`、`AB = mean_c H`、`mu` 为全均值。`H_3` 满足四条判据（`tests/test_his_v0.py` 21 项断言 + `his_cpu_checks.G3`）：

1. `H_3 + H_le2 = H` 精确重构；
2. `H_3` 沿三个类别轴的**边际均值恒为 0**（实测 1e-6 量级，float32 噪声）；
3. 只含常数/一阶/二阶项的合成张量 `H_3 ≈ 0`（实测 ≤2e-6，纯双精度下 <1e-11）；
4. 合成纯三阶张量 `H_3 ≠ 0`（rank-1 纯三阶项被逐元素保留）。

### 3.1 任务书公式的符号问题（重要，已在代码中修正）

任务书里印出的公式是

```
H_3 = H - mean_a(H) - mean_b(H) - mean_c(H) + mean_ab(H) + mean_ac(H) + mean_bc(H) - grand_mean(H)
```

这个式子**不是**残差：主干项符号反了。把它作用在纯二阶张量上得到的是非零（实测 max|·| ≈ 14.7），并且它的边际均值也不为零，恰好违反任务书同一节要求的第 2、3 条判据。正确的残差（上面实现的形式）来自同一节第 1、3 条判据的唯一解。

> 处理原则：**判据优先于印错的公式**。任务书明确要求"mean 的广播方向与轴定义必须经单元测试验证"，因此以四条可验证性质为准，并在
> `tests/test_his_v0.py::test_literal_brief_formula_is_not_the_residual` 中把两者都跑一遍、把差异固定下来，避免事后争议。这是本轮唯一一处偏离字面任务书的地方，且在**任何 GPU 结果之前**完成并记录。

### 3.2 为什么惩罚 H 而不是惩罚 E

`H = E @ W_path.T`。若直接惩罚 `E`，网络可以用 `E → cE, W_path → W_path/c` 这种**尺度重参数化**在不改变任何前向输出的情况下把惩罚压到任意小。惩罚 `H_3` 对 `c>0` 完全不变（`his_cpu_checks.G4`：`c ∈ {0.05, 3}` 下 penalty 变化 ≤1e-4 相对），所以无法被绕过。

另有一个有用事实：ANOVA 投影只作用在三个类别轴上，而 `W_path` 是对每个格右乘同一个矩阵，因此

```
project(E) @ W_path.T  ==  project(E @ W_path.T)      （G3 实测 7e-7）
```

即"对 embedding 表做二阶投影"与"对有效响应做二阶投影"**完全等价**。A2 的干预（替换 `path_emb` 为二阶 ANOVA 投影）因此只衡量三阶分量本身。

## 4. 正则强度（唯一一次事前校准）

```
lambda = 0.10 * ||g_L1|| / ||g_reg||
```

在**同一个冻结的首个 train batch**（`randperm(10000, Generator(101))[:128]`）、**同一个冻结初始状态**（`11c698ae…`）上，对**受影响参数**（`path_emb.weight` + `W_path` 这 32 列，共 12,192 个元素）取联合范数。校准不读取 valid/test、不引入额外优化步、RNG 隔离。得到后冻结整个训练过程，**不允许用 valid 成绩重选**。

- CPU 预览（初始模型、真实首 batch、真实标签）：`||g_L1|| = 24.73`，`||g_reg|| = 1.08e-2`，`lambda ≈ 228.7`。
- 正式校准在训练 GPU 上重算（同设备同 regime），冻结写入 `configs/his_v0.json`；训练进程启动时**再重算一次并断言相对差 ≤1e-6**，不一致直接报错退出。
- 预注册护栏：`lambda` 必须有限且落在 `[1e-4, 1e4]`，否则停止报告，不换校准方法。

## 5. 为什么这可能是有效的（机制假设）

Phase A 在冻结的 LCRC-A seed-0 checkpoint 上量到（`analysis/phase_a.json`）：

| 量 | 值 |
|---|---:|
| `‖H_3‖ / ‖H‖` | **0.655** |
| `H_3` RMS | 0.384（`H` RMS 0.586） |
| train 中真正被用到的 path code | **33 / 189**（156 类从未出现；DF 中位数 441，最小 1） |
| top-10 类别占全部 token 比例 | 0.974 |
| 把 `path_emb` 换成二阶投影后，512 个固定 train 分子上的 `mean|Δpred|` | **0.0877** |
| 同一干预下 train-512 MAE | 0.0050 → 0.0874 |
| 参照：把 `path_emb` 全部换成全局均值行（彻底消融）的 `mean|Δpred|` | 0.2040 |

也就是说：**三阶响应在训练好的模型里是真实且大幅活跃的**（≈ 彻底消融该通道效果的 43%），远不是数值噪声。而 path code 的"字母表"极度不均衡：33 个格子里，绝大部分出现次数集中在少数几类，156 个格子完全没有梯度。

在这张表上，三阶分量做两件事：

1. 在**被用到的 33 格**上给出任意形状的三阶交互，L1 可以自由使用它去拟合训练集（包括拟合噪声/偶然组合）；
2. 在**从未出现的 156 格**上，`H_3` 完全由 ANOVA 投影的耦合决定，没有数据约束——一个从未在 train 出现的 `(middle, bond1, bond2)` 组合会得到什么读出，取决于这些空闲行的优化轨迹（它们在 L1 里没有梯度，但在任何含三阶耦合的正则下会被拉动）。

`mean(H_3^2)` 对这两件事同时施压：它把"三阶特异响应"往"可加响应"收缩，等价于强制模型**只用低阶结构**解释二跳路径通道，把高阶特异性让给别的通道（或干脆放弃）。如果 H 成立，这会把在 33 格上过拟合的组合特异性压下去，从而改善对**组合新颖性**的泛化。

## 6. 数据侧的准确陈述（不要夸大）

reuse `zinc_dccl_bottleneck_v1` 的 radius-2 支撑口径（`analysis/phase_a.json → coverage_relation`）：

| 量 | 值 |
|---|---:|
| valid 中所有 path code 都在 train 出现过的分子 | **1000 / 1000** |
| valid 中所有 `(path code, end type, bond2)` 联合上下文都在 train 出现过的分子 | **997 / 1000** |
| 冻结 r2-unseen 分子数（含 ≥1 个 train 从未出现的 radius-2 签名） | 251（ordinary 225） |
| 其中"所有 path code 已见" | 251 / 251 |
| 其中"所有联合上下文已见" | 248 / 251 |
| 每分子最小 code-DF 的中位数（unseen vs seen 组） | 3362 vs 3362 |
| train 中真正出现的联合上下文数 / 总空间 | 159 / 11907 |

**结论性表述（必须按这个口径写）：** r2-unseen 分子**不是**由未见构件组成的；它们由**完全已见的构件**组成，其"未见"性在于**原子邻域内构件的精确联合排列**（完整的 typed radius-2 rooted signature）。因此本题研究的是**组合泛化**，不是"新词表外推"。而"组成构件已见"**不等于**"标签规律可学习"：本次实验只能检验"用低阶结构替代三阶特异响应"这一个具体做法，不能证明这些未见环境可学。

## 7. 明确不约束什么（本轮的核心局限）

- **`path_u`/`path_v` 低秩乘法联合通道不约束。** 它同样读 `path_cat`，同样可以表达任意三阶结构（`joint_proj(u_a * v_end)`）。若 HIS 无效，可能原因是三阶信息从这里绕过；若 HIS 有效，也不能宣称"消除三阶交互"，只能宣称"约束了这一个读出通道"。**不得事后扩大约束对象**。
- `end_emb`、`close_emb`、`path_gate`、S1 `nbr_emb`、bond/atom encoder、`f`、`rho` 均不约束。
- 不引入 junction token、不做消息传递、不改宽度、不改 LR、不加 EMA/soup/ensemble/distill/额外 SSL。
- 单 seed（0）只用于发现候选，不能宣称可重复性；分子 bootstrap 区间**不代表**跨训练 seed 的不确定性。

## 8. 可能的结果与解释（事前写好）

| 结果 | 解释 |
|---|---|
| HIS 明显更好（GREEN） | 低阶优先正则化在"用已见构件做新组合"上有效 → 值得买第二个 seed |
| 只有 r2-unseen/ordinary 局部更好（AMBER） | 方向对但幅度不足，或由极端行驱动 → 不晋级，记录为线索 |
| 无差异 | 三阶响应虽活跃但**对泛化无害**（可能是噪声拟合），或约束太弱（10% 梯度占比不足） |
| HIS 更差 | 三阶响应承载了真实的、可泛化的组合信息；把它压掉等于在 ordinary 上主动降容量 |
| penalty 训练中不下降 / H_3 ratio 不降 | 正则没有真正生效 → 无论指标如何都判 RED |
