## 0. 先回答三个问题

### 0.1 干预了哪个连通结构，LCRC 的预测怎样变化

干预对象是一个有明确化学意义的连通单元 `acylC–C(=O)–N`（酰基碳 · 羰基碳 · 酰胺氮）中的
**单键 `C(=O)–N`（视图 T）**，以及同一酰胺中心相邻的 **`C–C` 键（视图 K）**。每个视图只删除一条
物理键（同时删除 raw artifact 里的两条有向记录），原子类型/电荷/氢数/立体化学/其它所有键均保持，
再用**冻结的** `lipo_v1` 特征构造器重建输入，送进**冻结的** LCRC-C1 checkpoint（228,674 参数，
best epoch 244）。不重解析 SMILES、不加氢、不删原子、不封端。

冻结模型对这个遮挡的反应**强烈依赖 scope**（两种 scope 都在协议里事前固定，都报告）：

| scope | T 视图（切 `C(=O)–N`） | K 视图（切 `C–C`） | O（原分子） |
|---|---|---|---|
| FULL（全部输入重算，含 global42） | MAE 7.9485 / RMSE 8.1624，平均有符号位移 **−7.97** logD | MAE 7.4780 / RMSE 7.6764 | MAE 0.3841 / RMSE 0.5364 |
| G_FIXED（局部输入重算，global42 固定为原分子） | MAE 0.5828 / RMSE 0.7790，平均有符号位移 **−0.36** logD | MAE 0.4379 / RMSE 0.5676 | MAE 0.3841 / RMSE 0.5364 |

（MATCHED 人群 Test，n = 42 分子 / 43 实例 / 39 个 scaffold 簇。）

- 在 **FULL** 下，切掉几乎任何一条键都会把预测压进一个窄带：MATCHED Test 的 `f(O)` 均值 2.359，
  而 `f(T)` 均值 **−5.632**（sd 1.86，范围 −8.54…1.42）、`f(K)` 均值 −5.148；Test 里 **100%** 的分子
  `B_m > 0`，Valid 同样 100%。这不是"化学信息被删掉"的度量，而是**编码管线越界**的度量（见 §5：
  切断后 91.8% 的 Test 视图至少有一个 global 维落到 Train 分布之外，`frac_unreachable_pairs`
  平均偏离 **+224 个 Train 标准差**，`n_components` 偏离 +19.3）。
- 在 **G_FIXED** 下（只让局部输入反映断键），预测只是"变差一点"：切目标键比原分子多 0.199 logD
  误差，切匹配对照键多 0.053 logD。这两个数是**以原分子实验标签为参照的条件干预 MAE 增量**
  （"打断这条连接后，用原分子标签当参照，误差变大多少"），**不是**"这条连接的信息量"；
  固定 global42 的取值也不等于被干预视图与 Train 联合在分布内（见附录 A.2）。

### 0.2 目标连接是否比匹配切断"携带更多信息"？是否对 scope 和单分子敏感

**是（方向），但不稳健；而且高度依赖 scope 与个别分子。**

| 对比 | Valid | Test |
|---|---|---|
| `B = LT − L0`（切目标键 vs 原分子），FULL | 7.3545 [6.8255, 7.8513] | 7.5644 [6.9791, 8.1151] |
| `D = LT − LK`（目标切断 vs 匹配切断），FULL | 0.4192 [0.1917, 0.6276] | 0.4705 [0.0894, 0.8531] |
| `B`，G_FIXED | 0.2977 [0.1742, 0.4149] | 0.1988 [0.0678, 0.3300] |
| `D`，G_FIXED | **0.1542 [0.0167, 0.2759]** | **0.1449 [−0.0165, 0.3049]** |

（单位：原始 logD；区间为 scaffold 簇配对 bootstrap，1000 次，seed 20261114。）

- Test 的 `D` 区间**含 0**；Valid 的区间不含 0 但只有 52 分子 / 45 簇。
- 逐分子看（G_FIXED），Test 只有 **52%** 的分子 `D_m > 0`（Valid 63%）；`B_m > 0` 的比例是
  60% / 77%（FULL 下 `B_m > 0` 是 100%，但那正是 §5 的越界现象）。Test 的均值 0.145 对应中位数
  只有 0.039（FULL 的均值 0.470 对应中位数 0.554），说明 G_FIXED 下的均值由少数分子拉动。
- 固定影响检查（Test，G_FIXED）：去掉 `|D|` 最大的 1 个分子 → `D` = 0.116；去掉最大的 5%
  （3/42，行 494/694/3761）→ `D` = **0.061**，`B` = 0.128。也就是说，"目标连接比匹配控制更关键"
  这个量在去掉 3 个分子后掉到噪声量级。
- 反向的补充对照：远端同元素同键型 C–N 桥（R）**并不比目标键温和**——在 11 个同时有 R 候选的
  MATCHED Test 分子上 `D_R = LT − LR = −0.376 [−0.752, −0.125]`（切远端 C–N 反而更伤预测），
  而 53 个 Test R 候选中 27 个本身就是酰胺键。因此本协议**不能**支持"这一条特定连接独一无二"；
  能支持的只是"这类连接（酰胺/等价 C–N 桥）被打断时预测受的影响更大（以原标签为参照的误差增量）"
  ——注意这是**误差增量**，不是"信息量"（附录 A.2/A.4）。

**结论：`D > 0` 是一个方向一致（Valid/Test/FULL/G_FIXED 四个组合全为正）但幅度小、在 Test 上
区间含 0、且被个别分子明显放大的观察。** 我不把它写成"模型定位到了这条酰胺键"。
（事后澄清见附录 A.1：通过 §9 的事前四条件只说明"本协议下有方向性依赖"，不等于"对酰胺特异"；
可解释口径 G_FIXED 的 MATCHED Test `D` = 0.1449 [−0.0165, 0.3049] 仍然是**未定**。）

## 2. 目标结构与支持数（结构定义在预测之前冻结）

受限酰胺定义 `acylC–C(=O)–N`：`c` 为中性非芳香 C（class 2, charge 2, `atom_h=0`, degree 3）、
`o` 为 class 9 degree 1 双键 O、`n` 为中性非芳香 N（class 7，全部入射键为单键，`degree+H=3`）、
`acylC` 为 class 2/3，`c–n` 与 `c–acylC` 都是**桥**（Tarjan，4200/4200 分子与 `networkx.bridges`
交叉验证），且 `c` 的三个邻居恰为 `{o, n, acylC}`。N 允许本身位于别的环（但两条切键都不能是环键）。
这是"受限酰胺"，不是"所有酰胺"。

| population | Train（分子/实例） | Valid | Test |
|---|---|---|---|
| `ALL` | 1438 / 1657 | 194 / 234 | 185 / 208 |
| `MATCHED`（主分析） | 343 / 354 | 52 / 54 | **42 / 43** |
| `BALANCED`（`|n侧−酰基侧| ≤ 2`） | 172 / 172 | 28 / 28 | 23 / 23 |
| `R`（有远端候选） | 406 / 530 | 49 / 64 | 43 / 53 |

`MATCHED` 要求 `degree(n) = degree(acylC)` 且环原子标记相同；`MATCHED ∩ BALANCED` 只有
15（Valid）/ 7（Test）个实例，两个补充对照因此不能替代主分析。所有计数与协议预登记数值**完全一致**
（`analysis/prepare_checks.json::precounts_match_protocol = true`）。Test 主分析只有 42 个分子 / 39 个簇，
这是本报告最重要的支持度限制。

## 3. 视图构造与门禁

5155 个视图图（Train 3360 个 O；Valid 420 O + 504 切；Test 420 O + 451 切），6110 条带 scope 的
预测，10310 次 forward。切键操作只动一条物理键：`verify_cut` 证明被删有向记录恰好 2 条、无新增/改动
其它键、原子属性（`atom_class/atom_charge/atom_h`）逐字节不变、连通分量 +1，且 T 中 `o–c–n` 两键径
消失、K 中保留（`dist_c_n_after = 1`）。另有三条硬门禁：

1. **零切重编码恒等**：用新管线重编码未切断的分子，与冻结 cache 逐字节相同（Valid 420/420、
   Test 420/420，`n_mismatch = 0`）。
2. **原子重标号不变性**：3 个最小 MATCHED Test 分子做固定置换（seed 20261114），实例目录、
   预测与聚合量不变（最大预测差 1.43e−6）。
3. **O 视图 `G_FIXED ≡ FULL`（容差门禁）**：O 视图不含切键，两种 scope 在数学上必然相同；
   实测 A100 上 4200/4200 行的最大差为 Test 8.3e−7、Valid 7.2e−7、Train 9.5e−7，全部远低于 1e−5
   容差（差异来源是 CUDA 归约顺序，不是 scope 逻辑）。三个 split 的视图门禁
   （`bond_count_equal_O_minus_one`、结构失败列表、O 视图容差）现在都 AND 进顶层 `pass`。

## 5. 为什么 FULL 的巨大差异不能当作化学量（输入漂移诊断）

| 指标（Test） | O 视图 | 切视图 |
|---|---|---|
| global42 值落在 Train 全量 min/max 之外的比例 | 0.0000 | 0.0235 |
| 至少一个 global 维越界的视图比例 | 0.000 | **0.918**（Valid 0.954） |
| 越界幅度（Train SD 为单位）最大值 | 0.0 | **261.7** |
| `atom_scalar` 越界比例 | 0.00001 | 0.00008 |

切一条键后，平均改变最大的 global 维（Test，451 对 O/切配对）：

| 维 | 名称 | 平均 `|Δz|`（Train SD） | 平均 `Δz` |
|---|---|---|---|
| 10 | `frac_unreachable_pairs` | 223.5 | +223.5 |
| 4 | `n_components` | 19.3 | +19.3 |
| 11 | `frac_finite_pairs_ge3` | 3.8 | −3.8 |
| 23 | `bond_aromatic_fraction` | 1.6 | −1.6 |

冻结归一化只在**连通**的 Train 分子上拟合，`frac_unreachable_pairs` 在 Train 中近乎恒为 0、尺度极小，
所以任何切断值都直接飞出分布几个数量级，global 分支随后把预测压成常数。（精确说法见附录 A.3：
Train 是 3359 个单组件分子 + 1 个四组件分子（行 1646），所以 `n_components` / `frac_unreachable_pairs`
是**近常数**而非恒等常数；已存的归一化统计量、预测与漂移数值一律不改。）这解释了为什么 FULL 的
`B` ≈ 7.5 logD、`D` ≈ 0.47 logD，也解释了为什么"100% 的分子 `B_m > 0`"这种一致性不能当成化学证据。
**因此：可解释的局部量是 G_FIXED 的 `B` ≈ 0.20–0.30、`D` ≈ 0.14–0.15；FULL 的数字只应作为
"整条编码管线对该遮挡的敏感度"报告。**

## 9. 决策规则的应用

协议 §10 的四条件（在主分析 MATCHED Test、主 scope FULL 上判定）：

1. 主 `B`、`D` 的 95% CI 下界 > 0 → **满足**（7.5644 [6.9791, …], 0.4705 [0.0894, …]）；
2. Valid 点估计同向为正 → **满足**（7.3545 / 0.4192）；
3. G_FIXED 点估计同向为正 → **满足**（0.1988 / 0.1449）；Test 的 `D` 区间 [−0.0165, 0.3049] 仍含 0，
   所以"方向一致"不等于"已定"；
4. 两个固定影响检查下 `D` 仍为正 → **满足**（0.396 / 0.403）。

按事前规则，标签是 **"consistent amide-link prediction dependence under this masking
protocol"**，但必须与下列限定同时报告，**不得**升级：

- 这个标签的强度几乎全部来自 FULL（`B` ≈ 7.5 logD），而 FULL 的可解释性被 §5 的越界诊断否定；
- 换成可解释的 G_FIXED，Test 的 `D` 区间含 0（"方向性观察，证据未定"），Valid 才显著；
- 去掉 Test 42 个分子中 `|D|` 最大的 3 个后 `D` 从 0.145 掉到 0.061；
- 远端同类型 C–N 对照的损害不亚于目标键（`D_R < 0`，MATCHED Test 显著），⇒ **不支持唯一连接归因**；
- 单一 checkpoint、单一 seed、42 个 Test 分子 ⇒ 不能谈种子稳定性或跨任务普适性；
- 通过上面 4 条**只说明"在本遮挡协议下有方向性依赖"，不构成"对酰胺连接特异"的解释**；
  `B`/`D` 是条件干预的 MAE 增量而非信息量，`G_FIXED` 也不是联合在分布内的构造（附录 A.1/A.2）。

**我明确不主张**：模型"化学上理解了酰胺"；某个原子对预测的独占贡献；这是因果效应；这些遮挡图是
新化合物或新实验标签；`FULL` 的 7.5 logD 是"酰胺的信息量"。

## 12. 剩余不确定性

## 附录 A — 事后澄清与修正记录（随后一轮追加；只改表述，不改历史协议与数字）

### A.1 通过事前规则 ≠ "对酰胺特异的解释"

`§9` 的四条件在本协议下确实全部通过，但四条件判定的是"**在这个删边（masking）构造下，目标连接
的切断比匹配控制切断更伤预测**"，它同时还要满足：

- `B` 的强度几乎全部来自 `FULL`（≈7.56 logD），而 `FULL` 的响应已被 `§5` 判定为编码管线越界：
  切一条键后 91.8% 的 Test 视图至少一维落到 Train 全量范围外，`frac_unreachable_pairs` 平均偏离
  +224 个 Train SD。**越界响应不能用来支撑任何化学强度**（正比于"管道多脆"，不随干预的化学含义走）。
- 唯一可解释的口径 `G_FIXED` 下，MATCHED Test 的 `D` = **0.1449，95% CI [−0.0165, 0.3049]**
  ——区间含 0，仍是**未定**（Valid 0.1542 [0.0167, 0.2759] 只是 52 分子 / 45 簇的单点观察）。
  去掉 `|D|` 最大的 3 个 Test 分子后 `D` 掉到 0.061（正文 §9）。
- 因此正确的说法是：**"在保持其余设置的前提下删掉这条连接，平均而言比删掉匹配控制键更降低
  对原分子标签的拟合"——一个方向性、幅度小、可由少数分子放大的观察**；不是"模型识别出了酰胺
  官能团"，也不是"酰胺连接承载的信息量更大"。本协议不能把"通用 C–N / 羰基邻域敏感性"与
  "酰胺特异性"分开，因为从未构造过化学上匹配的非酰胺对照（见 A.4）。

### A.2 `G_FIXED` 的 `B` 是条件干预的 MAE 增量，不是"信息内容"；固定 global ≠ 联合在分布内

- `B = L_T − L_0`、`D = L_T − L_K` 都是**以原分子实验标签 `y` 为参照的误差差**。`y` 属于原分子，
  不属被干预的图；`B` 只回答"打断这条连接后，用原标签当尺子，误差变大多少"。
  它不是互信息、不是"这条边携带的比特数"，也不可跨分子/跨任务求和成"信息量"。
  `G_FIXED` 的 MATCHED Test `B` = **0.1988 [0.0678, 0.3300]** 应读作"**条件干预的 MAE 增量约
  0.20 logD（Test，以原标签为参照）**"。
- `G_FIXED` 只把 global42 **固定为原分子的取值**，被干预视图本身仍可能落在 Train 的联合分布之外
  （逐维在范围内 ≠ 联合在范围内；连通性/环/距离结构都变了）。所以 `G_FIXED` 的结果是
  "**给定原分子的全局摘要**时局部输入变化的效应"，不能升级为"联合在分布内的因果效应"。

### A.3 raw-graph 连通分量普查的精确说法（不改任何已存统计量）

正文 `§5` 曾说 `frac_unreachable_pairs` "在 Train 中恒为 0"。精确事实（本轮独立重算）：

| 项 | Train（3360 行） | Valid / Test |
|---|---|---|
| `n_components` 分布 | 1 组件 **3359** 行；4 组件 **1** 行（行 1646） | 全部 1 组件 |
| `n_components` 均值 / sd / max | 1.0009 / **0.0517** / 4 | 1 / 0 / 1 |
| `frac_unreachable_pairs` 非零行数 / max | **1** 行 / **0.0967** | 0 / 0 |

也就是说这两个维在 Train 上是**近常数（准退化）**而不是恒等常数：冻结归一化的尺度因此极小，
任何断键值都会飞出几个数量级——`§5` 的机制结论不变，只是"恒为 0"应改为"近乎恒为 0（唯一例外是
行 1646 这个四组件分子）"。**已存的归一化统计量、`per_view_predictions.csv`、漂移表与所有 `D`/`B`
数值一律不改**（它们正是用这套近退化尺度算出来的，结论方向不受影响）。

### A.4 远端 `R` 对照约一半本身就是酰胺 ⇒ 它不是"非酰胺阴性对照"

`R` 候选的构成：Test 27/53、Valid 34/64、Train 296/533 本身就是酰胺键。因此：

- `D_R < 0`（MATCHED Test −0.3759 [−0.7524, −0.1253]）只能限制"**位置特异性**"——断言"必须是
  这一条特定连接"是不成立的；
- 它**不能**否定"整类酰胺连接更重要"：一半的 `R` 也是酰胺，切断它们当然也会伤预测。把 `R` 当成
  "非酰胺阴性对照"并据此说"酰胺类的说法被推翻"是错的读法；
- 真正缺的对照（化学匹配但明确非酰胺、且构象/距离可比）本协议没有构造，这是本轮遗留缺口。

### A.5 `E_T` / `E_HH` 只能写"在本样本内误差更低"

`E_T` 只有 **21 对 / 8 个组件**，`E_HH` 只有 3 对（3 组件）。正文说 `E_T`"显著优于预测零变化"，
