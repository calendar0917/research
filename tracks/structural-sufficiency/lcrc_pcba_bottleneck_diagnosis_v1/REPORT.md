# LCRC MolPCBA 性能瓶颈诊断 v1 · REPORT

> **标签：`POST_HOC_EXPOSED_TEST_DIAGNOSIS`**
> 范围：只读、离线、CPU；训练步 0、GPU 0 h、无超参搜索、无 checkpoint 选择、无模型修改。
> 本文所有 Test 数字都是**已暴露 Test 上的事后工程分析**，不是独立确认集。
> 分析定义见 `PROTOCOL.md`（含 §12 事后修订声明）；完整数字见
> `analysis/report_tables.md` 与各 JSON/CSV。

本轮把 5 个冻结的 best-Validation 模型（W2 e24 / S3 e29 / RC-REAL e33 / BOC-FULL e29 /
BOC-BOND e30）放在同一份官方 scaffold split 上，先重放 AP 门禁（聚合 |Δ| ≤ 5.8e-6），
再回答四个问题：预测是否趋同（H1）、结构支持度能否解释收益（H2）、任务支持度是否
放大抵消（H3），以及这些证据够不够支持下一笔 GPU 架构实验。

## 第一部分：三个竞争解释的直接回答

| 问题 | 主要发现 | 可靠性 | 下一步意义 |
|---|---|---|---|
| **H1：预测函数是否明显趋同？** | **不趋同。** 106 个高支持任务上，S3 / RC-REAL / BOC-FULL 对 W2 的逐任务 Spearman 中位数只有 **0.74 / 0.66 / 0.66**；Top-1% 候选 Jaccard 中位数 **0.39 / 0.33 / 0.33**；高分正例中"只有新模型找到"与"只有 W2 找到"几乎对称（K1：2.3k–2.9k vs 2.3k–2.7k，共享 6.5k–7.3k）；正例排名百分位变化（按新颖性组汇总）中位数 \|Δ\| ≤ 0.0034。宏观 AP 相近**不是因为预测相同**，而是任务级差异互相抵消。 | **高**（对测得的排序相似度；只用冻结 logits，行对齐、官方/sklearn AP 一致、历史 AP 重放均已审计；判读依赖预注册的 0.80 阈值）。局限：rho 由大量负例主导，不能推断内部表示；这只是"排序行为"层面的结论。 | 排除"预测趋同"作为停滞原因；也说明后续任何比较都必须在任务级做，宏 AP 单值不足以代表模型行为。 |
| **H2：结构迁移是否失效？** | **`UNRESOLVED`（不支持也不排除）。** Train-only radius-2 WL2 分组有效（SEEN / PARTIAL / HIGH 的 `fraction_rare` 中位数为 0 / 0.13 / 0.41，Train 支持中位数 2248 / 875 / 30–36），但收益趋势在两个 split 上方向冲突：BOC-FULL 在 Validation 上 HIGH_NOVEL 增益更大（+0.0131 vs SEEN +0.0053），在 Test 上反号（−0.0133 vs +0.0098）；RC-REAL 的 HIGH_NOVEL 两组都为正（+0.0042 / +0.0046）；S3 两组都不单调。预注册判据无一满足，正例排名变化几乎为零。 | **低–中**：HIGH_NOVEL 只有 1.9k / 2.6k 个分子、37 个两 split 共有的可诊断任务；Valid 与 Test 的组均值方向相反。这是证据不足，不是"已证伪"。 | 不能写"结构迁移失败已证实"，也不应据此改架构；若研究者要这个结论，必须先把该分组测到有统计支持（更多 seed / 更大的新颖组），本轮不买。 |
| **H3：是否被任务支持度限制？** | **测量分辨率确实被低支持任务主导。** 19 个低支持任务（Test 正例 ≤19，占 15% 任务）贡献了逐任务绝对变动的 **38.5%–41.3%**；单个 6 正例任务即可把宏 AP 移动 **−0.0026**（S3 的 t31），与三个架构相对 W2 的全部差异（−0.0030 … +0.0023）同量级；Valid→Test 有 **21–33/127** 个任务符号翻转；高支持任务上均值差只有 −0.0009 … +0.0032（改善 60–65/108），而 Test 逐任务 ΔAP 的**中位数**为 +0.0010 … +0.0032（正）——均值被少数负尾拉平。 | **中–高**（纯算术分解，可复核）；但"任务稀疏是唯一瓶颈"**未**被证明。 | ±0.003 量级的宏 AP 差异在本轮测量下无法与任务级噪声分开；任何后续架构结论必须以支持度分层 + 多 seed 为前提。 |

三项可以同时部分成立；本轮明确结论是：**H1 不成立，H2 UNRESOLVED，H3 的"评价放大抵消"
部分成立但不足以单独解释停滞。**

  ——这是本任务的浮点噪声基线，也说明"AP 差 < 1e-3"本身不携带模型信息。

### 2.2 H1：宏观相似 ≠ 排序相似

高支持任务（106 个）上：

| 对比 | split | rho 中位数 [q1,q3] | Jaccard K1 | Jaccard K5 | K1 正例（both / only new / only ref） |
|---|---|---|---|---|---|
| S3 − W2 | Valid | 0.739 [0.693, 0.797] | 0.392 | 0.410 | 7274 / 2345 / 2299 |
| S3 − W2 | Test | 0.740 [0.690, 0.799] | 0.390 | 0.401 | 6943 / 2328 / 2300 |
| RC-REAL − W2 | Valid | 0.659 [0.600, 0.728] | 0.328 | 0.355 | 6819 / 2787 / 2754 |
| RC-REAL − W2 | Test | 0.660 [0.599, 0.730] | 0.330 | 0.347 | 6547 / 2754 / 2696 |
| BOC-FULL − W2 | Valid | 0.656 [0.579, 0.733] | 0.333 | 0.351 | 6904 / 2746 / 2669 |
| BOC-FULL − W2 | Test | 0.659 [0.579, 0.734] | 0.330 | 0.338 | 6512 / 2860 / 2731 |

- 全部高支持 cell 里只有 **0.7%** 的 rho ≥ 0.9，5.5% 的 rho < 0.5；分布很宽（q05 = 0.50，q95 = 0.86）。
- 代表性极值（按预注册规则取极值，不是挑选）：task 93（6554 个 Test 正例）rho ≈ 0.88–0.92；
  task 10（48 个 Test 正例）rho ≈ 0.37–0.48；task 107 的 Top-1% Jaccard 只有 0.04–0.07。
- **反例/边界**：互斥正例是对称的——新模型多找到的与丢掉的数量几乎一样，说明这是高分区"洗牌"
  而不是"改进"；正例百分位变化的逐任务中位数分布在 −0.0020 … +0.0035（5%–95% 分位），正例整体没有被系统性地重新排序。
  低支持任务的 rho 更低（0.48–0.63），按协议不进入 H1 结论。
- 预注册判读：`H1_NOT_SUPPORTED`（阈值 0.80）。因为全局 rho 中位数也低于 0.80，本轮没有触发
  `GLOBAL_RANKING_SIMILAR_BUT_DECISION_REGION_DIFFERS` 这个备选标签。**注意**：如果只把"趋同"
  定义为"宏 AP 标量接近"，那是同义反复，不能当作机制证据。
- **集合口径**：P1 的 `HIGH_SUPPORT` 是"Valid 与 Test 都 ≥20 正例"的 106 个任务；`LOW_SUPPORT`
  是 Test 正例 <20 的 19 个任务（只描述）；另有 2 个 Test 高/Valid 低支持任务不进入任何冻结集合
  （只在 CSV 中标记）。P4 的 `ge20` 是按各 split 自身的正例数分层（Valid 107 / Test 108），
  所以 P4 的分母比 P1 多 1–2 个任务。

Train-only WL2 支持度（350,343 个 Train 分子、9.0M 原子、112,623 个 WL2 颜色；
其中 31,154 个只出现在 1 个 Train 分子、62,463 个出现在 ≤4 个）：

| split | 组 | 分子数 | 正例数 | 重原子中位数 | `fraction_rare` 中位数 | 组内正例 ≥20 的任务数 |
|---|---|---|---|---|---|---|
| Valid | SEEN | 32,656 | 39,304 | 27 | 0.00 | 102 |
| Valid | PARTIAL_NOVEL | 9,262 | 13,765 | 25 | 0.13 | 86 |
| Valid | HIGH_NOVEL | 1,875 | 2,895 | 21 | 0.41 | 37 |
| Test | SEEN | 30,728 | 37,711 | 27 | 0.00 | 101 |
| Test | PARTIAL_NOVEL | 10,453 | 15,245 | 25 | 0.13 | 87 |
| Test | HIGH_NOVEL | 2,612 | 3,742 | 21 | 0.41 | 50 |

任务匹配（两个 split 都 ≥20 正例的同一批任务）上的组内 ΔAP：

| 对比 | 组 | 共享任务 | ΔAP Valid | ΔAP Test | Test−Valid | 改善任务 Valid→Test |
|---|---|---|---|---|---|---|
| BOC-FULL − W2 | SEEN | 99 | +0.0053 | +0.0098 | +0.0045 | 57→66 /99 |
| BOC-FULL − W2 | PARTIAL | 84 | +0.0063 | −0.0055 | −0.0118 | 47→44 /84 |
| BOC-FULL − W2 | HIGH | 37 | **+0.0131** | **−0.0133** | **−0.0264** | 26→15 /37 |
| RC-REAL − W2 | SEEN | 99 | +0.0039 | +0.0089 | +0.0050 | 59→72 /99 |
| RC-REAL − W2 | PARTIAL | 84 | +0.0011 | −0.0121 | −0.0132 | 42→35 /84 |
| RC-REAL − W2 | HIGH | 37 | +0.0042 | +0.0046 | +0.0003 | 20→21 /37 |
| S3 − W2 | SEEN | 99 | +0.0075 | +0.0012 | −0.0063 | 69→54 /99 |
| S3 − W2 | PARTIAL | 84 | +0.0014 | −0.0104 | −0.0119 | 47→33 /84 |
| S3 − W2 | HIGH | 37 | +0.0116 | +0.0016 | −0.0100 | 20→17 /37 |

- 预注册判读：`BOC-FULL` / `RC-REAL` → `NOVELTY_EFFECT_UNRESOLVED`；`S3` → `NO_CLEAR_NOVELTY_TREND`。
  没有任何 pair 达到 `GAIN_CONCENTRATED_ON_SEEN` 或 `GAIN_REVERSED_ON_NOVEL` 的 supported 标准。
- **反例**：RC-REAL 的 HIGH_NOVEL 在两个 split 上都是正增益；S3 的 SEEN 在 Test 上只有 +0.0012，
  与 HIGH 的 +0.0016 一样接近零（而 PARTIAL 为 −0.0104）。也就是说"越新颖越差"不是普遍模式，`PARTIAL_NOVEL` 在三对模型上都是 Test 负值，
  更像 split 层面的不稳定而不是单调的迁移衰减。
- **尺寸混杂**：HIGH_NOVEL 分子更小（重原子中位 21 vs 27），不是"更大更复杂"的代理；
  按 Validation 重原子三分位分层后，正例排名变化的中位数仍在 ±0.0071 内（详见 JSON），
  没有出现"只在某一尺寸段成立"的稳定模式。
- 结构分组对**正例排名**的影响几乎为零：Test 上组内正例 Δpct 中位数最大只有 −0.0034（FULL/HIGH）。
  组内 AP 的波动主要来自接近阈值的分子质量变化，而不是正例被系统性推高或压低。

### 2.4 H3：宏 AP 被少数任务与符号翻转主导

| 对比 | ΔAP Valid（改善） | ΔAP Test（改善） | 高支持 ≥20：均值（改善） | 低支持 ≤19：ΔAP 之和 | 低支持占绝对变动 | Valid+→Test− | Test 逐任务 ΔAP 中位数 |
|---|---|---|---|---|---|---|---|
| S3 − W2 | +0.00621 (84/127) | **−0.00298** (69/127) | −0.00090 (60/108) | −0.2822 | 39.0% | 33/127 | **+0.00103** |
| RC-REAL − W2 | +0.00244 (64/127) | +0.00232 (78/127) | +0.00093 (65/108) | +0.1951 | 38.5% | 21/127 | **+0.00215** |
| BOC-FULL − W2 | +0.00468 (77/127) | +0.00053 (69/127) | +0.00321 (61/108) | −0.2800 | 41.3% | 29/127 | **+0.00316** |
| BOC-BOND − W2（辅助） | +0.00463 (73/127) | −0.00195 (71/127) | +0.00046 (64/108) | −0.2973 | 39.2% | 27/127 | **+0.00263** |

- **单任务杠杆**：Test 上最大单项 −0.325（S3，task 31，仅 6 个正例）→ 宏 AP 贡献 −0.00256；
  BOC-FULL 的 −0.321（同 task 31）、−0.156（task 57，4 个正例）、−0.120（task 108，7 个正例）
  三者合计 −0.597，超过它在 108 个高支持任务上的 +0.347 总增益。
- **去尾敏感性（描述性）**：BOC-FULL 去掉绝对变化最大的 1/3/5 个任务后均值为 +0.00308 / +0.00298 /
  +0.00290；S3 为 −0.00043 / −0.00024 / −0.00034。这**不替代**官方 macro AP，只说明均值的符号
  对小任务高度敏感。
- **低支持贡献的两种口径**：按预注册规则（低支持占绝对变动 ≥25% 且符号与高支持相反），
  BOC-FULL、BOC-BOND → `H3_SUPPORTED_BY_SUPPORT_ASYMMETRY`；S3、RC-REAL → `H3_MIXED`。
  但按"低支持占净值"看，S3 的净差 −0.379 中有 **74.5%** 来自低支持任务（同向放大），
  RC-REAL 的 +0.295 中有 66.1%——两种口径都指向"低支持任务决定净差的大小甚至符号"。
- **反例**：不能说宏 AP 差异全是噪声——高支持任务上 BOC-FULL 的 +0.0032（61/108 改善）、
  RC-REAL 的 +0.0009（65/108）方向一致，且去尾后仍为正；但 60–65/108 只比一半多 5–12 个任务，
  远不足以称为稳定突破，也没有第二个 seed 支持。
- 这些是算术分解，不是显著性检验；本轮没有做任何 bootstrap/p 值。

### Q5：是否足以支持下一笔 GPU 实验？

**`PAUSE_ARCHITECTURE_SEARCH`**

本轮没有发现任何"明确、可干预、能改变研究路线"的机制线索：预测并不趋同，结构支持度
不能给出跨 split 一致的收益解释，而三个新架构相对 W2 的全部 Test 差异（−0.0030 … +0.0023）
与单个低支持任务的杠杆（±0.0026）同量级。在这个测量分辨率下继续购买单 seed 架构训练，
无法区分"真实的小效应"与"任务级噪声"。

如果研究者仍要购买下一轮实验，它必须先能区分：**(a) 高支持任务上的广泛小增益**
（多 seed、支持度分层的主指标）、**(b) 少数低支持任务的偶然杠杆**、以及
**(c) valid→test 的 split 级衰减**——三者在本轮数据里同时存在且无法分离。
本轮不设计、不执行该实验；是否投入由研究者决定。

## 附：可靠性边界

- 单 seed、Test 已暴露、模型只覆盖 5 个冻结 checkpoint；没有 seed 方差估计，所有
  "一致/不一致"都是对固定预测的描述。
- P1 只看排序行为；不涉及内部表示、attention、错误类型或预测证据。
- P2 的 WL2 是 radius-2 局部环境代理：它会把"差异在 3 键以外"的化学差异合并
  （测试里给出了吡啶对位碳与苯碳同色的例子），因此"被 Train 支持"不等于"结构相同"。
- P3 的组内 AP 依赖组内正例率，只在同 cell 的两个模型之间比较；组样本不足的 cell 已标注。
- 所有低支持/无正例/不可评分任务在 CSV 与 JSON 中显式标记；本轮未在 Test 上做任何
  校准、融合、权重拟合或模型选择。
