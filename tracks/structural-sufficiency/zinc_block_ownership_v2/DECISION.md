# DECISION — `zinc_block_ownership_v2`

**决策标签：`SINGLETON_CONTENT_EXPLAINS_THE_GAIN`**

**Phase B 判决：`d_RS = MAE(S) − MAE(R) = −0.000945`，远未达到 +0.003 的机制规模门槛。**

**执行动作：停止 GPU 工作。不进入 Phase C（不跑 R_s1 / N_s1 / S_s1）。**

v1 的结果、协议、判决与停止记录**未改动**：v1 仍是 `UNRESOLVED_DUE_TO_VARIANCE`，
其 seed-0 主门仍然 FAIL；v1 的 0.004884 **没有**被重新记为 PASS。

---

## 1. 判决依据（全部为预注册量，`PLAN.md` §2.1）

```
d_RS = MAE(S)_best − MAE(R)_best
     = 0.075762140 − 0.076707141
     = −0.000944910            （正数才表示多键块归属更好）
```

| 预注册条件 | 实测 | 结果 |
|---|---:|---|
| `d_RS >= +0.003` | **−0.000945** | **FAIL**（不仅没到门槛，符号还是负的） |
| `d_RS_W20 >= −0.002` | −0.001160 | PASS |
| `d_RS_T100 >= −0.002` | −0.001190 | PASS |
| 非单行驱动 | top-1 占比 1.329（>0.5）、`not_single_row_driven=False` | FAIL |
| `mechanism_active(S)` | True（block grad step1 1.14e-4；h_std 1.375；reader_ext 4.687；内容敏感度 0.0999） | PASS |

⇒ 标签 `SINGLETON_CONTENT_EXPLAINS_THE_GAIN`：**S（单键块真实内容 + 多键块分子级均场）
与 R（真实多键块归属）在 official valid 上没有可分辨差异**，因此 v1 的 R−N 正号
不可能由"多键块归属"解释。

## 2. 为什么写成"未取得证据"，而不是"已证明无效"

1. 本轮是**单 seed**（S 只跑一次），量级 0.0009 落在
   `ERRATA.md` E2 测得的同 init 执行漂移带 0.0015–0.0025 **之内**。按预定纪律，
   这个尺度上的差异读作"不可分辨"，不是"零"。
2. 点估计的方向是**S 略好**（W20/T100/final 三个免选择指标一致为 −0.0011…−0.0012），
   但这同样落在漂移带内，不能反过来宣称"S 更好"。
3. 因此本轮的**唯一**可下结论是：**多键块归属没有取得足以继续购买确认实验的证据**。
   这与"多键块归属已被证明无效"不是同一句话；后者需要两 seed 且两 seed 都落在
   零附近的区间估计，本轮没买。

## 3. 停止规则执行记录

`PLAN.md` §2.1：Phase B 未达 +0.003 或单行依赖 ⇒ `STOP_GPU_AFTER_B`。

- 未启动 `R_s1` / `N_s1` / `S_s1`；
- 未调宽度/层数/lr/wd/归一化/块类型/readout/阈值；
- 未用第二个 seed 去"救"这个符号；
- 未读 official test；
- 未做蒸馏、ensemble、seed 平均推理。

GPU 使用：**0.536 A100·h**（S_s0）+ CPU smoke ≈0.003 h = **0.54 h**，
软预算 3 h、硬上限 4 h ⇒ 剩余预算**不使用**（任务要求：无须用满）。

## 4. 本轮可保留的事实

1. **v1 的 R−N 点估计确实是"薄"的**：row 172 单行贡献 **41.9%**，
   top-5 行贡献 **82.7%**，top-10 超过净差；去 row172 后 +0.00284，
   去 top-10 极端对比行后 +0.00259（详见 `analysis/phase_a.json::A2`）。
   而这 41.9% 的贡献者 **`n_multi = 1`**，即 S≡R 的分子——它**根本不在**
   "多键块归属"这一机制的作用域内。
2. **R 与 S 的训练结果与推断干预一致为"无差别"**：
   * `d_RS = −0.0009`（W20/T100/final −0.0011…−0.0012）；
   * 冻结权重内容替换：`R→S` 的 `mean|Δpred| = 0.0048`、`ΔMAE +0.00029`；
     `S→R` 为 `0.0036 / +0.00038`；而 `R→N` 为 `0.1006 / +0.0627`、
     `S→N` 为 `0.1011 / +0.0595`。
   ⇒ 训练好的块通道**对"内容现存"极度敏感、对"内容如何在多键块间分配"几乎不敏感**。
3. **数据侧的定量解释**（`summary.json::phase_b_mechanism.block_input_distance`）：
   在 φ 真正看到的 `u_B`（每块平均内容，192 维）空间里，
   `R→S` 只改变 19.6% 的块（多键块 L2 0.891，单键块 0.0），且**逐分子总量守恒**；
   `R→N` 把 80.7% 的单键块也一起改掉（单键块 L2 3.135）。
   共享 φ + `Σ_B` 池化下，一个"保均值重分配"的扰动是二阶小量。
4. **S 臂的工程状态被完整验证**（与 v1 同级）：守恒（一阶 7.6e-6 / 二阶 1.2e-4，fp32）、
   `n_multi ≤ 1` 上 S≡R **逐位相同**（111 行，100%；`n_multi ≥ 2` 上 0%）、
   原子重编号/边反向/边序/batch 序不变性（≤9.5e-7）、
   三臂同 seed 初值哈希完全相同（`bd18518b…`，seed 0 与 1）、
   block 梯度 step0 恰为 0（zero-init reader_ext 的必然结果）而 step1 为 2.4e-2/2.9e-1。
5. **v1 的效应集中在"见过但稀有"的低支持分子，而不是未见组合**：
   low_support 贡献 +0.00375（占总 0.00488 的 77%），
   `ordinary ∧ sig_novel` 只有 +0.00008，`any_unseen` 为 −0.00006。
   v2 的 R−S 在这些组上同样没有正向（low_support −0.0043、any_unseen +0.0047，CI 全跨零）。

## 6. 独立确认需要什么（记录，不是本轮的提议）

本轮**不启动**、也**不建议现在购买**任何后续 GPU 搜索。仅记录一个判据，供未来
（若有新理由）写预注册时引用：真正的独立确认必须做到

* **结构组合留出**：在 train 内按"块尺寸组合 / 块签名组合"分组，留出一整族组合
  完全不参与训练，再在该留出族上比较 R / S / N —— 否则 1,000 行 official valid
  已被多轮适应性研究使用，任何重复成功都只是"在同一套评估上的再确认"。
* **两 seed 且两 seed 都带区间**：`d_RS` 的配对 CI 与执行漂移带不相交。
* **预注册"机制只在 `n_multi ≥ 2` 上生效"的 DiD 门**，而不是全 1,000 行均值。

## 7. 最终一句话

**S（单键真实 + 多键分子级均场）与 R（真实多键块归属）在 official valid 上差
−0.000945（W20/T100/final 同为 −0.001 量级），既未达 +0.003，也落在执行漂移带内；
冻结权重探针显示块通道对"多键块如何分配内容"几乎不敏感。因此多键块归属
**没有取得足以继续购买确认实验的证据**，Phase C 取消，不再提出即时 GPU 搜索。**
