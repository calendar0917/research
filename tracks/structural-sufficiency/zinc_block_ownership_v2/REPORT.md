## 1. 这一轮问什么

v1 里 R 比 N 好 +0.004884（seed 0，未过 0.005 主门，CI 跨零），但有两个未被区分的解释：

* **H1（单键内容）**：收益来自单键块（桥键）上的**逐键真实内容 + 非线性 φ**；
* **H2（多键归属）**：收益来自**多键块之间真实的归属关系**（哪个键属于哪个环系）。

v1 已经为此准备了 S 臂但按停止规则没跑。v2 只买 **S_seed0**，用

```
d_RS = MAE(S) − MAE(R)      （正 = 真实多键块归属更好）
```

在 seed 0 上把 H1/H2 分开。三个臂的块输入定义（v1 冻结代码，未改一行）：

| 臂 | 块内容 |
|---|---|
| **R** | 每块真实一阶/二阶矩之和 |
| **N** | 全图矩按块边数比例分配（全图均场，单键块也被污染） |
| **S** | 单键块真实；多键块共享**分子内多键集合的守恒均值** |

模型只读 `u_B = [mean_{e∈B} c_e, mean_{e∈B} c_e², 4 个块标量]`，经共享
`196→64→32` φ 后 `Σ_B` 池化，接到零初始化 `Linear(32→256)`。参数 497,161（三臂相同）。

### 2.5 A5 冻结权重内容干预（只证明"模型读了什么"）

对**已冻结**的 R_s0 与 S_s0 权重，只替换块内容：

| 模型 | 替换 | MAE 前 → 后 | ΔMAE | mean\|Δpred\| | max\|Δpred\| |
|---|---|---:|---:|---:|---:|
| R (训于 R) | **R → S** | 0.077741 → 0.078034 | **+0.000293** | **0.0048** | 0.052 |
| R (训于 R) | R → N | 0.077741 → 0.140454 | +0.062713 | 0.1006 | 0.635 |
| S (训于 S) | **S → R** | 0.076661 → 0.077037 | **+0.000376** | **0.0036** | 0.032 |
| S (训于 S) | S → N | 0.076661 → 0.136130 | +0.059470 | 0.1011 | 0.589 |

**读法**：两个模型都对"把内容换成全图均场"极其敏感（~0.10），而对 R↔S 的替换
几乎无反应（0.004–0.005），**且双向对称**。这不是"某个模型偏爱自己见过的内容"，
而是块通道本身对"多键块之间的分配"不敏感。

**这意味着什么、不意味着什么**：这类固定权重替换只能说明**模型读取了什么**；
它不能证明泛化因果效应（R 模型的权重是在 R 内容上拟合的，换成 S 是分布外输入）。
真正回答 H1/H2 的是 Phase B 的训练对照。

## 4. 判决

```
d_RS = 0.075762231 − 0.076707141 = −0.000944910
预注册门槛 = +0.003        ⇒ 差 0.00394，符号为负
非单行驱动条件             ⇒ 不成立（top-1 占比 1.329）
mechanism_active(S)        ⇒ True
```

**标签：`SINGLETON_CONTENT_EXPLAINS_THE_GAIN`。**
**动作：停止 GPU 工作，不进入 Phase C。**

这不是"多键块归属已被证明无效"，而是：

> **多键块归属未取得足以继续购买确认实验的证据。**
> `d_RS` 的量级（0.0009）落在同 init 执行漂移带（0.0015–0.0025）之内，
> 单 seed 无法把"零"与"±0.001"分开；要证明"无效"需要两 seed 且两 seed 的配对 CI
> 都落在零附近，本轮没有买。

**v1 的 0.004884 不重新记为 PASS。** 本轮之后对它的解释变成：
R−N 的差必须由 R 与 S **共享**的那部分内容解释，而不是由多键块归属解释；
共享部分 = 单键块真实内容（80.7% 的块）+ 多键块的分子级守恒总量。
A5/A5b/Phase B 三方一致地把"多键块归属"这一项的贡献压到不可分辨。

## 5. 任务书四个问题的直接回答

**Q1. 真实多键块归属是否确实带来可重复的增量？**
**没有。** seed 0 的 `d_RS = −0.000945`（W20/T100/final 一致为 −0.0011…−0.0012），
远低于 +0.003 的机制规模，也没有第二个 seed 去把它变成可重复性结论。
唯一在方向上支持它的是 `n_multi ≤ 1` DiD（+0.0104），但 CI [−0.013, +0.040]，
且是非判决的次级量。

**Q2. 收益是否超出单键内容与极端分子？**
**不超出。**
* 对**单键内容**：S 正是"单键内容保留、多键归属抹平"的臂，R−S ≈ 0 ⇒ 收益不需要
  多键归属来解释；而 A5 的 `R→N`（连单键内容一起换成均场）代价 0.0627，
  `R→S` 只有 0.00029 ⇒ 敏感的是单键内容。
* 对**极端分子**：v1 的 41.9% 净差来自 row 172，而 row 172 是 `n_multi = 1`，
  即 S≡R 的分子；v2 的 R−S 在固定 worst-10 上反而是 −0.138（CI 极宽）。
  两轮的 evidence 都说明"极端行"与"归属机制"不是同一件事。

**Q3. 如果没有，明确停止，不提出其他即时 GPU 搜索。**
**停止。** 不进入 Phase C（R_s1/N_s1/S_s1 全部取消），不调宽度/层数/lr/wd/归一化/
块类型/readout/阈值，不用第二个 seed 去救符号，不读 official test，
不提出任何"再加一个模块/再换一种均场"的即时 GPU 搜索。剩余预算（≈2.4 A100·h）不用。

**Q4. 如果有，给出结构组合留出的独立验证设计（本轮不启动）。**
不适用（Q1/Q2 的答案是否）。仅把判据记录在 `DECISION.md` §6，供未来若出现新理由时
写预注册用：真正的独立确认必须是**结构组合留出**（在 train 内留出一整族块尺寸/块签名
组合，完全不参与训练）+ **两 seed 且配对 CI 与漂移带不相交** + **只在 `n_multi ≥ 2`
上生效的预注册 DiD 门**。**本轮不启动，也不建议现在买。**
