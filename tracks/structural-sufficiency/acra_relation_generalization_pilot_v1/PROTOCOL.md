# PROTOCOL — acra_relation_generalization_pilot_v1

Status: **frozen before the first formal training run.** The commit that
contains this file is the protocol commit; every formal run manifest records
its own commit. Later commits may append actual conditions and explained
deviations, but the plan is not rewritten.

Round: `tracks/structural-sufficiency/acra_relation_generalization_pilot_v1/`.

Task: `ogbg-mollipo`, official scaffold split (Train 3360 / Valid 420 / Test
420). **Test labels and Test predictions are never read or produced.** The
official Valid set is not used for any new model in the Dev exploration; the
only Valid numbers in this round are frozen-weight diagnostics of the parent
ACRA_REL checkpoint (Phase A), which the parent round already reported.

## 1. Questions

* **H1** Is the parent `ACRA_REL` gain mainly the global second moment of the
  edge-pair representation, or the topological relation-category histogram?
* **H2** Does making the edge-pair interaction genuinely topology-conditioned
  improve whole-molecule accuracy and cross-molecule changes?
* **H3** Does shrinking local combinations with little Train support improve
  generalisation to unseen combinations?

The three hypotheses need not all hold. No GNN, message passing, Graph
Transformer or extra attention is introduced. The parent structural objects and
local representations are kept unchanged.

## 2. Frozen development split

All statistics below come from the official Train rows only (3,360 molecules).

* scaffold: RDKit Bemis--Murcko, `includeChirality=False`; an acyclic molecule
  has an empty Murcko scaffold and is keyed by its own SMILES, so acyclic
  molecules are not all forced into one giant group;
* scaffold keys sorted, permuted with `numpy.random.default_rng(0)`, groups
  added greedily while not exceeding the target;
* target fraction 15 %, actual:
  * Train-sub: **2,856** molecules, **1,354** scaffolds;
  * Dev: **504** molecules, **231** scaffolds;
  * 1,585 scaffolds in the official Train; no scaffold crosses Train-sub / Dev;
* the split is generated by a script that reads only SMILES and the official
  Train row ids, and is frozen in `data/split_train_sub_dev.json`
  (`sha256 60ac13c0…`); training loads that JSON and never invokes RDKit;
* labels are not used to choose the split; the target scaler is fitted on
  Train-sub only; category support masking uses Train-sub only;
* the old full-Train checkpoint is **not** a Dev baseline: it has seen Dev
  labels during its parent training.

## 3. Relation algebra (Phase A, no new training)

For the parent relation term, with `m` undirected bonds and
`Q = Σ_e q[e]`, `K = Σ_e k[e]`:

```
moment    = 0.5 * (dot(Q, K) - Σ_e dot(q[e], k[e])) / sqrt(rank)
histogram = Σ_bucket count[bucket] * bias[bucket]
E_rel     = gate * (moment + histogram) / max(1, m)
```

The exact identity is tested against the literal pair loop on all real
Train+Valid molecules and on random connected synthetic graphs (6–10 atoms,
real attribute rows). The maximum error is recorded in
`analysis/relation_factorization.json`. The old checkpoint's `E_rel` is split
per molecule, related to bond count / atom count / cycle rank / unseen-combination
fraction, examined for size-dependent scale effects, and subjected to
frozen-weight removal of `moment` or `histogram` on the official Valid split.
Frozen removal is a diagnostic, **not** a retrained causal effect.

Capability property: hold every edge representation and the relation-category
histogram fixed and permute which category is attached to which concrete bond
pair. Original ACRA_REL must be exactly invariant. This is an algebraic
property, not chemical performance evidence.

## 4. Fixed arms (seed 0 each)

All arms keep the parent data objects: every real bond gives two directed
events; `S` radius 1, `C` radius 2; shared rooted-frame encoder; atom term +
connection response + relation term; the same whole-molecule objective.

| arm | local interaction | relation term | extra parameters |
|---|---|---|---|
| A `ACRA_REL_REF` | original | original full | — |
| B `ACRA_MOMENT_ONLY` | original | `gate * moment / max(1,m)` only | no `rel_bias` |
| C `ACRA_HIST_ONLY` | original | `gate * histogram / max(1,m)` only | no site head / `rel_q` / `rel_k` |
| D `ACRA_TOPO_COUPLED` | original | `gamma[cat]*symmetric_dot/sqrt(rank) + bias[cat]` | 8 `theta` |
| E `ACRA_SUPPORT_GATE` | `rho(n)` times interaction | original full | none |

`ACRA_TOPO_COUPLED`:

```
gamma[t] = 1 + 0.5 * tanh(theta[t])      # 8 categories, theta initialised to 0
L_gamma  = 0.001 * mean((gamma - 1)^2)
```

`gamma=1` must reproduce the original REL relation term exactly. A non-constant
gamma must make the category-to-pair assignment matter.

`ACRA_SUPPORT_GATE`:

```
r(S,C) = scalar_S(S) + scalar_C(C) + rho(n) * interaction(S,C)
rho(n) = 0.5 + 0.5 * n / (n + 5)
```

`n` = number of distinct **Train-sub molecules** containing the same exact
`(S_identity, C_identity, cut_bond)` combination. Train-sub events use
leave-one-molecule-out support (combo molecule count − 1, even when the combo
occurs several times inside the molecule); Dev events use the full Train-sub
count. `scalar_S`, `scalar_C`, `E_atom` and `E_rel` are unchanged. The gate
never reads labels. Dev / Valid / Test structures never contribute to `n`.

Parameter counts are reported as-is; no capacity matching is attempted.

## 5. Recipe (uniform for all five arms)

* seed 0; AdamW; peak LR 1e-3; weight decay 1e-4; gradient clip 5.0;
* 5 warmup epochs then cosine decay to 1e-5;
* batch 64 molecules; 160 epochs; Train-sub label standardisation;
* best-by-Dev whole-molecule RMSE;
* parent fixed site and relation regularisers: `0.001 * L_site`,
  `0.01 * L_rel`; plus the TOPO gamma regulariser above;
* shared modules must have identical initialisation hashes across arms; all
  parameter differences are recorded;
* no per-arm hyperparameter search. If the GPU timing smoke shows the 2-hour
  budget is insufficient, one shared smaller horizon is fixed for all arms
  before formal runs; arms are never shortened individually.

## 6. Evaluation

Primary: Dev whole-molecule RMSE / MAE, Train-sub–Dev gap, Dev molecule-level
paired bootstrap against `ACRA_REL_REF`, Train-sub×Dev real matched-pair delta
MAE/RMSE, direction accuracy, parameter count, wall time and peak VRAM.

Auxiliary:

1. **Relation source**: moment-only vs histogram-only vs full vs
   topology-conditioned; separate correlation, expressivity and trained
   predictive gain.
2. **Support and generalisation**: Dev novelty buckets `0`, `(0,0.2]`,
   `(0.2,0.5]`, `(0.5,1]`; sample counts, RMSE, MAE; interaction amplitude vs
   Train support; REF vs SUPPORT_GATE error changes per bucket; whether
   low-novelty molecules degrade and high-novelty molecules genuinely gain;
   confounding by molecule size, bond count and cycle rank.
3. **Outlier sensitivity**: all Dev molecules retained for primary RMSE; extra
   MAE, error quantiles, worst molecule, leave-one-molecule-out RMSE range, and
   the effect of the five largest squared errors on model ranking. No
   post-hoc deletion is used to claim improvement.
4. **Structural mechanism capability**: real or explicitly labelled synthetic
   graphs with identical local object multiset and identical relation-category
   counts but a different category-to-pair assignment; check REF invariance and
   TOPO distinguishability. Synthetic/capability results are never presented as
   chemical predictive evidence.

## 7. Conditional full-Train revalidation

After Dev exploration, exactly one new candidate may be retrained on the full
official Train (3,360 molecules, seed 0) and evaluated on official Valid only if,
relative to `ACRA_REL_REF`:

* Dev RMSE improves by at least 0.02 **or** Dev MAE improves by at least 0.02;
* there is no obvious cross-molecule matched-pair degradation;
* all engineering gates pass.

The candidate is the new arm with the best Dev RMSE among those meeting the
threshold. No new official Valid result is read before this model-selection
decision. Any full-Train Valid result is a **historically Valid-guided
exploratory recheck**, not an independent blind confirmation. If no arm meets
the rule, no full-Train revalidation is run.

## 8. Engineering gates (all before formal training)

1. exact decomposition of original ACRA_REL;
2. per-molecule relation-category counts sum to `m(m-1)/2`;
3. moment-only + histogram-only equals original `E_rel`;
4. gamma=1 TOPO equals original REL;
5. non-constant gamma genuinely couples categories to edge pairs;
6. atom/bond renumbering invariance for every arm;
7. batch equals single-graph prediction;
8. Support Gate Train leave-one-molecule-out is correct;
9. Dev and Train-sub labels are strictly isolated;
10. Test labels and predictions are never accessed;
11. no trainable branch is accidentally inactive;
12. no NaN/Inf;
13. fixed-seed reproducibility.

The executable form is `tests/test_acra.py`; `code/acra_checks_v2.py` records
full-dataset coverage, branch gradients, shared hashes and the pytest result in
`analysis/checks.json`. Formal training starts only after these pass.
