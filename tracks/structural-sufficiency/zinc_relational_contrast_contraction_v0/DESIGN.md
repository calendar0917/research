# RCC-v0 设计说明与 CPU 判定

**协议**：`rcc-v0`，配置 `configs/rcc_v0.json`（sha256 `09cea39f…`）
**判定**：`STOP_BEFORE_GPU_REDUNDANT_SECOND_ORDER_CHANNEL`
**GPU 开销**：**0.0 A100·h**（预算上限 2.0 h，未动用）
**数据**：official PyG ZINC subset 的 official-train 行，split E（fit 7,996 / monitor 1,000 /
locked 1,000）。official valid / test 未加载（`torch.load` 行为审计记录在 `analysis/cpu_gates.json`）；
本轮**没有读任何标签**（梯度活性用零目标探针）。

---

## 0. 一句话

按用户给定的冻结设计把它实现出来、把 24 条数学/工程门禁跑完之后，**第 11 条把它拦下了**：
图级二阶收缩 `T = Zᵀ(K_R − K_D)Z` 在真实分子上与 reader 已有的局部矩高度重合——**T 的 99.4%
（Frobenius 加权 99.8%）可以被 `[Σh, Σh², 原子矩, global33, 结构质量]` 的线性函数重建**；更要命的是，
**连"关系核相对行和 Null 多出来的那一部分" `T_real − T_null` 也有 97.2%（99.1%）可以被同样重建**。
预注册的重建上限是 0.90。因此这不是"跑了但没效果"，而是**在任何训练之前就可以判定：这条通道
不携带 reader 拿不到的信息**，按冻结规则 STOP，不购买 GPU。

## 1. 建成的模型（与用户规格逐条对应）

| 规格 | 实现 |
|---|---|
| 复用 P3 SSL atom/bond/junction 编码器 | `M1.P3Encoders`，权重来自 `pretrain_encoder_s0.pt`（`006fabc1…`） |
| 一个共享 bond composer，联合消费真实 junction ownership 与原有全局 junction moments | `MLP(488→128→96)`，输入 `[b, Wl, Vl, Wg, Vg, log1p n_b, bond_feat]`；`Wg/Vg` = Null 分组（分子级矩复制到每键），`Wl/Vl` = 真实 incidence 归属（`junc_bond` 两个端点各加一次，静态、无递归） |
| `Z = Linear(96,16)(h)` | `z_proj` |
| `K_R = sym(P)`，P 为物理键线图一步 lazy walk | float64 构建 → float32 bank（`analysis/kernel_bank.npz`），零度行 one-hot，`SELF_LOOP=0.5` |
| `d = K_R1`，`K_D = ddᵀ/Σd`，`B = K_R − K_D`，零质量 → B=0 | `RCC.contrast`，逐 batch dense [B, bmax, bmax]，mask 后计算 |
| `T = ZᵀBZ`，保留对称上三角 136 维 | `einsum('bni,bnj->bij')` + `triu_indices(16,16)` |
| reader：共享键一/二阶统计、原子一/二阶、global33、结构质量/大小、T；小型受控 | `[96+96+96+96+33+5+136] = 558 → 256 → 256 → 1`（与 P3/DCC-L 同宽，不是新旁路） |
| 无 Attention、无第二轮局部状态更新 | 前向里只有一次 incidence 聚合 + 一次 composer + 一次收缩 |

**参数**：487,729（encoders 202,048 / composer 74,976 / z_proj 1,552 / reader 209,153），
上限 500,000；DCC-L 参照 494,193（差 −1.3%）。

**两臂**：`real` 用 `B`，`null` 用 `K_D`（行和与总质量逐分子精确匹配）。共享同一初始化
（state hash 相同、初始预测逐位相同，门禁 G2 验证 max|Δ|=0.0）、同一 batch order、同一训练行。

## 2. 与前两代主体的前向差别（不是等价重参数化）

- **vs DCC-L**：DCC-L 有**两个** composer（一个 Null 分组、一个 ownership 分组），reader 同时读
  `Σc_glob` 与 `Σc_loc, Σc_loc²`，没有任何图级二次通道。RCC 只有**一个** composer，输入是两种分组的
  并集，reader 读它的 `Σh, Σh²`，**外加** `T`。结构上不重合（没有双 composer 拆分，没有独立局部读出）。
- **vs BondRW（`bond_relation_attribution_v1` / `bond_random_walk_organization_v1`）**：BondRW 显式
  枚举**无序键对**、学 `φ(b_e,b_f)` 再用固定权重 K 池化，代价 O(n_b²)，表达类是"任意对称 pair 函数的
  加权和"。RCC **从不枚举键对**、不学 pair 函数：pair 权重就是固定算子 `B`，pair 内容是 rank-16
  因子化 `ZᵀBZ`。因此 RCC 的表达类严格落在"rank-16 投影的二次型"之内——这也正是它失败的地方（§4）。

## 4. 为什么 T 会塌成局部矩（机制，已被测量）

不是实现 bug，也不是"核没用"。三条独立证据链：

1. **核本身是有结构的**：`B` 的 top|λ| 占比只有 0.09（谱展开），且 `T` 与"最佳单标量乘中心化算子
   `I−11ᵀ/n`"算出的版本相差中位数 36%——所以不是 `B ≈ κC` 的代数退化。
2. **但共享键表征几乎是 1 维的**：对 `h` 做 PCA（63,921 条键），**participation ratio = 2.57**，
   top-1 主成分占 61.0%，top-5 占 85.0%，top-10 占 91.4%。原因在设计本身：composer 同时接收
   `Wg/Vg`（分子级常数，复制到每根键）与 `Wl/Vl`，输出方差被"分子共同项"主导；
   逐键偏离只占 43%（`Σ|h−h̄|²/Σ|h|²` 中位数 0.42）。
3. **零行和算子的二次型只能看到偏离项**：`T = Σ_ef B_ef δ_e δ_f`（`B·1=0` 已扣掉共同项）。
   当 `δ` 落在 2.6 维内、且 `B` 的特征向量跨分子高度相似（top-1 特征向量跨分子 **|cos| 中位数 0.68**），
   这个二次型就退化成"逐键二阶矩（`Σh²`）的固定线性组合"。于是 reader 已有的 `Σh²` 就能
   99% 复现它。

**结论（限定在本设计内）**：`rank=16` 的投影 + 一步 lazy walk 对比核 + 单 composer（含分子级常数输入）
+ reader 已读 `Σh, Σh²` 这个组合，图级二阶收缩**在信息上不是独立通道**。

## 5. 必须披露的三件事

1. **重建度是在共享初始状态上测的**，因为启动规则冻结为"label-free"。训练后的 composer 原则上可以让
   `h` 变得更"逐键"，从而降低重建度；但要检验这一点，恰恰需要被规则禁止的那次 GPU 训练。所以它只能
   作为下一轮的假设，不能作为本轮证据。这是一条真实的限制，不是免责声明。
2. **`z_proj` 的梯度在第 2 步才非零**（第 1 步 reader 的 T 列是零初始化，`dL/dW_proj` 的路径尚未打开）。
   这是零初始化新块的数学后果，与 SCM 轮的冷启动同型，不是 bug；门禁把它记录为 `z_proj: 2`。
3. **SSL 初值用的是仓库内的 full-10k 无标签 checkpoint**（`006fabc1…`），不是严格 Fit8k 的那个
   （`08e5f613…` 是远端产物，重生成约 0.45 A100·h）。因为本轮没有进入训练，这一点对判定无影响；
   若将来重启，必须按 Fit8k 重跑或明确披露。

## 7. 下一轮真正被约束的设计假设

> **图级二次通道只有在"逐键内容沿关系图相干变化"时才是独立信息；若内容几乎是每分子一个共同项
> 加上 2–3 维的逐键抖动，那么任何零行和的稠密二次型都会塌成 reader 已经拿到的二阶矩。**
> 因此下一代若再提"图级二阶统计"，必须先在 label-free 阶段证明它的 `T`（尤其是 `T_real−T_null`）
> 不能被 `[Σh, Σh²]` 线性重建（建议门槛 ≤0.5，而不是本轮的 0.9）；否则不要付 GPU。

这条约束是可证伪的，也给出去处，但**不包括"再中心化一次"**：`B·1=0` 已经等价于中心化，SCM 轮也
已经证明中心化 + 求和池化会抵掉 77% 的信号。两个方向都指向同一件事——瓶颈在**逐键内容本身**，
不在池化算子。所以下一步只有两条：要么换成**键对级的高通算子**（只保留相邻键之间的差，像 BondRW 的
`|b_e−b_f|` 那样，而不是稠密二阶矩），要么先把共享表征做成"一个分子共同项 + 一个明显更高维的逐键项"
（并且在 label-free 阶段量出逐键项的 participation ratio 升高），否则任何"图级二阶"提法都会重复本轮。
