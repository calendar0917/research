一句话：**在本载体上，"键内容 + 幅值敏感门控全图混合"把 valid 从 0.0805 拉到 0.0752（2 seeds × 2 C0 seeds × 4 个检查窗口），并且这个增益在训练集内部留出的 1,000 新鲜分子上重训后复现（−0.0095，CI 不含 0，集中在尾部）；但它在 official test 上并没有超过旧 DCC-L 家族（0.0678 vs 0.0673）。** 其余三种"全局结构混合"变体（普通 attention、有符号核、无混合）与不混合的载体同级，因此"加一个全局算子"本身没有收益，收益只属于这一种具体运算。

## 1. 实际构建的东西

一次前向、一个 reader、一个预测器。所有参数端到端训练（含训练好的 SSL 编码器），无冻结模块。

| 阶段 | 实际计算 | 参数 |
|---|---|---:|
| 局部前端（复用） | P3 `atom_encoder`/`bond_encoder`/`junction_encoder`（train-only masked-SSL 初始化，微调）+ DCC 的 global composer（图均值 junction 统计）与 local composer（真实 incidence 聚合） | 296,560 |
| 键对象 token | 每条**无向**物理键一个 token：`h0_b = Linear([c_global_b, c_local_b])` 192→48 | 9,264 |
| 静态关系 | 16 维 → 共享 `16→48→24`：12 个 `log1p` lifted 路径关联 + 最小端点距离 + 共享端点数 + 自关系 + 不可达 | 1,992 |
| 全局混合 A | 3 层、宽 48、4 头：`score_bc=(q_b·k_c−½‖k_c‖²)/√12 + β(r_bc)`，`a=softmax_c`，`g=1+tanh(γ(r_bc))`，`m_b=Σ_c a_bc g_bc v_c`，`h←h+O(m)`（O 小初始化 std=1e-3），再 `h←h+FFN(AdaRMSNorm(h))` | 57,480 |
| 读出 | `[z0(513), Σh/24.9279, Σh²/24.9279] → 128 → 128 → 1`；`z0` 与历史一致，**不经图级归一化** | 94,721 |
| **总计** | | **460,017** |

关系定义（与代码一致、与 CPU gate 一致）：对两个物理键 `b={u,v}`、`c={p,q}`，
`lift_l(b,c) = M S_l M^T = (S_l(u,p)+S_l(u,q)+S_l(v,p)+S_l(v,q))/2`，`S_l` 是 DBT 冻结的
atom-pair 简单路径计数（长度 1..12），`M` 每行在两个端点上取 `1/√2`。这是**键—键结构关联统计**，
不是原图键—键简单路径精确计数。距离取四个端点对的最小值（0..14，13=连通但>12，14=不可达）。

`AdaRMSNorm(x) = x/rms_eps(x) · rms_eps(α·x+β)`，`α0=0, β0=1`（借 PPGT 的 AdaRMSN，不是本轮发明；
不是普通 RMSNorm 改名）。

对照臂（同数据、同 collate、同训练器、同配方，只换混合运算/是否混合）：

| 臂 | 混合 | 参数 |
|---|---|---:|
| C0 | 无（只有 513 维 `z0` + 128 宽 reader） | 378,993 |
| N0 | 无混合：键 token 的 Σh、Σh² 进 reader，没有层、没有关系 | 400,545 |
| Asm | 普通归一化 attention：`softmax(q·k/√d + β(r))`，无 `−½‖k‖²`、无内容门 | 459,717 |
| K | 有符号非竞争核：`m_b=Σ_c tanh(K_l(r_bc))·V_l(N(h_c))/n̄_b` | 452,457 |
| A | 上述幅值敏感 + 关系门控 | 460,017 |
| reg_A | A + R2 配方（wd 1e-3、dropout 0.05，唯一一次有诊断依据的修正） | 460,017 |

## 3. 机制对照（改变下一步判断的两个训练对照）

| 对照 | 与 A 的差别 | valid | 结论 |
|---|---|---:|---|
| Asm_s0 | 去掉 `−½‖k‖²`（改成 `q·k/√d`），去掉 `1+tanh(γ(r))` 内容门，其余（内容通路、关系 bias、层数、宽度、参数 459,717）全同 | 0.080797 | **组件包（幅值敏感 logit + 关系条件内容门）值 ~0.005 valid**；"普通全图 attention + 同一结构关系"没有收益 |
| N0_s0 | 保留键 token/Σh/Σh² 进 reader，但**完全没有混合、没有关系** | 0.081145 | 只把键内容喂给 reader 也不产生收益（≈C0） |
| K_s0 | 有符号非竞争核 + 每通道 `tanh` 权重 + `1/n̄_b` 标度 | 0.081812 | 这一族的核参数化在本任务上**不如** A；也不优于 C0。样本只有 1 seed，`EARLY_STOP` 不适用（跑满 600 ep，best 在 ep329） |

这不是"关掉模块变差"的论证：Asm 是**同参数量级、同输入、同关系、同预算**的重新训练对照，
N0/K 是另外两条重新训练的运算。三者都落在 C0 的带内，说明收益不属于"有全局混合"或"有键内容"，
而属于 A 这一种运算的具体形式（幅值修正与门控作为**一个包**，本轮未拆分）。

reg_A_s0（R2 配方）显著变差（0.0861，且后期发散到 0.11），**否掉**"A 的问题只是正则不足"这一解释；
与历史 DCC-L R1 方向一致（更强正则更差）。因此没有为 A 再做配方修正。

## 7. 先例与未建立的新颖性（明确标注）

- `−½‖k‖²` 幅值敏感 logit：与 PPGT（arXiv:2504.12588）的 AdaRMSN/sL2/静态关系同源；AdaRMSN 公式直接借用。
- 连续/参数化全局核、有符号核：CKGConv（arXiv:2404.13604）已有；其 ZINC 表中"核 vs softmax 平滑核"的
  0.059 vs 0.073 差异**不是**本模型会得到同一改善的预测（本文实测方向相反且幅度小）。
- 键对象全地图 attention + atom-pair 路径计数关系：DBT（本 track 上一轮）已做过有向键对象版本；
  本轮换成无向键、lifted 关联统计、幅值敏感 logit + 内容门，**不新在"全局 attention + 路径计数"**。
- 端点/路径内容与树结构信息：PAGTN（arXiv:1905.12712）、SPSE（arXiv:2502.09365）已有先例；
  旧 `tracks/ksvd/notes/compact_v4_ordered_path_bond.md` 的有序键路径实验是**负结果**，且其做法是
  "先逐位置均值再编码"（`phi(mean)`），与本轮路线 P 设想的 `mean(phi(path))` 不同——路线 P 本轮**没有做**，
  因此不能引用它支持或反对本轮任何结论。
- RBO（`zinc_rooted_branch_operator_v0`）的教训在本轮得到一次独立复现：
  **构件覆盖/训练拟合（A 的 online train MAE 降到 0.0005）不保证组合或跨集迁移。**

## 8. 一句话下一步（唯一）

留出检验已经复现了 A 相对 C0 的增益（−0.0095），并且显示增益集中在**尾部/大误差分子**，
而加宽 reader 会让它消失。因此下一个（也是唯一一个）值得做的实验是：
**在 A 的 460,017 参数配置下，把 `−½‖k‖²` 与 `1+tanh(γ(r))` 拆成两个单独重训的对照**，
并用同一训练集内部留出集评估（而不是只用 valid）；目的不是再加模型，而是判断"尾部修正"
是由幅值项（近似 RBF/高斯核）还是由关系条件内容门提供的——这决定了下一步是改进关系
编码还是改进打分几何。DCC-L 的 test 0.0673 锚点在改进前保持不变。

### 8.1 已执行：训练集内部留出检验（answer to §8）

为了在**不碰 test** 的前提下判断"valid 上的 0.005 是否只是 valid 专属"，
用 `HOLDOUT_SEED=20261025` 从 official train 划出 1,000 分子（本轮任何开发决定都没看过），
在剩余 9,000 行上把 A 与 C0 各重训 600 epoch，用各自 best-valid checkpoint 打进留出 1000 行：

| arm | 训练行 | ep | official valid | 留出 1000 MAE | 训练(kept) MAE | GPU·h |
|---|---:|---:|---:|---:|---:|---:|
| **A** | 9,000 | 364 | 0.081299 | **0.114666** | 0.015609 | 0.752 |
| C0 | 9,000 | 384 | 0.085241 | **0.124116** | 0.015727 | 0.469 |

配对逐分子差 A − C0 = **−0.009450**，bootstrap 95% CI **[−0.014008, −0.005082]**（A 更优 54.8%）。
去掉最差 1 行 / AE 最大 10 行 / 5 个极端标签行后仍为 **−0.008619 / −0.006267 / −0.007208**。
**中位数 AE 几乎相同**（0.043296 vs 0.043118）——增益集中在尾部与大误差分子，中位分子没有变化。
（留出 MAE 绝对值偏高是因为这 1000 行里含 y=−42.0 的极端分子；official valid 尾部只到 −20.3。
两层用同一批行做配对比较，所以不影响差值结论。）

**这一步改变了判断**：A 的增益不是 valid 专属的。它在新鲜 1,000 分子上复现，且比
"依赖 row172 / 尾部单点"的解释更强。但同一机制没有在 test 上带来对 DCC-L 的优势（§4），
说明"对同载体有效"和"超过最强历史家族"是两件事。

#### 由留出结果直接导出的一个已预注册的补充检验（A160）

留出与 valid 同时提示：A 的载体 reader 只有 128 宽，而 DCC-L 同 composers 用 256 宽 reader
（C0 0.0805 vs DCC-L s0 0.0785，家族均值 0.0760），即"压缩 reader"在本轮自己的对照里值 0.002–0.0045。
若两者可加，`A + 最宽合规 reader`（160 宽，总量 **488,817**，是 500k 上限下最大的宽度）应到 ~0.072。
预注册规则（`LEDGER.md`，写在启动之前）：仅当 A160 两 seed best-valid 均值 ≤0.0735 且两个 seed
都优于 A 的同 seed 值时才冻结并做第二次 reporting-only test 读取；否则不读 test。

| arm | 参数 | seed | best-valid | ep | 结论 |
|---|---:|---:|---:|---:|---|
| A160 | 488,817 | 0 | 0.080073 | 423 | 比 A 同 seed 差 +0.00415 |
| A160 | 488,817 | 1 | 0.081810 | 330 | 比 A 同 seed 差 +0.00723 |
| A160 家族均值 | | | **0.080942** | | **未通过 ≤0.0735 的预注册门**；不读 test |

**结论：reader 宽度与 A 的算子不可加，方向与假设相反**——参数更多（488,817 > 460,017）、
其它全同，valid 反而差 0.0042–0.0072，且退回 C0/K 的水平（0.0809）。这与"压缩 reader 只是弱点"的
读法冲突，说明 A 的收益依赖一个较窄读出（也说明 C0 vs DCC-L 的差不能简单归给 reader 宽度）。
按预注册规则，**第二次 test 读取没有发生**；本轮只有 A 家族的 test 数字。

## 10. ERRATUM 与两个补救臂（2026-10-25，本文件未改，只追加）

Route A 的 `MixA` 把 key-energy 项 `0.5*‖k‖²` 以 `unsqueeze(-1)` 广播到了 **query** 轴，
行 softmax 精确抵消。因此本文件里 A 的成绩对应的是 **dot 打分 + 关系条件内容门 + AdaRMSNorm**，
不是 `(q·k − ½‖k‖²)/√d`。**所有数字保留**；撤回的只是机制解释（§0 表格“幅值修正+门控作为
一个包”、§3 的“组件包”、§8 的“拆分幅值项与门控”这一计划）。详见 `ERRATUM.md`。

两个补救臂（真 L2 打分 L2G、门控权重归一化 GN），同 9,000 行划分、同初态 sha、同配方：

| arm | best-valid@ep | 持续窗口 Δ vs A（ep500/600） | 内部留出 1,000 | Δ vs A（CI） |
|---|---:|---|---:|---|
| `ho_A_s0`（历史） | 0.081299@364 | — | 0.114666 | — |
| `l2g_A_s0` | 0.080472@427 | −0.0016 / −0.0015 | 0.115199 | +0.000533 [−0.0029, +0.0040] |
| `gn_A_s0` | 0.081915@405 | −0.0002 / −0.0002 | 0.120440 | +0.005774 [+0.0015, +0.0102] |

读法：真 L2 打分在 valid 上略好、在留出上无差别（点估计反向、CI 跨零）→ 不采纳、不买第二 seed；
门控权重归一化在 valid 上持平、在留出上**退化 0.0058**（CI 不含 0，训练正常）→ 支持“门控的可变总增益
是有效机制”。两者都不改变 test 上的 DCC-L 锚（0.0673，本轮未读 test）。成本 2.008 A100·h（上限 2.0，
超 0.4% 已在 `LEDGER.md` 明写）。下一决定：停止这条线（见 `ERRATUM.md` §6）。
