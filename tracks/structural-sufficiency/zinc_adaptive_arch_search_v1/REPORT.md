## 0. 一句话结论

**本轮没有做出比 DCC-L 更强的新主体；但它给出了一条比"又输一次"更有用的结论：
可分辨的差异全部来自"内容/信息量"，而"编排/组合方式"的改动全部落在噪声里。**

支撑这条结论的是三组同 seed、同参数、同初值的对照（量级表见 §3.4 / Q3b）：

| 改动 | 类型 | ΔMAE（正 = 变差） | CI 排除 0 |
|---|---|---:|---|
| pair 内容改图级池化（S2 vs S1） | 编排（抹掉局部性 = 信息损失） | **+0.0107** | 是 |
| 换 pair 内容主体（SQBC vs BOSI-B） | 内容（同时缺矩 bank，属复合差异） | **+0.0079** | 是 |
| 删掉 moment bank（A0M0 vs A0） | 内容 | **+0.0053** | seed0 是 |
| 加目标条件化（A1 vs A0） | 编排 | +0.0008 | 否（符号翻转） |
| 加 pair-interaction 通道（A0 vs B） | 编排 | −0.0002 | 否（符号翻转） |

而"噪声"是可测的：**BOSI 这一族同一个主体、同一份代码，seed 0 → 0.082405、
seed 1 → 0.076949，极差 0.00546** —— 大于任务书定义的 0.003"强信号"门槛，
也大于本轮所有编排级效应。在只存在 seed 0/1 两份 SSL 编码器的条件下，
"再训一个主体"无法回答"它是否好 0.003"，因此本轮在 4.65 GPU·h 处主动停止
（软预算 14），而不是把预算花完（见 §4）。

具体：

* **方向 A（BOSI-QP，pair 图元条件化）：`STOP_A`**。3 个对照 × 2 个 seed，
  符号全部翻转、95% CI 全部跨 0（`A1−A0`：−0.0015 / +0.0030；
  `A1−B`：−0.0043 / +0.0054；`A0−B`：−0.0027 / +0.0024）。
  A1 seed-0 的 0.0782 是"一个极端分子 + 一个好 seed"的合成结果，不可复现。
* **方向 B（SQBC，独立 lean pair-ownership 主体）：`STOP_B`**。S1 = 0.090343，
  比 BOSI-B 差 **+0.0079**（CI [+0.0031, +0.0133]，所有分组同向）——
  这是本轮唯一一个 CI 排除 0 的**主体级**差异（除了它自己的池化对照）。
  同时 `S1 − S2 = −0.0107`（CI 排除 0）：**同一份 pair 内容必须局部 ownership 池化，
  图级平均会输 0.011**。
* **方向 C（图级结构组合/块组织）：不启动**。S2 的结果（图级池化是过强而非过弱）
  直接否掉了它的启动前提。
* **附加消融（A0M0，moment bank 置零）：`MOMENT_ESSENTIAL`**。+0.00527（两 seed 同向，
  seed 0 CI 排除 0）；损失集中在 unseen（+0.0187）与 rings≥4（+0.0165）。
* **本轮最强单次成绩**来自一个"老"主体：BOSI-B seed 1 = **0.076949**（新训，
  0.384 GPU·h），比 DCC-L seed 0（0.078537）还好——但这是 seed 运气，
  不是机制。（BOSI-B 两个 seed：0.082405 / 0.076949。）

## 1. 边界与合规

* **official test**：`cache/ad_test.pt` 在本轮从未被打开；所有代码路径只 `load_cache("train"/"valid")`。
  `summary_*.json` 每个文件都写着 `"official_test_loaded": false`。
* **结构禁令**：没有多轮 node/edge 消息传递、没有 attention、没有 GNN/Transformer 递归。
  A 方向是**一次**静态 per-pair 前馈（`P[v,e] = Σ_{f≠e} Φ(...)`，共享 Φ），
  B 方向是**一次**静态 per-(centre,bond-pair) 前馈 + 局部求和。
  两张计算图都不含任何"从邻居再取邻居"的迭代。
* **参数上限**：A1/A0/A0M0 = 488,321；A3（未训）= 457,185；SQBC = 381,505；
  BOSI-B = 473,889。全部 ≤ 500,000。
* **配方**：R0 逐字冻结，`total_updates = 47,400` 在每次 `train.json` 里可查；
  没有 lr/wd/dropout/EMA/horizon 扫描。
* **公平性**：同一 seed 下，所有 BOSI 族臂的公共参数**逐张量 bit-identical**
  （`initial_state_sha256` 相同，A1/A0 都在 `3ffb8a59…`(s0) / `4c3850f2…`(s1)；
  A0M0 与 A0 同 seed 也相同），SSL 初始化来自同一 `pretrain_encoder_s{0,1}.pt`，
  batch 顺序由同一 seed 决定，valid 只用于逐 epoch 评估与 best 选择。
* **不变性/单元 gate**（CPU，正式训练前全部通过）：
  A 组 11/11（`cpu_checks.json`）、B 组 12/12（`cpu_checks_b.json`）、
  C 组 10/10（`cpu_checks_c.json`）。覆盖参数审计、relabel/bond-order/batching
  不变性、空邻域、跨分子泄漏、梯度有限性、初值一致性、短训可下降、checkpoint 往返。

## 3. 三个方向的判决

### 3.1 方向 A — BOSI-QP：`STOP_A`

**设计**：A1 = 冻结 BOSI-B + 一条并联分支
`P[v,e] = Σ_{f≠e} Φ([x_{v,e}, x_{v,f}, |x_{v,e}−x_{v,f}|, x_{v,e}·x_{v,f}])`
（Φ: 128→64→32，追加到未改动的 Side 输入之后，新增列零初始化 ⇒ step-0 前向
与 BOSI-B **逐位相同**）。A0 = 匹配零假设：把目标半键状态换成"伙伴集合均值"。
两者参数、初值、配方、seed 全同。

**同 seed 配对结果**（负号 = 前者更好）：

| 对照 | seed 0 | seed 1 | 符号 | CI 排除 0 |
|---|---:|---:|---|---|
| A1 − A0（目标条件化是否有效） | −0.001500 | +0.003017 | **翻转** | 否 / 否 |
| A1 − B | −0.004250 | +0.005428 | **翻转** | 否 / 否 |
| A0 − B | −0.002749 | +0.002412 | **翻转** | 否 / 否 |

`drop-row172` 与 headline 几乎同值（|Δ| ≤ 0.0021），所以这**不是** row 172 造成的，
而是主体在两个 seed 之间本身就在跳：**BOSI-B 自己** seed0 0.082405、seed1 0.076949，
极差 **0.00546**。

**判决**：`STOP_A`。失效类别 **EVIDENCE_INSUFFICIENT**（不是实现失败、不是泛化失败）：
这个主体族达不到分辨 0.003 级机制效应的统计功效，继续在它上面加图元
（A2/A3）或加 seed 都无法给出可辩护的结论。A2/A3 已取消。

> 记账说明：`aas_analyze.py` 里预注册的机械判定会拿"最后一个 seed 的 A1"
> 去和冻结的 `B_s0` 比（seed 错配），它对 A1_s1 给出 `STOP_A`；
> 本报告的裁判依据是上表**同 seed 配对**，两者结论一致但理由不同。
> 该函数已补上 `paired_by_seed` / `same_arm_seed_spread` /
> `contradiction_verdicts` 三个块，`contradiction_verdicts` 对三个对照都输出
> `SIGN_FLIP_ACROSS_SEEDS`。

### 3.2 方向 B — SQBC：`STOP_B`（水平失败 + 一个干净的分组位置结论）

**设计**（独立主体，不继承 BOSI 的任何分支）：bond token 双向投影
`u_e = W_q b_e, w_e = W_k b_e`（96→32）；在中心原子 v 处
`Φ([u_e, w_f, u_e·w_f, |u_e−w_f|, a_v, rel_onehot, log1p n])`（229→96→32）；
`P[v,e] = Σ_{f≠e} w_e,f`；键侧 `[b_e, P_u+P_v, |P_u−P_v|, P_u·P_v, bond_feat, log1p n_junc]`
（200→192→96）；reader `[Σc, Σc², Σa, Σa², g]`（417→288→288→1）。381,505 参数。
三个臂 S1/S0/S2 参数与初值**逐位相同**，唯一差别是编码的不变量与池化位置。

| run | 池化/编码 | best_valid | vs B_s0 | vs S2 |
|---|---|---:|---:|---:|
| S1 | 局部 ownership + **有序** pair | 0.090343 | **+0.007937** [+0.0031, +0.0133] | −0.010731 |
| S2 | **图级均值** + 同一份有序 pair 内容 | 0.101074 | +0.018669 | — |
| S0 | 对称不变量（有序性对照） | 未训（规则不触发） | — | — |

* `S1 − S2 = −0.0107`，CI [−0.0187, −0.0038]，ordinary −0.0066、`rings≥4` −0.0172、
  unseen −0.0060 全组同向 → **pair 内容必须留在局部；图级平均把它抹成常数，输 0.011**。
* `S1 − B_s0 = +0.0079`，所有分组一致变差 → lean pair-ownership 主体在任何分组
  都不如 BOSI-B，差距主要在 unseen（+0.0147）与 ordinary（+0.0057）。

**判决**：`STOP_B`。失效类别 **INDUCTIVE_BIAS**：键 token + 中心原子 + 关系 one-hot
不足以表达"这个键处在什么环境里"——BOSI 的 moment bank 与半键状态才是那个内容。
S0 不买（预注册规则只在水平有竞争力时才需要"有序 vs 对称"）。

**与历史证据合起来的分组位置结论**（本轮最有价值的机制结论）：
dual-channel 轮测得局部 ownership 优于匹配 null（`L−C = −0.0038`），但同轮 `L − P3B = +0.0023`；
本轮 `S1 ≫ S2`（局部 ≫ 图级）但 `S1 ≪ B`。三者一致地说明：
**池化位置取决于被池化的对象**——数量少、语义承载重的 junction 内容适合作图级统计
（P3Null 的 `n_b · mean_g(w)`），数量巨大、高度局部的 pair 内容必须留在局部；
"把 pair 内容提到图级"是灾难，而"把 junction 内容按 ownership 局部化"也不是性能杠杆。

### 3.3 方向 C — 条件启动，未启动

启动前提是"有证据表明图级结构组合未被表达"。S2 给出的是**反例**：
图级池化已经过强（−0.011），而不是缺失。故不启动。

### 3.4 附加：A0M0（moment-bank 消融）

A0 与 A0M0 在参数（488,321）、初值、配方、seed 上完全相同，唯一差别是
A0M0 在每个 forward 里把 BOSI 的 moment 块 `M` 置零（Side 输入宽度不变），
用来回答"有了新的 pair-interaction 通道之后，moment bank 是否还是载荷"。
预注册规则：`≤ +0.001` = MOMENT_REDUNDANT，`≥ +0.003` = MOMENT_ESSENTIAL。

`A0M0 − A0`：seed 0 **+0.008619**（CI [+0.0006, +0.0187]，排除 0；W20 +0.0099、
T100 +0.0102、final +0.0101），seed 1 **+0.001921**（CI [−0.0025, +0.0063]）；

1. 消融臂的 **train@best 反而更差**（0.0191/0.0114 vs 0.0135/0.0075）——

3. 幅度随 seed 变化（+0.0086 / +0.0019），与 §4 的功效论证一致：即使是这样
   一个"真实"的效应，2 seed 下的区间也宽到 ±0.004。

## 4. 为什么这轮没赢：功效分析（本轮的核心科学产出）

本轮把"能不能分辨"这件事本身变成了可测量的东西。

1. **BOSI 族的 seed 地板**：同一个主体、同一份代码、同一个 commit，
   seed 0 → 0.082405，seed 1 → 0.076949。极差 **0.00546**。
   任务书定义的"强信号"门槛是 0.003 —— **比这个族自己的噪声还小**。
2. **两 seed 配对对照的可分辨极限**：本轮 6 个同 seed 配对差值的绝对值分布在
   0.0015–0.0054，95% CI 半宽约 0.005–0.011。按双侧 5%、80% 功效粗算，
   2 seed 配对对比只能分辨 **≳0.006** 的效应。
   历史 DCC-L vs P3Null 的家族差是 0.0048，之所以可信，是因为它是 **4+4 seeds**
   （DCC-L sd 0.0021、P3Null sd 0.0030，均值标准误 0.0011/0.0015）。
3. **可用的 seed 上限是 2**：SSL 预训练编码器只存在 `pretrain_encoder_s0.pt` /
   `s1.pt`（seed 2 一跑就 `FileNotFoundError`）。所以在不新增 SSL 预训练成本的前提下，
   任何单主体都不可能做到 4 seed。
4. 结论：**在现有资源与冻结配方下，"再训练一个主体"无法回答"它是否比 BOSI-B 好 0.003"**。
   这正是任务书要求的"无高价值假设时应 STOP"的情形，而不是"预算还剩就再跑几个"。

（`train@best` 一列是这条论证的另一个侧面：所有臂都能把 train 拟合到 0.008–0.016，
final 时到 5e-4。模型容量不是瓶颈，valid 的差距来自支撑/泛化，与 DCC-L bottleneck
轮"82% 误差来自低支撑环境"的结论一致。）

## 6. 七问回答

### Q1 做出了什么？

* **一个可复用的、带统计裁判的架构搜索脚手架**：`aas_models.py`（4 个新主体臂）、
  `aas_sqbc.py`（独立主体 + 2 个匹配对照）、`aas_train.py`（R0 冻结训练器，
  记录 commit / 初值 hash / 参数审计 / 精确 updates / GPU·h / checkpoint hash）、
  `aas_freeze.py`（冻结每个 run 的预测与 hash）、`aas_analyze.py`
  （配对 bootstrap、10 个分组、同 seed 配对、seed 极差、反例判定）、
  33 条 CPU gate（11+12+10）。
* **9 个正式训练结果**：4 个本轮新主体（A1/A0 × 2 seed、S1、S2）、
  1 个匹配基线（B_s1）、2 个消融（A0M0 × 2 seed），全部在 ≤500k 参数、无递归、
  R0 配方下完成。
* **一条负结果 + 一条正面机制结论**：
  * 负：目标条件化的 pair 图元、lean pair-ownership 主体都在可分辨性上失败；
    "pair 通道能取代矩统计"被消融否掉（+0.0053）。
  * 正：**池化位置与内容匹配**（junction→图级、pair→局部）是一个方向明确、
    CI 排除 0 的效应（S1 − S2 = −0.0107），它与 dual-channel 轮的 `L−C` 方向一致，
    并且解释了为什么 P3Null 的"朴素"图级均值能打赢更"讲究"的 ownership 局部化。

### Q2 最强机制？

**在本轮测过的所有新机制里，最强的是"局部 ownership 求和"本身**——
S1 比 S2 好 0.0107，是唯一 CI 排除 0 的机制级对照。但它只是**不让内容被抹平**，
不足以把主体推到 DCC-L 的水平（S1 比 BOSI-B 差 0.0079，比 DCC-L 家族差 0.0144）。

**若问"哪一个计算成分最值钱"，本轮给了一个可量化的答案：BOSI 的矩统计（M, n）。
把它置零代价 +0.0053（unseen 组 +0.0187），比任何编排改动都大。**

**在整个 track 的历史证据里，最强的机制仍然是 DCC-L 的"junction 对象 +
ownership 路由 + 双通道（全局/局部）composer"**（4 seeds 0.075990），
其次是 P3Null 的"junction 内容的图级均值 × 局部计数"（4 seeds 0.080761）。
本轮没有推翻这个排序，只是把它解释得更细：DCC-L 赢在**内容**（junction 对象带深度/
所有权信息）与**两条互补通道并存**，不是赢在"局部化"这个动作本身。

### Q3 哪些旧判断被改变？

1. **"矩统计可以被更好的 pair 编码取代"——被否。** 在已经加上 pair-interaction
   通道的 A0 上把矩块置零，代价 +0.0053（且 train@best 变差 40%），损失集中在
   unseen/rings≥4。矩 bank 与 pair 通道是**互补而非替代**关系。
2. **"单 seed 的 ≤0.004 差异可以当机制信号"——被推翻。** BOSI-B 自己两个 seed
   就差 0.0055；A1_s0 的 0.0782（曾被机械规则判为 `DEEPEN_A`）在 seed 1 上变成
   0.0824。本 track 历史上所有单 seed 判决（含 `bosi_architecture_v0`、
   `bosi_joint_moment_v1` 的若干"显著"分组、本轮的 seed-0 初判）都受同一问题影响。
3. **"row 172 是扰动项"——被强化为"主效应"。** 它的 |AE| 摆动幅度（5.0–13.6）
   足以覆盖任何一个 0.004 级结论；`drop-row172` 必须与 headline 并列，而不是附录。
4. **"局部 ownership 是性能杠杆"——被削弱为"池化位置必须匹配内容"。** 局部化
   对 pair 内容是刚需（+0.011），对 junction 内容则不是（P3Null 的图级均值更强）。
5. **"query/目标条件化（target-aware pair）是下一个机制"——被否。**
   `A1−A0` 在 2 个 seed 上符号翻转，均值 +0.00076。
6. **"pair 内容可以作为独立主体"——被否。** 它比 moment/半键状态的主体差 0.008，
   且差距集中在 unseen（+0.0147），说明缺的是"环境表达"而不是"编排方式"。

### Q3b 一张量级表（同 seed、同参数、同初值的可解释对照）

| 改动 | 类型 | ΔMAE（正 = 变差） | CI 排除 0 |
|---|---|---:|---|
| pair 内容改图级池化（S2 vs S1） | 编排（抹掉局部性） | **+0.0107** | 是 |
| 换 pair 内容主体（SQBC vs BOSI-B） | 内容（同时缺矩 bank，属复合差异） | **+0.0079** | 是 |
| 删掉 moment bank（A0M0 vs A0） | 内容 | **+0.0053**（+0.0086/+0.0019） | seed0 是，seed1 否 |
| 加目标条件化（A1 vs A0） | 编排 | +0.0008 | 否（符号翻转） |
| 加 pair-interaction 通道（A0 vs B） | 编排 | −0.0002 | 否（符号翻转） |

**这张表是本轮的主要科学产出**：在"显式结构统计"范式内，可分辨的差异都来自
**内容/信息量**（0.005–0.011），而"谁对谁做什么"的编排改动全部 ≤0.003 且不可分辨。
唯一显著的编排效应是**把内容放到错误的池化位置**（+0.0107），它本质上是信息损失。

### Q4 差距原因？

DCC-L 4-seed 均值 0.075990，本轮最强 2-seed 新主体 A0 = 0.079509（差 **+0.00352**）。
按证据强度排序，原因是：

1. **统计功效（首要）**：2 seed 可分辨极限 ≈0.006，而差距是 0.0035 ——
   在现有 SSL seed 预算下**无法判定**新主体是否真的更差。这是"没赢"的第一原因。
2. **内容而非结构**：量级表（Q3b）显示，除"把 pair 内容提到图级"这个信息损失外，
   所有"编排"类改动（目标条件化、加通道）效应都在 ±0.003 内摆动并符号翻转；
   造成 >0.005 差异的全是**内容**（SQBC 的 pair
   内容 → +0.0079 更差；BOSI 的 moment/半键内容 → 与 DCC-L 的 junction 内容差 0.0035）。
   这与"显式结构统计"范式的假设一致：**可用的信息量决定上限，组合方式只决定能否接近它**。
3. **支撑结构**：所有臂的误差都集中在 `radius2 低支持/存在未见`（0.14–0.18）与
   tail（0.26–0.43），而 ordinary 组停在 0.062–0.067。train@best 只有 0.008–0.016、
   final 到 5e-4 —— 不是欠拟合，是**低支撑环境的外推**。要把 overall 推到 0.05x，
   需要的是"在 1 万条训练分子里对低支撑环境更有效的归纳偏置"，而本轮所有机制都
   在 ordinary 上打转。
4. **单分子主导**：row 172 一行就能值 0.009，使任何 <0.005 的结论都不稳。

### Q5 如果只允许再做一次实验，做什么？

**做功效，而不是做机制。** 具体地：**为 seed 2 与 seed 3 预训练两份 train-only masked
SSL 编码器**（成本量级 ~0.2–0.5 GPU·h/份，开工前须先核对 `structure-contribution`
轮的真实记录，不要凭记忆），**然后把 BOSI-B 与 DCC-L(B-R0) 各补到 4 seed 的同协议
重训（2 主体 × 2 新 seed = 4 个 run，~1.6 GPU·h）**。

理由：本轮所有不确定性都来自"2 seed 无法分辨 0.003"。这次实验不引入任何新结构，
只把已有的、最强的两个主体放到**同一个 4-seed 功效**下，直接回答
"BOSI 族与 DCC-L 的 0.0035 差距是真的吗"。它一次性修好本 track 的测量工具，
比再赌一个主体有价值得多（也让后续任何新主体有可信的对照基线）。

明确**不**做的事：不再改 width/Φ 维度/reader 宽度去"救"A 族；不再给 row 172
或任何单分子加规则；不再在 2 seed 下宣称 <0.005 的差异。

### Q6 论文创新可能？

* **可发表的负结果 + 方法论**："在显式结构统计范式内，单 seed 的 0.004 级架构差异
  不可复现；同族 seed 极差（0.0055）大于文献中大量被报告为'改进'的效应。"
  配一个 33-gate + 10 分组 + 配对 bootstrap + `drop-top-1` 的评估协议，
  这是目前 ZINC 小数据子集上少见但必要的严格性。
* **池化位置匹配内容**（`junction→图级`、`pair→局部`，0.0107 的分组级证据）：
  一个可检验的、跨主体的设计律，而不是又一次"我们的模块更好"。
* **一个分子的杠杆效应**：single-molecule influence（row 172 值 6–17% 的总 MAE）
  对长尾分子性质回归的评测启示。
  这三条都不需要新 SOTA，且本轮数据已足够支撑。
