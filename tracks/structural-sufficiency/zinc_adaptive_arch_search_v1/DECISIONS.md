## D1 — 方向 A 第一步：BOSI-QP（A1）与匹配 null（A0）

**Hypothesis**
BOSI 的伙伴矩是"先聚合再使用"：`M[v,e] = Σ_f T_k(x[v,f])`，目标键状态只在之后
的 Side 里才与它相遇。若把目标半键状态放进**每一个 pair 的共享非线性编码**（聚合之前），
局部组合规则可以以更少的样本被学到，从而改善 official-valid MAE。

**Intervention**（`code/aas_models.py`，commit `451fc8d`）
`P[v,e] = Σ_{f≠e} Phi([x[v,e], x[v,f], |x[v,e]-x[v,f]|, x[v,e]·x[v,f]])`，
`Phi = 128→64→32`（SiLU，共享），`P` 追加到**未改动**的 BOSI-B Side 输入
（617→649；新增 32 列零初始化）。其余（矩块、closure、Side/Compose/Reader、配方、
SSL 初始化、batch 顺序）逐项不变。488,321 参数。

**Control**（A0）
同参数、同初始化、同优化器、同数据顺序；只把 `q_e = x[v,e]` 换成**同一伙伴集合的均值**
`q_null[v,e]`。A0 仍能看到伙伴内容（经 Phi 的非线性 + 与均值的交互），所以它隔离的
正是"目标键自己是否参与每个 pair 的计算"，而不是"是否多做了一次非线性编码"。

**CPU 门控**（`analysis/cpu_checks.json`，11/11 PASS）
步 0 前向与 BOSI-B **逐位相同**（max\|Δ\|=0.0）；A1/A0 除新分支外初始张量与 BOSI-B
逐张量相同；`P` 为 0 的比例 8.25%（= 度 1 端点的空伙伴集，严格 0）；伙伴行置换下
`P` 差 3e-8；扰动单个目标半键只移动它自己的 `P` 行（A0 的自身行不动，跨集合泄漏 0）；
`Phi` 在 step 0 梯度为 0、step 1 起非零有限；40 步拟合 loss 1.54→0.61。

**Observation**（official-valid 1,000，`analysis/tables_a.md`）

预注册判定：`A1−B = −0.004250`（≤−0.003）、`A1−A0 = −0.001500`（≤−0.001）、
W20 −0.00383、T100 −0.00364、ordinary −0.00143（未退化）→ **DEEPEN_A**。

**但是**（事后诊断，先于下一笔采购，`per_molecule_a.csv`）：

|---|---:|---:|---:|

row 172（`y=−20.34`，valid 里 \|y\| 最大）单个分子贡献 A1−B 的 −4.388 AE 差；
去掉它以后 **A1 与 B 在其余 999 个分子上相同（+0.0001）**。A1 对 row 172 的
AE 从 B 的 4.4 降到 0.03 量级——这是真的（不是错位），但它是一个分子。
配对 bootstrap 的 95% CI 全部跨零（A1−B best `[−0.0151,+0.0028]`），
逐分子更优比例 0.495。

**判读（不修改预注册阈值）**
1. `DEEPEN_A` 的机械判定成立，但**它不构成性能突破**：整体增益由一个极值分子决定，
   其余 999 个分子的增益 ≤0.0001。按轮次规则（§10）这属于
   `EVIDENCE_INSUFFICIENT`（overall 被极少数分子搬动），不允许用它宣称强模型。
2. A1−A0 = −0.0012（去 172）方向在两个 checkpoint 一致，但小于该 split 的 seed 噪声
   （本 track 实测 0.003–0.004），只能算 **机制线索**，不是可复现收益。
3. **主要机制是"前聚合共享非线性内容编码"**（A0 也拿到 −0.0027 overall / +0.0014 去172），
   目标条件化只在其上再给 −0.0012。
4. 因此**不**在 A1 家族上做容量/宽度加深（A2/A3 暂缓），下一笔买独立主体（方向 B），
   因为 A1 的"提升"无法作为进一步深化的可靠基准。

**Alternative explanation**
若 A1 ≈ A0 且两者都优于 B，则收益来自"前聚合的非线性内容编码"，而不是目标条件化。
若 A1/A0 都劣于 B，需先排除输入尺度/优化异常（已由 C5 型尺度检查与 step-0 逐位一致排除），
之后才判该机制无益。

**Decision（seed 0 时点）**：`MECHANISM_SIGNAL_ONLY`。不买 A2/A3；A1_s1 / A0_s1
按原计划继续（这恰好也是预注册的 cross-seed 检验）。

## D2 — 方向 B：SQBC（S1 有序 vs S0 对称）

**Hypothesis**
DCC-L 的强项是"learned junction 内容 + 真实 ownership 汇入键"；BOSI 的弱项是没有
把 pair 当作**有角色的有序对象**。若把键级 pair 计算做成**目标键有显式角色**的共享
非线性算子（S1），并且只保留一次静态组合，则比"同信息但目标盲"的对称楔形（S0）
更能改善低支持/未见局部环境。

**Intervention**（`code/aas_sqbc.py`，commit `4ae20ac`）
独立无递归主体：`u_e=Wq b_e, w_e=Wk b_e`（96→32），对每个共享中心的有序键对
`(e,f)` 计算 `w_ef = Phi([u_e,w_f,u_e·w_f,|u_e-w_f|, a_v, rel, log1p n])`，
`P[v,e] = Σ_{f≠e} w_ef`，`c_e = Compose([b_e, P_u+P_v, |P_u-P_v|, P_u·P_v, bond_feat,
log1p n_junc])`，读出 `[Σc, Σc², Σa, Σa², global33] → 288 → 288 → 1`。381,505 参数。
没有 junction encoder、没有 384 维矩 bank、没有图级关系通道、没有 attention。

**Control**（S0）
**逐张量相同的初始状态**（`initial_state_bit_identical=true`），只是 pair 输入换成
无序对的基本对称不变量 `[u+w, |u-w|, (u+w)|u-w|, u·w]`——这是 `{u,w}` 的完全不变式。
因此两支的差别**只在**"目标键是否有非对称角色"，参数/容量/初始化/配方完全相同。

**CPU 门控**（`analysis/cpu_checks_b.json`，10/10 PASS）
参数形状与初值逐位相同；S1/S0 前向不同；角色互换（诊断开关）下 S1 的 `P` 变化
>1e-3 而 S0 **逐位不变**；空伙伴集 `P=0` 且全有限；原子重标号/键反向/键序/批次重组
不变性 ≤1.5e-7（**键反向最初失败 3.2e-3，因为把 `P_u,P_v` 放进了不对称槽位**；
已改为只在键级使用对称组合，见 `aas_sqbc.py` 注释——这是本轮唯一一次实现修复，
在正式训练前完成）；所有模块梯度有限非零。

**Observation**
见 `REPORT.md` / `analysis/summary_b.json`。

**Decision**：待定。

## D2 — 方向 B（SQBC，独立主体）：**STOP_B**（水平失败，但给出一个干净的分组位置结论）

预注册规则见 `configs/aas_b1.json`。两臂同参数（381,505）、同初值（bit-identical）、
同配方同 seed；S1 把 pair 内容按 ownership 聚到目标键，S2 把**同一份** pair 内容
按图级均值池化（P3-Null 形式，三个 32-d 槽位宽度完全一致）。

| run | params | best | W20 | T100 | final | train@best | GPU·h |
|---|---:|---:|---:|---:|---:|---:|---:|
| S1_s0（局部 ownership，有序 pair） | 381,505 | **0.090343** | 0.091456 | 0.091475 | 0.091518 | 0.00990 | 0.321 |
| S2_s0（同一内容，图级池化） | 381,505 | **0.101074** | 0.101665 | 0.101727 | 0.101720 | 0.01640 | 0.453 |
| B_s0（冻结参照，moment 主体） | 473,889 | 0.082405 | 0.083203 | 0.083241 | 0.083242 | 0.00854 | 0.373 |

* `S1 − S2 = −0.010731`，95% CI [−0.0187, −0.0038]，**排除 0**，且 ordinary
  (−0.0066)、`rings≥4` (−0.0172)、unseen (−0.0060)、worst10 (−0.1258) 全组同向 →
  **pair 内容必须按 ownership 局部池化；图级平均把它抹成常数，损失 0.011**。
* `S1 − B_s0 = +0.007937`，CI [+0.0031, +0.0133]，**所有分组一致变差**
  （ordinary +0.0057、unseen +0.0147、`rings≥4` +0.0020）→ 低于门槛 0.002 的
  "更差"是语义上的：它比 BOSI-B 差、比 A0 差 0.010，比 DCC-L 家族差 0.014。

**Decision**：`STOP_B`。
1. **水平失败**：lean pair-ownership 主体（无 moment bank、无半键状态、无深度信息）
   在任何分组都不如 BOSI-B。缺的不是不变性（B 组 12/12 gate 已排掉实现问题），
   而是**内容**：键 token + 中心原子 + 关系 one-hot 不足以表达"这个键在什么
   环境里"；BOSI 的 moment bank 与半键状态才是那个内容。
2. **机制结论（保留）**：`POOLING_LOCATION_MATTERS`，方向为"局部 ownership 更好"。
   这与 dual-channel 轮的 `L−C = −0.003830`（局部 ownership 优于局部 null）同向，
   **但同时**那一轮的 `L−P3B = +0.002313` 说明"ownership 局部池化"本身不是性能
   杠杆：P3-Null 的图级 junction 均值仍然更强。两轮合起来：**池化位置取决于被池化
   的对象**——junction 内容（语义对象、数量少）适合图级统计，pair 内容（数量巨大、
   高度局部）必须留在局部；把 pair 内容提到图级是灾难（−0.011），把 junction 内容
   按 ownership 局部化也没有收益（+0.002 vs P3B）。
3. S0（对称对照）**不跑**：预注册规则只在水平有竞争力时才买"有序 vs 对称"，
   S1 已比 B 差 0.008，该对比没有决策价值。
4. 方向 C（图级结构组合/块组织）**不启动**：它的启动条件是"有证据表明图级结构
   组合未被表达"，而本轮 S2 恰好是反例——图级池化已经是过强而非过弱。

**Failure class**：`INDUCTIVE_BIAS`（pair content 的表达力不足）+ `EVIDENCE_INSUFFICIENT`
（S1 只有 1 个 seed，但 +0.008/全组同向不需要更多 seed 就能否掉）。

## D1c — 补齐 BOSI-B seed 1 匹配基线后的最终裁定：**STOP_A（无可分辨效应）**

BOSI-B 在 seed 1 上必须重训（历史 B_s1 属于 Fit8k/Locked 协议，不可用），
成本 0.384 GPU·h。结果把 stage A 的判读彻底改写：

| 对照 | seed 0 | seed 1 | 均值 | 符号 |
|---|---:|---:|---:|---|
| A1 − A0 | −0.001500 | +0.003017 | +0.00076 | 翻转 |
| A1 − B | −0.004250 | +0.005428 | +0.00059 | 翻转 |
| A0 − B | −0.002749 | +0.002412 | −0.00017 | 翻转 |

所有 95% CI 都跨 0；`drop-row172` 与 headline 几乎同值（±0.001），说明这不是
row 172 造成的，而是**两个 seed 之间主体本身的差异**：

* BOSI-B 自己：seed0 **0.082405**、seed1 **0.076949** → 同主体 seed 极差 **0.00546**。
* 也就是说，BOSI 这一族单 seed 的噪声（0.0055）**大于本轮任何机制效应**，
  也大于任务书定义的"≥0.003 强信号"门槛。只有 4-seed 协议（DCC-L sd 0.0021）
  才有足够功效分辨 0.003 级差异。

**Decision**：`STOP_A`。方向 A（query/pair 条件化的图元）**没有可分辨效应**，
无论是否带目标状态；A1_s0 的 0.0782 是"一个分子 + 一个好 seed"的合成结果。
3 个 seed 的 A 家族均值（0.0797 / 0.0800 / 0.0824 / 0.0769...）与 BOSI-B 不可区分。

**由此产生的元结论（写入报告）**：本 track 未来任何 <0.003 的单 seed 结论都不可信；
`bosi_architecture_v0` / `bosi_joint_moment_v1` / 本轮全部单 seed 判决都受同一问题
影响。DCC-L（4 seeds）与 P3Null（4 seeds）的历史比较之所以可信，只因为它是 4+4。

**Failure class**：`EVIDENCE_INSUFFICIENT`（不是实现失败、不是泛化失败）。

## D3 — A0M0（moment-bank 消融）：**MOMENT_ESSENTIAL**

预注册（`configs/aas_a3.json`，GPU 前冻结）：`mean_seeds(A0M0 − A0) ≤ +0.001` →
MOMENT_REDUNDANT；`≥ +0.003` → MOMENT_ESSENTIAL。A0M0 与 A0 参数（488,321）、初值、
配方、seed 全同，唯一差别是每次 forward 把 BOSI 的矩块 `M` 置零。

| | seed 0 | seed 1 | 均值 |
|---|---:|---:|---:|
| A0 | 0.079656 | 0.079361 | 0.079509 |
| A0M0 | 0.088275 | 0.081282 | 0.084779 |
| **Δ(A0M0−A0)** | **+0.008619** [+0.0006, +0.0187] | **+0.001921** [−0.0025, +0.0063] | **+0.00527** |

两个 seed 同向，seed 0 的 95% CI 排除 0 → `MOMENT_ESSENTIAL`。

**结论**：
1. 新加的 pair-interaction 通道**没有取代**矩 bank：删掉矩块连 train@best 都变差
   （0.0191/0.0114 vs 0.0135/0.0075）→ 是信息缺失，不是优化噪声。
2. 损失集中在 `radius2_any_unseen`（+0.0187）与 `rings≥4`（+0.0165），ordinary 仅
   +0.0055 → 矩块承载的是"环境表达"，与 D1c/D2 的诊断一致。
3. **本轮的量级排序**（同 seed、同参数、同初值的可解释效应对照）：

   | 改动 | 类型 | ΔMAE（正 = 变差） |
   |---|---|---:|
   | 删掉 moment bank（A0M0） | 内容 | **+0.0053**（+0.0086 / +0.0019） |
   | 换 pair 内容主体（SQBC vs BOSI） | 内容 | **+0.0079** |
   | pair 内容改图级池化（S2 vs S1） | 编排 | **+0.0107** |
   | 加目标条件化（A1 vs A0） | 编排 | +0.0008（符号翻转） |
   | 加 pair-interaction 通道（A0 vs B） | 编排 | −0.0002（符号翻转） |

   即：**内容（信息量）解释 0.005–0.008 的差距，编排（谁对谁做什么）解释 ≤0.003
   且不可分辨**——唯一例外是"把内容池化错位置"（0.0107），那是把信息抹掉，
   本质上仍是内容问题。

**Failure class**：无（这是一次成功的消融，给出方向明确的结论）。
