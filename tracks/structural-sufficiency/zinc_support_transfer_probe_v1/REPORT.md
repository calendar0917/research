**轮次**：`zinc_support_transfer_probe_v1`（`tracks/structural-sufficiency/`）
**日期**：2026-10-23
**判定**：**D — 头能拟合 C_fit，但在其自己的选择集上选择规则选空，query 增益 ≈ 0，且区间排除任何有价值效应；实际应用已拟合头会显著变差。**
**附带（超出原假说范围的机制证据）**：残差在**同一半径 2 键族内部**也不可预测（within-key 留出 Δ=0.0000、最优步同样为 0），且"事后最优常数偏移"在 query 上的上限 ≤ 0.0011。因此失败不是"跨结构类型迁移"特有的，而是"基座的符号残差相对于给定特征基本是标签噪声"。

## 1. 问题与本轮要证伪的命题

目标仍是 official ZINC subset raw-y test MAE < 0.060（0.05×）。本轮不问"全量结构够不够"，
而问一个更窄、可证伪的问题：

> 当基座模型对目标结构的局部键型**完全没有监督支撑**（n₂=0）时，
> 能否从**其他结构**的真实样本外误差中学到一条**共享、可迁移**的纠错规则？

三条假说（内部判定）：H1 有支撑结构的符号误差可跨结构类型迁移；H2 局部结构特征
在粗统计量之外还有增量；H3 迁移到全 10k trunk 并改善 official valid。
内部 H1/H2 增益 ≠ H3。

**本轮的答案**：H1 不支持，H2 不支持（S 在拟合后比 G 更差），H3 未检验（门禁未开）。
而且否证是**定量有上界**的：即使允许在 query 上事后挑最优常数，改进也 ≤ 0.0011。

## 5. 主结果：24 个头全部选择"不纠错"

冻结的选择规则（C_dev，trim5）作用在 2 头 × 2 wd × 3 init × 2 seed = 24 次训练上，
**每一次都在 step 0 取到最小值**，即**被选中的 G 与 S 在构造上等于 B**。
wd 网格的两个点给出**完全相同**的 C_dev 值（0.091877，等于基座），即两个 wd 都选择不纠错，
最终选中 wd = 0（规则：并列取更小者）。

| seed | 头 | wd | C_fit gated MAE | C_dev 基座（trim5） | C_dev 头最优（trim5） | 选中步 |
|---|---|---|---:|---:|---:|---:|
| 0 | G | 0 | 0.1202 | 0.1140（0.0919） | 0.0919 | 0 / 0 / 0 |
| 0 | S | 0 | 0.1202 | 0.1140（0.0919） | 0.0919 | 0 / 0 / 0 |
| 1 | G | 0 | 0.1230 | 0.1130（0.0957） | 0.0957 | 0 / 0 / 0 |
| 1 | S | 0 | 0.1230 | 0.1130（0.0957） | 0.0957 | 0 / 0 / 0 |

这是本轮的核心事实，且方向和幅度都很干脆：头**确实在学**（C_fit 的 L1 从 0.120 掉到
0.027–0.057），但**每多学一步，C_dev 就更差一步**，单调、无中途回升：

| 头（seed 0, init 0） | step 0 | 50 | 200 | 600 | 1,500 |
|---|---:|---:|---:|---:|---:|
| S：C_fit L1 | 0.1202 | 0.0806 | 0.0500 | 0.0360 | 0.0269 |

因此"被选中的纠错"= 恒等：Q_A/Q_B/Q_bg 上 G−B = S−B = **0.0000**（逐分子完全相同的预测，
未 gated 分子上的恒等性检查最大绝对偏差为 `0.0`）。

## 8. 机制诊断：残差是否可预测？（三把尺子）

### 8.1 同一键族内部留出（不是迁移问题）

把 C_fit 在**每个 C 族键内部**按分子 80/20 切分，训练分子与留出分子共享完全相同的
半径 2 键；在留出部分上重跑同一套选择：

| seed | 头 | 留出基座 MAE | 选中步 | 留出 Δ（选中） | 留出 Δ（到底） | 到底时的训练 L1 |
|---|---|---:|---:|---:|---:|---:|
| 0 | G | 0.0966 | 0 | **0.0000** | +0.0232 | 0.0546 |
| 0 | S | 0.0966 | 0 | **0.0000** | +0.0213 | 0.0282 |
| 1 | G | 0.0966 | 0 | **0.0000** | +0.0427 | 0.0544 |
| 1 | S | 0.0966 | 0 | **0.0000** | +0.0224 | 0.0269 |

**即使键型完全被训练分子覆盖**，留出分子上的纠错也只能是零。所以本轮失败不能归因于
"结构类型之间不可迁移"；它更基本：**给定这些输入，基座符号残差的条件均值基本为零。**

### 8.2 事后最优常数（组级纠错的天花板）

在 query 自己的标签上找最优常数偏移（纯 oracle，不可部署）：

| 包 / seed | 基座 MAE | 最优常数 | 最优后 MAE | 增益 |
|---|---:|---:|---:|---:|
| Q_A s0 | 0.1975 | −0.0000 | 0.1975 | 0.000001 |
| Q_A s1 | 0.1951 | −0.0085 | 0.1948 | 0.000279 |
| Q_B s0 | 0.1291 | −0.0100 | 0.1280 | 0.001050 |
| Q_B s1 | 0.1329 | +0.0125 | 0.1321 | 0.000789 |
| Q_bg s0 | 0.1331 | −0.0030 | 0.1331 | 0.000078 |
| Q_bg s1 | 0.1345 | −0.0025 | 0.1344 | 0.000031 |

**任何"组级常数"型纠错的理论上限是 0.0011**，而本轮目标需要 0.003（0.060→0.057）。
也就是说：即使有人把"未见键惩罚"这个常数估得完美无缺，也够不到 0.05× 的 1/3。

### 8.3 尾部分子核算（为什么均值会骗人）

| seed | 包 | MAE | 中位 \|r\| | 最大 \|r\| | 最高 2% 分子占绝对误差 | \|r\|>1 的分子 |
|---|---:|---:|---:|---:|---:|---:|
| 0 | Q_A | 0.1975 | 0.0694 | **29.87** | **50%** | 3 |
| 0 | Q_B | 0.1291 | 0.0686 | 0.97 | 13% | 0 |
| 0 | Q_bg | 0.1331 | 0.0463 | 12.01 | 45% | 7 |

Q_A 的 0.1975 里有一个 y = −42.04 的分子（基座给 −12.17，误差 30），单它就贡献 0.083；
剔除 |r|>1 的 3 个分子后 Q_A MAE 为 0.109/0.104。Q_B 没有这种尾部，MAE 0.129 是"真"的。
这一条同时解释了为什么 A2 的 trim5 选择是必要的，也解释了为什么"均值型纠错"必然失败。

## 12. 回答 A–F

**A. 学到可迁移的纠错了吗？**
没有。选择规则在 24/24 个头上选择"不纠错"；被选中的 G/S 与 B 逐分子完全相同（Δ=0.0000）。
Q_A/Q_B/Q_bg 的 95% 区间（分子与键簇两种重采）在有害侧排除 0（例如 Q_B 的 S 到底 +0.078…+0.171）。

**B. 详细局部结构比通用纠错更好吗？**
没有，**更差**。S 与 G 在 C_dev 上都被选为空；强行用到 1,500 步时 S−G = +0.0038/+0.0061（Q_A）、
+0.0678/+0.0799（Q_B）、+0.0075/+0.0043（Q_bg）。附加的 108 维原子特征 + 支撑统计没有带来
可迁移信息，只带来更多过拟合通道（S 的 C_fit L1 降到 0.027 而 C_dev 升到 0.165）。

**C. 在另一个包和另一个基座 seed 上成立吗？**
成立（这里"成立"指"同样是空"）：两个基座 seed（不同 SSL 初始化、独立训练）与两个查询包
（A：35 个键 / B：37 个键 / 父键不交）、外加旧支撑包，全部给出同一符号；
旧包的 `sup_minus` 基座（更早的配方、不同拟合集）也一样。
两点提醒：Q_B 的 S 到底伤害是所有格子里最大的（+0.12），说明这一格方差最大；
Q_A 的 MAE 由 3 个分子主导（§8.3），故 Q_A 的绝对数值不宜单独引用。

**D. 迁移到全 10k valid 了吗？test 达标了吗？**
没有测，也不该测：内部门禁未开（见 §10）。official valid / test 本轮零读取，
test 距离 0.060 的进度**无变化**。本轮没有产生任何新的 test 候选。

**E. 性能进步 / 有限机制证据 / 失败 / 不确定？**
**失败，但是有定量边界的失败**（不是"不确定"）。可带走的机制证据有三条，
都指向"这不是结构迁移问题，而是 L1 残差在测量分辨率上不可预测"：
(1) within-key 留出 Δ=0.0000 —— 键型被完全覆盖时也无法纠错；
(2) oracle 组级常数上限 ≤0.0011 —— 任何"整体偏移"型机制在数学上够不到 0.003；
(3) 均值残差 −0.111 而中位残差 +0.0005 —— 绝大多数"支撑不足惩罚"是少数极端分子的假象。

**F. 下一步唯一最好的动作，以及什么会改变判定？**
**唯一动作：停止在 raw-y 上加性纠错头这条线，把"支撑不足"的度量从 MAE 的均值层
移到分子层——即先证明"存在一个只用结构就能算出的分子级信号，能挑出哪些分子会被系统性高估"，
再谈纠错。**
具体地：把本轮的诊断反过来当作可证伪命题去测——在 F 上用交叉拟合构造 out-of-fold 残差，
看**分子级**是否存在可被结构特征（键支撑、原子未见比例、尺寸）区分的高估/低估子群，
要求子群内 **L1 残差中位数**（不是均值）显著偏离 0，且该子群在 query 包上可复现。
如果存在，纠错应该做成分组/条件机制，而不是平滑的头；如果不存在（按本轮证据更可能），
那么 0.05× 的瓶颈就不在"未见键的后处理"，必须回到覆盖/表示本身。
会改变判定的证据：任一新包上，**在完全不含 query 标签的固定规则**下，query MAE 改善 ≥0.003
且键簇 bootstrap 区间不含 0，并且在第二个基座 seed 上复现。

## 15. 偏离与限制（必须携带）

1. **A1/A2 是协议修订**，虽在见到任何新数值前写入，仍需在引用时一并说明；
   A2 的 trim5 选择统计量会让"选择为空"更容易发生（但对 Q 的读数无影响，Q 全程不参与选择）。
2. **Q_A 不是好的 MAE 载体**：3 个分子占绝对误差 50%，其中一个 y=−42.04 贡献 0.083。
   本轮已在 §8.3 披露；未来若要再用 Q_A 判定，应改用 trim 或分母级指标。
3. **C_fit 只有 988 个 gated 分子**，头容量（10.5k 参数）相对偏大；不能排除"更小的头
   会在 C_dev 上也不为空"。但 §8.1 的 within-key 诊断用的是同一容量，且同样为空，
   所以"容量不合适"不足以解释结论。
4. **只测了一种加性形式**：`f_base + m_F·h`。乘法/分段/分位数形式未被否决；
   但它们同样受 §8.2 的 0.0011 组级天花板约束，除非能做到分子级选择。
5. **旧包结果的历史暴露**（M 曾参与上一轮的 checkpoint 选择，Q_old 标签旧轮已读）；
   本轮只把它当一致性检查，不作判定依据。
6. **两个基座 seed 共享同一个 SSL 编码器的**目录来源但不共享权重；因此 seed 间差异
   不包含 SSL 预训练本身的方差。
7. 本轮**没有**做 structural-alignment shuffle 控制（因 S 明确劣于 G，控制无解释力），
   **没有**读 official valid/test，**没有**任何外部通信。
