## 8. 诊断（**逐条限定**）

### 8.1 A3：那个特征 bug 到底有多大

| 检查 | 结果 |
|---|---|
| 逐原子计数 vs 逐分子暴力计数（12 个 C_fit 分子，纯 Python 集合成员） | 最大差 **0.0** |
| 键空间独立重编号（k1/k2 各自随机置换）后的全部特征 | 最大差 **0.0**（ctx/aux/atoms/mask） |
| 同一重编号下**修正前**表达式 `sup2[atom_k1]` 的变化 | 最大差 **4022**（即依赖任意编号） |
| 受影响的上下文列 | 仅 27/28（`min_n1`、`mean_n1`），n2 列与其余块不变 |
| 数值尺度（C_fit 全部原子，中位数） | 旧 277 → 新 3,630；未见原子上 **100%** 数值改变，最大改变 4,797（Q_B 上 5,857） |

含义：修正前 S 的"父结构支撑"通道基本是**另一套编号的随机查询**，G 的两个 n₁ 列同理。
修正后语义才成立（未见 k₂ 但父 k₁ 常见 ⇒ 高 n₁）。

**但修正不改变本轮的选择结论**：重训后 24/24 仍选 step 0（trim5），保留曲线的 12 个臂未裁剪也在 step 0 最小（§5）。
也就是说，初版的负结论**没有**被这个 bug "解释掉"，但初版的**机制解释**确实站不住。

### 8.2 within-key：撤回"同键族内部也不可预测"

C_fit 在每个 C 族键内部按分子 80/20 切分（留出分子与训练分子共享完全相同的半径 2 键）：

| seed | 头 | 留出基座 MAE | 选择器选中步 | 选中 Δ | 未裁剪最优步（事后） | 未裁剪最优 Δ（事后） |
|---|---|---:|---:|---:|---:|---:|
| 0 | G | 0.0966 | 0 | 0.0000 | 0 | 0.0000 |
| 0 | S | 0.0966 | 0 | 0.0000 | **50** | **−0.0102** |
| 1 | G | 0.1002 | 0 | 0.0000 | 0 | 0.0000 |
| 1 | S | 0.1002 | 0 | 0.0000 | 0 | 0.0000 |

正确表述：**预注册选择器（trim5）在 4/4 格选择不纠错；未裁剪曲线只在 1/4 格出现下探，
且不跨基座 seed 复现。** 因此可以写"没有可复现的 within-key 增益"，**不能**写"同键族内部不可预测"。
下探本身是事后读数，不构成选择依据，也不允许据此挑 checkpoint。

### 8.3 组级常数上限：只约束"整包平移"，不约束其它规则

在 query 自己的标签上找最优常数（纯 oracle，不可部署）：

| 包 / seed | 基座 MAE | 最优常数 | 增益 |
|---|---:|---:|---:|
| Q_A s0 / s1 | 0.1975 / 0.1951 | +0.0005 / −0.0085 | 0.000001 / 0.000279 |
| Q_B s0 / s1 | 0.1291 / 0.1329 | +0.0145 / +0.0125 | **0.001050** / 0.000789 |
| Q_bg s0 / s1 | 0.1331 / 0.1345 | −0.0030 / −0.0025 | 0.000078 / 0.000031 |

（最优常数落在 ±0.015 内的一个平坦区，具体取值受网格并列影响；有意义的是**增益**列。）

限定：这只说明"把一个包整体平移一个常数"最多值 0.0011（低于 0.05× 所需的 0.003）。
它**不**说明条件中位数为 0，也**不**给"依赖分子特征的分组/条件纠错"设上界。
另一个相关事实：Q_A 的平均残差是 −0.111 而中位数只有 +0.0005（均值被少数极端分子拉动），
这正是"按均值平移"必然有害的原因（§7 第一列），但这同样只是关于**平移**的结论。

## 11. 判定

**D，限定版**：在"加性 + m_F 门控 + 这组特征（粗统计量 / 108 维原子特征 + n₁,n₂）+ L1 + C_dev(trim5) 选择"
这一族里，选择规则在 24/24 个头上返回不纠错（trim5；保留曲线的 12 个臂未裁剪也在 step 0 最小），
强行应用在 Q_A/Q_B/Q_bg 上一致变差（区间在有害侧排除 0）。旧支撑包与另一基座 seed 同向。

不选 E（证据不足）的理由：24 个头 × 2 基座 seed × 2 个独立包 + 旧包，符号一致，
且不依赖 trim5（在保留曲线的 12 个臂上未裁剪同样选 0）。不选 A/B/C 的理由：没有任何一格的选中增益为正。

**撤回**：初版"A（强形式）"里的三条机制性陈述（条件均值≈0 / within-key 不可预测 / 所有可学习纠错上限 0.0011）。
本轮**没有**足以支持这些陈述的证据。

## 12. 回答 A–F（更正版）

**A. 学到可迁移的纠错了吗？**
在这一族方案里没有：24/24 个头的选择规则返回"不纠错"（trim5；保留曲线的 12 个臂未裁剪也在 step 0 最小），
选中臂与 B 逐分子相同。强行用到 1,500 步则 Q_A +0.036…+0.049、Q_B +0.051…+0.122、Q_bg +0.012…+0.017。
**不能**据此说"残差不可预测"。

**B. 详细局部结构比通用纠错更好吗？**
没有一致的差异：Q_A 上 S 略好（−0.005/−0.007），Q_B 上 S 明显更差（+0.051/+0.060），Q_bg 上符号相反；
两者都不过选择门。初版"S 一律更差"的判断已撤回（它建立在含 bug 的特征上）。

**C. 在另一个包和另一个基座 seed 上成立吗？**
"选择为空"这一点成立：两个基座 seed、两个查询包、旧支撑包、以及修正前后两次特征，
都是同一符号。但注意两点：Q_A 的数值由 3 个分子主导（§8.4）；S 与 G 的相对次序不稳定。

**D. 迁移到全 10k valid 了吗？test 达标了吗？**
没有测，也不该测（门禁未开）。official valid/test 未读，test 进度无变化。

**E. 性能进步 / 有限机制证据 / 失败 / 不确定？**
**失败（限定范围）**。可带走的证据只有三条，且都只关于这一族方案：
(1) 这族头能拟合 C_fit（L1 降到 0.027–0.054）但在任何一个中间 checkpoint 上都不改善跨结构 C_dev（未裁剪与 trim5 同向）；
(2) 把"整包平移一个常数"做到事后最优也只值 ≤0.0011，低于 0.003；
(3) A3 修正后结论不变，说明失败不是特征 bug 造成的（尽管 bug 曾使 S 的 n₁ 通道失去语义）。
**不可带走**的：关于条件中位数、关于"任何可学习纠错的上界"、关于"同键族内部不可预测"。

**F. 下一步唯一动作，以及什么会改变判定？**
**关闭"从冻结 P3 残差里做后处理纠错"这条线。** 本轮 + 上一轮（`zinc_composition_transfer_v1`）
已经两次在同一位置失败，且一次是在修正后的特征上失败的；继续在同一残差上换头型/换特征/换分组，
预期收益 ≤0.001，低于目标所需 0.003。
若下一次要投入 GPU，应转向**端到端重新学习结构表示**（而不是残差挖掘）：在 F 上从头训练一个
能直接表达"未见键"的表示，并且用与官方 10k 一致的评估口径判断。
会改变判定的证据：在**完全不含 query 标签**的固定规则下，query MAE 改善 ≥0.003、
键簇 bootstrap 区间不含 0、并在第二个基座 seed 上复现——这需要新的表示，而不是新的头。

## 15. 限制（更正版）

1. **A3/A4/A5 是事后更正**：它们不改变选择规则、查询集、预算，也不改变任何一个 query 标签的使用方式，
   但它们确实是"看到结果之后"的修改，引用时必须同时引用初版（`ccd6110`）与本版。
2. 只测了**加性**形式 `f_base + m_F·h`；乘法/分段/分位数/图级形式未被否决。
   本轮也**没有**证明这些形式不可能有收益——只是没有证据支持继续投入。
3. **within-key 的未裁剪下探只出现 1/4 格且不跨 seed 复现**；它不是选择依据，也不再被当作"不可预测"的证据。
4. **Q_A 由 3 个分子主导**（其一 y=−42.04 贡献 0.083）；Q_A 的绝对数值不宜单独引用。
5. **wd = 1e-3 的 12 个臂只保留了 wd 级 trim5 均值（等于基座），完整曲线未落盘**；
   因此"未裁剪也在 step 0 最小"这一句只对保存曲线的 12 个臂成立，对另外 12 个臂只能引用其 trim5 水平。
6. C_fit 只有 988 个 gated 分子，头容量（10.5k 参数）可能偏大；不过未裁剪曲线在 24/24 个头上都是
   step 0 最好，容量不适不足以解释"选择为空"，但也没有排除"更小的头会略有不同"。
7. 旧包数字含历史暴露（M 曾用于旧轮 checkpoint 选择），只作一致性检查。
8. 两个基座 seed 不共享权重，但共用同一个 SSL checkpoint 目录；SSL 预训练本身的方差未被采样。
9. 本轮**没有**读 official valid/test，**没有**做 shuffle 控制，**没有**任何外部通信。
