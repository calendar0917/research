# REPORT — 可解释结构规律发现与稀疏预测研究 v0
**DEVELOPMENT_TEST**：所有 Test 结果已暴露但只报告，不用于选择规则、阈值、容量或 C。
## 首页结论（直接回答五个问题）
1. **少量显式结构规则的预测能力有限，但并非无效。** 仅用分子大小 + 128 条单结构阈值规则的 `R128`：Valid ROC-AUC `0.7702`、Test `0.7637`（AP `0.2048` / `0.2261`）；`R0` 为 `0.6785` / `0.7174`。与冻结强模型仍有差距：`B2` `0.8283` / `0.7688`，`X-CF` `0.8329` / `0.8070`。Test 上 `B2−R128=+0.0052 [-0.0461, +0.0564]`，区间跨零；`X-CF−R128=+0.0433 [+0.0019, +0.0814]`，区间不跨零。因此当前简单规则尚不足以保留强模型的预测价值，但不能据此断言可解释模型整体上不可能有竞争力。
2. **阈值规则没有超出线性计数的稳定非线性增量。** `B2-U64−B2`：Valid `-0.0112 [-0.0275, +0.0043]`、Test `+0.0111 [+0.0012, +0.0213]`（方向相反）。`B2-U64−B2-L64`：Valid `-0.0037 [-0.0152, +0.0062]`、Test `+0.0076 [+0.0003, +0.0149]`。Test 的小幅优势与线性修正相当接近，不能排除普通参数修正；Valid 反而略低。暂缓设计更复杂的单结构非线性函数。
3. **树路径联合条件没有优于同预算单规则或匹配随机组合。** 可执行预算 `K=16`（合格真实联合候选 32 条，匹配随机 211 条）。`B2-U+P−B2-U64`：Valid `-0.0003 [-0.0037, +0.0038]`、Test `-0.0135 [-0.0313, -0.0008]`；`P−S` Test `-0.0132 [-0.0321, +0.0008]`；`P−N` Test `-0.0157 [-0.0368, +0.0009]`。三项均未提供联合形式带来增益的证据；至少在本轮设置中，树路径来源并未显示特殊价值。
4. **得到了少量可表达的真实结构条件，但更强的“规律”仍是假设。** 知识卡片包括：芳香 C–C–O 三节点（COARSE 157，Test 激活率 0.031 vs 基座 0.032，负系数）；一个 Train 上 319/319 全负的可读计数阈值（FULL 1089）；COARSE 419 芳香碳–硫四节点（Train 17.0% vs 3.7% 正例率，Valid 7.2%、Test 16.9%）；以及一个弱/有反例规则。COARSE 419 的四个 FULL 子型在硫的度/H/连接环境上真实不同，但本轮没有一条 FULL 子型进入 512 条候选池，故其细粒度差异**未**被规则模型采用。这些是预测关联与模型计算规律，不是化学因果机制。
5. **被削弱的解释**：阈值优于线性计数、联合条件具有特殊价值、X-CF 树路径来源的独立性、细粒度 C–S 子型被规则模型使用。**仍不能区分**：阈值修正的小幅 Test 增益是否只是样本噪声或普通参数化；R128 与 B2 在 Test 上的差距是否真实（区间跨零）；更强的 GNN/树模型到底从同一结构中提取了什么非线性信息。
6. **是否值得继续**：规则的紧凑表达值得作为一种受控基线保留；但本轮没有出现联合规律的正向预测信号，也没有发现同共现条件下明确的位置差异效应。因此**没有充分证据支持下一阶段专门研究真实结构连接关系**；如需推进，应先在更强的显式结构读出与本轮规则的严格同输入比较中确认非线性/联合信号。

## 数据、复用与核验
官方划分 32901/4113/4113；冻结 C(754)/F(3652) 与 `registry_v1` 列顺序通过 Train df 逐列核验；B2 用冻结系数与截距重放，max|Δlogit|=4.34e−7；X-C/X-F booster 特征映射与真实 split condition 在 25×4000 个叶子路径上逐节点重放，零错位；offset logistic 梯度相对误差 2.45e−9；R0 与 sklearn 系数差 5.6e−5；R128 原始单位加和闭合 4.6e−15；开关规则的变化等于其贡献；所有指标从存储预测独立重算，max|Δ|=1.1e−16。15/15 检查通过。
历史资产只读复用：SGA-v1 输入 bundle、X-C/X-F booster、MSDS-v0 B2 系数/预测、registry_v1、case_structures、Bemis–Murcko scaffold、实例缓存。未重训任何历史模型；无 GPU；seed=0；X-CF booster 在 MSDS-v0 Phase D 未保存，按协议不重训，故联合规则只来自同粒度（C–C / F–F）路径。

## Phase A：候选规则
从 X-C/X-F 共 6242 个结构分裂节点聚合出 4095 个唯一条件；Train 双侧支持过滤后 3508，去重合并 95，最终保留 512 条单规则。真实 root-to-leaf 路径 21289 条，产生 2122 个不同共同路径对；经 2×2 单元支持与去重后 952 对，保留 256 条 `PROJECTED_PAIR`（C–C 206、C–F 38、F–F 12；**都不是原始树完整决策规则**）。随机匹配 211 对，覆盖率 82.4%；联合激活频率绝对差中位数 0.0064、最大 0.0968；边际频率匹配较差（最大差约 0.48），这是本轮匹配的明确局限。

## Phase D：真实 C–S 家族
COARSE 419 = `a:Carx3 b:Sx1`，`a-a:AROMATICx2 a-b:SINGLEx1`（三个芳香碳连一个硫）。四个 FULL 子型均是其真子图（实例位置核验 overlap=1.0），但硫的度/H 不同：2078/1788 硫 deg4/H0，2525 硫 deg2/H0，2275 硫 deg4 且 in-ring。Train 正例率 2078=37.2%(197/529)、2525=15.8%(38/240)、1788=7.7%(117/1519)、2275=3.1%(11/356)；Valid/Test 对应 31.3%/53.8%、7.1%/5.0%、4.5%/17.6%、0%/8.6%。方向大体保留但幅度波动很大。B2 系数分别 +0.159/+0.087/−0.084/−0.009；COARSE 419 为 +0.245。**四个 FULL 子型没有一个进入 512 条候选单规则**，COARSE 419 只以 S271 等阈值规则进入 R128，且 S271 在 R128 中的标准化系数接近零（−0.039）。2078 的实例总是伴随 COARSE 419，Train 中位原子数高于全库（31 vs 23），不同 FULL 子型 Jaccard ≤0.069，共现重叠不是主要解释；分子大小与特定骨架仍可能是代理（2078 在 >50 原子分子中 Train 正例率 0.726 vs 全库 0.172）。因此“芳香碳–硫细粒度差异”是可观察的预测关联，但本轮没有证明它是硫的因果作用或独立机制。

## 局限
1. X-CF booster 未保存，不重训；联合规则只来自 X-C/X-F 的同粒度路径，C–F 组合缺失。2. 随机匹配只覆盖 82.4%，边际激活频率匹配较差，因此 `P−N` 是保守但非严格的对照。3. 只有 seed=0；bootstrap 只描述固定预测的样本不确定性。4. 规则关闭实验是冻结模型内部的忠实性检验，不等于真实分子中删除子图的条件预测变化。5. 没有对结构实例空间关系建模；联合规则仅表示整分子共现。
