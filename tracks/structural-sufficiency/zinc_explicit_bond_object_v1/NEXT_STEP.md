# NEXT_STEP — ESOC-v1

本轮结论：**`STRUCTURE_SIGNAL_ONLY`**。真实成对边对应关系是有效信号（配对置换下 REAL 移动 0.355、NULL 精确 0.000），REAL 比 NULL 好 0.0282（95% CI [−0.0345, −0.0220]，14/14 分组同向），但绝对水平 0.128 距 DCC-L 的 0.0760 仍有 0.052。

## 立即可做（按性价比排序）

### 1. 把 correspondence 信号搬到一个已证明有竞争力的主体上（最高优先）

本轮的 0.128 主要被**主体/读出**限制，不是被 correspondence 限制。最有信息量的下一步不是继续改局部对象，而是：

* 取 DCC-L 的 494k 主体（已知 valid 0.0760），只把它的 pair 通道输入换成 REAL vs NULL 的对照；
* 这样 Δ 就在一个"绝对水平已达标"的模型上测量，能直接回答"这个信号能否把 0.0760 再往下推"。

这是唯一能把"信号有效"升级成"信号有用"的实验，且成本低（DCC-L 600 ep 已有配方）。

### 2. 补 seed-1（成本 2 h，但信息量有限）

本轮 −0.0282 只有单种子。补一对种子能给出幅度误差棒。**建议在第 1 项之后再做**，否则只是给一个"绝对值不够"的模型加误差棒。

### 3. horizon 敏感性（成本 1 h/点）

REAL 的 best 在 ep481、之后平台，但没测过更长 horizon。若要排除"600 ep 仍在下降"的可能，跑 900 ep 一个点即可（不改配方，只改 horizon）。

## 不要做

* **不要**为提升绝对值去扫 LR / depth / readout。本轮已证明 correspondence 有信号，扫这些只会混淆归因。
* **不要**把本轮 0.128 与 PPGT 的 0.0566 比较。URPE 未实现，不是同一模型。
* **不要**在 valid 上做任何形式的选择后仍把 valid 数字当泛化证据。valid 是暴露集。
* **不要**加载 test，除非有一个在 valid 上冻结的决策需要 test 确认。
