# ESOC-v1 · HARD_PERM 对照报告

**对照问题**：REAL 相对 NULL 的收益，有多少来自**正确的 pair-edge 对应关系**，有多少来自 **one-hot 与连续频率输入的分布差异**？

**一句话结论**：两者都有，且**分布差异略大于对应关系**——对应关系占 REAL 收益的 **43.7%**，输入分布占 **56.3%**。对应关系这一项本身仍然显著（CI 排除 0），但**不足以单独支撑原报告里 "correspondence 是主要机制" 的解读**。

---

## 1. 为什么需要这个对照

REAL vs NULL 同时改变了两件事：

1. 原子对 `(i,j)` 与边类型之间的**对应关系**；
2. **输入分布**——REAL 每对喂 one-hot，NULL 把对象级 4 类频率广播到每一对。

所以原来的 −0.02816 不能归因于 (1)。HARD_PERM 冻结 (2)、只破坏 (1)。

## 2. HARD_PERM 的构造

对每个键中心对象 `P_b`：

* **保持**：节点集、原子类型、角色 `(dist(i,u), dist(i,v))`、骨架（哪些对是键/非键）、边类型 one-hot 的**类别多重集**。
* **打乱**：把类型标签在真实键之间**重新指派**，指派规则只依赖**内蕴描述符**（节点类型 + 无序距离对、边的无序节点键对、原始标签），不使用原子编号、不使用标签。

因为骨架固定，4 类直方图、`loc_nedges`、每个节点度数、全部非边都与 REAL **逐位相同**，所以 NULL 的输入向量也**逐位相同**（实测 `null_input_bitwise_identical = true`）。

### 关键设计约束（逐项验证）

| 约束 | 做法 | 结果 |
|---|---|---|
| 根键交换不变性 | 节点键用 `sorted((ru,rv))`，边键用 `sorted((key_a,key_b))` | **300/300** |
| 原子重编号不变性 | 排序键**不含位置 tie-break**（位置依赖编号） | **300/300** |
| 真实改变比例 | 旋转半个环，保多重集 | 见下 |

> **注意一处已修正的设计错误**：初版用 `(边键, 标签, 枚举位置)` 排序，重编号不变性只有 **0.20**。原因是末位的 `e` 依赖原子编号。移除后达到 1.00。这不是放宽约束，而是修 bug；修完后变化率几乎不变（0.6856 → 0.6856）。

## 4. 必须报告的非物理性

固定度数重指派标签**无法**保持每个原子的键级和，因此部分对象在化学上不可能：

| | 打乱前 | 打乱后 |
|---|---|---|
| 原子槽键级和 > 4 | 400 | 3,290 |
| 键级和发生变化的原子槽 | — | 47,627 / 118,486 = **40.2%** |

这是**任何**破坏对应关系的对照的固有代价：它探的是"对应关系是否携带信号"，不是"打乱后的图是不是合法分子"。这一点在解释时必须计入——HARD_PERM 学到的东西不等于一个可用的化学模型。

## 7. row172 排除后的结论

row172 是极端离群点（三臂 AE ≈ 19.7–20.7），且 HARD_PERM 反而最好。排除它：

| 对比 | 全部 1000 行 | 排除 row172 |
|---|---|---|
| REAL − HARD_PERM | −0.01231 [−0.01786, −0.00681] | **−0.01325 [−0.01847, −0.00796]** |
| REAL − NULL | −0.02816 [−0.03448, −0.02197] | −0.02811 [−0.03441, −0.02168] |
| HARD_PERM − NULL | −0.01585 [−0.02216, −0.00975] | −0.01486 [−0.02077, −0.00887] |

**结论不依赖 row172**：排除后对应关系效应甚至略大（−0.01325），占比 47%。worst-10 去掉 row172 后 9 行均值：REAL 1.342、HARD_PERM 1.307、NULL 1.402——HARD_PERM 在这 9 行上仍略优于 REAL，进一步说明**极端难例上对应关系无收益**。

## 8. Observed / Interpretation / Decision

### Observed

1. REAL − NULL = −0.02816，可精确分解为对应关系 −0.01231（43.7%）+ 输入分布 −0.01585（56.3%）。
2. 两个分量各自的 95% CI 都排除 0。
3. HARD_PERM 的 one-hot 输入、类别直方图、骨架、边数、NULL 输入向量与 REAL 逐位一致（唯一差异是标签落在哪一对上）。
4. 置换真实改变了 68.6% 的对象、42.8% 的键标签；仅 0.96% 因对称而未变。
5. 根键交换与原子重编号不变性均 300/300。
6. 非物理性可量化：40.2% 的原子槽键级和改变，键级和 >4 的槽从 400 增至 3,290。
7. 排除 row172 后结论不变（对应关系效应 −0.01325，占比 47%）。
8. HARD_PERM 用 1.009 GPU-h，在 1.5 h 上限内。

### Interpretation

* **对应关系是真实信号，但不是主因。** REAL 确实显著优于保留了 one-hot 频率的 HARD_PERM，说明模型不只是吃"这个对象里各类型边有几个"，它确实用到了"哪一对是哪一类"。这一点现在有了干净证据。
* **但原来 −0.028 的一半以上是输入分布效应。** one-hot 逐对输入比广播频率提供了更细的梯度/更可分的输入，即使对应关系被破坏，仍能拿到 −0.0159。这解释了为什么 HARD_PERM 落在中间而不贴近 NULL。
* **因此原报告的解读需要下调。** 原报告写"correspondence 是有效信号"，这仍然成立；但若读者把它理解成"REAL 的主要优势来自 correspondence"，那是**过度归因**。正确表述是：约 44% 来自 correspondence，约 56% 来自输入分布。
* **最难的分子上对应关系几乎无收益**（worst-100：−0.00067）。这与"correspondence 帮助泛化到未见签名"部分矛盾——在 unseen 签名上它有效（−0.01745），在最难 100 例上它无效。可能原因是这些分子的误差由别的东西主导（如 y 极负的尾部，绝对误差 0.7+），对应关系的局部修正量级不够。
* **HARD_PERM 不是合法分子模型**（40% 原子槽键级和改变）。它作为对照有效，但不能被当作"一个可用的替代架构"来引用。

### Decision

**REAL 的收益是否仍然超过保留 one-hot 边类型频率的 shuffled 控制？**

**是，但幅度只有原收益的约 44%。** REAL − HARD_PERM = −0.01231（95% CI [−0.01786, −0.00681]），排除 row172 后 −0.01325。方向在 12/14 个分组上一致（仅 row172 与 worst-10 两个极端组反向，二者都由 1 个离群点主导），在 unseen 签名上更强。所以"对应关系携带真实、可复现的信号"这一结论成立；但"对应关系是 REAL 优势的主要来源"这一结论**不成立**。

**它是否提供足够理由，去购买一个与 DCC-L 相容的新结构机制实验？**

**不足以支持"因为 correspondence 强，所以值得迁移"这个理由**——因为 correspondence 只占 44%，且在最难的分子上几乎为零收益。

**但支持一个更窄、更明确的理由**：REAL 与 HARD_PERM 的差距证明"逐对的 one-hot 对应"这一具体机制有独立贡献，而这个机制**在 DCC-L 主体里目前根本不存在**（DCC-L 走的是关系通道，不是逐对 one-hot）。所以值得买的不是"correspondence 很强"，而是"这是一个尚未在强主体上被测过的、有独立信号的机制"。

若要做，应设定**明确的止损条件**：若在 DCC-L 主体上 REAL−HARD_PERM 的对应关系分量 < 0.005，则判定该机制在强主体上被容量吸收，不再投入。

**本轮不自动开展后续实验。**
