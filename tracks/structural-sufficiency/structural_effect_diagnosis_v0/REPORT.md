## 0. 五问速答与决策

### Q1. 修正 SES 冻结选择干预后，SELECT 相对 uniform 的收益是多少？

父轮 `ses_analyze.py` 的 `se_b` 错用了 RANDOM 臂的 expected MSE，而不是 SELECT 臂自身的逐候选平方误差均值。SES 误差单位为 eV。修正后：

| split | SELECT top-1 RMSE | uniform SELECT 修正 RMSE | A−B ΔRMSE 修正 | 95% CI | A−B ΔRMSE 父轮（错） |
|---|---:|---:|---:|---|---:|
| Valid | 0.909834 | 1.077793 | **−0.167959** | [−0.225015, −0.106925] | −0.129986 |
| Test | 0.914259 | 1.019615 | **−0.105356** | [−0.164120, −0.050745] | −0.069470 |

修正后的 B RMSE 与 SELECT manifest `rmse_expected` 一致（Valid 差 1.2e−9，Test 差 3.8e−9）。**冻结选择干预的选择收益比父轮报告的更大，不是更小**；父轮的定性结论（A 优于 B/C，DENSE 仍明显更好）不变。父轮结果未修改，本轮只记录勘误。

### Q2. 多候选等权平均能改善多少？改善来自哪里？

Valid SELECT：uniform 期望 **1.077793** → 全候选等权平均 **0.985912**（RMSE 改善 **−0.091881**，CI [−0.105418, −0.079114]）；Test：**1.019615 → 0.930961**（**−0.088653**，CI [−0.100498, −0.078167]）。

但改善**完全来自候选方差抵消**，不是互补结构信息：

- 逐分子恒等式 `expected_mse = mean_prediction_se + candidate_variance` 精确成立（最大绝对误差 5.3e−15）。
- Valid SELECT 的候选方差占 expected MSE：逐分子平均 **29.9%**，中位数 **17.0%**，pooled **16.3%**；Test 为 **31.7% / 17.8% / 16.6%**。
- 全候选平均的 MSE 恰好等于 `mean_prediction_se`；它相对 uniform 的 MSE 改善恰好等于候选方差（Valid 0.189616，Test 0.172925）。它没有降低“平均预测本身”的误差。
- top-2 相对 top-1：Valid **+0.003448**（CI [−0.036591, +0.039498]），Test **−0.012835**（CI [−0.046952, +0.022756]），均不显著。第二个候选没有可靠的互补增益。

结论：多候选只提供了**方差缩减空间**，没有证据表明存在可通过组合学到的互补改善空间。全候选平均仍明显差于 DENSE（Valid +0.337434，CI [+0.258662, +0.417743]；Test +0.249473，CI [+0.175251, +0.333052]）；相对 SELECT top-1，Valid 显著更差（+0.076078，CI [+0.016842, +0.130442]），Test 方向相同但不显著（+0.016702，CI [−0.037761, +0.075111]）。

### Q3. 组合后实际读取了多少结构？

以 SELECT 候选集为例（Valid / Test 平均覆盖率）：

| 方案 | 节点覆盖率 | 边覆盖率 |
|---|---:|---:|
| top-1 | 63.0% / 63.1% | 59.5% / 59.6% |
| top-2 并集 | **83.6% / 82.8%** | **81.4% / 80.5%** |
| 全候选并集（等权平均读取） | **99.3% / 99.4%** | **99.0% / 99.1%** |

以 Valid 计，top-2 相对 top-1 多读约 **20.6 个百分点节点、21.9 个百分点边**（Test 为 19.7/20.9），却没有可靠误差改善；全候选平均几乎读取整图（Valid 相对 top-1 多读 36.3 个百分点节点、39.5 个百分点边），误差反而差于 top-1。**这是“多视图聚合/方差缩减”，不是结构压缩。** 若组合后联合覆盖接近全图，不得宣称实现了结构压缩。

### Q4. 已有非 MP（非消息传递）整图模型是否优于条件查表？

是，且差距很大。LCRC-W3（冻结的整图绝对预测，`delta_pred = pred(B) − pred(A)`）对比 SFEC v1 冻结的 `PAIR_Q` 条件查表：

| 子集 | n_obs | PAIR_Q MAE (eV) | LCRC MAE (eV) | ΔMAE（LCRC−PAIR_Q, eV） | 95% CI |
|---|---:|---:|---:|---:|---|
| 全体可评价 | 36,952 | 0.281999 | **0.111144** | **−0.170855** | [−0.177925, −0.163419] |
| unseen exact context | 6,765 | 0.202566 | **0.114742** | **−0.087824** | [−0.097944, −0.078662] |
| unseen + q supported | 6,689 | 0.202702 | **0.114650** | **−0.088053** | [−0.096868, −0.078988] |
| clean subset | 24,381 | 0.284989 | **0.103782** | **−0.181206** | [−0.190698, −0.172247] |

LCRC 不仅绝对预测准（全体可评价 pair 涉及的 24,020 个唯一分子 MAE **0.10002 eV**；不是全部 72,181 个 Valid 分子的整体 MAE），而且真实替换响应也强：delta 相关 **0.946**、回归斜率 **0.912**、预测/真实标准差比 **0.964**；unseen 子集为 **0.888 / 0.797 / 0.897**。PAIR_Q 的响应斜率只有 **0.352**（unseen 0.387），std 比 0.600（unseen 0.714）——查表明显把效应压缩了。整体上没有出现“绝对预测准但替换响应弱”的情况。

### Q5. 是否复现了条件符号反转？

在官方 Valid 上有充分支持的组中，**是**：

| thr | 冻结 pairs | 冻结 groups | 有 Valid 观测的 groups | 支持组（≥5 contexts） | 支持观测 | 真实中位数符号复现 | LCRC 符号复现 | LCRC 与真实同号 |
|---:|---:|---:|---:|---:|---:|---:|---:|---:|

### 决策

- **SES：不扩大现有 selector。** 修正后选择仍有效，但压缩仍受限；多候选平均只带来方差缩减，且远差于 DENSE，top-2 不优于 top-1。父轮路由 `SELECTION_EFFECTIVE_COMPRESSION_LIMITING` 保持不变。
- **PCQM：值得研究已有整图预测计算中的结构作用，而不是继续单独学习条件功能词典。** 现有 W3 已能预测真实替换响应并复现条件符号反转；下一步的科学问题应是“它的计算如何利用结构”，不是再拟合一个 PAIR_Q 式查表。
- **不自动开启下一轮训练。** 本轮到此停止；任何新训练/新模型选择都需要单独授权。

## 2. SES 勘误

### 2.1 错误定位

父轮 `structural_evidence_selection_pilot_v0/code/ses_analyze.py` 的冻结选择干预中：

```python
se_b = np.asarray(per_split[split]["random_expected_mse"], np.float64)
```

`B` 的定义是“从 **SELECT** 候选集中均匀随机取一个候选”，其 expected MSE 应是 SELECT 臂自己的逐候选平方误差均值；父轮却用了 RANDOM 臂的 expected MSE。后果是：

- `B_uniform_expected` 的 **RMSE** 和 `A_vs_B` 的 bootstrap 用了错误臂；
- `B_uniform_expected` 的 **MAE** 原本取自 `sel[f"{split}_mae_expected"]`，仍是 SELECT 自己的，所以父轮 B 行的 RMSE 与 MAE 实际上来自不同臂；
- 父轮主表和路由结论没有被这个错误推翻，但 A−B 的幅度被低估。

需要区分：父轮主表的 `SELECT − RANDOM expected`（−0.1300/−0.0695）是有效的跨 arm 比较，不应被当作错误；错误在于冻结选择干预把 `B = SELECT uniform` 也用了同一个 RANDOM expected。两者数值恰好相同，但科学含义不同。修正后的 B 是 SELECT 自身的 uniform，A−B 变为 −0.1680/−0.1054。

## 3. SES 多候选互补诊断

### 3.1 定义

对每个分子，候选集有 3–4 个候选（Valid 平均 3.995，最少 3，最多 4）。记候选预测为 \(p_j\)，标签为 \(y\)：

- **uniform expected**：均匀随机取一个候选的期望 MSE/MAE；
- **all-candidate mean / median**：所有候选等权平均/中位数；
- **candidate oracle**：逐分子取误差最小的候选（仅后验诊断，不可部署）；
- **top-1 / top-2**：按 SELECT 冻结分数取最高 1/2 个，top-2 取平均；
- **random two expected**：在同一 SELECT 候选集中均匀随机取两个不同候选的精确期望 MSE/MAE。

所有聚合都在逐分子层面计算，再汇总 RMSE/MAE；除后验 oracle 外，没有用标签选择聚合方式，oracle 仅作诊断。

### 3.3 恒等式与方差分解

逐分子验证：

\[
\text{expected\_mse} = \text{mean\_prediction\_se} + \text{candidate\_variance}
\]

| split / arm | expected MSE | mean_prediction_se | candidate variance | 最大恒等式误差 |
|---|---:|---:|---:|---:|
| Valid SELECT | 1.161638 | 0.972022 | 0.189616 | 5.3e−15 |
| Test SELECT | 1.039614 | 0.866689 | 0.172925 | 3.6e−15 |
| Valid RANDOM | 1.081225 | 0.936785 | 0.144440 | 1.8e−15 |
| Test RANDOM | 0.967723 | 0.833882 | 0.133841 | 1.8e−15 |

候选方差占比：

| split / arm | 逐分子平均 | 逐分子中位数 | pooled |
|---|---:|---:|---:|
| Valid SELECT | **29.9%** | 17.0% | **16.3%** |
| Test SELECT | **31.7%** | 17.8% | **16.6%** |
| Valid RANDOM | 28.7% | 13.1% | 13.4% |
| Test RANDOM | 28.7% | 13.8% | 13.8% |

关键点：全候选均值的 MSE 恰好等于 `mean_prediction_se`。换句话说，**平均只是把候选方差项消掉，并没有降低平均预测本身的误差**。Valid SELECT 的 MSE 改善 1.161638 − 0.972022 = 0.189616，恰好等于候选方差；Test SELECT 为 1.039614 − 0.866689 = 0.172925，也恰好等于候选方差。这是“方差缩减”的精确数值证据，而不是“互补结构信息”的证据。

### 3.5 SES 判断

1. 修正后 SELECT 选择收益更大：Valid −0.168、Test −0.105；父轮冻结选择干预的 A−B −0.130/−0.069 是错用 RANDOM 基线导致的低估（父轮主表的 cross-arm RANDOM 比较不受影响）。
2. 多候选平均的改善是**候选方差缩减**，不是互补结构信息。逐分子恒等式与 MSE 分解都支持这一点。
3. top-2 没有可靠优于 top-1；第二个候选不提供可加的选择增益。
4. 组合后读取的结构量接近全图（全候选 99% 节点/边；top-2 仍 >80%），不能宣称结构压缩。
5. 全候选平均仍远差于 DENSE（+0.337/+0.249），且差于 top-1（Valid 显著）。按决策规则：**不再扩大 SES selector**。后验 oracle 接近 DENSE 只说明候选集上界，不构成扩大现有 selector 或增加候选平均的理由；本轮不据此提出 selector 扩展。

### 4.6 条件符号反转复现

SFEC v1 的“符号反转组”定义：同一 canonical pair 在不同 context `q` 上出现正、负相反的中位效应；对每个 `(pair, q)` 组，检查 Valid 真实中位数是否保持 Discovery 的符号。这里使用 SFEC v1 冻结的组定义（`n_discovery ≥ 10`，`|median| > thr`，同一 pair 同时有正、负组），在官方 Valid 上评估；只对 ≥5 个 Valid contexts 的组计算复现率。

| thr | 冻结 pairs | 冻结 groups | 有 Valid 观测的 groups | 支持组 | 支持观测 | 真实符号复现 | LCRC 符号复现 | LCRC 与真实同号 |
|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 0.10 | 172 | 749 | 541 | **215** | 3,282 | 201/215 = 93.5% | 209/215 = **97.2%** | 205/215 = 95.3% |
| 0.05 | 271 | 1,257 | 886 | **336** | 5,104 | 305/336 = 90.8% | 316/336 = **94.0%** | 315/336 = 93.8% |

Pair 级（双侧符号都得到支持）：

| thr | 双侧支持的 pairs | 真实双侧复现 | LCRC 双侧复现 | 严格双侧（真实 / LCRC） | 中位绝对误差：真实−Discovery / LCRC−真实 |
|---:|---:|---:|---:|---:|---:|
| 0.10 | 31 | 28/31 | 29/31 | 26/31 / 28/31 | 0.1116 / 0.0458 eV |
| 0.05 | 50 | 44/50 | 44/50 | 39/50 / 40/50 | 0.1061 / 0.0421 eV |

解释：

- LCRC 的符号复现率略高于 Valid 真实中位数本身（97.2% vs 93.5%；94.0% vs 90.8%）。这不表示模型“优于真实”，而是模型预测更平滑，受有限 Valid contexts 的采样噪声影响更小；关键数字是 **LCRC 与真实中位数的一致率 95.3% / 93.8%**。
- LCRC 的组中位数误差（0.0458/0.0421 eV）约为 Discovery 查表误差（0.1116/0.1061 eV）的 40%。这说明它不只是复述 Discovery 的组中位数，而是随 Valid 分子对发生了实质偏移。
- **支持限制：** 0.10 只有 215/749 个冻结组达到 ≥5 Valid contexts；0.05 只有 336/1,257。未支持组不能解释为“模型未掌握”；它们只是没有足够的 Valid 证据。
- **与 SFEC phase E 的区别：** SFEC v1 原来的 460 verifiable / 418 reproduced（0.10）是在其 **Train 内部 held-out cells** 上，不是官方 Valid。本轮按任务使用官方 Valid；本轮没有对 Train cells 做推理（任务只允许一次 ≤3 min 的 Valid 冻结推理，且 Train 规模远大于 Valid），所以不能把 215 组与 460 组直接比较，也不能把 97.2% 与 SFEC 的 90.9% 当作同一估计。

## 5. 科研判断与边界

### 5.1 对五个问题的直接回答

1. **修正后 SELECT 收益：** Valid −0.168、Test −0.105；比父轮冻结选择干预报告的 A−B −0.130/−0.069 更大（父轮主表的 cross-arm RANDOM 比较不受影响）。选择仍有效，但相对 DENSE 的压缩差距仍在。
2. **多候选平均改善及来源：** 全候选平均比 uniform 好 −0.092/−0.089 RMSE，但其 MSE 改善恰好等于候选方差（pooled 16.3%/16.6%），是方差缩减，不是互补结构信息；top-2 不优于 top-1。
3. **组合后实际读取的结构量（Valid）：** 全候选平均读 99.3%/99.0% 节点/边；top-2 读 83.6%/81.4%；top-1 读 63.0%/59.5%。没有结构压缩，只有多视图聚合/方差抵消。
4. **整图模型是否优于条件查表：** 是。LCRC MAE 0.111/0.115/0.104，PAIR_Q 0.282/0.203/0.285（全体/unseen/clean）；response slope 0.912/0.797/0.919 vs 0.352/0.387/0.359。整图模型已经编码了真实替换响应，而不仅是绝对标签。
5. **是否复现条件符号反转：** 是，在有充分支持的组上：0.10 为 209/215（LCRC）与 201/215（真实）；0.05 为 316/336 与 305/336。LCRC 的 pair 级双侧复现为 29/31 与 44/50（真实为 28/31 与 44/50）。支持组有限（215/749、336/1,257），不能外推到未支持组。

### 5.2 决策规则逐条

- **组合仍远差于 DENSE → 不再扩大 SES selector。** 全候选平均 Valid +0.337、Test +0.249（RMSE 更差）；top-2 不优于 top-1。即使后验 oracle 接近 DENSE，也不能用标签 oracle 作为扩大 selector 的依据。父轮路由 `SELECTION_EFFECTIVE_COMPRESSION_LIMITING` 保持。
- **组合接近 DENSE 但覆盖近全图 → 只能说多视图聚合有价值。** 本轮组合并未接近 DENSE（全候选平均仍差 0.337/0.249），且覆盖近全图；因此连“多视图聚合接近 DENSE”都不能说，只能确认方差缩减的价值。
- **整图优于 PAIR_Q 且复现条件规律 → 值得研究已有预测计算中的结构作用。** LCRC 在四个子集上显著优于 PAIR_Q，并在支持组上复现符号反转；这支持把下一步问题定为“现有整图预测计算如何利用结构”，而不是继续单独学习条件功能词典。
- **预测准但真实响应弱 → 报告绝对预测与结构响应差距。** 本轮整体上没有出现这种情形：LCRC 的 delta 相关 0.946、斜率 0.912、std 比 0.964；unseen 仍有 0.888/0.797/0.897（小效应端有收缩，见 4.4）。PAIR_Q 才是明显收缩的一方（斜率 0.352）。

### 5.3 科学结论

- **SES：** 选择器确实从候选中选出了比 uniform 更好的方案，但候选集的多候选结构没有提供可学习的互补组合；平均只抵消方差，top-2 不增加选择信息。候选集的后验上界接近 DENSE，说明“选择”仍是主要瓶颈；但在没有新的可学习选择信号前，扩大现有 selector 或增加候选平均不是有依据的方向。
- **PCQM：** 现有非 MP 整图模型（W3）在官方 Valid 上对真实替换响应的预测显著优于 SFEC v1 的条件查表，并且在其支持组上复现了条件符号反转。这个结果说明：**条件结构替换响应已经存在于整图绝对预测的计算中**，值得研究其内部结构作用；它不是“模型已经掌握了显式符号规则”的证明。LCRC 的 delta 是两个逐分子绝对预测之差，没有显式 pair 监督；因此本轮证明的是“预测意义上的响应编码”，不是因果机制或符号规则。

### 5.4 局限

1. **官方 Valid 是开发集。** W3 checkpoint 按官方 Valid MAE 选择（epoch 39），本轮又在同一 Valid 上评估；绝对和 delta 指标可能略偏乐观。没有 Test 标签，不能声称是 held-out 泛化估计。相对比较（LCRC vs PAIR_Q）使用同一 Valid 集，仍具诊断价值。
2. **单 checkpoint、单 seed。** 没有训练不确定性、没有多 seed、没有 W1/W2 对照；不能把 W3 的结果推广到所有非 MP 整图模型。
3. **近邻泄漏不能完全排除。** 已删除与 Train 完全重复的分子身份，并检查了 clean subset（去立体化学/重复 identity），但 1M Train 中仍可能有相似 scaffold/近邻分子；unseen exact context 只保证 C context hash 未见（SFEC 定义），不保证分子近邻未见。强结果在 unseen 和 clean 上仍成立，降低了但未消除这一担忧。
4. **符号反转支持有限。** 0.10 只有 215/749 组、0.05 只有 336/1,257 组达到 ≥5 Valid contexts；未支持组不能解释为失败。SFEC 内部 eval 的 460/418 与官方 Valid 的 215 组不是同一估计。
5. **依赖结构。** 分子在多个 context 中重复出现；context bootstrap 可能低估不确定性。分量 bootstrap 更宽但结论不变；最大分量在全体中占 10.2%、clean 中占 12.7%，仍不是独立样本。
6. **后验 oracle 不可部署。** candidate oracle 用了标签，只用于给出候选集上界；不能作为 selector 或组合方法的证据。
7. **LCRC 不是因果/符号模型。** 它预测绝对标签，delta 是差；没有显式学习“替换规则”的符号表示。说“编码了响应”是预测意义上的，不是说它内部有一个可读的 if-then 规则。
