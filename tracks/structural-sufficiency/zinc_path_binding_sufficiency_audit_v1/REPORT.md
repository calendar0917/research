## 3. L1 — 数学层（只做数学陈述，不含经验主张）

### 3.1 定理 1：逐路径求和 ≡ 先分支后合并（含梯度）

对固定根 `v`，令 `P_v` 为其有序非回溯两跳路径集合，`e1=v→w`、`e2=w→u`：

```
Σ_{p∈P_v} Q_p ⊙ K_p ⊙ Z_p  ≡  Σ_{w∈N(v)} Q(v,w) ⊙ ( Σ_{u∈N(w)\{v}} K(w,u) ⊙ Z(u) )
```

右侧只把 `K⊙Z` 在 `u` 上先合并、再乘 `Q`。两侧在 float64 下最大绝对差 **3.55×10⁻¹⁵**（692,716 条 train 路径），与逐路径统计流式实现差 **2.31×10⁻¹⁴**。梯度恒等也由 `tests/test_pb_math_equivalence.py::test_gradients_...` 在 torch autograd 下逐元素验证（`q,k,z` 三个梯度全部 `allclose(1e-12)`）。

**含义.** `T_real` 没有引入任何新的表达能力或新的统计内容；唯一能"新"的东西是 `Q,K,V` 的投影参数——而它们就是同一批 `a,b` 的线性读出。所以"动态路径绑定层"在数学上等于"给现有内容的乘积换一个求和顺序 + 学三个投影矩阵"。

### 3.2 `T_null` 是匹配尺度的边缘模型

`T_null = √n·(q̄⊙k̄⊙z̄)`，均值在**单个根内部**取。对独立同分布因子，`E[T_real]=E[T_null]`：4,000 次 Monte-Carlo、`n∈{1,2,3,5,8,13}` 下逐通道 `E[D]` 的偏差最大 z 值 **0.039**（`n=1` 时恒等为 0）。所以 `D` 不是范数伪影，而是"同一根下多条路径内容不独立"的度量。

### 3.3 命题 2：S2 是路径-内容构型的**非单射**压缩（构造性反例）

`content_agg(v) = Σ_p gate[cat_p] ⊙ a_{u_p}` 是 `(路径类型 × 端点内容)` 矩阵的一个 **秩 ≤96** 线性映射。因此在同一 `(cat189, end63, closure)` 单元内部重新分配端点内容，`content_agg` —— 因而整个 `X_v` —— **逐位不变**，但 `T_real` 会变。

真实分子上的实例（root atom 20089，6 条路径同属一个单元）：`content_agg` 最大差 **4.44×10⁻¹⁶**，`T_real` 最大差 **7.76**（相对差 **1.44**）。`tests/test_pb_math_equivalence.py` 把这条固化为回归测试。

**同时**，`T` 也不能决定 S2：`T` 对所有路径求和、对路径类型完全盲，把两个不同 `cat` 路径的内容互换，`T` 不变而 `content_agg` 改变（同一测试文件 `test_T_does_not_determine_S2_either`）。所以 S2 与 T **互不包含**，不是"同一个量的两种写法"。

### 3.4 补充事实：连一阶路径边缘都不完全在 X 里

过邻居 `w` 的两跳路径数正好是 `deg(w)−1`，所以一阶路径边缘 `Σ_p Q_p` 是**按邻居度数加权**的关联键嵌入之和；而 LCRC-A 的 S1 只存了**不加权**的 `b_sum = Σ_w b_vw`。这不是设计缺陷，但说明"路径统计 ⊂ 现有摘要"从一开始就不精确成立。经验值见 §4.5：`R²(T_Q|X)=0.951–0.971`。

### 3.5 L1 明确**不**声称的东西

- 不声称"存在两个不同 ZINC 分子共享同一个 `X_v` 但 `T` 不同"。within-cell 重分配是一个**统计构型**上的反例；它在真实图上是否可实现，本轮没有构造，也不下结论。
- 不声称"低秩 ⇒ 表达力不足"。§3.3 的结论来自显式构型，不来自秩。
- 不声称 `T` 携带了图以外的信息：`Q,K,Z` 全部是 `(a_v,b_e1,a_w,b_e2,a_u)` 的函数。

### 4.3 within-cell 配对质量 `U`

`T_swap` 把 `(K,Z)` 在**同一 (cat189,end63,closure) 单元内部**随机重排（X 不变、T 变），`U = T_real − T_swap`：

- 35.7% 的原子至少有一个多路径单元；47.1% 的原子 `U≠0`；最大单元重数 6；
- `rms(U)/rms(T_real) = 0.59–0.63`。

也就是说 `T_real` 的**大部分幅度**来自"哪条同类型路径带哪份内容"这种 X 结构上不可见的配对。这是 §3.3 命题在真实分子上的量化版本。**注意**：这只是"X 看不见"，不等于"真实图之间可实现不同配对"（§3.5）。

### 4.4 type-only 控制：残差是内容性的，不是类型路径性的

用 train-only 的 `ā[type]`、`b̄[(type,type,bond)]` 替换逐原子内容（同一投影、同一图、同一归一化），得到 `T_type/D_type`：

- 幅度只有真实的 **9–13%**（`rms D_type/rms D = 0.092–0.133`），因为 `ā` 的方差只有 `a` 的 0.48 倍、三重乘积后 ≈0.11 倍；
- 相对色散却与真实几乎相同：`rms(D_type)/rms(T_type) = 0.75–0.76`，而真实 `rms(D)/rms(T_real) = 0.69–0.72`；
- 在自己尺度下，22% 的原子的 `D_type` 恰为 0（所有路径的 typed 内容完全相同），`ρ_type_own` p10 = 0、`frac(ρ≥0.05)=0.78`；
- **关键**：train 上拟合的线性映射/CCA 在 valid 上**完全失效**——
  `R²(D_type → D) = −0.03 / −0.04`，`R²(D → D_type) = −0.08 / −0.08`，
  valid 规范相关全部 **≤0.017**（train 上 top-8 奇异值 0.35–0.62，是典型的过拟合，见 §6 缺陷 D1）。

**读法**：类型级结构只解释真实残差的 9–13%，且在 held-out 分子上与真实残差正交。所以真实 `D` **不是**类型路径结构的影子，而是"学习到的逐原子内容在 2–8 条路径间的离散度"——一个内容性的二阶统计量。

拟合原子 185,231（2000 个 train 分子留作 monitor）；valid 23,083。目标用 fit-subset 统计量标准化。无退化通道，无 near-constant 通道（224 维目标矩阵）。

|---|---|---|---|---|---|

| `T_null` | 0.261±0.018 | 0.439±0.014 | 0.285±0.018 | 0.440±0.015 | 0.076±0.008 |
| **`D`** | **0.173±0.012** | **0.281±0.023** | **0.195±0.014** | **0.288±0.023** | **0.056±0.006** |
| `T_type` | −1.06 | −1.25 | −1.13 | −1.28 | −0.28 |
| `D_type` | −0.78 | −0.99 | −0.84 | −1.01 | −0.19 |
| `h` | 0.822±0.012 | 0.896±0.003 | 0.853±0.011 | 0.899±0.003 | 1.000 |

（6 个 run = 2 checkpoint × 3 投影种子；`h` 行是"输入→h"的探针容量参考，不是 h 的自我复原。）

四个必须一起读的事实：

1. **置换控制**：打乱 train 目标行后，同一管线的 `R²(D)` = −0.002…0.000（S/X/h 全部）。管线不泄漏。
2. **探针容量已验证**：`X → T_lin`（`T_lin = X·W_rand`，32 维）ridge `R² = 0.998–1.000`；`X → h`（h 是 X 的 LayerNorm∘MLP 确定性函数）MLP `R² = 0.896–0.902`，ridge 0.82–0.86。所以 §4.5 的低 R² **不是**拟合能力或目标噪声造成的。
3. **缺陷是各向同性的**：X→D 的 32 个通道逐个 R² 落在 0.149–0.411（s0）/ 0.171–0.499（s1），均值 0.267 / 0.322；X→D 拟合后残差的熵有效秩 29.4/32、参与比 25.6。不是"漏了一个方向"。
4. **D 比 T_real 本身更难**（0.29 vs 0.45）：符合预期——`T_null` 那一半是"可学的平滑部分"，`D` 只剩对齐项。

**MLP 联合拟合的保守性（必须披露）**：协议让一个 MLP 同时拟合 224 维目标（含两个不可学的 type 块），早停按整块 monitor R² 决定，因此 type 块会占用容量并主导早停。用**专用目标集**（`[T_Q, T_QK, T_real, T_lin]`，128 维）重跑同一管线，`X→T_real` 升到 **0.383 / 0.447**；这是 `R²(D|X)` 的上界读数。两个读数都远低于 HARD 阈值 0.80，HARD 判据在两种读数下都成立。

### 4.6 缺口在哪：一阶在、二阶不在

同一探针，把 `T` 拆成三个因子层级（`T_Q` 只用第一跳，`T_QK` 加第二跳键嵌入，`T_real` 再加端点内容对齐）：

| 输入 | `T_Q` | `T_QK` | `T_real` |
|---|---|---|---|
| X ridge | 0.951–0.971 | 0.383–0.472 | 0.222–0.302 |
| X MLP | 0.957–0.961 | 0.599–0.648 | 0.383–0.447 |
| **X⁺ ridge** | **0.996** | **0.981** | 0.327–0.389 |
| **X⁺ MLP** | **0.982–0.984** | **0.968–0.971** | **0.707–0.788** |

`X⁺ = [X, Σ_p b_e2, Σ_p a_u, Σ_p q, Σ_p k, Σ_p z, Σ_p qk, Σ_p kz]` —— **同一批内容**的一次性定宽求和（881 维），不引入任何新编码器、不引入新参数。

结论：**第一跳几乎全在 X 里（0.95–0.97，缺的 3–5% 正是 §3.4 的度数加权）；第二跳键嵌入完全不在（0.38–0.65）；把第二跳内容和成对乘积加进摘要后，`T_real` 的复原跳到 0.71–0.79。** 缺口是可定位的"摘要组成"缺口，不是"信息不存在"缺口。`X⁺` 只是诊断探针（它借用了冻结随机投影），不是提议的特征集。

### 4.7 图级坍缩：否

`E = [global33, mean h, mean h², log(1+|V|)]`（162 维，已是 ρ 读头的精确输入）。`E → G_D`（每分子 `sum/mean/mean²` 的 `D`）：ridge ≤0.214、MLP ≤0.181；`E → G_T_real` ≤0.254；`G_T_type/D_type` 为负；反向 `G → E` 也为负。`D` **不是**披着原子外衣的分子标量。

### 4.8 支撑度分层：越"新"的地方绑定越强、越不可复原

半径-2 支撑键（train 分子计数；unseen=0 / low=1–3 / seen≥4），valid 原子 506 / 891 / 21,686（2.2% / 3.9% / 94.0%），25.1% 的 valid 分子至少有一个 unseen 原子：

| 组 | ρ 中位（s0 / s1） | rms D / 全局 | `R²(D|X)` ridge（s0 / s1） |
|---|---|---|---|
| unseen | **0.76 / 0.78** | 2.11 / 1.79 | **0.034 / 0.043** |
| low | 0.71 / 0.71 | 2.07 / 1.62 | 0.058 / 0.079 |
| seen | 0.41 / 0.47 | 0.89 / 0.89 | 0.215 / — |

绑定残差在**组合上新**的局部环境里最大，而那里恰好是整个摘要最不可复原的地方。

## 6. 判定（机械执行 `PROTOCOL.md` §8，附加缺陷披露）

### 6.1 机械结果

| 判据 | 结果 | 测量 |
|---|---|---|
| P1 BROAD（真实 `D`） | **FAIL** | A_s0 仅 1/3 种子通过（top1% 能量 0.310 / 0.278 > 0.25）；A_s1 3/3 通过 |
| P2 HARD（X 与 h 都难复原） | PASS | `min R²(D|X) = 0.175`，`min R²(D|h) = 0.048` |
| P3 CHECKPOINT-CONSISTENT | **FAIL** | 所有可学目标 spread ≤0.063；`D_type` 的 spread 0.28–0.32（两个 checkpoint 的 R² 都是负的，见 D2） |
| P4 NO-GRAPH-COLLAPSE | PASS | `max R²(G_D|E) = 0.214` |
| P5 TYPE-BINDING-PRESENT | **FAIL** | `n_broad(D_type)=0`；自己尺度下也仅 0/6 |

→ 触发 **N1**（不够 broad）与 **N4**（type binding 缺席）→ 冻结判定 **REDUNDANT / NO-GO**。**N2 与 N3 未触发**（`R²(D|X)` 最大 0.32，`R²(G_D|E)` 最大 0.21，都离 0.90 很远）。

敏感性：若把 P5 换成"type 控制在自己的尺度上"（`rho_type_own`），仍是 0/6 通过（22% 原子 `D_type≡0`、p10=0、`frac(ρ≥.05)=0.78`），结论不变；因此 **NO-GO 不依赖 P5 的尺度选择**。

### 6.2 三个协议缺陷（发现于测量之后，未回改协议）

- **D1（type 控制的尺度混淆）**：`D_type` 的幅度由内容方差决定（0.11×），不是由"是否有类型级绑定"决定。冻结的绝对尺度读法把"内容幅度小"误读成"结构不存在"；等尺度读法又因为 typed 内容离散（22% 原子零残差）而失败。两种读法都**不能**回答"N4 触发词所说的：新统计量是不是 X 中已有内容的重新参数化"。这个问题由 `R²(D|X)≤0.32`、`X⁺→0.79`、以及 `CCA(D_type,D)≈0` 三者共同回答：**不是**。
- **D2（一致性判据施加于不可学目标）**：`|R²(s0)−R²(s1)|≤0.15` 被施加到 `D_type`，而两个 checkpoint 的 `R²(D_type)` 都 ≈ −1（比预测均值还差）。两个"无意义负数"之差不是不一致性。排除 `D_type` 后，P3 的最大 spread 是 0.063。
- **D3（top-1% 能量 vs 广泛性）**：A_s0 的 31% 能量集中在 1% 原子上——但同一批测量显示 92.5% 原子 ρ≥0.05、100% 分子中位 ρ≥0.05。协议同时写了"top1% >0.25 ⇒ 不 broad"和"任何由 ≤1% 原子承载的结果 ⇒ INCONCLUSIVE"；两条在这里指向相反方向。本报告按协议字面判 FAIL，但把"重尾且化学上有结构（fused 环，3.3% 原子 / 20% 能量）"作为事实并列报告。

### 6.3 本报告实际主张的结论（与判定分开）

1. **不是代数冗余**：`T` 不是 S1/S2 的重新参数化（`R²(D|X) ≤ 0.32`；把同一内容的一阶+二阶求和加入摘要后升到 0.71–0.79）。
2. **不是 h 压缩问题**：`R²(D|h)=0.06 ≪ R²(D|X)=0.29`。h 是 X 的收缩，修 h 不能修 D。
3. **不是图级现象**：`R²(G_D|E) ≤ 0.21`。
4. **是内容性二阶统计量，不是类型路径结构**：type-only 残差占 9–13%，且在 valid 上与真实残差正交（CCA ≤0.017）。
5. **DFPB 层能买到的只有"组成"**：它的全部输入 `a_v,b_e1,a_w,b_e2,a_u` 已经由同一批共享编码器算出（`b` 在任意跳都是同一个 bond 编码器）；它新增的自由度是 3 个 32×d 投影。也就是说，DFPB = "对既有内容学一个二阶摘要"。
6. **所以：不为 DFPB 买 GPU 轮次**。若要让审计产生行动，最小判别实验不是 DFPB，而是**在现有编码器上加一次"第二跳组成"摘要并重训**（见 §8）。

## 7. §6 已知历史缺陷：LCRC-v1 `N` 分支的批次级 mean-field（只记录，不修数字）

**缺陷.** `lc_models.LCRC` 的 `N` 聚合模式用 `z.mean(0)`——对整个 batch 求均值——作为"每分子 mean-field"。于是同一分子的 `Δ_rel` 取决于 batch 里还有谁。`R` 模式按分子聚合，无此问题。

**为什么当年没被抓到.** 关系读头零初始化，`Δ_rel≡0`，任何聚合方式都给出 0；G2 不变性 gate 因此被平凡通过。

**本轮测量（`analysis/batch_invariance.json`，非零关系头 scale 0.05，随机初始化 LCRC 主体，probe 分子 0–3，batch ∈ {4,128}）**：

| 聚合方式 | 跨 batch 的 `max|Δ_rel|` 极差 | `mean|Δ_rel|` 极差 |
|---|---|---|
| `R`（按分子） | **0.0** | 0.0 |
| 修正 `N`（按分子 mean-field） | **0.0** | 0.0 |
| 历史 `N`（整 batch 均值） | **8.22×10⁻⁴** | 7.93×10⁻⁴ |

`Δ_rel` 的量级约 3.9×10⁻³，所以历史 `N` 的跨 batch 漂移是 **~21% 相对**。

**对历史数字的影响（诚实评估）**：冻结的 `lcrcN_s0` 的关系头范数只有 **2.23×10⁻³**，在 batch 4 vs 128 下的 `Δ_rel` 极差 **4.04×10⁻⁴**，相对该 checkpoint 的 valid MAE（0.0815）约 0.5%。所以 LCRC-v1 报告的 N 数字**方向性结论不变**，但 N 分支实际上几乎是惰性的；任何未来的 N 实验必须用按分子的修正聚合。

**回归测试**（`tests/test_pb_n_branch_batch_invariance.py`）：① `R` 模式批次不变；② **非零**头下历史 `N` 必须有批次依赖（这是对冻结历史实现的刻画测试，修好后应当失败并提示重推 N 的解释）；③ 修正聚合批次不变（严格 0）；④ 修正聚合等于显式逐分子均值。

## 8. 建议：唯一的最小判别实验

**不买 DFPB GPU 轮次**（冻结判定 NO-GO；且 §4.6 表明 DFPB 的唯一增量是"组成"，不是"内容"）。

若要把本审计转成一次行动，唯一值得的最小实验是 **1 GPU·h** 的"第二跳组成"注入，用现有编码器、现有目标、现有划分：

- 在 `LocalContent` 的输入上追加 3 个**定宽、无参数**摘要：`Σ_p b_e2`、`Σ_p K_p`、`Σ_p K_p⊙Z_p`（或等价的 `Σ_p b_e2` + `Σ_p a_u⊙b_e2` 分块求和），维数 ≤160；
- 其余一切冻结（同 237,519 → 略增参数、同 epoch 预算、同 seed、同 valid gate）；
- 判别指标：valid MAE 相对 A_s0 0.076582 的变化，与 LCRC-v1 已测到的 seed 噪声（±0.002）比较。

若这个 1 GPU·h 实验无信号，则"两跳内容组成"方向应当关闭；若有信号，才值得再讨论学习式 Q/K/V（DFPB）——且那时它已经是"已证明有用的组成的可学习版本"，而不是一次盲赌。

## 10. 结论

`T_real` 在数学上是既有内容的一个求和顺序；在真实分子上，它的对齐残差 `D` 广泛存在（原子 ρ 中位 0.44–0.48）、高维（erank 24–27）、化学上有结构（fused 环 3.3% 原子承载 10–20% 能量），并且**确实不在**现有 S1/S2 里（`R²(D|X)≤0.32`，探针容量已被 `X→T_lin=1.000`、置换控制 `≈0` 验证）。缺的东西可以被定位：第一跳在（0.95–0.97），第二跳键嵌入不在（0.38–0.65），把同一内容的第二跳与成对求和加入摘要后跳到 0.71–0.79。类型级结构只解释 9–13%，且在 held-out 分子上与真实残差正交。因此这不是"新统计量"的胜利，也不是"代数冗余"的胜利；这是**摘要函数**的缺口。冻结判定按 N1+N4 给出 NO-GO，所以不买 DFPB GPU；若要花 1 GPU·h，就花在第二跳组成的注入上。

**最值得改进的不是统计内容（`T` 已被证明只是既有 `a,b` 的组成，无需任何新编码），不是 `X_v→h_v` 的压缩（`R²(D|h)=0.06 ≪ R²(D|X)=0.29`，h 的收缩只会丢掉更多），而是统计量的组成函数（statistics composition function）——把定宽的一阶求和换成保留第二跳内容与联合配对的二阶摘要。**
