## Q1 — C1（228 674）能否替代 A0（247 106）作为主模型？

**判定：`KEEP_C1_AS_MAIN_BUT_NOT_EQUIVALENT`**

依据（10 个数据集、每个 3 seeds / 10 个 fold-seed 单元）：

| 数据 | Δ C1−A0 | 95% CI | 方向 |
|---|---|---|---|
| ESOL（RMSE） | −0.0111 | [−0.0507, +0.0248] | C1 好 |
| FreeSolv（RMSE） | −0.0211 | [−0.0921, +0.1017] | C1 好 |
| BACE（AUC） | +0.0095 | [−0.0259, +0.0453] | C1 好 |
| BBBP（AUC） | +0.0019 | [−0.0169, +0.0283] | C1 好 |
| Tox21（macro AUC） | +0.0022 | [−0.0023, +0.0153] | C1 好 |
| MolHIV（AUC） | −0.0105 | [−0.0511, +0.0093] | C1 差 |
| NCI1（acc） | −0.0055 | [−0.0113, +0.0018] | C1 差 |
| PROTEINS（acc） | −0.0059 | [−0.0180, +0.0031] | C1 差 |
| IMDB-BINARY（acc） | −0.0110 | [−0.0310, +0.0075] | C1 差 |
| IMDB-MULTI（acc） | +0.0033 | [−0.0073, +0.0130] | C1 好 |

* **10/10 的 CI 跨 0**，且没有一个数据集的方向达到其自身 fold/seed 波动的量级。
* 5 好 5 差（分子 5 好 1 差、TU 1 好 3 差），**方向不一致** →
  既不能宣布"C1 更强"，也不能宣布"C1 更弱"。
* 唯一方向稳定的是 Lipophilicity 冻结历史：3 个 repeat 上 C1 的 Valid RMSE
  一致低 0.0006–0.0019，Test 差值 −0.0160…+0.0030 由 repeat 噪声主导。

**取舍**：保留 C1 作为主模型（参数少 7.5%、每 epoch 时间与 A0 相同、
显存/缓存略低，且没有任何证据显示它系统性更差），
但在写作与后续引用中**必须**写成"未见可检测差异"，**不得**写成"等价"。
若下一轮需要更强的结论，应提高 seed 数而不是继续增加数据集
（当前每数据集 3 seeds，CI 半宽 ≈ 0.02–0.05 RMSE / 0.01–0.03 AUC）。

## Q2 — 结构统计块（`b_mean`）被删掉意味着什么？

**判定：`B_MEAN_NOT_THE_MECHANISM`**

1. 删除的 18 432 参数**全部**落在 `local.mlp.lins.0.weight`
   （192×529 → 192×433），是纯粹的输入宽度缩减，没有改变任何结构通路。
2. 预测层面无差异（Q1），说明在这个规模上 `b_mean = b_sum/deg`
   提供的信息**被其它通道替代**（`b_sum`、`a`、typed-S2 仍在）。
3. `FROZEN_MODEL_INPUT_INTERVENTION` 显示：13 个 checkpoint 中 11 个
   以 typed-S2 为最强输入通道（零化后 Δ 为对照通道的 2–11 倍，
   分类任务排序相关系数降到 0.15–0.42），而 **C1 与 A0 的依赖程度基本相同**。
   → 删掉 `b_mean` **没有**降低对 typed-S2 路径特征的依赖。
4. 效率层面：参数 −7.5%，但每 epoch 时间比 0.97–1.02、推理吞吐与 CUDA peak
   在噪声内、结构缓存完全相同（共享流水线）。

**取舍**：不要把这个结果读成"bond-mean 统计无用"，只能读成
"在本轮 6 个分子数据集 + 4 个 TU 数据集上，删掉它不改变可测量的性能，
也不改变模型对 typed-S2 的依赖"。要检验"结构统计是否充分"，
需要**同容量**重训对照（本轮禁止，也没有做），或直接对
`b_sum` / `s2_*` 做同容量消融。

## Q3 — 迹分解能否解释/预测局部编辑误差？

**判定：`NO_INCREMENT_THIS_PROBE`（可追溯性成立，可预测性不成立）**

* **可追溯性成立**：`d_pred = dL_var + dL_core + dR` 在 6 个 checkpoint、
  509 对、3054 条迹上最大残差 **1.1e-6**；反序 5.7e-7、批量 4.8e-7、
  原子重编号 8.3e-7 —— 都是浮点噪声级。
* **可预测性不成立**：一次性 Audit（74 对 / 26 个配对组件）上，
  C1 的 `Gain = Audit_MAE(BEST_BASE) − Audit_MAE(TRACE) = +0.0015`
  （CI [−0.0108, +0.0114]，阈值 0.03），A0 为 +0.0033。
  更关键的是：**每个单元的最佳方法基本都是零预测器** `NATIVE`/`FAMILY`；
  `Gain > 0` 只因为 Diagnose 上选出的 `BEST_BASE=GLOBAL` 在 Audit 上
  比零预测器差 0.004–0.006。
* 描述性诊断：去最差组件/分子后符号不变（不是单点驱动）；
  闭环残差非零（mean 0.0081 / max 0.0560）→ 不能声称单分子预测器闭合；
  gauge 变换使 MAE 变化 0.04–0.40 → 这些系数只能当误差预测器，不是化学分解。

**取舍**：迹分解继续作为**诊断工具**（恒等式与稳定性已被验证），
但**不要**把它当作误差的可解释性来源。若要继续，
下一轮应在协议层面修正两处（见 Q5）。

## Q4 — 与文献/冻结历史相比，本轮模型处在什么位置？

**判定：`REFERENCE_ONLY_LOW_MID`（定位可以，胜负不可以）**

|---|---|---|---|
| MolHIV GIN+virtual node（官方榜） | 0.7707 ± 0.0149 | A0 0.7716 / C1 0.7611 | 与 GIN-VN 同档 |
| MolHIV PNA / GINE / CIN / HIG | 0.7905 / 0.7921 / 0.8094 / 0.8403 | 同上 | 低于全部四个 |
| NCI1 GIN（Xu et al. 2019） | 82.7 | A0 82.96 / C1 82.41 | 与 GIN 同档 |
| PROTEINS GIN | 76.2 | 75.92 / 75.33 | 略低于 GIN |
| IMDB-BINARY GIN | 75.1 | 73.70 / 72.60 | 低于 GIN |
| IMDB-MULTI GIN | 52.3 | 48.10 / 48.43 | 明显低于 GIN |
| ZINC-12k DCC-L（本仓库冻结） | 0.0673 MAE | —（本轮不重训） | 仅作参照 |
| ZINC-12k GRIT / ESA+（论文） | 0.059 / 0.052 | — | 本轮不复现 |

## Q5 — 执行与预算是否充分？下一轮该做什么？

**判定：`EXECUTE_AGAIN_WITH_PROTOCOL_FIXES`**

**预算事实**：墙钟 ≈ 6.7 h（上限 8 h），GPU **9.091 GPU-h**（软上限 14、硬上限 16），
0 个失败单元，36 次一次性 Test 访问，13/13 门禁通过。
预算不是限制因素——`C_5x2` 的选择是**成本规则**的结果，不是时间压力。

**必须修的三件事（按优先级）**

1. **把 `NATIVE`（零预测器）固定为 baseline 集合成员**
   （本轮 `BEST_BASE` 只在 `{NATIVE, FAMILY, GLOBAL}` 里选，理论上已包含，
   但 Diagnose CV 让它选了比零预测器更差的 `GLOBAL`）。
   修正：报告 `Gain` 时**同时**给出对零预测器的增益，并以"对零预测器的增益"
   作为主判定量；否则任何过拟合的 baseline 都会制造假正增益。
2. **提高 Audit 的配对组件数**：26 个组件给出的 CI 半宽 ≈ ±0.011，
   要分辨 0.03 的效应至少需要 ~4 倍组件数（≈100 个组件）。
   在现有 509 对里做不到，需要新的编辑对生成轮次。
3. **换特征族而不是换正则**：`dL_var/dL_core/dR` 已被证否；
   值得试的是 mapping 质量指标（`n_core_atoms_changed`、`max_abs_dh_unchanged`、
   `mapping_unique`）与逐原子 `Δf/Δh` 的分布矩。

**不必再做**

* 不要再用更多数据集/种子去追 A0/C1 的差异：10/10 CI 跨 0，方向不一致，
  继续加样本的边际收益低于修协议。
* 不要用 `C_5x2` 的结果去主张 10 折的等价性。
* 不要复用本轮 checkpoint 做"同容量消融"之外的机制声明。

## 一句话总结

**预测强度**：C1 可以继续作为主模型，但只能声明"未见可检测差异"（10/10 CI 跨 0）。
**结构充分性**：`b_mean` 不是机制所在——删它不改性能，也不改对 typed-S2 的依赖。
**可追溯性**：迹恒等式成立到 1e-6，但**误差不可由迹预测**（`NO_INCREMENT_THIS_PROBE`）。
**外部定位**：与 GIN/GIN-VN 同档，低于 PNA/GINE/CIN/HIG 与 GRIT/ESA+，且本轮不复现它们。
**下一步**：修 baseline 规则（零预测器）、扩 Audit 组件数、换特征族；不要再加数据集。
