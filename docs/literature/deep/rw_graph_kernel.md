## 一句话

用两图上**共同随机游走**（或标签路径期望）定义相似度，再 SVM 等分类。

## 四问

### 1. 旧方法缺陷？

- 图同构难；需要可计算的结构相似度。  
- 仅节点特征忽略连接模式。

### 2. 关键一步 / 假设与代价？

- 直积图 / 标签路径计数；marginalized kernel 用隐路径期望。  
- 假设：游走统计能反映结构像不像。  
- 代价：朴素实现贵（可低秩加速）；**输出是核值 \(K(G,G')\)，不是可还原子图字典**。

### 3. 目的？

**B** 图分类（核机器）为主；也可当结构指纹。

### 4. 与主线？

| | 关系 |
|--|------|
| WL-Kernel | 另一类预定义结构特征（重标记直方图） |
| GSN/CIN | 显式子结构，但是计数/cell，不是核 |
| **KSVD** | 都承认「路径/局部模式携带结构」；我们要 **分解原子**，不是核矩阵 |

## 数据流

```
G,G' → 游走/路径特征 → K(G,G') → SVM
```

组内：路径标签序列可作路线 **R1** 的 \(y\)；主推仍是 **R2 诱导子图 + KSVD**。

## 边界

- 导师口述「步数接近→结构像」的学术来源在此；**不能**把核 Acc 和我们 KSVD+GIN 混表。  
- 不解决感受野冗余的「采样设计」问题。

## 口述 3 点

1. RW 很早就是合法结构指纹。  
2. 核 = 相似度，不是可还原编码。  
3. 我们站在「指纹 → 再分解」而不是「指纹 → SVM」。
