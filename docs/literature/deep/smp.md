# SMP（Structural Message-Passing）—— 等变局部上下文编码

> 组内动机：luyin12 的「置换不变 vs 编码局部结构」矛盾 + 第九/十/十一轮 ID-free/canonical 路线的第三方对照。  
> 本文：**具体做法 + 等变参数化原理** + 与组内 KSVD/patch 路线的距离。

| 项 | 内容 |
|----|------|
| 短名 | SMP |

| 作者 | Clement Vignac, Andreas Loukas, Pascal Frossard |

---

## 四问

### 1. 旧方法缺陷？

标准消息传递（MPNN/GIN 类）把邻居当**无序集合**对称聚合（sum/mean/max）→ 表达力 ≤ **1-WL**：

- 节点只有 O(d) 维向量，存不下「谁和谁连」的局部拓扑（triangular prism vs K3,3 分不开，与我们 `wl_ksvd` 审计同源）；
- 想编码局部结构就必须给节点定顺序，但**等变要求禁止用顺序**——这是「置换不变 vs 编码」的核心矛盾。

### 2. 关键一步 / 假设与代价？

两步，外加一个明确的代价：

1. **传 one-hot，构造 local context matrix**：每个节点 v 维护一张矩阵 `M_v`，行/列按 one-hot 索引（即按节点编号组织），里面同时有「邻域谁连谁」（拓扑）和「每个节点什么特征」。信息量远超一个向量。
2. **消息/更新函数用等变参数化**：所有处理 `M_v` 的函数对行/列**任意置换**等价（对称聚合、对排列共享参数），于是「矩阵带顺序没关系，读出来的结果与顺序无关」。

- 代价：每节点上下文矩阵 O(d²) 存储/计算，论文里半径受限、讨论稀疏化；不是免费的。
- 假设：等变读 + 完整上下文 = 表达力与不变性可以兼得（不需要洗掉或固定顺序）。

### 3. 目的？（A 表达力 / B 图分类 / C 其它）

A + B：

- **A**：合成数据预测图拓扑性质（直径、连通性、三角形数等）显著优于旧方法；
- **B**：ZINC 分子回归达到当时 SOTA（MAE ≈ 0.115，无边特征 / ≈ 0.079，有边特征）。

### 4. 与主线 Kernel–GNN–GSN–KSVD？

| 对象 | 存储局部结构的方式 | 等变怎么保证 |
|------|--------------------|--------------|
| WL / GIN | 子树 multiset（求和哈希） | 对称聚合 |
| GSN / CIN | 环/子图计数（特征）或 lift 成 cell | 计数本身不变 / cell 结构不变 |
| **SMP** | **节点级 local context matrix** | **等变参数化读**（不固定顺序） |
| **我们（patch 路线）** | 窗格 45D 邻接 / 22D 描述子 | ID-free 洗掉 / rooted-canonical 固定 / 关系等变 |

SMP 恰好站在我们两条修复路线（洗掉 / 固定）之间的第三态：**保留完整局部编码，用等变算子读**。

## 数据流

```
图 G + node features
  → 每节点初始化 local context matrix（one-hot × features 的结构快照）
  → L 层：等变消息传递（聚合邻居的上下文矩阵，等变更新）
  → 池化上下文矩阵 → 节点表示 → 图级 readout → 预测
```

---

## 具体做法（三层）

### Step A — 每节点一张「局部上下文矩阵」

- 对每个节点 v，定义上下文矩阵 `M_v`，行/列索引 = v 邻域内节点的 one-hot 编码；
- 矩阵元同时编码：`(i,j)` 位置 = 节点 i、j 之间是否有边（拓扑）+ 各自特征；
- 结果：v 的表示从「一个向量」升级成「一张局部结构快照」，能保存 1-WL 会抹掉的二阶/局部拓扑信息。

### Step B — 等变的消息传递

- 消息：邻居把各自的上下文矩阵发过来，聚合时用**对排列不变/等变的对称函数**（共享参数，sum/mean 类）；
- 更新：对 `M_v` 的操作要求与行/列排列**可交换**——例如对称化（行/列同时换序仍等价）、对行/列做排列共享的聚合；
- 关键性质：整个计算图的每一步都是 permutation-equivariant，所以整体对 one-hot 的具体选择不变。

### Step C — 池化与读出

- 把每节点的上下文矩阵池化成节点向量（如对矩阵行/特征做对称聚合）；
- 节点向量再图级 readout → 图表示 → 预测。

---

## 等变参数化（关键，组内概念对齐）

- **等变**：对任意节点排列 π，`f(P·x) = P·f(x)`——「先换序再算」=「先算再换序」；
- **等变参数化**：设计网络参数，使函数对排列无感。最朴素是**对称聚合**（sum/mean/max 对集合顺序不变）；难在**对带顺序的矩阵**也要等变——不能直接 `W·M`（W 固定时行排列会变输出），必须用**对行/列排列共享参数的算子**（对称化、按行列聚合）；
- 一句话：**等变参数化 = 让函数「对节点排序无感」的设计；把带顺序的表示，读成与顺序无关的量。**

这与我们第四轮结论形成对照：我们试过**固定顺序**（slot-persistent，失败）；SMP 证明**不固定顺序、用等变读**也可行，且保留更多信息。

## 和组内 KSVD / patch 路线对照

| | SMP | 我们 |
|--|-----|------|
| 局部结构对象 | 节点级上下文矩阵 | 窗格（10 节点诱导子图） |
| 顺序怎么办 | 保留，等变参数化读 | ID-free 洗掉 / rooted-canonical 固定 |
| 关系 | 邻域矩阵内蕴 | 显式 overlap + center distance（第九轮） |
| 表达力来源 | 上下文矩阵 > 1-WL | 窗格感受野 + 关系 |
| 编码器 | 学出来的等变网络 | 尚未实现（ridge 审计 + 重建主链冻结） |

**直接启示**：我们下一步的 relation-aware encoder 的约束，SMP 已经给出规格——

1. 输入可以是**完整 45D patch 邻接**（不必先洗成 22D 统计）；
2. 对「窗格内节点排列」和「窗格序列排列」都要**等变参数化**；
3. 这样既不丢信息（相对 ID-free），又不依赖 canonical 唯一命名（相对第十一轮 automorphism 边界）。

---

## 边界（这篇不能证明什么）

- **不是首个超过 1-WL 的方法**：与 GSN（2019）/ CIN（2021）同期/先后，路线不同；
- **上下文矩阵是手工 one-hot，不是学出来的结构词汇**——不等同于「字典原子有意义」；
- ZINC 数字是 **2020 年** SOTA，已被后续方法超越，作基线引用需注明年代；
- O(d²) 上下文的**理论复杂度与稀疏化**未完全解决，真实大图代价要评估；
- 不涉及图压缩/可还原性，与第八轮 rate-distortion 问题无关。

---

## 口述 3 点

1. SMP 让每个节点攒一张「局部结构快照」（one-hot × 特征的上下文矩阵），信息量大于一个向量，所以超过 1-WL。
2. 它用「对排列共享参数的等变函数」去读这张带顺序的矩阵——编码完整，但换标签结果不变。
3. 对我们的意义：它就是「完整邻接 + 等变编码器」的现成答案，是我们 ID-free / canonical 之外的第三条路，也是 luyin12 那个 Transformer 愿景的直接设计参考。
