# Random Walk Positional Encoding（压缩精读）

> 组内对照：不可还原的 RW 统计 vs 可还原 KSVD

| 项 | 内容 |
|----|------|
| 短名 | RWPE |
| 代表 | 图 Transformer 中常用：多步随机游走着陆概率 / 转移矩阵对角线等作位置或结构特征（如 Rampášek et al. GraphGPS 等设定中的 RWPE 族） |
| 层级 | C（对照） |
| 日期 | 2026-07-24 |

## 一句话

把节点的**多步游走统计**（如 \(t\) 步回到自己的概率）当成位置/结构向量，拼进网络。

## 四问

### 1. 旧方法缺陷？

- 纯 Transformer 无图结构偏置。  
- Laplacian PE 有符号歧义等；需要稳定结构信号。

### 2. 关键一步 / 假设与代价？

- 用 \(RW^t_{ii}\) 或着陆分布摘要作 \(d\) 维向量。  
- 假设：返回/扩散统计反映角色与距离结构。  
- 代价：**统计不可还原为「原子拼接」**；与「字典分解」叙事不同。

### 3. 目的？

**C**：当 PE/结构偏置抬下游；非表达力主证明工具。

### 4. 与主线？

| | 关系 |
|--|------|
| GSN/CIN | 都显式结构；一边计数/cell，一边游走统计 |
| **KSVD** | 都可当结构通道；我们要 **可重构 \(Y\!\approx\!DX\)**，RWPE 作**对照基线**最合适 |

## 数据流

```
G → P^t 或着陆统计 → pe(v) → concat / add 进 GNN/GT
```

## 边界

- luyin4 提过 RW 概率当 PE；**不能**说成组内 KSVD。  
- 消融：同一下游下 pe vs KSVD 系数，才谈「可还原」是否多卖点。

## 口述 3 点

1. RW 统计 = 便宜结构偏置。  
2. 不可还原。  
3. 我们用它当对照，不是终点。
