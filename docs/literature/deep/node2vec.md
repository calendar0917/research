## 一句话

用 **二阶偏置随机游走**（参数 \(p,q\)）在 BFS/DFS 之间插值采邻域，再 Skip-gram 学节点嵌入。

## 四问

### 1. 旧方法缺陷？

- 手工网络特征：费力、任务绑定。  
- 谱方法 / 矩阵分解：特征分解贵，且目标与多样连通模式不对齐。  
- DeepWalk / LINE：邻域定义**过刚**——均匀游走或固定 1/2-hop，难同时刻画 **同质性（社区）** 与 **结构等价（角色/hub）**。

### 2. 关键一步 / 假设与代价？

**关键**：邻域 \(N_S(u)\) 由可调采样策略 \(S\) 生成；\(S=\) 长度 \(l\) 的 2 阶 RW，转移

\[
\pi_{vx}=\alpha_{pq}(t,x)\,w_{vx},\quad
\alpha_{pq}(t,x)=\begin{cases}
1/p & d_{tx}=0 \text{（回退到刚来的 }t\text{）}\\
1 & d_{tx}=1\\
1/q & d_{tx}=2
\end{cases}
\]

| 旋钮 | 作用（直觉） |
|------|----------------|
| **\(p\)（return）** | 大 \(p\)：少立刻回头 → 减 2-hop 冗余、促探索；小 \(p\)：常回退 → 更贴局部 |
| **\(q\)（in-out）** | \(q>1\)：偏 inward / 近似 **BFS** → 利于 **结构角色**；\(q<1\)：偏 outward / 近似 **DFS** → 利于 **社区同质** |
| \(r,l,k,d\) | 每点 walk 数、长度、Skip-gram 窗口、嵌入维 |

目标：\(\max_f \sum_u \log Pr(N_S(u)\mid f(u))\)，负采样 + SGD。边特征用节点向量二元算子（平均 / Hadamard / L1 / L2）。

**假设**：无监督邻域保持对下游有用；真实图是同质与角色的混合。  
**代价**：\(p,q\) 需网格/半监督搜；2 阶预处理 \(O(a^2|V|)\)（\(a=\) 均度）；采样随机性 → 要报种子。

### 3. 目的？（A / B / C）

| 标签 | 本文 |
|------|------|
| **C** | 主：节点嵌入 → 多标签分类、链接预测（任务无关表示） |
| 非 A | 不讨论 WL / 图同构表达力 |
| 非我们的 B | 不是图级 TUD 分类主战场 |

### 4. 与主线 Kernel–GNN–GSN–KSVD？

| | 关系 |
|--|------|
| Kernel | 都用路径/游走结构；核是计数相似度，这里是 **嵌入** |
| GNN | 更早、无监督邻域；我们下游可接 MLP/GNN，但 **不** 把 n2v 当结构原子 |
| GSN | 都关心子结构形态；GSN 人设计数，n2v 是 **采样形态旋钮** |
| **KSVD 轨** | **只借游走偏置**：\(p,q,l\) 控制「走出的形状」→ 诱导子图 → 再 KSVD。**不**采用 Skip-gram 终局，**不**声称 n2v 嵌入可还原 |

## 数据流

```
G → 预计算 π(p,q) → 每点 r 条长 l 的 2 阶 RW
  → 把轨迹当「句子」→ Skip-gram / 负采样 → f(v)∈R^d
  → 节点分类 / 边算子链接预测
```

组内若只采子图，**截断在「RW 产出节点集/边序列」**，不接 Skip-gram。

## 边界（这篇不能证明什么）

- 不能证明游走诱导子图可还原、也不能给 KSVD 字典合法性。  
- 不保证枚举到化学环；\(q\) 偏局部只是统计倾向。  
- Les Misérables 案例是示意，不能外推到 molhiv。  
- \(p=q=1\) 退化为 DeepWalk 式均匀游走。

## 口述 3 点

1. 一张图两种相似：社区挤一起 vs 角色像（hub/桥）——要用不同搜索。  
2. \(p,q\) 是 BFS↔DFS 的连续旋钮，不是魔法超参名。  
3. 我们拿 **采样策略**，不拿它的 **词向量终点**。

## 组内可抄参数草案（RW-C0）

| 参数 | 起步建议 | 备注 |
|------|----------|------|
| \(p\) | \(\{0.5,1,2\}\) | 大 → 少回头 |
| \(q\) | \(\{0.5,1,2\}\) | 分子环可先试 \(q\ge1\) 偏局部 |
| \(l\) / 或 \(|S|_{\max}\) | 4–16 / cap \(m\) | 防半图 |
| 输出 | 轨迹或诱导 \(G[S]\) | 进 KSVD 的 \(y\) |
