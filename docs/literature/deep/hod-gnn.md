# HOD-GNN（High-Order Derivative GNN）—— 用导数增强表达力

> 组内对标动机：GNN 表达力层次（1-WL → Subgraph GNNs → KSVD）与结构编码（RWSE/GSN）的交叉点。  
> 本文：**用 MPNN 导数替换子图枚举**，理论上等价于 k-OSAN，计算上更高效。

## 四问

### 1. 旧方法缺陷？

MPNN 表达力 ≤ 1-WL，区分不了简单非同构图。增强表达力主要有两条路：

- **Subgraph GNNs**（如 DS-GNN、k-OSAN）：枚举子图 → 表达力强 → 复杂度 `O(n^(k+1))`，中等图就 OOM；
- **Structural Encodings**（如 RWSE、Laplacian PE）：附加结构特征 → 提升有限，无法达到 Subgraph GNNs 表达力。

两者间存在 **表达力 → 可扩展性** 的 trade-off，缺一个「又强又能跑大图」的方案。

### 2. 关键一步 / 假设与代价？

**关键一步**：用泰勒展开连接「标记操作」与「导数」——标记后的 GNN 输出 `M(X + ε·e_v)` 可展开为各阶导数的加权和。因此**导数天然编码了标记操作的信息**，可以近似任意 Subgraph GNN 的行为。

**代价**：
- 需要解析激活函数（SiLU 等）才能达到理论最优表达力；ReLU 也能用但略弱；
- 高阶导数张量理论上 `O(n^(k+1))`，但利用稀疏性可压到 `O(n · min{n^k, d^(k·T)})`；
- 当前 PyG 稀疏矩阵算子效率有限，实际速度有提升空间。

**假设**：基础 MPNN 的聚合函数是线性的（GIN/GCN 等主流架构满足）。

### 3. 目的？（A 表达力 / B 图分类 / C 其它）

**A + B**：

- **A**：理论上证明 1-HOD-GNN 严格强于 RWSE+MPNN（Thm 4.2），k-HOD-GNN 可近似任意 k-OSAN 从而可达 folklore k-WL（Thm 4.1）；
- **B**：ZINC、OGB、Peptides 上一致 top-2 表现，且 Peptides 上超越所有采样子图方法；
- 可扩展性本身也是卖点：Peptides 上完整子图 GNN 跑不了，HOD-GNN 能跑。

### 4. 与主线 Kernel–GNN–GSN–KSVD？

| 方法 | 结构信息来源 | 表达力 | 计算复杂度 | 与 KSVD 关系 |
|------|-------------|--------|-----------|--------------|
| GIN/MPNN | 隐式邻域聚合 | ≤1-WL | O(E) | 对照基线 |
| RWSE | 随机游走对角 | >1-WL 有限 | O(L·E) | 我们也在用 RW |
| GSN | 子图同构计数 | >1-WL（手选 H） | O(计数开销) | 同显式结构，但 GS 预设计数 |
| CIN | 环 lift 成 cell | >1-WL | O(环枚举 + MP) | 环先验强，分子好 |
| k-OSAN | 枚举 k-节点子图 | folklore k-WL | O(n^(k+1)) | 最接近的理论对标 |
| **HOD-GNN** | **MPNN 导数** | **=k-OSAN** | **O(n·min{n^k, d^(k·T)})** | 可做导数版结构编码，**与 KSVD 正交**（KSVD 学字典，HOD 用导数） |

HOD-GNN 站在 Subgraph GNNs 和 Structural Encodings 之间：它用**解析导数**替代了子图枚举，获得等价表达力但更高效。与 KSVD 的关系是**正交的**——HOD 提供一种新的结构感知特征构造方式，可以与稀疏编码结合。

## 数据流

```
图 G = (A, X)
  → 基础 MPNN ℳ 前向：h^(T), h^out
  → 同时计算导数张量 D^(T), D^out（算法 1：消息传递式导数传播）
  → 编码器 U^node / U^out 提取导数特征
  → 拼接 h^der_v = h^(T)_v ⊕ U^out(D^out) ⊕ U^node(D^(T))
  → 下游 GNN 𝒯 用 h^der 做预测
```

---

## 具体做法

### 1-HOD-GNN（k=1，单节点导数）

**导数张量定义**：
```
D[h][v, u, i, j, α] = ∂^α h_v,i / ∂X_u,j^α
```
- `D^(T) ∈ R^(n×n×d'×d×m)`：节点 v 对节点 u 的各阶导数
- `D^out ∈ R^(n×d'×d×m)`：图输出对节点 u 的导数

**编码器**：
- `U^out(D^out)_v = MLP(D^out[v,...])`（DeepSets）
- `U^node(D^(T))` 用 **2-IGN** 处理节点对张量

**最终特征**：
```
h^der_v = h^(T)_v ⊕ U^out(D^out)_v ⊕ U^node(D^(T))_v
```

### k-HOD-GNN（通用，混合偏导）

扩展到同时对 k 个节点求导：
```
D_k[h][v, u, i, α] = ∂^(α1+...+αk) h_v,i / ∂X_u1^α1 ... ∂X_uk^αk
```
编码器用 (k+1)-IGN 和 k-IGN，理论可达 folklore k-WL。

### 高效导数计算（算法 1）

核心观察：将 MPNN 更新拆为两步，分别处理导数传播：

1. **线性聚合步**：`D̃(t-1)[v] = (1+ε)D^(t-1)[v] + Σ_{u∈N(v)} D^(t-1)[u]`（与消息传递同结构，利用图稀疏性）
2. **DeepSet 更新步**：用 **Faà di Bruno 公式**（高阶链式法则）通过 MLP 传播导数

**稀疏性保持**：初始 `D^(0)` 只有对角非零，每层只向邻居扩展，浅层网络时导数张量高度稀疏。

**复杂度**：
- 空间：`O(n · min{n^k, d^(k·T)})`
- 时间：`O(d · n · min{n^k, d^(k·(T-1))})`
- 对比 k-OSAN：`O(n^(k+1))` 空间，`O(d · n^(k+1))` 时间
- 当 `d^T < n` 时（稀疏图 + 浅层 MPNN），HOD-GNN 显著更优

## 理论结果

| 定理 | 核心内容 |
|------|---------|
| **Thm 4.1** | k-HOD-GNN（解析激活）可任意精度近似 k-OSAN → 可区分 folklore k-WL 无法区分的图 → 可计算 k-apex forest 同态计数 |
| **Thm 4.2** | 即使只用一阶导数 + ReLU，1-HOD-GNN 也严格强于 RWSE+MPNN |
| **Prop 4.3** | 导数张量稀疏性上界 `O(n · min{n^k, d^(k·t)})`，逐层递推计算 |
| **Prop 4.4** | 编码器可设计为利用稀疏性，保留 k-OSAN 表达力但复杂度 `O(n · min{n^k, d^(k·T)})` |

**Thm 4.1 证明思路**（三步骤）：
1. 将 k-OSAN 的标记输入 `X + e^u` 视为泰勒展开中的扰动项；
2. 解析激活保证无限收敛半径，可用有限阶导数截断逼近任意精度；
3. 编码器（DeepSet/IGN）可先从导数张量重建标记输出，再聚合为节点特征。

**Thm 4.2 证明要点**：
- 构造性：初始化基础 MPNN 权重使一阶导数 = RWSE；
- 区分性：在顶点传递图 Qt15 vs Qt19 上，RWSE+MPNN 无法区分，HOD-GNN 通过二阶导数路径长度差异可区分。

### 消融

- **导数阶数**：0→1 阶 MAE 大幅下降（0.1555→0.0275），1→4 阶持续改善，4 阶后饱和；
- **骨干网络**：GCN→GIN→GPS 依次提升，HOD-GNN 在所有骨干上一致改善；
- **显存对比**：HOD-GNN 仅 12,964 MiB，子图方法 25,000+ MiB（molhiv 上）。

## 与组内 KSVD / RW 路线的关系

| | HOD-GNN | 我们（KSVD/RW） |
|--|---------|-----------------|
| 结构信息来源 | **MPNN 导数**（解析计算） | **采样 patch + 稀疏编码** |
| 表达力来源 | 高阶导数 = 泰勒展开 ≈ 标记操作 | 字典原子重构 |
| 计算模式 | 可微消息传递式导数传播 | 非可微稀疏编码 + 可微下游 |
| 是否数据驱动 | 导数由网络权重决定，端到端学习 | 字典从数据分解学习 |
| 感受野 | 受基础 MPNN 深度 T 控制 | 受 patch 大小控制 |
| 能否结合 | **可**：用 HOD 导数特征替代/补充 RWSE，作为 KSVD 的输入特征 | — |

**直接启示**：
1. HOD-GNN 提供了一种**可微的、无需子图枚举的结构编码方案**，可作为我们 RW 采样的替代或补充特征；
2. 其「导数 = 标记操作」的视角，对我们理解「结构信息在 GNN 中如何传播」有理论参考价值；
3. 实验表明**窄而深的基础 MPNN + 导数**效果很好（hidden=16, layers=20），这跟我们 KSVD 希望用小模型加结构信号的思路一致；
4. Peptides 的可扩展性结果对我们选择验证基准有参考价值。

## 边界（这篇不能证明什么）

- **不是首个可微结构编码方法**：RWSE、GPSE 等同样可微，HOD 的优势在于表达力更强（Thm 4.2）；
- **不是比 Subgraph GNNs 严格更优**：表达力等价（k-OSAN），优势在可扩展性，不是数字全面碾压；
- **ZINC 上 MAE 0.066 不是 SOTA**：MOSE (0.062) 和 Subgraphormer (0.063) 更好，HOD 在统计误差范围内；
- **理论需要解析激活**，但实际 SiLU 可用，ReLU 也能用——理论最优性和实际可用性之间需要区分；
- **导数计算仍依赖稀疏矩阵运算**，当前 PyG 实现效率有限，完全优化的速度潜力未发挥；
- **不涉及字典学习或可还原性**，与 KSVD 线的「重构→可解释结构」无直接关系；
- **未系统研究导数与 oversquashing/oversmoothing 的深层联系**（仅观察现象，留作未来工作）。

## 口述 3 点

1. HOD-GNN 用 **MPNN 的高阶导数** 替代子图枚举，理论上等价于 k-OSAN（可达 folklore k-WL），计算上更高效，Peptides 上完整子图方法跑不了它能跑。
2. 核心 tricks：拆 MPNN 为线性聚合 + DeepSet 更新 → 导数用消息传递式传播 + Faà di Bruno 公式 → 保持稀疏性，可端到端训练。
3. 对我们的意义：它提供了 **可微的、无需子图枚举的结构编码方案**，和 KSVD 正交（可结合），且「窄深模型 + 结构信号」的实验设定与我们的方向一致。
